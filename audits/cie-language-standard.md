# CIE Language Standard

This project uses original teaching and assessment content. Current Cambridge International
syllabus terminology is authoritative; endorsed coursebooks are used to calibrate register and
sentence structure, not as text to copy.

## Teaching explanations

- Use British English and the current name `Cambridge International`.
- Introduce a term, describe its mechanism or process, state its result, and identify a relevant
  limitation where one is needed.
- Use direct classroom instructions that state the required student output.
- Avoid jokes, anthropomorphism, promotional phrasing and conversational metaphors that obscure
  the technical point.
- Do not require students to repeat a lesson title, include a Chinese note in an examination
  answer, or use a particular linking word when the command word does not require it.

## Questions

- Use a recognised command word and make the required subject, context and response scope clear.
- Keep the demand consistent with the available marks and assessment objective.
- Use a scenario before or after the command word only when it provides information needed for
  the answer.
- Retain Cambridge pseudocode for Paper 2. Java remains supporting implementation practice only.

## Mark schemes

- Award one distinct item of evidence for each mark.
- Use positive marking points. Add `Allow` or `Do not accept` guidance only when it defines a real
  answer boundary.
- Use `M1` and `A1` only for a genuine method-result dependency; use `B1` for independent theory
  points.
- Identify the candidate's earlier result when follow-through is allowed.
- Accept precise equivalent wording unless a named syllabus term or notation is required.

## Chinese support

- Keep concise terminology support where it assists understanding.
- Ensure that each Chinese term corresponds to the English technical term in the same context.
- Do not add sentence-level translations or make Chinese wording part of an assessed response.
