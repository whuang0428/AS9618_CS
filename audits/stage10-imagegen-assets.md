## Final prompt pattern

Each prompt requested an academically styled Cambridge AS Computer Science website illustration on a minimal white and cool-gray textbook page, using precise architectural linework, restrained flat shapes, subtle paper grain and a slight axonometric projection. Prompts explicitly prohibited written text, labels, logos, watermarks, people, toy-like 3D rendering, cartoon proportions, glowing effects, cinematic drama and copyrighted characters.

The subject-specific requests and fact-check boundaries are recorded in the table above. Source PNGs were resized to 1400 pixels wide and converted to quality-82 JPEG for the website; each final file is below 400 KB.
