11101001₂

Is this 233, -23, or something else? It depends on the representation.

Teaching cue

Always ask: "Which representation is being used?" before interpreting a leading 1.

Why this matters

The same bit pattern can represent different values under unsigned and signed schemes.

Common trap

Do not read every leading 1 as “negative” unless the question states a signed representation.

Warm-up hook

What does `11101001₂` represent?

Pick an answer. The trick is that more than one can be true in a different representation.

Knowledge point 1

Three ways to represent negative binary values

Sign-and-magnitude

The leftmost bit is the sign: `0` positive, `1` negative. The remaining bits store the magnitude.

Example: `10010111₂` = -23

One’s complement

Start with the positive binary value and invert every bit to make the negative value.

`00010111₂` → `11101000₂` = -23

Two’s complement

Invert every bit, then add 1. This gives one zero and a range from -128 to +127.

`11101000₂ + 1 = 11101001₂` = -23

Teaching cue

Use sign-and-magnitude as a comparison, then spend more time on one’s and two’s complement because they are explicit syllabus terms.

Common trap

Sign-and-magnitude, one’s complement and two’s complement do not interpret the same 8 bits in the same way.

Knowledge point 2

Two’s complement method

Positive denary to negative two’s complement

  1. Write the positive magnitude in 8-bit binary.
  2. Invert every bit.
  3. Add 1.
  4. Label the result as two’s complement.

Two’s complement binary to denary

  1. If the leftmost bit is 0, convert as normal positive binary.
  2. If the leftmost bit is 1, subtract 256 from the unsigned value.
  3. Alternatively: invert, add 1, then add a negative sign.
  4. State the representation in the answer.
For 8-bit two’s complement, a quick decode is: unsigned value - 256 when the MSB is 1.

Knowledge point 3

8-bit signed ranges and zero

Sign-and-magnitude

-127 to +127

Has two zeros: `00000000₂` and `10000000₂`.

One’s complement

-127 to +127

Also has two zeros: `00000000₂` and `11111111₂`.

Two’s complement

-128 to +127

Has one zero and one extra negative value.

Mistake 1

-23 in two’s complement is `11101000₂`

`11101000₂` is one’s complement for -23. Two’s complement adds 1, so the answer is `11101001₂`.

Mistake 2

`10000000₂` in two’s complement is negative zero

Two’s complement has one zero. `10000000₂` represents -128.

  4. Extension: explain why two’s complement has a range of -128 to +127, not -127 to +127.

Homework support

Check only after attempting

Denary to two’s complement: `-18 = 11101110₂`; `-64 = 11000000₂`; `-1 = 11111111₂`.

Two’s complement to denary: `11110010₂ = -14`; `11000000₂ = -64`; `01111111₂ = 127`.

Explanation focus: one’s complement inverts bits and has two zeros; two’s complement adds 1 and has one zero plus the extra value -128.
