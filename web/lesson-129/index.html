Lesson 129 | 45 minutes | Paper 2 Section 11 | informal questioning

Repeat while a condition says so, not because you feel optimistic.

Condition-controlled loops are used when the number of repetitions is not known in advance. A WHILE loop checks before it runs; a REPEAT...UNTIL loop runs once before checking. The condition is the door guard: if it never changes, the program may keep walking into the same wall.

The loop condition is not a decoration. It is the exit plan.

Why this matters

Paper 2 often uses condition-controlled loops for validation, EOF-style reading and sentinel values.

Common trap

A loop that never updates the variable in its condition is not persistent; it is stuck.

WHILE loop

Pre-condition loop: check before running

Chinese support: condition 条件, pre-condition 前置条件, termination 终止, infinite loop 死循环。

General pattern

WHILE Condition
    // repeated statements
    // update something used by Condition
ENDWHILE

Password example

INPUT Password
WHILE Password <> CorrectPassword
    OUTPUT "Try again"
    INPUT Password
ENDWHILE
OUTPUT "Access granted"
A WHILE loop may run zero times if the condition is false before the first iteration.

Validation pattern

Keep asking until the input is valid

    INPUT Mark
UNTIL Mark >= 0 AND Mark <= 100

INPUT Mark
WHILE Mark < 0 OR Mark > 100
    OUTPUT "Invalid"
    INPUT Mark
ENDWHILE
