Section 1: Information representation - cumulative check

Command word: Calculate5 marks

1. A weather station stores a 2,048,000-byte log and displays temperature 26 using BCD. (a) Calculate the log size in MB, showing your working. [2] (b) Give the 8-bit BCD code for 26, showing each digit separately. [2] (c) Explain one reason to display its binary memory addresses in hexadecimal. [1]

Answer and marking guidance
  1. Divide 2,048,000 by 1,000,000 bytes per MB.
  2. The log size is 2.048 MB.
  3. The digit 2 has BCD code 0010.
  4. The digit 6 has BCD code 0110, giving 0010 0110.
  5. Hexadecimal groups each four address bits into one digit, making the address more compact to read.

Award one mark for each distinct point, within the mark allocation for each part. Accept equivalent correct working and explanations. Do not award the same point twice.

Command word: Calculate5 marks

2. The station needs the value of −6 − 3. (a) Calculate it using 8-bit two's-complement addition, showing both encoded operands and the retained result with its denary meaning. [3] (b) Explain whether signed overflow occurs. [1] (c) Explain why Unicode is more suitable than standard ASCII for notes in English and Chinese. [1]

Answer and marking guidance
  1. Rewrite as −6 + (−3), using operands 11111010 and 11111101.
  2. The full sum is 1 11110111, so the retained result is 11110111.
  3. The retained result represents −9.
  4. No signed overflow occurs because −9 lies within −128 to +127.
  5. Unicode includes the required Chinese characters as well as English letters; standard ASCII does not.

Award one mark for each distinct point, within the mark allocation for each part. Accept equivalent correct working and explanations. Do not award the same point twice.

Command word: Explain5 marks

4. The station records a mono sound. (a) Explain the effects on time accuracy and uncompressed sample-data size of doubling the sampling rate during recording, with duration and bits per sample unchanged. [2] (b) A one-bit bitmap row is 0000000011111111. RLE stores each run as an 8-bit count and a 1-bit colour. Give its count-and-colour pairs, calculate the encoded size and decide whether it is smaller than the original 16-bit row. [3]

Answer and marking guidance
  1. The converter measures amplitude twice as often, so it can represent changes over time more accurately.
  2. Twice as many samples require twice the uncompressed sample-data size.
  3. The pairs are (8, 0) and (8, 1).
  4. Two pairs require 2 × (8 + 1) = 18 bits.
  5. The encoded row is 2 bits larger; count overhead outweighs the saving.

Award one mark for each distinct point, within the mark allocation for each part. Accept equivalent correct working and explanations. Do not award the same point twice.

  1. The controller is a computer system built into the larger printer.

  4. The heated pressure rollers fuse transferred toner to the paper.

2. Explain why a handheld recorder uses RAM for changing sound samples, non-volatile firmware memory for start-up instructions, and a buffer between sampling and storage. State why PROM cannot be repeatedly updated and identify a ROM type that permits electrical rewriting.

Answer and marking guidance
  1. RAM can be read and written repeatedly as the current samples are processed.
  2. Non-volatile firmware memory keeps the start-up instructions available after the power is removed.
  3. The buffer holds samples temporarily when sampling and storage transfer data at different rates.
  4. PROM is programmed only once, so it cannot support repeated updates.
  5. EEPROM permits electrical erasure and rewriting.

Answer and marking guidance
  1. The pressure sensor supplies a reading of the tyre pressure to the controller.
  2. The controller compares that reading with the stored target and decides whether further pumping is needed.
  3. The motor is the actuator whose operation raises the physical pressure.
  4. A new sensor reading provides feedback so the controller can stop or adjust pumping based on the actual result.
  5. A display only reports the measurement; by itself it does not change tyre pressure.

1. Explain how an instruction at address 160 is fetched when PC=160. Include MAR, MDR, CIR, the read control signal and the next sequential PC. Each instruction occupies one location.

Answer and marking guidance
  1. MAR ← [PC] places 160 in MAR for the address bus.
  2. The CU issues a memory-read signal on the control bus.
  3. The fetched instruction reaches MDR over the data bus.
  4. CIR ← [MDR] retains that instruction for decoding.
  5. PC ← [PC] + 1 gives the next sequential address 161.

Answer and marking guidance

The developer can notify users and disable sharing until it is fixed, or hide the fault to avoid bad publicity. Explain one consequence for users and one for the company under each action, then justify a response.

  1. Notification and disabling sharing allow users to stop further exposure of photos while the fault is repaired.

Command word: Justify5 marks

3. A charity must modify a scheduling program and share it with branches. Offer A uses an OSI-approved open-source licence permitting both acts if notices are retained. Offer B is a 15-day shareware trial with no modification rights. Justify one choice, state an obligation, explain a limitation of B, and explain why copyright remains relevant even with permission to share.

Answer and marking guidance
  1. A permits the charity to adapt the source to its scheduling needs.
  2. A also allows branches to receive copies of the adaptation under the licence, meeting the distribution requirement.

Command word: Evaluate5 marks

4. A bus service tests AI to recognise spoken destinations. It could make booking easier and reduce call-handling work, but speech from some passengers is often misrecognised and the service requires additional computing hardware. Answer and marking guidance
  1. SRAM provides fast access for the small cache, reducing processor waiting time.
  2. DRAM has lower cost per bit and higher density, making large main memory practical.
  3. SRAM stores a bit in a powered bistable latch, whereas DRAM stores capacitor charge.

  7. Its electrical erase and rewrite capability permits later firmware updates.
  8. After 4 ms, four blocks have been removed, leaving two blocks in the buffer.
