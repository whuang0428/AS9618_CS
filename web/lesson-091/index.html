Hardware questions reward precise parts. "The CPU does stuff" is not a lifestyle.

This review connects hardware selection, storage, embedded systems, logic gates, CPU architecture, registers, the fetch-decode-execute cycle, interrupts and processor performance. The goal is to explain mechanisms, not merely list component names.

Selecthardware and storage by matching characteristics to user needs

Explainlogic circuits, interrupts and performance factors precisely
FetchPC, MAR, memory, MDR, CIR DecodeCU interprets opcode and addressing ExecuteALU/registers perform operation

Registers are tiny, fast and examiners love them more than vague paragraphs.

Teaching cue

For each answer, name the component, state its role, then link it to the scenario or processor step.

Why this matters

Hardware review questions often look descriptive, but marks sit in cause, consequence and exact register names.

Common trap

Cache is not the same as RAM. Cache is smaller, faster memory close to/on the CPU for frequently used data and instructions.

Warm-up hook

Which topic is being tested?

If an answer starts with "it makes it faster", pause. Faster how? Because of which part? Under what workload?

Logic gate review

Truth table shortcuts

Gate

Exam trap
AND

OR is not "also"; it has its own rule.
OR
at least one input is 1
Includes both inputs being 1.
XOR
inputs are different
Not the same as OR when both inputs are 1.
NAND / NOR
