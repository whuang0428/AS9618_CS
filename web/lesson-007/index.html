Character sets: ASCII, extended ASCII and Unicode

Overview Warm-up Character set ASCII Unicode Encoding Syllabus audit Inspector Examples Practice Exam-style Homework

Lesson 007 | 45 minutes | Informal questioning

Text is numbers wearing a very convincing disguise.

Computers store characters as binary values. A character set defines which characters are available and which numeric code is assigned to each character. This lesson compares ASCII, extended ASCII and Unicode without asking anyone to memorise a table like a very small, very boring phone book.

A = 65

`A` is displayed as a letter, but stored using a binary code such as `01000001`.

Teaching cue

Keep the chain visible: character → code point / code value → binary storage → displayed symbol.

Why this matters

Wrong encoding can turn meaningful text into broken symbols, especially across languages and systems.

Common trap

Do not say Unicode is “just bigger ASCII”. It is a much larger character set designed for global text.

Warm-up hook

Can standard ASCII store `你`?

Pick an answer. The issue is not artistic talent; it is whether the character set contains the character.

Knowledge point 1

What a character set actually does

Character A visible symbol such as `A`, `?`, `é`, `你` or `€`.
Character set A defined collection of characters and the code assigned to each character.
Character code The numeric value used to represent a character inside the computer.
Binary storage The numeric code is stored using bits, for example `65₁₀ = 01000001₂`.
Chinese support: character set = 字符集；character code = 字符编码值；encoding = 编码方式。

Knowledge point 2

ASCII and extended ASCII

Standard ASCII

Uses 7 bits, so it can represent `2⁷ = 128` possible codes.

It covers common English letters, digits, punctuation and control characters.

Extended ASCII

Uses 8 bits, so it can represent `2⁸ = 256` possible codes.

It adds extra characters, but still cannot cover the world’s writing systems.

Character Denary code 8-bit binary Exam note
A 65 01000001 Example only; no need to memorise.
B 66 01000010 Codes are numeric values.
a 97 01100001 Uppercase and lowercase have different codes.

Teaching cue

Ask students why `A` and `a` cannot share a code. The display may look related, but the stored values must distinguish them.

Common trap

Font changes appearance. A character set defines which character a code represents. These are not the same thing.

Knowledge point 3

Unicode: more characters, more global use

Purpose

Unicode is designed to represent characters from many languages and symbol systems.

Scale

Unicode supports far more characters than ASCII, including Chinese characters and many symbols.

Trade-off

More possible characters may require more bits per character, depending on the encoding used.

Emoji are not magic stickers. They are characters with assigned Unicode code points, then rendered by software and fonts.

Knowledge point 4

Character set vs encoding

Character set

Defines the characters and their code points or code values.

Example idea: `A` has a defined code in ASCII and Unicode.

Encoding

Defines how those codes are stored as bytes.

For AS exam answers, keep this distinction simple unless the question gives a specific encoding.

A good exam sentence: “Unicode can represent a wider range of characters, so it is more suitable for multilingual text.”

Correct the almost-right answer

“ASCII can store all languages because every character is just binary.”

All stored data is binary, but the character set must contain the character. Standard ASCII only has 128 codes.

“A font is the same thing as a character set.”

A font controls appearance. A character set maps characters to codes.

Homework

Clear tasks

  1. Define character set, character code and encoding in one sentence each.
  2. Explain why standard ASCII cannot represent all written languages.
  3. Calculate the number of possible codes for 7-bit and 8-bit character sets.
  4. Write a 4-mark comparison of ASCII and Unicode for a multilingual website.

Definitions: character set maps characters to numeric codes; character code is the assigned numeric value; encoding stores codes as bytes.

ASCII limitation: standard ASCII has only 128 possible codes, so it cannot include characters from all languages.

Capacity: `2⁷ = 128`; `2⁸ = 256`.

Comparison focus: ASCII is suitable for basic English text; Unicode is more suitable for multilingual text because it supports many more characters.
