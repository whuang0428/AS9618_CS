Algorithms remember things. Sadly, only if you initialise the memory first.

Many AS Paper 2 algorithms process a list of values and keep a running result: a total, a count, a maximum or a minimum. The idea is simple, but exam marks are strict: initialise the variable, update it inside the correct loop, and show a trace that proves every value was processed.

One loop can collect several facts, but each variable needs a clear starting value and update rule.

Why this matters

Cambridge-style mark schemes often credit initialisation, loop control, condition tests and update statements separately.

Common trap

Using `Maximum <- 0` fails if all data values can be negative. Use the first input value when the range is not guaranteed.

Initialisation

The starting value decides whether the algorithm is honest

Total and count

Total <- 0
Count <- 0

FOR Index <- 1 TO 4
    INPUT Score
    Total <- Total + Score
    Count <- Count + 1
NEXT Index

Zero is safe because nothing has been added or counted yet.

Maximum and minimum

INPUT Value
Maximum <- Value
Minimum <- Value

FOR Index <- 2 TO 4
    INPUT Value
    IF Value > Maximum THEN
        Maximum <- Value
    ENDIF
    IF Value < Minimum THEN
        Minimum <- Value
    ENDIF
NEXT Index

The first real value is safer than guessing a starting maximum or minimum.

Fixed-count input

When the number of values is known, use a count-controlled loop

Example: total and average of 4 scores

Total <- 0
FOR Index <- 1 TO 4
    INPUT Score
    Total <- Total + Score
NEXT Index
Average <- Total / 4
OUTPUT Average

Trace focus

For scores 72, 55, 91, 64, the total becomes 72, 127, 218, 282. The average is 70.5.

Do not output the average inside the loop unless the question asks for a running average.

Sentinel input

When input stops on a special value, do not process the sentinel

Example: enter numbers until -1

Total <- 0
Count <- 0
INPUT Number
WHILE Number <> -1
    Total <- Total + Number
    Count <- Count + 1
    INPUT Number
ENDWHILE
OUTPUT Total
OUTPUT Count

Exam wording

The sentinel is a control signal, not data. If the inputs are 4, 6, 2, -1, the total is 12 and the count is 3.

Chinese support: sentinel value = 哨兵值 / 结束标记。

Pseudocode vs Java

Use Cambridge assignment and loop keywords in exam answers

Cambridge-style pseudocode

Total <- 0
PassCount <- 0
FOR Index <- 1 TO 5
    INPUT Mark
    Total <- Total + Mark
    IF Mark >= 50 THEN
        PassCount <- PassCount + 1
    ENDIF
NEXT Index
OUTPUT Total
OUTPUT PassCount

Java support only

int total = 0;
int passCount = 0;
for (int index = 0; index < 5; index++) {
    int mark = input.nextInt();
    total = total + mark;
    if (mark >= 50) {
        passCount = passCount + 1;
    }
}
Exam reminder: Java helps implementation practice, but Paper 2 expects clear Cambridge-style pseudocode unless Java is explicitly requested.
