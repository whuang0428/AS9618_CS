Knowledge points 2-3

Two conversion directions, two reliable methods

Binary to denary

  1. Write the place-value row: 128, 64, 32, 16, 8, 4, 2, 1.
  2. Place the binary digits under the row.
  3. Add only the values with a `1` above them.
  4. Label the answer as denary.

Denary to binary

  1. Start at 128 and move right.
  2. Write `1` if the place value fits into the remaining number.
  3. Subtract that place value when a `1` is used.
  4. Write `0` when it does not fit.

Common trap

Students often add a zero column or skip a column. Eight-bit answers need exactly eight bits.

Knowledge point 4

Range and leading zeros

Smallest 8-bit value

00000000₂ = 0₁₀

All place values are off.

Largest 8-bit value

11111111₂ = 255₁₀

All place values are on: 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1.

Leading zeros

00000111₂ = 111₂ = 7₁₀

Leading zeros preserve fixed bit width; they do not change the value.

Mistake 1

10110110₂ = 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1

Only columns with a `1` are counted: 128 + 32 + 16 + 4 + 2 = 182.

Mistake 2

7₁₀ = 1111111₂

As an 8-bit value, 7 is `00000111₂`. Leading zeros keep the bit width.

Homework

Clear tasks, not vague revision

  1. Convert these binary values to denary, showing columns: `01010101₂`, `11100010₂`, `00011111₂`.
  2. Convert these denary values to 8-bit binary: `19`, `104`, `250`.
  3. Write a 3-mark explanation of why `00001010₂` and `1010₂` have the same value but not the same bit width.
  4. Extension: create one wrong solution and annotate exactly where the mistake happens.

Homework support

Check only after attempting

Binary to denary: `01010101₂ = 85`; `11100010₂ = 226`; `00011111₂ = 31`.

Denary to 8-bit binary: `19 = 00010011₂`; `104 = 01101000₂`; `250 = 11111010₂`.
