Algorithms are built from three moves: do this, choose that, repeat carefully.

Sequence runs steps in order. Selection chooses a path using a condition. Iteration repeats steps while a count or condition says to continue. Most AS algorithms are these three structures combined with clear variables and Cambridge-style pseudocode.

Why this matters

Exam pseudocode marks often depend on selecting the right structure before worrying about syntax.

Common trap

Do not use a loop because the problem sounds busy. Use a loop only when steps must repeat.

Knowledge explanation

Sequence: steps run in a fixed order

Idea

Sequence is used when every step must happen once, in order, with no branch and no repetition.

Chinese support: sequence = 顺序结构。

Example

INPUT Length
INPUT Width
Area <- Length * Width
OUTPUT Area

Knowledge explanation

Selection: choose a path using a condition

Idea

Selection is used when the algorithm must decide between different actions.

Chinese support: selection = 选择结构；condition = 条件。

Example

INPUT Mark
IF Mark >= 50 THEN
    OUTPUT "Pass"
ELSE
    OUTPUT "Resit"
ENDIF

Knowledge explanation

Iteration: repeat steps

Type
Use when
Cambridge-style pattern
Count-controlled
the number of repeats is known
FOR Count <- 1 TO 10 ... NEXT Count
Condition-controlled
repeat until a condition changes
WHILE Number <> -1 ... ENDWHILE
Repeat-until style
the body must run at least once
REPEAT ... UNTIL Valid = TRUE
Iteration = 迭代/循环。Known count? Use count-controlled. Unknown stopping point? Use condition-controlled.

Combining structures

Real algorithms usually combine the three structures

1Use sequence to initialise variables and read inputs.
2Use iteration when the same action happens repeatedly.
3Use selection inside the loop when each item needs a decision.
4Use sequence after the loop to calculate or output final results.
5Indent nested structures so the examiner can see the logic.

Pseudocode vs Java

Cambridge pseudocode is the exam form; Java is support only

Cambridge-style pseudocode

PassCount <- 0
FOR Count <- 1 TO 5
    INPUT Mark
    IF Mark >= 50 THEN
        PassCount <- PassCount + 1
    ENDIF
NEXT Count
OUTPUT PassCount

Java support only

int passCount = 0;
for (int count = 1; count <= 5; count++) {
    int mark = input.nextInt();
    if (mark >= 50) {
        passCount++;
    }
}
System.out.println(passCount);
Exam reminder: do not answer Paper 2 pseudocode questions with Java braces, semicolons or `System.out.println`.

Summary

Control-structure checklist

SequenceUse when steps happen once in a fixed order.
SelectionUse when a condition chooses between actions.
IterationUse when steps repeat, either a known number of times or until a condition changes.
