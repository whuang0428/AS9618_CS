Nested loops are loops with roommates. Everyone needs their own job.

A nested loop places one loop inside another. This is useful when a problem has rows and columns, repeated groups, tables of inputs or every-pair comparisons. The outer loop usually chooses the row or group; the inner loop processes each item inside that row or group.

Why this matters

Cambridge-style questions often mark the loop headers, correct indentation, reset position and total number of iterations.

Common trap

Resetting a row total outside the outer loop gives one grand running total, not a separate total for each row.

Knowledge explanation

Outer loop first, inner loop second

Core structure

FOR Row <- 1 TO 3
    FOR Column <- 1 TO 4
        OUTPUT Row, Column
    NEXT Column
NEXT Row

The inner loop completes all columns for one row before the outer loop moves to the next row.

Reset rules

Put row-level variables inside the outer loop

Correct: row total resets for each row

GrandTotal <- 0
FOR Row <- 1 TO 3
    RowTotal <- 0
    FOR Column <- 1 TO 4
        INPUT Mark
        RowTotal <- RowTotal + Mark
    NEXT Column
    OUTPUT RowTotal
    GrandTotal <- GrandTotal + RowTotal
NEXT Row
OUTPUT GrandTotal

Why placement matters

`RowTotal <- 0` must happen once for each row. If it is before the outer loop, RowTotal keeps carrying earlier rows.

A row variable resets at the start of each outer-loop pass. A grand total resets before all rows begin.

Counting steps

Total visits = outer repetitions x inner repetitions

Example

FOR Row <- 1 TO 2
    FOR Column <- 1 TO 3
        OUTPUT "*"
    NEXT Column
NEXT Row

Count it

The `OUTPUT "*"` statement runs 2 x 3 = 6 times. The inner loop runs fully for Row 1, then fully again for Row 2.

Do not add 2 + 3. Nested loop visits multiply when every inner loop runs for every outer loop value.

Pseudocode vs Java

Indentation is evidence in nested loops

Cambridge-style pseudocode

FOR Row <- 1 TO 3
    FOR Column <- 1 TO 4
        Product <- Row * Column
        OUTPUT Product
    NEXT Column
NEXT Row

Java support only

for (int row = 1; row <= 3; row++) {
    for (int column = 1; column <= 4; column++) {
        int product = row * column;
        System.out.println(product);
    }
}
Exam reminder: Java braces and semicolons are not Cambridge pseudocode. Use clear `FOR`, `NEXT`, indentation and assignment arrows in Paper 2 answers.
