This lesson turns bitmap knowledge into reliable calculation habits: calculate pixel data, convert bits to bytes, decide whether metadata is included, and label every final answer clearly.

100 × 80 × 8

Pixel data first. Metadata only joins the party if the question invites it.

Why this matters

Most wrong answers in this topic come from a correct formula followed by a careless unit or metadata decision.

Common trap

If the question says “ignore metadata”, do not add headers, dimensions or file information to the answer.

Warm-up hook

A file is 64 000 bits. Is that 64 000 bytes?

Pick an answer. Bits are not bytes wearing a fake moustache.

Knowledge point 1

The calculation chain

1. Pixels width × height
2. Bits pixels × colour depth
3. Bytes bits ÷ 8
4. Metadata add only if the question includes it
`100 × 80 × 8 = 64 000 bits = 8000 bytes`

Knowledge point 2

Metadata is data about the image, not the pixels themselves

Examples

Width, height, colour depth, file type, date created, camera model, location data or thumbnail data.

Purpose

Metadata helps software interpret, organise, search or display the image correctly.

Calculation rule

Add metadata size only when the question gives it and asks for total file size.

Exam wording matters: “ignore metadata” means pixel data only.

Knowledge point 3

Units: do not trip at the finish line

Bits to bytes

`8 bits = 1 byte`, so divide bits by 8.

Bytes to KiB

`1 KiB = 1024 bytes`, so divide bytes by 1024 when binary units are requested.

Rounding

Only round if the question requests it. Otherwise keep an exact value or enough working.

Extra practice

Vector graphics and drawing lists

A vector graphic is stored as a drawing list of objects. Each object has properties such as type, coordinates, dimensions, line colour, fill colour and line thickness; software redraws the objects from these instructions.

Vectors scale without pixelation and suit logos, diagrams and shapes. Bitmaps store individual pixels and suit photographs or detailed textures. Choice must be justified using the source image and intended editing/scaling.

Worked example: Store a red circle

A drawing-list entry could record object = circle, centre = (80, 60), radius = 20, fill = red and outline = black. Enlarging it changes the geometry before redrawing, not a grid of stored pixels.

Targeted practice

1. Name two properties stored for a vector object.

Show answer

Any two of coordinates, dimensions, fill, line colour or line thickness.

2. Choose vector or bitmap for a company logo that must appear on a pen and a billboard.

Show answer

Vector, because geometric objects can be scaled without pixelation.

3. Why is bitmap normally better for a photograph?

Show answer

A photograph contains complex per-pixel colour and texture that is inefficient to describe as drawing objects.

4KiB uses 1024 bytes, not 1000 bytes.

Homework

Clear tasks

  1. Calculate the pixel data size of a `128 × 128` image using 8-bit colour depth, in bytes.
  2. Add 1024 bytes of metadata to the answer from task 1 and give the total in KiB.
  3. List four examples of image metadata and explain one purpose of metadata.
  4. Write a 4-mark explanation of why the phrase “ignore metadata” changes the calculation.

Task 1: `128 × 128 × 8 = 131 072 bits = 16 384 bytes`.

Task 2: `16 384 + 1024 = 17 408 bytes = 17 KiB`.

Metadata examples: width, height, colour depth, file type, date created, camera model, GPS location.

Explanation focus: ignoring metadata means calculating only the image pixel data, not additional data about the file.
