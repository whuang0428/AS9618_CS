Scenario triage

Turn question wording into an algorithm plan

Step 1: Output first

Ask: what must be displayed, returned or stored at the end? The final output tells you which variables need to exist.

Output needed: average rainfall

Therefore:
Total is needed
Count is needed
Average <- Total / Count

Step 2: Stop condition

Ask: does the question state a fixed number of values, or does input continue until a condition is met?

Exactly 7 days      -> FOR Day <- 1 TO 7
Until -1 entered   -> WHILE Value <> -1

Step 3: Update placement

Updates go inside the loop; final outputs normally go after the loop. The exam enjoys catching students who swap those two.

Total <- Total + Reading
Count <- Count + 1

// after the loop
Average <- Total / Count
OUTPUT Average

Pseudocode vs Java

Paper 2 wants readable Cambridge-style pseudocode

Cambridge-style answer

Total <- 0
Count <- 0
INPUT Value
WHILE Value <> -1
    Total <- Total + Value
    Count <- Count + 1
    INPUT Value
ENDWHILE
Average <- Total / Count
OUTPUT Average

Java support only

int total = 0;
int count = 0;
int value = input.nextInt();
while (value != -1) {
    total += value;
    count++;
    value = input.nextInt();
}
double average = (double) total / count;
