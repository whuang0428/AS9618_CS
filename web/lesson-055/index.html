Lesson 055 | 45 minutes | Paper 1 Section 5 | System software

Utility software is the toolkit that keeps a system usable, recoverable and safer.

Utility programs perform maintenance, protection and management tasks. They are system software, but they are not the operating system itself. The exam expects the exact purpose of each utility, plus a scenario where it is appropriate.

Describebackup, compression, encryption, defragmentation and antivirus utilities
Applythe correct utility to a user or organisation scenario
Explainbenefits, limitations and common exam traps precisely
Backup: recover data Compression: reduce file size Encryption: protect confidentiality Defrag: rearrange fragmented files Antivirus: detect and remove malware

A utility is not a magic "make computer better" button. Name the job.

Why this matters

Cambridge questions often give a scenario. Marks come from matching the utility to the exact problem.

Common trap

Do not write "secure" or "efficient" alone. Explain what is protected, reduced, recovered or detected.

Knowledge point 1

Utility software performs maintenance and support tasks

System softwareSoftware that supports the operation and management of the computer system.
Utility softwareSystem software designed for a specific maintenance, protection or management task.
Not application softwareIt supports the system rather than directly producing user documents, games or media.
Scenario linkThe correct utility depends on whether the problem is loss, size, confidentiality, fragmentation or malware.

Knowledge point 2

Backup utilities create copies so data can be restored

PurposeCreate copies of files or systems in another location or storage medium.
BenefitData can be restored after accidental deletion, hardware failure, corruption or ransomware.
Good practiceUse automatic scheduling, versioning and off-site/cloud copies where appropriate.
LimitationA backup is only useful if it is recent, complete and can actually be restored.

Knowledge point 3

Compression utilities reduce file size

PurposeEncode data so it takes up fewer bits than the original file.
UsesSave storage space, reduce upload/download time and fit within attachment limits.
LosslessOriginal data can be reconstructed exactly, suitable for text, programs and archives.
LossySome detail is discarded, often suitable for media where small quality loss is acceptable.

Knowledge point 4

Encryption utilities protect confidentiality

PurposeScramble plaintext into ciphertext using an algorithm and a key.
BenefitUnauthorised users cannot read the data without the correct key.
ExamplesEncrypting a laptop drive, a backup archive or files sent over a network.
LimitationEncryption does not stop deletion or malware; losing the key can make data unrecoverable.

Knowledge point 5

Defragmentation rearranges fragmented files on magnetic disks

FragmentationParts of a file are stored in non-contiguous blocks across a disk.
PurposeRearrange file blocks so related parts are stored closer together.
BenefitCan reduce mechanical disk head movement and improve hard disk access time.
BoundaryDo not apply the same benefit to SSDs; they have no moving disk head.

Knowledge point 6

Antivirus utilities detect, quarantine and remove malware

PurposeScan files, memory or downloads for malware signatures or suspicious behaviour.
ActionsWarn the user, quarantine infected files, delete malware or block malicious activity.
UpdatesDefinitions and detection rules should be updated to recognise newer threats.
LimitationAntivirus reduces risk but cannot guarantee protection against every new or disguised threat.
