Lesson 006 | 45 minutes | Informal questioning

The binary point is not decoration. It moves the weights.

This lesson extends place value to fractional positions such as `1/2`, `1/4` and `1/8`, then uses simple examples to explain why some denary fractions cannot be represented exactly in a fixed number of binary places.

Identify binary fractional place values after the binary point
Convert simple fixed-point binary fractions and denary fractions
Explain precision limits, truncation, rounding and representation error
10.101₂

`10.101₂` is not ten point one hundred and one. Binary is less dramatic, but more strict.

Why this matters

Computer systems store numbers using limited bits, so some fractions are approximations rather than exact values.

Common trap

Do not treat `0.1₂` as one tenth. It is one half because the first place after the point is `2⁻¹`.

Warm-up hook

Which value is `0.1₂`?

Pick an answer. The first binary fractional place is worth `1/2`, not `1/10`.

Knowledge point 1

Binary fractional place value

Place 2² 2¹ 2⁰ . 2⁻¹ 2⁻² 2⁻³ 2⁻⁴
Value 4 2 1 . 1/2 1/4 1/8 1/16
Example `10.101₂` 0 1 0 . 1 0 1 0
`10.101₂ = 2 + 1/2 + 1/8 = 2.625₁₀`

Common trap

Bits to the right of the point get smaller from left to right: `1/2`, `1/4`, `1/8`, `1/16`.

Knowledge point 2

Converting simple binary fractions

Binary fraction to denary

  1. Write the place values above and below the point.
  2. Add the values for every `1` bit.
  3. Keep the base label until the final answer.
  4. State whether the answer is exact.

Denary fraction to binary

  1. Use `1/2`, `1/4`, `1/8`, `1/16` as target values.
  2. Subtract a target value when it fits.
  3. Write `1` for a used value and `0` for a skipped value.
  4. Stop when the remainder is zero or the bit limit is reached.
Example: `0.625₁₀ = 0.101₂` because `0.5 + 0.125 = 0.625`.

Knowledge point 3

Precision limits: why computers sometimes approximate

Exact

`0.75₁₀ = 0.11₂` exactly because `1/2 + 1/4 = 3/4`.

Limited precision

With four fractional bits, `0.1₁₀` becomes approximately `0.0001₂`, which is `0.0625₁₀`.

Error

Representation error is the difference between the intended value and the stored approximation.

This lesson uses fixed fractional places only. Mantissa, exponent and floating-point normalisation belong to later A Level content.

Extra practice

Binary-coded decimal (BCD)

BCD encodes each denary digit separately in four bits. For example, 59 becomes 0101 1001, not the pure-binary value 00111011.

Only 0000 to 1001 are valid BCD digit groups. BCD is useful when decimal digits must be displayed exactly, such as clocks and calculators, but it usually uses more bits than pure binary.

Worked example: Encode 407

Treat 4, 0 and 7 separately: 4 = 0100, 0 = 0000, 7 = 0111, so 407 in BCD is 0100 0000 0111.

Targeted practice

3. Why is 1010 invalid as one BCD digit?

Show answer

Summary

Keep the point under control

1Binary fractional places are `1/2`, `1/4`, `1/8`, `1/16`...
2Convert by adding active place values or subtracting target fractions.
3Limited bits can force truncation or rounding, creating representation error.
4Do not mix fixed binary fractions with later floating-point normalisation.

Homework

Clear tasks, not “revise everything”

  1. Convert `0.11₂`, `10.01₂` and `11.101₂` to denary.
  2. Convert `0.25₁₀`, `0.875₁₀` and `2.625₁₀` to binary.
  3. Using four fractional bits, approximate `0.3₁₀` by repeated subtraction and state the error.
  4. Write a 4-mark explanation of why limited binary places can cause precision loss.

Binary to denary: `0.11₂ = 0.75₁₀`; `10.01₂ = 2.25₁₀`; `11.101₂ = 3.625₁₀`.

Denary to binary: `0.25₁₀ = 0.01₂`; `0.875₁₀ = 0.111₂`; `2.625₁₀ = 10.101₂`.

0.3 with four fractional bits: `0.0100₂ = 0.25₁₀`, error `0.05`; if rounding to nearest four bits, `0.0101₂ = 0.3125₁₀`, error `0.0125`.

Explanation focus: a fixed number of bits may stop before the exact fraction is reached, so the stored value is an approximation.
