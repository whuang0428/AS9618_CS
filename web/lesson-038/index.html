Good hardware is not the fanciest box. It is the box that fits the job.

This lesson focuses on selecting suitable hardware for different users and scenarios. You will classify hardware, compare alternatives, and justify choices using features, user needs and consequences.

Classifyhardware as input, output, storage, processing or communication
Comparealternatives using speed, capacity, cost and reliability
Justifyhardware choices for specific user needs
feature -> need -> consequence

"It is better" earns very little. "It is portable, so the delivery driver can scan parcels at the door" earns marks.

Why this matters

Cambridge-style hardware questions reward suitability. A named device without scenario-specific justification is usually only half an answer.

Common trap

Do not recommend the most powerful hardware by default. A librarian does not need a gaming GPU to scan barcodes, even if the GPU looks lonely.

Warm-up hook

Phone, keyboard, USB drive: which captures data, which stores data, and which just makes humans feel in control?

Knowledge point 2

Choose using criteria, not vibes

SpeedNeeded for real-time input, rapid searches, video editing or low-delay output.
CapacityNeeded for large files, media archives, backups or databases.
CostMatters when many devices must be purchased or the user has a fixed budget.
DurabilityImportant for mobile, outdoor or high-use environments.
AccuracyImportant for barcode scanning, sensors, medical data and attendance records.
CompatibilityHardware must connect to existing software, ports, networks and operating systems.
Exam sentence frame: "I would choose X because it has Y, which matters for Z, so the user can..."

Knowledge point 3

Different users value different trade-offs

LibrarianNeeds fast, accurate item input and reliable local/network database access.
Delivery driverNeeds portable, durable, wireless hardware and quick barcode/QR capture.
Video editorNeeds high-speed storage, strong CPU/GPU performance and colour-accurate display.
Weather stationNeeds accurate sensors, durable enclosure, low power use and stable communication.
A strong answer rejects one tempting unsuitable option. This proves the choice was evaluated, not guessed.

Mistake debugging

Fix the weak hardware recommendation

"Use an SSD because it is better."

Use an SSD because it has faster access times than an HDD, which helps a video editor load large project files and preview footage with less delay.

"A delivery driver should use a desktop computer because it is powerful."

A handheld scanner or smartphone is more suitable because it is portable, can connect wirelessly and can scan parcels at the delivery location.

Homework

Clear tasks

  1. Design a hardware setup for a library checkout desk. Include two input devices, one output device and one storage/processing choice.
  2. Write a 6-mark answer recommending hardware for a delivery driver who scans parcels and collects signatures.
  3. Compare SSD and HDD for a video editor using speed, capacity, cost and reliability.
  4. Rewrite this weak sentence: "Use a touchscreen because it is easier."

Library: barcode scanner, keyboard/touchscreen, receipt printer/display, networked computer with reliable storage.

Delivery: handheld scanner or smartphone, GPS, mobile data, durable case and battery life.

SSD vs HDD: SSD is faster and more shock-resistant; HDD may be cheaper per GB for bulk archive storage.

Rewrite: specify the feature, such as direct selection reducing training time for non-specialist users.
