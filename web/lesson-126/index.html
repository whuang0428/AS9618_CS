Core syllabus content

Translate descriptions into Cambridge pseudocode

To translate a flowchart, follow arrows from Start, convert input/output symbols directly, convert diamonds into IF/CASE or loop conditions, and preserve every branch and reconnection. To translate structured English, identify its controlled verbs and indentation before selecting Cambridge constructs.

The answer must be Cambridge pseudocode, not Java: use assignment arrow, THEN/ENDIF, FOR...NEXT, WHILE...ENDWHILE or REPEAT...UNTIL as appropriate. Trace both versions with the same data to confirm equivalence.

Worked example: Flowchart sum loop

A flowchart sets Total to 0 and repeats input/add until Value = -1. Pseudocode uses Total <- 0; REPEAT; INPUT Value; IF Value <> -1 THEN Total <- Total + Value; ENDIF; UNTIL Value = -1; OUTPUT Total.

Translate a flowchart or structured English into pseudocode

  1. Lesson fact: Follow a flowchart from Start: translate input/output symbols, decisions, branches and loop-back arrows without losing a path.
  2. Lesson fact: From structured English, preserve the controlled verbs, conditions and indentation when selecting Cambridge pseudocode constructs.
  3. Lesson fact: Dry-run the source description and pseudocode with the same data; matching paths and outputs confirm equivalence.

Programs do three basic things: go next, choose, and repeat.

Sequence runs statements in order. Selection chooses between paths. Iteration repeats a block while a condition or count controls it. That sounds small, until one missing ENDIF turns a calm algorithm into a drama production with variables.

Three control-flow ideas

  1. Lesson fact: Sequence answers what happens next and depends on statement order.
  2. Lesson fact: Selection answers which path is taken and uses IF or CASE structures.
  3. Lesson fact: Iteration answers what repeats and when repetition stops.
  4. Lesson fact: FOR, WHILE and REPEAT are iteration forms with different controls.

Selection

Conditions decide the path

IF selection

INPUT Mark
IF Mark >= 50 THEN
    OUTPUT "Pass"
ELSE
    OUTPUT "Resit needed"
ENDIF

CASE selection

CASE Grade OF
    "A" : OUTPUT "Excellent"
    "B" : OUTPUT "Good"
    OTHERWISE OUTPUT "Check grade"
ENDCASE
Boundary tests matter: Mark = 49, 50 and 51 reveal whether the condition is correct.

Conditions decide the path

  1. Lesson fact: Use IF for a Boolean condition or range and close it with ENDIF.
  2. Lesson fact: Use CASE for several discrete values of one expression and close it with ENDCASE.
  3. Lesson fact: Test marks 49, 50 and 51 to verify the pass boundary.

Loops repeat with control

  1. Lesson fact: A FOR loop uses a counter range and checks whether the next iteration is within its bounds.
  2. Lesson fact: A FOR loop may execute zero times when its bounds are incompatible.
  3. Lesson fact: A WHILE loop checks its condition before each iteration and may execute zero times.
  4. Lesson fact: A REPEAT loop checks after the body and therefore runs at least once.

Same logic, different exam language

  1. Lesson fact: Cambridge pseudocode uses IF, THEN, ELSE and ENDIF for a two-way selection.
  2. Lesson fact: Mark 50 follows the pass branch when the condition uses greater than or equal to 50.
  3. Lesson fact: Java braces may support understanding but are not Cambridge pseudocode.
