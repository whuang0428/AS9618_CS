Common trap

Do not only copy the model answer. Write why your original answer did not earn the mark, then write the corrected rule.

Correction workflow

The four-line correction format

1. Original

Copy the sentence or pseudocode line that failed.

2. Mark lost

Name the exact mark: missing M1, B1 or A1.

3. Rule

Write the general rule that would prevent the error next time.

4. Retest

Answer a similar mini-question without looking at the model answer.

A good correction is reusable. “I forgot” is honest, but it is not a strategy.

Homework

Final correction pack

  1. Choose three lost marks from a mock or practice paper and classify each error type.
  2. For each lost mark, write the original answer, the missing mark, the correction rule and a rewritten answer.
  3. Complete one similar retest question for each corrected error.
  4. Write a one-page final Paper 2 checklist covering pseudocode, data structures, file handling and software development explanations.
Marking focus: corrected answer plus transfer. If the same error appears again, the correction was too passive.
