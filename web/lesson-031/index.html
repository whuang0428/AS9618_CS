Core syllabus content

Output, storage devices and primary memory

A laser printer charges a drum, a laser discharges selected points, toner adheres to the image, toner transfers to paper and heat/pressure fuse it. A 3D printer deposits or solidifies material layer by layer from a digital model.

A speaker uses a DAC/amplifier to drive a coil and cone, producing pressure waves. An output buffer temporarily holds data because the processor can produce it faster or in different-sized bursts than a printer or audio device can consume it.

An HDD spins magnetic platters while an actuator positions read/write heads; writing changes magnetic orientation and reading senses it. Flash memory stores charge in floating-gate cells and has no moving parts.

An optical drive spins a disc and directs a laser at its track. Reflected-light differences are read as data; a writer uses a higher-power laser to change a dye or recording layer.

A magnetic HDD uses moving read/write heads over rotating platters. Flash memory stores charge electronically with no moving parts. An optical disc reader/writer uses a laser to read marks and, on writable media, to create or alter marks.

RAM is volatile read/write primary memory used for programs and data currently being processed. ROM is non-volatile primary memory used for instructions that must remain when power is removed, such as firmware or start-up instructions. ROM is not ordinary long-term storage for user files.

SRAM stores bits using flip-flop circuits, needs no refresh and is fast but expensive with lower density, so it is used for cache. DRAM stores charge in capacitors, requires refresh and is slower but cheaper and denser, so it is used for main memory.

PROM is programmed once. EPROM can be erased with ultraviolet light and reprogrammed. EEPROM is erased and rewritten electrically, often without removing it from the system. All three are non-volatile ROM technologies.

A buffer temporarily holds data when connected components operate at a different speed or transfer data in different-sized bursts.

Required device overview: a laser printer uses an electrostatic drum, laser, toner and fuser; a 3D printer builds successive layers; a speaker converts an electrical signal into sound. An HDD or magnetic hard disk uses rotating magnetic platters, flash memory stores charge electronically, and an optical reader/writer uses a laser.

Worked example: Print a page / Read an HDD block / Choose a storage mechanism / Choose memory for a computer system

The operating system places page data in a print buffer. The CPU can continue other work while the slower printer consumes buffered data and performs drum, toner and fusing stages. The controller moves the head to the correct track, waits for the sector to rotate beneath it, senses magnetic patterns and transfers the decoded bits through a buffer. A portable device may use flash memory for shock resistance; an archive may use optical media when an optical disc reader/writer is available. Use DRAM as main RAM because its density and lower cost support a large working capacity. Use a small amount of SRAM for cache because faster, no-refresh access reduces processor waiting. Store updateable firmware in EEPROM because it remains without power but can be rewritten electrically.

It has no moving read/write head or spinning platter.

An HDD.

9. Which device uses a laser?

Show answer

An optical reader/writer.

10. Compare RAM from ROM by volatility and use.

Show answer

RAM is volatile and holds current programs/data; ROM is non-volatile and holds persistent firmware or start-up instructions.

Show answer

Charge in its storage capacitors leaks and must be restored.

12. Why is SRAM used for cache while DRAM is used for main memory?

Show answer

SRAM is faster and needs no refresh; DRAM is denser and cheaper per bit for a larger capacity.

Show answer

PROM is programmed once; EPROM is erased with ultraviolet light; EEPROM is erased and rewritten electrically.

Lesson 031 | 45 minutes | Paper 1 Section 3

Primary storage is the computer's working desk, not its filing cabinet.

This lesson explains RAM, ROM, cache and virtual memory. The main exam skill is explaining what each type is used for, whether it is volatile, and how it affects performance.

cache -> RAM -> virtual memory

Closer to the CPU usually means faster, smaller and more expensive. Convenient, like a front-row seat with a tiny desk.

Why this matters

Cambridge-style answers often require exact contrasts. "RAM is temporary" is weaker than "RAM is volatile and stores data/instructions currently in use."

Common error

Virtual memory is not extra physical RAM. It uses secondary storage as if it were memory, which is slower than RAM.

Why active data stays close to the CPU

  1. Mechanism: The CPU repeatedly requests current instructions and data.
  2. Reason: Nearby electronic storage answers with less delay than secondary storage.
  3. Result: Faster access prevents the processor waiting as often.

Analogy: Keep today's papers on the desk, not in a distant archive.

Boundary: Closer and faster storage is smaller and more expensive per byte.

Knowledge point 2

RAM and ROM: similar letters, very different jobs

Why RAM changes while ROM remains stable

  1. Mechanism: RAM holds the changing state of running programs.
  2. Reason: Most RAM needs continuous power to preserve that state.
  3. Result: ROM retains fixed startup instructions when power is removed.

Analogy: A working notepad changes constantly; a printed reference card should not.

Boundary: ROM can sometimes be updated, but not as ordinary working memory.

Exam warning
Cache
Stores frequently/recently used data or instructions so the CPU can access them faster than from RAM.
Do not say cache permanently stores user files.
Virtual memory
Allows the system to continue running more/larger programs than RAM alone can hold.
Do not say it is as fast as RAM; using it heavily can slow the system.

Why cache helps and virtual memory slows

  1. Mechanism: Cache holds copies of recently or frequently used instructions and data close to the CPU.
  2. Reason: A cache hit avoids a slower main-memory access.
  3. Result: Virtual memory uses secondary storage when RAM is insufficient and increases apparent capacity rather than physical RAM speed.

Analogy: A desk tray saves a walk; using the archive as desk space creates walks.

Boundary: Virtual memory increases capacity, not physical RAM speed.

Mistake debugging

Fix the weak memory answer

"ROM is faster RAM that stores open programs."

ROM is non-volatile memory used for firmware/startup instructions. RAM stores currently running programs and data and is volatile.

"Virtual memory gives the computer more real RAM."

Virtual memory uses part of secondary storage as if it were RAM. It can let more programs run, but it is slower than RAM and heavy use reduces performance.

Comparison: RAM = current volatile working memory; ROM = non-volatile startup instructions; cache = very fast frequently used data; virtual memory = slower secondary storage used when RAM is full.

Virtual memory: it involves moving data between RAM and secondary storage, which is slower than accessing RAM directly.

ROM startup: ROM retains boot instructions when power is off, so the system can start before the operating system is loaded.

Misconception: "RAM keeps files after power off" is wrong because RAM is volatile.
