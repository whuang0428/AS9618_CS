The CPU is not one magic chip doing everything by vibes.

A processor works because specialised parts cooperate: the ALU performs calculations and logical operations, the CU coordinates activity, registers hold tiny but fast working values, buses move signals, and the clock keeps timing organised.

Why this matters

Section 4 questions often reward precise verbs: calculates, coordinates, stores temporarily, transfers, synchronises.

Common trap

Students write "the CPU stores data". Better: registers temporarily hold data or instructions currently being processed.

Knowledge point 1

CPU architecture is about cooperating parts

Processor / CPU The hardware that executes instructions. It is inside the computer system, but it is not the same as RAM or secondary storage.
Internal components The ALU, CU and registers are inside the CPU and are involved in processing instructions.
Connections Buses provide pathways for data, addresses and control signals between CPU, memory and other components.
Timing The clock provides regular pulses so CPU operations occur in a synchronised order.
Chinese support: architecture = 结构/体系结构；processor = 处理器；component = 组成部分；synchronise = 同步。

Visual explanation

Inside the CPU, outside the CPU, and what connects them

The ALU, CU and registers are processor components. Main memory is outside the CPU; buses carry addresses, data and control signals between them.

Check the diagram: is main memory a register inside the CPU?

No. Registers are small, fast storage locations inside the CPU. Main memory is a separate component connected to the CPU by buses.

Knowledge point 2

ALU and CU: do not swap their jobs

Component
Full name
Role
Exam-safe wording
ALU
Arithmetic Logic Unit
Performs arithmetic calculations and logical operations.
The ALU performs addition, subtraction and comparisons such as AND/OR or greater-than tests.
CU
Control Unit
Coordinates CPU activity and issues control signals.
The CU decodes instructions and controls the sequence of operations in the fetch-decode-execute cycle.

Common trap

"The CU calculates" is wrong. The CU controls; the ALU calculates. The CU is the traffic controller, not the calculator.

Knowledge point 3

Registers, buses and clock

Registers

Registers are small, very fast storage locations inside the CPU. They temporarily hold data, instructions, addresses or intermediate results while processing takes place.

Specific registers such as PC, MAR, MDR and CIR are handled more deeply in later lessons.

Data bus

Carries data and instructions between the CPU, memory and other components. It is about the value being transferred.

Address bus

Carries the memory address that identifies where data or an instruction should be read from or written to.

Control bus

Carries control signals such as read, write, interrupt and timing signals between CPU and other components.

Clock

Produces regular pulses used to synchronise CPU operations. Clock speed is measured in hertz, often GHz for modern processors.

Performance caution

A higher clock speed may allow more cycles per second, but performance also depends on architecture, cache, cores, instruction type and memory access.

Extra practice

Immediate access store (IAS)

The immediate access store is memory directly accessible by the processor for instructions and data currently required. In the stored-program model, instructions and data share this memory and are distinguished by how they are used.

IAS is not the same as a CPU register or secondary storage. Registers are smaller locations inside the CPU; secondary storage must supply programs/data to main memory before normal execution.

Worked example: Run a stored program

Instructions and working data are loaded from SSD into the IAS/main memory. The CPU fetches an instruction from that memory into the MDR/CIR, then executes it using registers and the ALU.

Targeted practice

1. What two kinds of item are held in IAS?

Show answer

Instructions and data currently required.

2. Is IAS a CPU register?

Show answer

No; it is processor-accessible main memory.

3. Why must a program on secondary storage be loaded into IAS?

Show answer

The processor fetches executable instructions from directly accessible main memory.
