Protocols are not alphabet soup if you pair them with jobs.

This lesson matches common application protocols to their context: web pages, secure web pages, file transfer, sending email and receiving email. The exam usually rewards the job, not just expanding the acronym.

The acronym is the label. The use case earns the mark.

Why this matters

Protocol questions often use short scenarios. Students must identify the context and avoid swapping SMTP with POP3/IMAP.

Common trap

SMTP sends email. POP3 and IMAP retrieve/access email. A mailbox is not delivered by wishful thinking.

Warm-up hook

A student sends homework by email, then checks the same mailbox on a phone and laptop. Which pair matters most?

Pick the pair that separates sending email from synchronised mailbox access.

Knowledge point 2

FTP for file transfer

FTP: File Transfer Protocol

FTP is used to transfer files between a client and a server, such as uploading website files or downloading files from a file server.

Do not use FTP as a generic answer for “anything on the internet”. It is specifically about file transfer.

Knowledge point 3

Email protocols: SMTP, POP3 and IMAP

SMTP

Used to send email from a client to a mail server and between mail servers.

POP3

Used to download email from a mail server to a client, often removing it from the server depending on settings.

IMAP

Used to access and synchronise email stored on a mail server across multiple devices.

Common trap

IMAP is usually better for multiple devices because messages and folders stay on the server and remain synchronised.

Fix the weak protocol answer

“SMTP is used to read email from the server.”

SMTP is used to send email. POP3 or IMAP is used to retrieve/access email from a mail server.

“HTTPS just means the page is faster.”

HTTPS is the secure version of HTTP and uses encryption to protect web communication in transit.

Homework

Clear tasks

  1. Create six flashcards: HTTP, HTTPS, FTP, SMTP, POP3 and IMAP. Each card must include one use case.
  2. Draw an email journey showing SMTP for sending and POP3/IMAP for receiving/accessing.
  3. Explain why IMAP is usually suitable when a user reads email on multiple devices.
  4. Write a 5-mark answer comparing HTTP and HTTPS.

Flashcards: include the job, not only the full name.

Email journey: SMTP sends; POP3 downloads; IMAP synchronises/accesses server mailbox.

IMAP: mention messages/folders remain on server and changes sync across devices.

HTTP/HTTPS: both transfer web pages; HTTPS adds encryption/security for data in transit.
