Knowledge point 1

Core performance terms

Bandwidth

The maximum amount of data that can be transmitted over a connection per second.

Typical units: bits per second, Mbps, Gbps.

Latency

The delay before data starts to arrive or before a response is received.

Typical units: milliseconds (ms).

Congestion

Occurs when too much data is trying to use part of a network, causing queues, delay or packet loss.

Symptom: performance worsens when many users/devices compete.

Throughput

The actual amount of data successfully transferred per second, often lower than theoretical bandwidth.

Chinese support: bandwidth = 带宽；latency = 延迟；congestion = 拥塞；throughput = 实际吞吐量；packet loss = 丢包。

Knowledge point 2

Factors that affect performance

Good answers name a factor and explain its effect. "It becomes slower" needs a cause.

Transmission medium

Fibre may provide high bandwidth and low interference; wireless may vary with distance, obstacles and interference.

Number of users

More users can share the same capacity, increasing congestion and reducing throughput per user.

Distance and route

Longer physical distance and more hops can increase latency.

Hardware and server load

Slow routers, overloaded servers or weak wireless access points can become bottlenecks.

Packet loss and retransmission

If packets are lost, data may need to be resent, increasing delay and reducing effective throughput.

Protocol overhead

Error checking, encryption and headers are useful, but they add extra data or processing.

Knowledge point 3

Simple transfer time calculation

Transfer time = file size in bits / bandwidth in bits per second

Remember: 1 byte = 8 bits. A 50 MB file is not 50 Mb. That capital B is doing real work.

Mini example

A 25 MB file is downloaded over a 10 Mbps link.

  1. Convert file size: 25 MB x 8 = 200 Mb.
  2. Divide by bandwidth: 200 Mb / 10 Mbps = 20 seconds.
  3. This is an ideal estimate; real throughput may be lower due to congestion and overhead.

Mistake debugging

Fix the weak performance answer

"Bandwidth is how quickly the first bit arrives."

That describes latency. Bandwidth is the maximum amount of data that can be transmitted per second.

"A 40 MB file over 20 Mbps takes 2 seconds."

40 MB = 320 Mb. 320 Mb / 20 Mbps = 16 seconds, before real-world overheads.

Extra practice

Bit streaming, bit rate and broadband

Bit streaming delivers media progressively so playback can begin before the whole file arrives. Real-time streaming carries a live event with minimal delay; on-demand streaming sends stored content selected by the user.

Bit rate is the number of bits transmitted each second. Available broadband speed must normally exceed the media bit rate and absorb variation; otherwise the player buffers, lowers quality or pauses. A buffer stores arriving data temporarily.

Worked example: 6 Mbit/s video on 4 Mbit/s link

The stream consumes data faster than the link supplies it. A starting buffer only delays the shortage; sustained playback requires a lower bit rate or faster connection.

Exam-style question

4 marks

A video has a bit rate of 8 Mbit/s. Explain why a connection advertised as 8 Mbit/s may still pause during playback.

Show MS
  1. B1 video requires about 8 million bits each second
  2. B1 actual available speed may be below advertised/maximum speed
  3. B1 other traffic, overhead or variation reduces throughput
  4. B1 buffer empties when data arrives more slowly than playback consumes it
