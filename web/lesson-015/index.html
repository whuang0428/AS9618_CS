The stopwatch is not the enemy. The missing unit usually is.

Why this matters

Cambridge marking rewards visible method, correct units and scenario links. A bare final answer is a very brave way to lose marks.

Common trap

Mixing decimal prefixes with binary prefixes: MB is based on powers of 1000; MiB is based on powers of 1024.

Warm-up hook

Four questions walk into an exam. Which one steals the most marks?

Pick the most dangerous answer. Hint: the examiner cannot infer a missing unit just because the calculator looked confident.

Knowledge point 1

Question triage: choose the toolbox first

Number bases

Look for binary, denary, hexadecimal, place values, carries, overflow or two's complement.

Text representation

Look for ASCII, Unicode, character set, character code, multilingual text or symbols.

Images and sound

Look for resolution, colour depth, sampling rate, sample resolution, duration and file size.

Compression

Look for lossless, lossy, exact reconstruction, reduced quality, RLE or repeated data.

Chinese support: triage = 先判断题型；method = 解题方法；unit = 单位；follow-through = 后续步骤跟随前一步。

Knowledge point 2

Section 1 method bank

Storage units

1 KiB = 1024 bytes. 1 MiB = 1024 KiB. Decimal prefixes use 1000, binary prefixes use 1024.

Binary to denary

Add active place values. For 8-bit unsigned, range is 0 to 255.

File size

Image bits = width x height x colour depth. Sound bits = sample rate x sample resolution x duration x channels.

Compression choice

Lossless allows exact reconstruction. Lossy removes data permanently but can reduce file size more.

Timed section

Six-minute review sprint

Use the timer for a short retrieval round. The goal is not panic; the goal is clean method under a clock.

06:00
  1. Convert 10101100 to denary.
  2. Calculate the size in bits of a 100 x 50 bitmap image with 8-bit colour depth.
  3. State why Unicode is suitable for a multilingual app.
  4. Choose lossless or lossy compression for a legal document archive and justify the choice.

1: 172, because 128 + 32 + 8 + 4 = 172.

2: 100 x 50 x 8 = 40 000 bits.

3: Unicode supports a wider range of characters, so it can represent many languages.

4: Lossless, because the document must be reconstructed exactly.

Mistake debugging

Repair common review answers

“The image file is 240000.”

State the unit and method: 200 x 150 x 8 = 240 000 bits, which is 30 000 bytes.

“Lossless is better because it is higher quality.”

Lossless is suitable when exact reconstruction is required; it is not automatically better for every purpose.

Summary

The Section 1 survival checklist

1Identify the representation topic before solving.
2Show method for calculations; do not jump to a lonely answer.
3Write units: bits, bytes, KiB, MiB, colours, samples per second.
4For explanations, include cause and consequence in the given scenario.

  3. Write one improved answer for every mistake you made in the practice section.
