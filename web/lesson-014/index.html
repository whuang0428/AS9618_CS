Good representation is not “use more bits everywhere”.

Real systems choose representations based on range, accuracy, storage, compatibility, transfer speed and whether exact reconstruction is required. This lesson combines number, text, image, sound and compression choices.

The best answer is the one that fits the system, not the one with the biggest number.

Teaching cue

Force every recommendation to include a reason and a consequence. “Use Unicode” is not enough.

Why this matters

Scenario questions reward decisions that match constraints, not memorised definitions pasted into the answer.

Common trap

Higher resolution, higher colour depth or higher sample rate may waste storage if the system does not need it.

Warm-up hook

A weather sensor stores temperatures from -40°C to +60°C. Which representation issue matters first?

Pick an answer. Negative temperatures are a quiet hint that unsigned storage may be wrong.

Knowledge point 1

A decision framework

1. What data?

Integer, signed value, text, image, sound or repeated data.

2. What range?

Check minimum, maximum, precision and whether negative values are possible.

3. What quality?

Choose resolution, colour depth, sample rate or sample resolution only as high as needed.

4. What constraints?

Storage, bandwidth, compatibility, exact reconstruction and processing cost.

Chinese support: requirement = 需求；constraint = 限制条件；trade-off = 权衡。

Knowledge point 2

System cases

Multilingual chat app

Use Unicode so messages can include characters from many languages.

Sensor logger

Use enough bits and signed representation if values may be negative.

Website thumbnail

Lower resolution and lossy compression may be acceptable to reduce transfer time.

Legal archive

Use lossless compression because exact reconstruction is required.

Knowledge point 3

Useful trade-off sentences

Range

More bits increase the possible range but require more storage per value.

Image quality

Higher resolution or colour depth can improve detail or colour range but increases file size.

Sound quality

Higher sample rate or sample resolution can improve accuracy but increases file size.

Compression

Lossless preserves exact data; lossy can reduce size more but loses data permanently.

“Use Unicode because it is better.”

Use Unicode because it supports a wider range of characters, making it suitable for multilingual text.

“Use maximum image quality for every thumbnail.”

A thumbnail is small on screen, so lower resolution or lossy compression may be acceptable and reduces file size / transfer time.

Homework

Clear tasks

  1. For a parking sensor storing distances from 0 to 255 cm, choose a suitable integer representation and justify it.
  2. For a multilingual school website, explain why Unicode is suitable.
  3. For a photo gallery thumbnail, justify one setting that could be reduced to save space.
  4. Write a 6-mark answer choosing representations for a hospital document archive.

Parking sensor: 8-bit unsigned integer is enough for 0-255 if no negative values or fractions are needed.

Website: Unicode supports many languages and symbols, so it fits multilingual text.

Thumbnail: lower resolution or lossy compression can reduce file size because the image is displayed small.

Archive: use lossless compression and suitable character encoding because exact reconstruction and legal accuracy are required.
