Lesson 084 | 45 minutes | Paper 1 Section 8 | SQL basics

SQL is how you ask a database a precise question. "Show me stuff" is not a query; it is a cry for help.

This lesson turns English questions into basic single-table SQL queries using SELECT, FROM and WHERE. The focus is field selection, table selection and conditions. Sorting, aggregates, grouping and joins are left for later lessons.

Selectthe fields required by the question
UseFROM to name the correct table
Filterrecords using WHERE conditions and comparison operators
SELECTTitle, DueDate FROMLoan WHEREReturned = FALSE

Think: fields, table, condition. Then write the clauses.

Why this matters

SQL questions are often marked with one point per clause or condition. A missing field or wrong table can lose easy marks.

Common trap

Do not use SELECT * unless all fields are required. Cambridge usually asks for specific output fields.

Knowledge point 1

The three foundation clauses

SELECTNames the fields to output, such as Title, DueDate.
FROMNames the table to use, such as Loan.
WHEREFilters records using a condition, such as Returned = FALSE.
Thinking order: What fields do I need? Which table contains them? Which records should be included?

Knowledge point 2

WHERE conditions and comparison operators

A WHERE clause tests each record and returns only records where the condition is true.

Knowledge point 3

Text values need quotes; numbers usually do not

Text/stringCategory = 'Fiction'. The text value is quoted.
NumberPrice < 10.00. Numeric values are not quoted in basic exam SQL.
BooleanReturned = FALSE. Use the Boolean value expected by the question/table.
Field namesUsually not quoted: SELECT Title, not SELECT 'Title'.
Chinese support: clause = 子句；condition = 条件；string/text value = 字符串/文本值；quotes = 引号。
