Knowledge point 2

Binary magnitudes: powers of two, not a decorative 1024

What the phrase means

A binary magnitude is a size based on powers of two. Storage questions often use 210, 220, 230 and 240.

Calculator-free anchors

  • 210 = 1024
  • 220 = 1,048,576
  • 230 = 1,073,741,824
  • 240 = 1,099,511,627,776

Exam consequence

If a question says KiB, MiB, GiB or TiB, use 1024 between adjacent units. If it says kB, MB, GB or TB, use 1000 unless the question states otherwise.

Knowledge point 3

Decimal prefixes vs binary prefixes

Decimal prefixes

Often used by storage manufacturers.

  • 1 kB = 1000 bytes
  • 1 MB = 1000 kB
  • 1 GB = 1000 MB
  • 1 TB = 1000 GB

Binary prefixes

Used when sizes are based on powers of two.

  • 1 KiB = 1024 bytes
  • 1 MiB = 1024 KiB
  • 1 GiB = 1024 MiB
  • 1 TiB = 1024 GiB
Exam habit: read the prefix before calculating.

Why this matters

The syllabus explicitly expects the contrast between kibi/kilo, mebi/mega, gibi/giga and tebi/tera.

Common trap

decimal prefixes 按 1000 进位；binary prefixes 按 1024 进位。MiB is not just a fancy spelling of MB.

Extra practice

Binary and decimal magnitude prefixes

Binary prefixes use powers of 1024: 1 KiB = 2^10 bytes, 1 MiB = 2^20 bytes, 1 GiB = 2^30 bytes and 1 TiB = 2^40 bytes.

Decimal prefixes use powers of 1000: 1 kB = 10^3 bytes, 1 MB = 10^6 bytes, 1 GB = 10^9 bytes and 1 TB = 10^12 bytes. Case and the i in KiB/MiB/GiB/TiB carry meaning.

Worked example: 2 TiB drive

2 TiB = 2 x 2^40 = 2,199,023,255,552 bytes. A 2 TB drive is 2,000,000,000,000 bytes, so the labels are not interchangeable.

Targeted practice

1. How many bytes are in 4 GiB?

Show answer

4 x 2^30 = 4,294,967,296 bytes.

2. Which is larger, 1 TB or 1 TiB?

Show answer

1 TiB, because 2^40 is greater than 10^12.

3. Convert 3,000,000 bytes to MB.

Show answer

3 MB using the decimal prefix mega.

Exam-style question

State the number of bytes represented by 1 GiB and explain why 1 GB represents a different number of bytes.

Show MS
  1. B1 1 GiB = 2^30 bytes / 1,073,741,824 bytes
  2. B1 gibi uses a binary power / multiples of 1024
  3. B1 1 GB = 10^9 bytes / 1,000,000,000 bytes
  4. B1 giga uses a decimal power / multiples of 1000
