Lesson 063 | 45 minutes | Paper 1 Section 6 | Security, privacy and data integrity

Some attacks target software. Some target the person holding the keyboard.

Malware is malicious software designed to damage, disrupt, steal or gain unauthorised access. Social engineering manipulates people into giving access, information or permission. Exam answers need the mechanism, not just a scary label.

Classifycommon malware types by mechanism and impact
Explainhow social engineering exploits human trust or pressure
Recommendcontrols that match the threat and protected security goal
Virus: attaches, needs host/action Worm: self-replicates across networks Trojan: disguised as legitimate Spyware: secretly monitors/steals Social engineering: manipulates people

If the attack starts with "just click this", check both the device and the decision.

Why this matters

Many candidates list names of malware but do not describe what each one does. Names alone are low-yield.

Common trap

Do not use encryption as a cure for every threat. It may protect confidentiality but does not remove malware or train users.

Knowledge point 1

Malware is malicious software; social engineering manipulates people

MalwareSoftware created to disrupt, damage, steal data or gain unauthorised access.
PayloadThe harmful action, such as deleting files, encrypting data or stealing credentials.
PropagationHow it spreads, such as infected files, networks, removable media or deceptive downloads.
Social engineeringManipulating a person into revealing information or performing an unsafe action.
Chinese support: malware = 恶意软件；payload = 有害载荷/破坏行为；propagation = 传播方式；social engineering = 社会工程学攻击。

Knowledge point 2

Virus and worm: both can spread, but not in the same way

VirusAttaches to a host file/program and often needs the host to be run or shared.
WormSelf-replicates, often across networks, without needing to attach to a host file.
ImpactCan corrupt data, slow systems, consume bandwidth or install further malware.
TrapDo not say every self-spreading threat is a virus.

Knowledge point 3

Trojan: malicious code disguised as legitimate software

MechanismAppears useful or harmless so a user installs or runs it.
ImpactMay create a backdoor, steal data, install other malware or change settings.
ControlDownload from trusted sources, check permissions, use anti-malware and user education.
TrapA Trojan does not need to self-replicate to be harmful.

Knowledge point 4

Spyware secretly monitors activity or collects data

MechanismRuns without clear user awareness and gathers information.
ExamplesKeylogger, screen monitoring or browser tracking used to capture credentials.
Goal affectedOften threatens confidentiality and authenticity if credentials are stolen.
ControlAnti-malware, least privilege, patching, browser controls and caution with downloads.

Knowledge point 5

Ransomware denies access by encrypting or locking data

MechanismEncrypts files or locks systems, then demands payment for restoration.
Goal affectedMainly threatens availability; may also threaten confidentiality if data is stolen.
ControlOffline backups, patching, anti-malware, restricted permissions and user training.
TrapPaying is not a reliable recovery strategy in an exam answer.

Knowledge point 6

Social engineering exploits people rather than code

MechanismUses trust, urgency, authority, curiosity or fear to influence a user.
ActionUser may reveal passwords, approve access, install software or transfer data.
Goal affectedOften threatens confidentiality and authenticity through impersonation or credential theft.
ControlUser training, verification procedures, MFA, reporting routes and least privilege.

Knowledge point 7

Match controls to mechanism, not just the word "malware"

Extra practice

Anti-spyware as a security measure

Spyware secretly monitors activity or collects data, such as keystrokes, credentials or browsing behaviour. Anti-spyware scans files, memory and behaviour for known signatures or suspicious actions, then blocks, quarantines or removes detected software.

It must be updated because new spyware and signatures appear. Anti-spyware reduces risk but cannot guarantee detection of every new or concealed threat.

Worked example: Keylogger detected

The scanner matches the process to a known signature, prevents it running and quarantines the file so it cannot continue capturing credentials.

Targeted practice

1. What is spyware designed to do?

Show answer

Secretly monitor activity or collect user/system data.

2. What does quarantine do?

Show answer

Isolates suspicious code so it cannot execute normally.

3. Why update anti-spyware definitions?

Show answer

To recognise newly identified spyware.

Exam-style question

4 marks

Explain how anti-spyware software can reduce the risk from a keylogger.

Show MS
  1. B1 scans/monitors files, memory or behaviour
  2. B1 uses signatures/rules to detect suspicious software
  3. B1 blocks/quarantines/removes the keylogger
  4. B1 prevents/reduces capture of keystrokes or credentials
