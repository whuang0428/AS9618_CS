A truth table is a receipt: every input row must pay for its output.

This lesson moves from individual logic gates to complete Boolean expressions. You will construct truth tables systematically, add intermediate columns, and use them to prove the final output.

Q = (A AND B) OR NOT C

The brackets are not decoration. They tell the table what to do first.

Teaching cue

Make students say the column plan before filling numbers: inputs, intermediate gate outputs, final Q.

Why this matters

Cambridge-style mark schemes often award method marks for intermediate columns even when the final output contains an error.

Common trap

Students often skip intermediate columns. That turns a logic question into mental arithmetic with a dramatic chance of wrongness.

Warm-up hook

A door opens when a card is valid AND either the PIN is correct OR the supervisor override is active.

Click the row that opens the door. The door accepts Boolean evidence, not persuasive eyebrows.

Rule: Q = Card AND (PIN OR Override). There are two opening rows here.

Knowledge point 1

Boolean expressions describe gate behaviour

Variables A, B and C represent input signals. Each row assigns them 0 or 1.
Operators NOT, AND, OR, NAND, NOR and XOR describe the logic applied.
Intermediate columns Each bracketed part or gate output should get its own column.
Final output Q is the final result after all intermediate columns have been combined.
Chinese support: Boolean expression = 布尔表达式；intermediate column = 中间列；evaluate = 求值；precedence = 优先级。

Knowledge point 2

A reliable truth-table method

1. Count inputsn inputs produce 2^n rows. Two inputs give 4 rows; three inputs give 8 rows.
2. List input combinationsUse a systematic order such as 000, 001, 010, 011, 100, 101, 110, 111.
3. Add intermediate columnsOne column for each gate result, such as A AND B or NOT C.
4. Fill final QUse the intermediate columns to avoid guessing the final output.

Knowledge point 3

Brackets and NOT usually come before the final combination

Brackets firstFor (A OR B) AND C, complete A OR B before the AND with C.
NOT nextFor A AND NOT B, invert B before applying AND.
Then combineUse AND, OR or XOR to combine the prepared columns.
Check one rowPick one row and explain it in words to catch swapped columns.
Do not assume a hidden priority when the expression is unclear. In exam answers, use brackets or intermediate columns to remove ambiguity.

Mistake debugging

Fix the weak truth-table method

"For three inputs, I only need six rows because there are three letters and two values."

Three inputs require 2^3 = 8 rows. Each input can be 0 or 1, and every combination must appear exactly once.

"I can fill Q directly for Q = (A AND B) OR NOT C without showing working."

Add intermediate columns for A AND B and NOT C. Cambridge-style marking can credit those columns and they reduce row errors.

Exam-style questions

Homework

Clear tasks

  1. Complete the full truth table for Q = (A OR B) AND NOT C.
  2. Complete the full truth table for Q = (A XOR B) OR C.
  3. Write one paragraph explaining why intermediate columns are useful in exam answers.
  4. Given this rule, "alarm sounds if motion is detected and the system is armed", define variables and write a Boolean expression.

First table: use columns A, B, C, A OR B, NOT C, Q.

Second table: use columns A, B, C, A XOR B, Q.

Paragraph: mention method marks, reduced errors and clear evidence for final Q.

Alarm expression: for example, let M = motion detected and A = system armed, then Alarm = M AND A.
