Lesson 097 | 45 minutes | Paper 1 Sections 1-8 | stage review

A mock is not a verdict. It is an expensive diagnostic report, so use it properly.

This clinic turns a Paper 1 mock into targeted correction. You will classify lost marks, rewrite weak answers, identify section-level gaps and build a practical repair plan before Paper 2 begins. The goal is not to feel bad about a number; it is to make the next number less dramatic.

Diagnoseclassify lost marks by topic, command word and answer flaw
Repairrewrite weak answers using precise Cambridge-style language
Planset focused next steps for Paper 1 maintenance alongside Paper 2
Lost marktopic gap, command error, method error, wording issue Correctionterm, mechanism, context, unit, judgement Actionretry, flashcard, worked example, timed drill

Do not just circle the mark. Put it on trial and ask what evidence was missing.

Why this matters

Reviewing a mock by only checking the final score wastes the most useful feedback in the course.

Common trap

"I knew that" is not a correction. The question is whether the answer on the page earned the mark.

Diagnosis

Four common sources of lost marks

Error type
What it looks like
Repair move
Topic gap
wrong section or wrong concept
re-label the syllabus area and write the first correct keyword
Command error
state/describe/explain/compare/evaluate answered with wrong depth
reshape the answer to match the command word
Method error
calculation, SQL, trace or logic method is wrong/incomplete
write formula, clause skeleton or register sequence before final answer
Wording issue
vague terms such as better, secure, efficient, fast

Correction clinic

The rewrite protocol

1. LabelWrite the section/topic and command word beside the question.
2. LocateUnderline the exact missing mark: term, method, mechanism, context or judgement.
3. RewriteWrite a new answer, not a note saying "be more careful".
4. MarkUse B/M/A labels to show why the corrected answer earns marks.
5. DrillCreate one similar question and answer it under a time limit.
6. TrackRecord whether the issue is knowledge, method, wording or timing.

Homework

Clear tasks for consolidation

Task 1: Error tally Create a table of your mock lost marks: section, command word, error type and one-sentence correction.
Task 2: Five rewrites Rewrite your five highest-value lost answers. Add B/M/A labels showing why each corrected answer earns marks.
Task 3: Maintenance plan Schedule three 12-minute Paper 1 micro-drills during the first Paper 2 week: one calculation, one explanation, one database/ethics item.
