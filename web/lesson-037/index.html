Start with the rule. The circuit should simply obey it, without inventing new drama.

Why this matters

Cambridge questions often give worded requirements. Marks depend on turning words such as only if, either, and not into the right gates.

Common trap

Do not draw gates before defining variables. A circuit with mystery inputs is not clever; it is just hard to mark.

Warm-up hook

A school door unlocks only if the card is valid and the emergency stop is not active.

Click the correct expression. The door is allergic to vague English.

Look for "only if" and "not active". Those two phrases usually decide the gate choices.

Knowledge point 2

A circuit design method that examiners can follow

1. Name the outputUse a clear output such as Alarm, Unlock, Fan or Light.
2. Define variablesWrite what each input means, for example A = system armed.
3. Write expressionTranslate the requirement with AND, OR, NOT, NAND, NOR or XOR.
4. Draw in stagesDraw inner gates first, then connect them to the final output gate.
A correct circuit is not just a pretty drawing. It must match the Boolean expression and produce the correct truth-table output.

Mistake debugging

Fix the weak circuit design

"The alarm sounds if door OR window is open. The system armed condition can be drawn somewhere at the end."

If the requirement says the system must be armed, Armed must be part of the expression: Alarm = Armed AND (Door OR Window). The final AND is essential.

"Emergency stop is not active, so I write NOT Card AND Emergency."

The NOT applies to Emergency, not Card. The correct expression is Unlock = Card AND NOT Emergency.

Homework

Clear tasks

  1. For "A warning sounds if the system is armed and either a door or window is open", define variables, write the expression and describe the gate sequence.
  2. For "A fan starts if the room is hot and manual override is not active", define variables and draw the gate structure in words.
  3. Create one requirement that needs XOR and explain why OR would be wrong.
  4. Verify one of your circuits with two truth-table rows: one where output is 1 and one where output is 0.

Alarm: let A = armed, D = door open, W = window open. Alarm = A AND (D OR W).

Fan: let H = hot, O = override active. Fan = H AND NOT O.

XOR: use "exactly one" wording, such as exactly one button pressed.

Verification: write input values, intermediate gate result and final output.
