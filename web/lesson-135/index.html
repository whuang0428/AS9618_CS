Good input gets data in. Good output lets humans understand it.

INPUT stores data entered by the user. OUTPUT displays data to the user. Formatting controls how information is presented: labels, spacing, order, decimal places and line breaks. Algorithms do not get extra marks for being mysterious. If the output reads like a printer having an existential crisis, fix the format.

UseINPUT and OUTPUT precisely in Cambridge-style pseudocode
Formatlabels, concatenated strings, numeric values and table-like output
Avoidconfusing prompts, output text and stored input values
INPUT Markread and storedata enters the algorithm
OUTPUT Markdisplay valuedata leaves to screen
OUTPUT "Mark: " & Markformatted messageclear for humans

Prompting tells the user what to enter. INPUT actually receives it.

Teaching cue

Ask students to underline every value that is stored, and circle every value that is displayed.

Why this matters

Paper 2 answers often lose marks when candidates output a prompt but never input the value, or calculate correctly but display unclearly.

Common trap

OUTPUT "Enter mark" is only a prompt. It does not store the user's mark. Use INPUT Mark.

Warm-up hook

INPUT

INPUT reads data and stores it in a variable

Chinese support: input 输入, store 存储, variable 变量, prompt 提示信息。

Cambridge-style pseudocode

OUTPUT "Enter mark"
INPUT Mark

Trace

Promptscreen shows Enter mark
Inputuser enters a value such as 72
StorageMark now stores 72

OUTPUT

OUTPUT displays text, values or expressions

Display text and values

Name <- "Ada"
Mark <- 72
OUTPUT "Student: " & Name
OUTPUT "Mark: " & Mark

Displayed output

Student: Ada

Mark: 72

Labels make the output meaningful. A lonely 72 on a screen is not a user interface; it is a small mystery.

In Cambridge-style pseudocode, clear labels and logical order often matter more than language-specific formatting syntax.

Input type handling

Input data must be used with the correct data type

Numeric calculation

OUTPUT "Enter price"
INPUT Price
Total <- Price * 1.20
OUTPUT "Total: " & Total

Reasoning

Price must be treated as numeric for multiplication. If a language reads all input as text, conversion may be needed.

Cambridge pseudocode usually focuses on the algorithm. If the question demands conversion, show it clearly.

Table-like output

Formatted output can make repeated records readable

Pseudocode idea

OUTPUT "Name    Mark"
OUTPUT "Ada     72"
OUTPUT "Lin     85"

Displayed output

Name Mark

Ada 72

Lin 85

Headings, spacing and row order make the values interpretable.

Summary

Three rules to keep

INPUTreads data and stores it in a variable.
OUTPUTdisplays text, values or expression results.
Formattinguses labels, order and spacing so output is meaningful.
