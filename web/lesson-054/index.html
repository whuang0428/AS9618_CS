An interface is the conversation style between user and computer.

A user interface lets a person interact with a computer system. Different interfaces suit different users, tasks and environments. The exam rewards specific advantages and limitations, not "GUI is nicer".

IdentifyCLI, GUI, menu-driven and natural language interfaces
Compareadvantages and limitations for realistic scenarios
Justifywhich interface is suitable for a given user and task
CLI: type commands GUI: windows, icons, menus, pointer Menu-driven: choose from options Natural language: speak or type ordinary language

The best interface is not the fanciest one. It is the one that fits the task.

Why this matters

Scenario questions often ask for suitability. Students must link interface features to the user, not just list features.

Common trap

Do not write that GUI is always best. CLI can be efficient for expert users and automation.

Knowledge point 1

A user interface allows interaction with a computer system

User interfaceThe method by which a user communicates with a computer system.
UsabilityHow easy and effective an interface is for a specific user and task.
AccessibilityHow well an interface can be used by people with different needs or abilities.
ContextThe environment, user skill level and task determine suitability.
Chinese support: user interface = 用户界面；command line = 命令行；graphical = 图形化；menu-driven = 菜单驱动；natural language = 自然语言。

Knowledge point 2

Command line interface: precise text commands

How it worksThe user types commands and parameters at a prompt.
AdvantagesFast for experts, supports automation/scripts, can use fewer system resources.
LimitationsUsers must know exact commands; errors can occur from mistyped syntax.
Good fitSystem administration, batch operations, remote servers and repeatable tasks.

Knowledge point 3

Graphical user interface: visual objects and pointer actions

How it worksUses windows, icons, menus and a pointer/touch input.
AdvantagesIntuitive for many users, easy to learn, supports visual feedback and direct manipulation.
LimitationsCan use more memory/processing power; repetitive actions may be slower than commands.
Good fitGeneral desktop use, creative work, browsing files and visual tasks.

Knowledge point 4

Menu-driven interface: choose from fixed options

How it worksThe user selects from displayed options, often step by step.
AdvantagesReduces memorisation, restricts invalid choices, useful for simple repeated tasks.
LimitationsCan be slow for expert users; limited to available options; nested menus can frustrate users.
Good fitATMs, ticket machines, phone menus and kiosks.

Knowledge point 5

Natural language interface: ordinary language input

How it worksThe user speaks or types instructions in ordinary human language.
AdvantagesCan be accessible, hands-free and intuitive for simple requests.
LimitationsMay misinterpret ambiguous wording, accents, noise or context.
Good fitVoice assistants, search queries, smart speakers and accessibility support.

Summary

Interface choice depends on task and user

CLITyped commands; efficient for experts and automation.
GUIVisual objects; easier for many users and visual tasks.
Menu-drivenFixed options; guides users through limited choices.
