Lesson 008 | 45 minutes | Informal questioning

A bitmap image is a grid of tiny colour decisions.

A bitmap stores an image as pixels. Each pixel is assigned a colour code. Resolution tells us how many pixels are stored, and colour depth tells us how many bits are used for each pixel.

`100 × 80 × 8` is not a secret password. It is a bitmap size calculation.

Why this matters

Image quality, storage space and download time are linked through resolution and colour depth.

Common trap

Do not write width × height × colour depth and then call the answer bytes. That product is in bits.

Knowledge point 1

Bitmap images are pixel grids

Bitmap

An image represented as a grid of pixels, where each pixel has a stored colour value.

Pixel

The smallest addressable picture element in a bitmap image.

Metadata

Extra data about the file, such as dimensions or format. Exam calculations often say to ignore it.

Chinese support: bitmap = 位图；pixel = 像素；resolution = 分辨率；colour depth = 色深。

Knowledge point 2

Resolution: width × height

Pixel dimensions

`100 × 80` means 100 pixels across and 80 pixels down.

Total pixels: `100 × 80 = 8000`.

Quality effect

Higher resolution can show more detail because more pixels are stored.

It also increases file size if colour depth stays the same.

Click pixels to toggle them. Each square is one stored picture element.

Knowledge point 3

Colour depth: bits per pixel

1-bit colour

`2¹ = 2` possible colours. Useful for black/white examples.

4-bit colour

`2⁴ = 16` possible colours.

8-bit colour

`2⁸ = 256` possible colours.

24-bit colour

`2²⁴ = 16 777 216` possible colours.

Higher colour depth allows more possible colours, but it does not magically improve a low-quality original image.

Knowledge point 4

Bitmap file size formula

file size in bits = width × height × colour depth file size in bytes = bits ÷ 8
`100 × 80 × 8 = 64 000 bits = 8000 bytes`

Mistake debugging

Fix the file size mistake

`100 × 80 × 8 = 64 000 bytes`

The formula first gives bits. `64 000 bits ÷ 8 = 8000 bytes`.

“Doubling width only adds a small amount because height is unchanged.”

If height and colour depth stay the same, doubling width doubles the number of pixels and doubles the file size.

Extra practice

Image resolution and screen resolution

Image resolution is the number of pixels stored in the image, commonly width x height. Screen resolution is the number of physical display pixels available on the screen.

They are independent. A high-resolution image shown in a small area may be scaled down; a low-resolution image enlarged across a high-resolution screen may appear pixelated. More image pixels increase uncompressed bitmap size when colour depth is unchanged.

Worked example: 800 x 600 image on a 1920 x 1080 screen

The file stores 480,000 image pixels. The screen contains 2,073,600 display pixels. Showing the image at 1600 x 1200 requires scaling; it does not create new captured detail.

Targeted practice

1. What does 3840 x 2160 describe for a monitor?

Show answer

Its screen resolution: the number of physical display pixels.

2. Does a higher screen resolution automatically increase an image file's size?

Show answer

No. File size depends on stored image data, not the screen used to view it.

3. Why can a 200 x 100 image look pixelated when enlarged?

Show answer

The same limited image pixels are spread over more screen pixels; no extra detail is stored.

Exam-style question

Distinguish image resolution from screen resolution and explain why increasing image resolution can increase bitmap file size.

Show MS
  1. B1 image resolution is the number/dimensions of pixels stored in the image
  2. B1 screen resolution is the number/dimensions of physical pixels on the display
  3. B1 more image pixels must be stored
  4. B1 therefore more bits are required when colour depth is unchanged

Clear tasks

  1. Define bitmap, pixel, resolution and colour depth.
  2. Calculate the size of a `200 × 150` image using 8-bit colour depth, ignoring metadata.
  3. Calculate how many colours can be represented with 12-bit colour depth.
  4. Write a 4-mark explanation of how increasing colour depth affects quality and file size.

Definitions: bitmap = pixel grid image; pixel = smallest addressable picture element; resolution = width × height in pixels; colour depth = bits per pixel.

Image size: `200 × 150 × 8 = 240 000 bits = 30 000 bytes`.

Colours: `2¹² = 4096` possible colours.

Explanation focus: higher colour depth allows more possible colours but uses more bits per pixel, increasing file size.
