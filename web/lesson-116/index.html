Core syllabus content

Select and write two-dimensional arrays

A two-dimensional array uses two indexes, normally interpreted as row and column. In DECLARE Marks : ARRAY[1:30, 1:4] OF INTEGER, the first range gives 30 valid row indexes and the second gives 4 valid column indexes, for 120 cells.

Select 2D when the scenario has two independent position dimensions, such as Student and Test, Row and Column, or Day and Period. A simple list, sequence or one category of positions remains 1D even when it contains many elements.

Two-dimensional pseudocode declares both ranges, accesses one cell as Marks[Student, Test] and normally uses nested loops: one loop traverses rows and the inner loop traverses every column for the current row.

Worked example: Input a student-by-test table

DECLARE Marks : ARRAY[1:30, 1:4] OF INTEGER. Use FOR Student <- 1 TO 30 and inside it FOR Test <- 1 TO 4; INPUT Marks[Student, Test]; NEXT Test; NEXT Student. Every one of the 120 cells is visited exactly once.

A two-dimensional array is a spreadsheet with rules.

A two-dimensional array stores values of the same type using two indexes: usually row and column. If a one-dimensional array is a row of lockers, a two-dimensional array is the whole locker wall. Accessing one value means naming both its row and its column.

Nested loops

Outer row loop, inner column loop

Input every cell

FOR Row <- 1 TO 3
    FOR Column <- 1 TO 4
        INPUT Marks[Row, Column]
    NEXT Column
NEXT Row

Total every cell

Total <- 0
FOR Row <- 1 TO 3
    FOR Column <- 1 TO 4
        Total <- Total + Marks[Row, Column]
    NEXT Column
NEXT Row
OUTPUT Total
For a 3 by 4 array, the inner statement runs 3 * 4 = 12 times.

Pseudocode vs Java

Do not import Java indexing into Cambridge answers

Cambridge-style pseudocode

DECLARE Marks : ARRAY[1:3, 1:4] OF INTEGER

FOR Row <- 1 TO 3
    FOR Column <- 1 TO 4
        OUTPUT Marks[Row, Column]
    NEXT Column
NEXT Row

Java support only

int[][] marks = new int[3][4];

for (int row = 0; row < 3; row++) {
    for (int column = 0; column < 4; column++) {
        System.out.println(marks[row][column]);
    }
}
Paper 2 reminder: if the question states ARRAY[1:3, 1:4], valid row indexes are 1 to 3 and valid column indexes are 1 to 4.
