Why this matters

Many Section 2 mistakes are not knowledge gaps. They are wrong-toolbox mistakes: using DNS language for routing, or bandwidth language for latency.

Common trap

Do not write "it is faster/easier/secure" and leave. Name what changes and why the user or network benefits.

Answer craft

Precision rules for Section 2 answers

1. Define with a boundary

Switch: inside a LAN. Router: between networks. Extranet: selected external users. These boundary phrases often carry marks.

2. Name the mechanism

DNS resolves names to IP addresses. Fibre uses light pulses. HTTPS encrypts communication. Congestion causes queues.

3. Link to the scenario

If the question says online banking, mention sensitive data in transit. If it says tablets, mention mobility and wireless access.

4. Avoid empty adjectives

"Better", "faster", "secure" and "efficient" need a cause and consequence. The adjective is not the mark.

Mistake debugging

Rewrite vague answers into mark-worthy answers

"A router is better because it sends data faster."

A router connects different networks and forwards packets using IP addresses/routing information, for example from a LAN to the internet.

"HTTPS is used because it is secure."

HTTPS encrypts communication between browser and web server, helping protect sensitive data such as login or payment details in transit.

"Cloud is good because it is online."

Cloud services use remote servers accessed over a network; benefits may include remote access, collaboration or scalability, but risks include provider dependence and privacy/security concerns.

Summary

The Section 2 answer pattern

IdentifySpot the topic before writing: device, protocol, address, medium, service or performance.
MechanismName what actually happens: resolve, route, forward, encrypt, translate, queue.
BoundaryState where it applies: within LAN, between networks, public, internal, selected external users.
ScenarioUse the nouns from the question: bank login, tablets, supplier, school network, remote file.
ConsequenceExplain the result: lower delay, protected data, fewer collisions, reduced throughput, remote access.
CorrectionRewrite vague adjectives into cause-and-effect statements.
