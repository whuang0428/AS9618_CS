Sound file size is multiplication with consequences.

This lesson extends the basic mono calculation by adding channels and multi-step unit conversion. The key habit is to keep each factor visible: sampling rate, sample resolution, duration and number of channels.

Stereo is not a vibe. It is another channel in the calculation.

Why this matters

Cambridge-style marks often reward method steps separately from the final number.

Common trap

If the question says stereo, multiply by 2 channels. If it says mono, do not.

Warm-up hook

A mono clip becomes stereo. What happens to size?

Pick an answer. Stereo stores two channels, so the channel factor matters.

Knowledge point 1

The full uncompressed sound formula

size in bits = sampling rate × sample resolution × duration × channels size in bytes = bits ÷ 8 KiB = bytes ÷ 1024; MiB = KiB ÷ 1024
Sampling ratesamples per second, measured in Hz
Sample resolutionbits used for each sample
Durationlength of the sound in seconds
Channelsmono = 1, stereo = 2

Knowledge point 2

Channels: mono and stereo

Mono

One channel of audio. Use channel factor `1`.

`rate × resolution × duration × 1`

Stereo

Two channels, commonly left and right. Use channel factor `2`.

`rate × resolution × duration × 2`

Chinese support: channel = 声道；mono = 单声道；stereo = 立体声/双声道。

Knowledge point 3

Unit conversion without changing the answer

Bits

The formula gives bits first.

Bytes

`8 bits = 1 byte`.

KiB

`1 KiB = 1024 bytes`.

MiB

`1 MiB = 1024 KiB`.

Do not divide by 1000 when the question asks for KiB or MiB.

Knowledge point 4

Parameter changes and consequences

Higher sampling rate

More samples per second; may improve accuracy; increases file size.

Higher sample resolution

More bits per sample; more amplitude levels; increases file size.

Longer duration

More seconds of samples; increases file size in direct proportion.

More channels

More separate audio streams; stereo doubles mono size when other factors match.

Mistake debugging

Find the missing factor

Stereo clip: `8000 × 16 × 10 = 1 280 000 bits`

Stereo has 2 channels, so multiply by 2: `8000 × 16 × 10 × 2 = 2 560 000 bits`.

`160 000 bytes = 160 KiB`

For KiB, divide by 1024: `160 000 ÷ 1024 = 156.25 KiB`.

Homework

Clear tasks

  1. Calculate the size in bytes of a 10-second stereo clip sampled at 8000 Hz with 16-bit sample resolution.
  2. Convert 160 000 bytes to KiB.
  3. Calculate the size in MiB of a 60-second stereo clip sampled at 44 100 Hz with 16-bit sample resolution.
  4. Write a 4-mark explanation of why a stereo sound file is larger than a matching mono sound file.

Task 1: `8000 × 16 × 10 × 2 = 2 560 000 bits = 320 000 bytes`.

Task 2: `160 000 ÷ 1024 = 156.25 KiB`.

Task 3: `44 100 × 16 × 60 × 2 = 84 672 000 bits = 10 584 000 bytes ≈ 10.09 MiB`.

Explanation focus: stereo stores two channels, so it stores twice as many sample values as mono when rate, resolution and duration match.
