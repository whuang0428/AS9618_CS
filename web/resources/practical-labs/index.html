Array traversal: from pupils to tests

Preparation: Lesson 061 · Lesson 062 · Lesson 077

Predict, run and amend

Predict the two row totals before running the starter. Then amend it to output one total for each test (column), in column order. Retain all six scores. Write the Cambridge pseudocode first, including the location where Total is reset.

Download starter: ArraysLab.java

javac ArraysLab.java
java ArraysLab
Read the runnable starter
import java.util.Scanner;

// Enter six integers: two pupils, three tests each, in row order.
public class ArraysLab {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int[][] scores = new int[2][3];
        for (int row = 0; row < scores.length; row++) {
            int total = 0;
            for (int column = 0; column < scores[row].length; column++) {
                scores[row][column] = input.nextInt();
                total += scores[row][column];
            }
            System.out.println(total);
        }
    }
}

Connect the code to the concept

Java indices start at 0. Pseudocode Scores[1,1] corresponds to Java scores[0][0] for this matrix. The inner loop restarts for every outer iteration. Read all input before traversing by columns.

Adapt a sort and preserve every value

Preparation: Lesson 064 · Lesson 074 · Lesson 077 · Lesson 078

Predict, run and amend

Trace the first ascending pass by hand. Run the starter, then change it to descending order without calling a sorting library. Keep the early-exit flag and zero-based bounds. Explain why duplicate values must remain and why an already sorted input still needs a checking pass.

Download starter: SortingLab.java

javac SortingLab.java
java SortingLab
Read the runnable starter
import java.util.Scanner;

public class SortingLab {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int[] values = new int[5];
        for (int index = 0; index < values.length; index++) {
            values[index] = input.nextInt();
        }
        int last = values.length - 1;
        boolean swapped = true;
        while (last > 0 && swapped) {
            swapped = false;
            for (int index = 0; index < last; index++) {
                if (values[index] > values[index + 1]) {
                    int temp = values[index];
                    values[index] = values[index + 1];
                    values[index + 1] = temp;
                    swapped = true;
                }
            }
            last--;
        }
        for (int value : values) {
            System.out.println(value);
        }
    }
}

Connect the code to the concept

Swap neighbouring values when the left value is smaller to obtain descending order. The smallest remaining value moves to the end of the active prefix. Reset the flag once per pass; use Index < Last because Index + 1 is also accessed.

Persistent files and blank lines

Preparation: Lesson 065 · Lesson 078

Predict, run and amend

Create a UTF-8 source.txt containing Ada, an empty line and Bo on separate lines. Predict the starter's count, run it to a new copy.txt, close the program and inspect the saved copy. Amend it to copy only non-empty lines, preserving their order, and count the lines actually written. Use a new output filename on each run.

Download starter: FilesLab.java

javac FilesLab.java
java FilesLab source.txt copy.txt
Read the runnable starter
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardOpenOption;

public class FilesLab {
    public static void main(String[] args) throws IOException {
        if (args.length != 2) {
            throw new IllegalArgumentException("Usage: java FilesLab source.txt new-copy.txt");
        }
        Path source = Path.of(args[0]);
        Path output = Path.of(args[1]);
        // CREATE_NEW prevents replacing either the source or an existing file.
        try (var reader = Files.newBufferedReader(source, StandardCharsets.UTF_8);
             var writer = Files.newBufferedWriter(output, StandardCharsets.UTF_8,
                     StandardOpenOption.CREATE_NEW, StandardOpenOption.WRITE)) {
            int count = 0;
            String line;
            while ((line = reader.readLine()) != null) {
                writer.write(line);
                writer.newLine();
                count++;
            }
            System.out.println(count);
        }
    }
}

Connect the code to the concept

BufferedReader.readLine() returns an empty string for a blank line and null at end of file. Those are different states. The supplied try-with-resources block closes both files, including when an error occurs. CREATE_NEW protects existing files; this starter deliberately refuses to overwrite them. Cambridge WRITE normally creates or replaces contents, while APPEND keeps earlier contents and adds at the end.

Validation, parameters and returned results

Preparation: Lesson 078 · Lesson 080 · Lesson 081 · Lesson 083

Predict, run and amend

Enter integers until three valid marks from 0 to 100 have been accepted. Predict the mean, run the starter, then additionally output the number of accepted marks at least 50. Invalid attempts must change neither result. Supply enough input to finish; handling non-integer tokens is outside this task.

Download starter: SubprogramsLab.java

javac SubprogramsLab.java
java SubprogramsLab
Read the runnable starter
import java.util.Scanner;

public class SubprogramsLab {
    static boolean valid(int mark) {
        return mark >= 0 && mark <= 100;
    }

    static int add(int total, int mark) {
        total = total + mark;
        return total;
    }

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int total = 0;
        for (int count = 0; count < 3; count++) {
            int mark;
            do {
                mark = input.nextInt();
            } while (!valid(mark));
            total = add(total, mark);
        }
        System.out.println(total / 3.0);
    }
}

Connect the code to the concept

Java passes all arguments by value. add receives copies of two integers; assigning its returned result to total changes the caller's variable. Calling add(total, mark) without using its return value leaves that caller variable unchanged. This is not Cambridge BYREF. Java do ... while (!valid(mark)) repeats on TRUE; Cambridge REPEAT ... UNTIL ValidMark(Mark) stops on TRUE. Use / 3.0 for a fractional Java mean.

import java.util.Scanner;

public class SubprogramsLab {
    static boolean valid(int mark) {
        return mark >= 0 && mark <= 100;
    }

    static int add(int total, int mark) {
        return total + mark;
    }

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int total = 0;
        int passed = 0;
        for (int count = 0; count < 3; count++) {
            int mark;
            do {
                mark = input.nextInt();

            total = add(total, mark);
            if (mark >= 50) {

            }
        }
        System.out.println(total / 3.0);
        System.out.println(passed);
    }
}

public class TestingLab {
