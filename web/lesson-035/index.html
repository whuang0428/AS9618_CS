Logic gates are tiny decision machines: no mood, no maybe, just 0 or 1.

This lesson introduces the six AS-level logic gates: NOT, AND, OR, NAND, NOR and XOR. You will read gate rules, complete truth tables, and translate ordinary conditions into Boolean logic.

Why this matters

Cambridge questions often combine gates. Students lose marks when they know gate names but cannot apply the exact output rule.

Common trap

OR means at least one input is 1. XOR means exactly one input is 1. They are not the same gate wearing different shoes.

Knowledge point 1

Logic gates use binary signals

0 False, off, no signal, condition not met
1 True, on, signal present, condition met
Input A value entering the gate, usually labelled A, B or C.
Output The result produced by the gate, often labelled Q or X.

One input. Bubble means inversion.

ANDFlat left, curved right

Mistake debugging

Fix the weak logic answer

"OR is true only when one input is true."

OR is true when at least one input is 1, so 01, 10 and 11 all produce 1. The phrase "only one" describes XOR, not OR.

"NAND means A and B, so it is true only when both are 1."

NAND is NOT AND. First find A AND B, then invert it. NAND is 0 only when both inputs are 1.

Homework

Clear tasks

  1. Write the truth table for each gate: NOT, AND, OR, NAND, NOR and XOR.
  2. Complete the full truth table for Q = (A AND B) OR NOT C, including intermediate columns.
  3. Write a 4-mark comparison of OR and XOR using exact input combinations.
  4. Create one real-life rule that uses AND and one that uses OR, then translate both into Boolean expressions.

Gate tables: NOT has two rows; the two-input gates have four rows: 00, 01, 10, 11.

Compound expression: include columns for A AND B, NOT C, then final OR.

OR vs XOR: OR gives 1 for 01, 10, 11; XOR gives 1 only for 01 and 10.

Expressions: keep variables short, such as Key, Exam, Rain, Sensor.
