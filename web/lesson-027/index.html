A computer system is not one magic box. It is a team with very specific jobs.

This lesson introduces the main parts of a computer system: input, processor, memory, storage and output. The aim is to classify hardware by purpose and explain how data moves through a system in a real scenario.

Data enters. Instructions run. Results leave. Files do not live inside the CPU.

Why this matters

Hardware questions often award marks for suitability. Naming a device starts the answer; matching its feature to the scenario earns it.

Common trap

RAM and secondary storage both hold data, but not in the same way. RAM forgets when power is off; storage is the more dependable librarian.

Knowledge point 1

The basic system flow

1. InputData is captured by an input device, such as a keyboard, sensor, scanner, camera or microphone.
2. ProcessingThe processor executes instructions and performs operations on data.
3. MemoryData and instructions in current use are held temporarily in primary memory such as RAM.
4. StorageFiles and data that must persist are saved in secondary storage such as SSD, HDD or optical media.
5. OutputResults are presented through output devices such as screens, speakers, printers or actuators.

Knowledge point 2

Component roles and examples

Input devices

Allow data to enter the system.

Examples: keyboard, mouse, barcode reader, touch screen, microphone, camera, sensor.

Output devices

Present data or results from the system.

Examples: monitor, speaker, printer, projector, actuator.

Processor

Executes instructions and coordinates operations. It processes data; it is not where user files are stored.

Primary memory

Stores instructions and data currently in use. RAM is volatile; ROM is non-volatile and stores startup instructions.

Secondary storage

Stores data and files long term, even when power is off.

Examples: SSD, HDD, optical disc, flash storage.

Interfaces

Hardware and software work together. A useful answer explains how the chosen device fits the user task.

Mistake debugging

Fix the weak hardware answer

"The CPU stores all the files."

The CPU processes instructions and data. Files are stored in secondary storage; data in current use may be held in memory.

"RAM and storage are the same because both hold data."

RAM is primary memory used for current tasks and is volatile. Secondary storage is non-volatile and keeps files long term.
