Security, privacy, integrity and the need for protection

01

Security, privacy and integrity

S6.01.A01

Visual overview

Ask a different question about each property

Data security protects data against unauthorised access, loss or damage. Privacy concerns who may access personal information and whether its collection, use or disclosure is appropriate. Data integrity concerns accurate, complete and consistent information during storage, processing and transfer. A security control may support privacy or integrity, but the terms describe different questions.

Use consequences rather than exclusive labels

If an unchanged medical record is sent to an unauthorised advertiser, its disclosure affects privacy and security even though its contents have not been corrupted. Conversely, a permitted employee can enter the wrong date in a protected file. The access restriction worked, but the stored date is inaccurate. Do not infer an integrity failure merely because an incident was serious.

Unpack integrity

Check accuracy against the intended fact, completeness against the required information, and consistency between values that should agree. A missing examination mark makes the result set incomplete; two stored totals that should agree but differ are inconsistent. Rules, source comparisons and controlled updates address different causes. Lesson 037 develops the checking methods.

Worked example · Four independent events involving a source mark of 46

  1. Starting condition

    A verified source records 46. Each case below starts independently from a correct saved record and a working service.

  2. Disclosure

    An employee sends the unchanged named record to an unauthorised recipient. Privacy and security are affected; this fact alone does not show lost integrity.

  3. Mistyped update

    An authorised teacher enters 64 instead of 46. The stored mark is inaccurate despite successful access control.

  4. System failure

    The correct file remains on storage, but its application cannot start. The authorised user cannot use the service; this does not establish a changed mark.

  5. Only copy deleted

    The correct saved record is erased with no backup. Data is lost; the system can no longer provide a complete set of results.

  6. Choose protection

    Restrict and review disclosure; compare entries with sources; restore a working system; maintain a separate recoverable copy. These address different failure mechanisms.

Core explanation · Exam essentials

  • Security protects against unauthorised access, loss and damage; privacy concerns appropriate use and disclosure of personal data.
  • Integrity concerns accuracy, completeness and consistency. Judge each consequence; one incident can affect several properties.
Common misconception

One incident may affect more than one property; the terms are not interchangeable.

Check your understanding

A correct total is copied to an unauthorised recipient. Must integrity have failed?

Check your answer

No. Unauthorised disclosure affects privacy/security, but unchanged accurate contents do not establish an integrity failure. Explain the property from the actual event.

Protect the data and its processing system

Keep both protection targets in view

Data is the information being protected; the computer system supplies the hardware, operating system and applications needed to use it. Protecting a file alone does not keep that processing environment trustworthy or available. Malware could stop an application, or misuse an already authenticated session to read data after the application decrypts it.

Follow data beyond the original computer

Also follow the copies. A locked server room protects one physical location, not a readable export on a lost removable drive. Controls must suit data at rest, data in transit and data in use. These describe where or how the data is being handled, not three new encryption algorithms.

Explain why recovery belongs alongside prevention

Recovery needs a usable copy and a functioning destination. A backup left on the failed disk may be unavailable with the working data. A tested separate backup can restore a chosen saved state, but not later changes it never captured. Lesson 029 teaches backup operation; here the point is why protection must include continued use and recovery.

Worked example · Restore a clinic service from a stated recovery point

  1. Before failure

    At 09:00 a separate protected backup holds verified appointment records. At 09:30 malware prevents the clinic computer from starting. No later appointments have been entered.

  2. What encryption achieved

    The protected archive can remain unreadable to a person without its key; this does not start the failed application.

  3. Restore

    Use a trusted repaired or replacement system with a compatible application; restore the available 09:00 records and recover access with the authorised key.

  4. Check the result

    Open the application and compare the restored records with the known 09:00 state. Staff can again use those appointments.

  5. Change the condition

    If appointments had been added at 09:20 without another backup, the 09:00 copy would not recover those additions.

Core explanation · Exam essentials

  • Protect every relevant data copy and the computer system that processes it.
  • Confidentiality, a functioning service and recoverable data require complementary measures.
Common misconception

Confidentiality alone is not enough when the service is unusable.

Check your understanding

Does locking the computer room protect a data copy sent to the wrong recipient?

Check your answer

No. Physical protection of the computer does not control a copy after disclosure.

Practice questions

3 core tasks · 7 teacher marks · 9–13 minutes (teacher estimate). Explain your reasoning before checking the answer.

Question 1 · Command word: Identify3 teacher marks

Identify the principal concern and explain the consequence in each independent case: a school publishes unchanged private medical details; an authorised teacher enters 82 instead of source mark 28; an intruder deletes the only copy of required records. State whether the first incident necessarily establishes lost integrity.

S6.01.A01
Answer and checking points — teacher-written
  1. The first incident affects privacy and security through unauthorised disclosure; unchanged accurate contents do not by themselves establish an integrity failure.
  2. The incorrect mark affects integrity because the recorded value differs from the source, even though the teacher may edit it.
  3. Deleting the only copy causes unauthorised data loss and removes required information; the incident is a security failure and can leave the records incomplete.

Common error: These properties are not mutually exclusive labels. Tie each claim to the stated consequence.

Question 2 · Command word: Explain2 teacher marks

Explain why password protection does not ensure that an entered examination mark is accurate. Give an example of a protected but inaccurate value.

S6.01.A01
Answer and checking points — teacher-written
  1. A password restricts access but does not compare the entered mark with its source.
  2. For example, an authorised teacher may enter 64 instead of the actual 46.

Common error: A password is not a validation or verification check.

Question 3 · Command word: Explain2 teacher marks

Explain why a company must protect its computer system as well as encrypt its stored customer files. Give two different consequences of system compromise.

S6.02.A01
Answer and checking points — teacher-written
  1. Malware may prevent authorised staff from running the customer application.
  2. An attacker controlling an authenticated session may read or alter data after the application decrypts it.

Common error: Relate the consequence to the running system rather than repeating that data is valuable.

Optional consolidation · 1 tasks · 2 teacher marks

Choose a task when you need another check of this idea.

Question 1 · Command word: Explain2 teacher marks

Explain why securing a server room is insufficient when staff carry unencrypted copies of records on removable drives.

S6.02.A01
Answer and checking points — teacher-written
  1. The removable copy is outside the protection of the server room.
  2. Someone finding the drive can read its contents unless the copy itself is protected.

Common error: Consider the location of each copy.

Original question · Cambridge 9618/12

1. Separate privacy from integrity

Cambridge 9618/12 · October/November 2023 · 5(a), 5(b) · 2 marks

Selected parts: 5(a) [1]; 5(b) [1].

Reading the question — teacher guidance

These are two one-mark definitions. State the essential property of each; examples of attacks are not required.

Solution / model answer — teacher-written

5(a): Privacy means that data is accessed by or disclosed to authorised people only.

5(b): Integrity means that data remains accurate, complete and consistent during and after processing.

Official mark scheme
Why this earns marks — teacher explanation

Each subpart has a one-mark maximum. The scheme also accepts data being up to date for integrity; listing all acceptable words does not multiply the mark.

Common mistakes — teacher analysis

Data can be accurate but disclosed to the wrong person, or kept private but entered incorrectly. These properties are independent.
