Security, privacy, integrity and the need for protection

01

Concept teaching

Visual overview and core explanation

01

Data security, privacy and integrity

S6.01.A01

Visual overview

Core explanation

Data security is protection against unauthorised access, loss or damage. Privacy concerns appropriate collection, use and disclosure of personal data. Integrity means data remains accurate, complete and unaltered except by authorised processes.

The concepts overlap but are not synonyms: encrypted inaccurate data may be secure but lack integrity; authorised publication may preserve integrity while violating privacy.

Both data security and computer-system security are necessary. Protecting only a data file is insufficient if an attacker can control the operating system, install malware, steal credentials or make the computer system unavailable; protecting only the device is insufficient if copied data is disclosed, altered or lost.

Common misconception

Security protects assets, privacy governs appropriate personal-data use, and integrity concerns accuracy and consistency. The three terms overlap but are not synonyms.

02

The need for data and computer-system security

S6.02.A01

Visual overview

Core explanation

Both data security and computer-system security are necessary. Protecting only a data file is insufficient if an attacker can control the operating system, install malware, steal credentials or make the computer system unavailable; protecting only the device is insufficient if copied data is disclosed, altered or lost.

Data security is protection against unauthorised access, loss or damage. Privacy concerns appropriate collection, use and disclosure of personal data. Integrity means data remains accurate, complete and unaltered except by authorised processes.

The concepts overlap but are not synonyms: encrypted inaccurate data may be secure but lack integrity; authorised publication may preserve integrity while violating privacy.

Common misconception

Computer-system security is needed for confidentiality, integrity and availability; protecting secrecy alone does not keep a system reliable or usable.

Practice questions

Command word: Compare5 marks

Compare data security, privacy and integrity, then explain why both data and its computer system require security.

S6.01.A01S6.02.A01
Answer and marking points
  1. security protects against unauthorised access/loss/damage.
  2. privacy controls appropriate personal-data use/disclosure.
  3. integrity concerns accuracy/completeness/authorised change.
  4. computer-system compromise can expose/alter/destroy data or prevent authorised access.
  5. data-specific and system controls are both required / one does not replace the other.

Common error: For the command word compare, perform that exact action; do not replace it with an unrelated fact.

Command word: Explain2 marks

Explain why must the computer system also be protected?

S6.02.A01S6.01.A01
Answer and marking points
  1. A compromised or unavailable system can expose, alter, delete or prevent access to the data it processes, even when a stored file has a separate protection such as encryption.
