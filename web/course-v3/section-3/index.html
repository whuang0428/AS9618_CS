Section 3 / Hardware

Follow the data.
Understand the machine.

Start with a familiar system. Look inside its devices, follow changes in memory, then use feedback and logic to explain its decisions.

Start the hardware journey →

A route through hardware

01

Follow data through a computer

You already know how data is represented and transferred. Now follow a recording from its first input to a saved file, and discover why a computer needs several different kinds of hardware.

02

See how devices turn data into physical effects

Work through one device family at a time. Start with recording and playback, follow saved data into three storage technologies, then investigate printing and interactive displays.

03

Choose memory for the job

A saved file, a waiting data block and a current calculation need different treatment. Separate the job memory performs from the technology used to build it.

04

Measure a condition, then decide whether to change it

Begin with a sensor reading. Distinguish reporting a condition from acting on it, then close the loop by measuring the real outcome.

05

Build decisions from logic gates

Start with exact conditions, then learn the gate symbol and complete truth table for each rule. Here 1 represents TRUE or high, and 0 represents FALSE or low.

06

Move between words, expressions, circuits and tables

These four forms describe the same rule. Learn a reliable route from each starting form, then verify the result against every original input case.
