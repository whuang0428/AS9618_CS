Core explanation

A state-transition diagram documents an algorithm by showing persistent states and the events that cause changes between them.

The purpose of state-transition diagrams to document an algorithm.

Common misconception

A state-transition diagram shows states and event/condition-labelled transitions; it does not replace a flowchart for every processing step.

Command word: State2 marks

State two precise facts about state-transition diagrams.

S12.03.A01
Answer and marking points
  1. it does not require candidates to construct a state-transition diagram.
  2. A structure chart documents decomposition into modules, procedures and functions.
  3. Boxes name modules.
  4. hierarchy lines show which module calls another.
  5. labelled arrows show data or control parameters passed between them.
  6. Its purpose is to communicate modular structure and interfaces before coding.

Common error: Do not copy the worked example unchanged; transfer the method and check it against the new context.
