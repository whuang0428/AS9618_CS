Selecting and using one-dimensional arrays

Retain an indexed sequence of values and process it with a complete loop.

When is one index enough, and how do we process every element?

Before you start

A program records one mark for each of four tests. How many indices identify a mark?

Check your answer

One: the test number. A 1D array is suitable.

Use one index for one independent position

Core explanation

Choose a one-dimensional array when one index identifies each item, such as a test number selecting one mark. The declaration must provide enough positions and an element type suitable for all values. For four whole-number marks, DECLARE Marks : ARRAY[1:4] OF INTEGER gives one element per test.

An array retains individual values for later indexed access. If a task requires only a running total, a total variable alone may be enough; retaining an array is justified when later processing needs the original marks, for example displaying the third test mark after all inputs have been read.

Common misconception

A long list is still one-dimensional if each element is selected using one index.

Check your understanding

Why retain marks after calculating their total?

Check your answer

The program may later need an individual mark, such as Marks[3], without asking for the input again.

Core explanation

Initialise Total once before the traversal. Each iteration inputs a value into Marks[Index], then adds that same element to Total. FOR Index <- 1 TO 4 visits both bounds, and NEXT Index closes the count-controlled loop. No DO keyword is used in this FOR form.

Keeping the final OUTPUT after the loop produces one total for all four elements. OUTPUT Marks[3] then demonstrates that the third value remains available. Moving Total <- 0 inside the loop would discard the contributions from earlier elements.

Worked example · Store four marks and report their total

  1. Task

    Read four INTEGER marks into a 1D array. Display their total, followed by the third mark.

  2. Pseudocode
    DECLARE Marks : ARRAY[1:4] OF INTEGER
DECLARE Index : INTEGER
DECLARE Total : INTEGER
Total <- 0
FOR Index <- 1 TO 4
    INPUT Marks[Index]
    Total <- Total + Marks[Index]
NEXT Index
OUTPUT Total
OUTPUT Marks[3]
  3. Result

    Inputs 6, 9, 4, 7 produce 26 and 4.

Common misconception

INPUT Value without saving Value into the indexed element does not populate the array.

Check your understanding

What total would the example produce if Total were reset immediately before every addition?

Check your answer

Only the final mark, 7, would remain in Total.

Question 1 · Command word: Select2 marks

A club stores one attendance count for each of 12 meetings. Select a structure and write its declaration.

S10.04.A01
Answer and marking points
  1. A 1D array is suitable because meeting number selects one count.
  2. DECLARE Attendance : ARRAY[1:12] OF INTEGER.

Common error: The number of meetings determines capacity, not the number of dimensions.

Question 2 · Command word: State2 marks

State the Total after each iteration and both outputs from the supplied array-total algorithm for inputs 5, 0, 8, 2.

Use this complete algorithm in the question.

DECLARE Marks : ARRAY[1:4] OF INTEGER
DECLARE Index : INTEGER
DECLARE Total : INTEGER
Total <- 0
FOR Index <- 1 TO 4
    INPUT Marks[Index]
    Total <- Total + Marks[Index]
NEXT Index
OUTPUT Total
OUTPUT Marks[3]
S10.05.A01
Answer and marking points
  1. The successive totals are 5, 5, 13 and 15.
  2. The outputs are 15 and 8.

Common error: The second output reads index 3, not the final element.

Question 3 · Command word: Write4 marks

Write pseudocode to input four INTEGER marks into Marks[1:4], then output their total and the third mark. Explain where Total is initialised.

S10.05.A01
Answer and marking points

One valid pseudocode solution

DECLARE Marks : ARRAY[1:4] OF INTEGER
DECLARE Index : INTEGER
DECLARE Total : INTEGER
Total <- 0
FOR Index <- 1 TO 4
    INPUT Marks[Index]
    Total <- Total + Marks[Index]
NEXT Index
OUTPUT Total
OUTPUT Marks[3]
  1. Declare the array and INTEGER Index and Total.
  2. Set Total to zero before a FOR loop from 1 to 4.
  3. Input Marks[Index] and add it to Total on each iteration.
  4. After NEXT Index, output Total and Marks[3].

Common error: Initialise the accumulator outside the loop.

Question 1 · Command word: Select · 3 marks

A sensor stores eight fractional pressure readings and later displays reading 6. Select and declare an appropriate array, and write the statement that displays the requested value.

Answer and marking points
  • Use a one-dimensional array because reading number alone identifies a value.
  • DECLARE Pressure : ARRAY[1:8] OF REAL.
  • OUTPUT Pressure[6].

Common error: Measured pressures may need a fractional part.

Question 2 · Command word: Write · 5 marks

Write pseudocode to input four REAL masses into Mass[1:4] and output the largest. All inputs may be negative in a calibration test.

Answer and marking points

One valid pseudocode solution

DECLARE Mass : ARRAY[1:4] OF REAL
DECLARE Index : INTEGER
DECLARE Largest : REAL
FOR Index <- 1 TO 4
    INPUT Mass[Index]
NEXT Index
Largest <- Mass[1]
FOR Index <- 2 TO 4
    IF Mass[Index] > Largest THEN
        Largest <- Mass[Index]
    ENDIF
NEXT Index
OUTPUT Largest
  • Declare a REAL array, INTEGER index and REAL largest value.
  • Read all four elements using their valid indices.
  • Initialise Largest from Mass[1].
  • Compare elements 2 to 4 and replace Largest only for a greater value.
  • Output Largest after completing the comparisons.

Common error: Initialising the maximum to zero fails when all readings are negative.

Question 3 · Command word: State · 3 marks

The array Cost[1:3] contains 2.5, 4.0 and 1.5. An algorithm sets Total to 0 inside its loop immediately before adding Cost[Index]. State its final Total and describe the correction needed to obtain the sum.

Answer and marking points
  • Its final Total is 1.5 because previous additions are erased.
  • Initialise Total once before iterating from 1 to 3.
  • The corrected final sum is 8.0.

Common error: Adding another output does not repair the misplaced initialisation.

04

Lesson review

Summary

Selection

Use a 1D array when one index identifies every retained value.

Traversal

Input or process each indexed element within the declared bounds and initialise a total before the loop.

Maximum

Initialising a maximum from an actual element also works when every value is negative.
