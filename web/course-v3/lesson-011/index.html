LAN hardware, routers and Ethernet

Follow one frame or packet through each device, then model how shared Ethernet handles a collision.

A laptop reaches a school server and then the internet. Which device connects it, which device forwards inside the LAN, which crosses the network boundary, and what happens if two stations transmit together on a shared Ethernet medium?

Before you start

Which device forwards frames inside a LAN, and which forwards packets between networks?

Check your answer

A switch forwards frames inside a LAN; a router forwards packets between networks using destination IP information.

01

Every LAN device has a specific job

S2.09.A01S2.09.A02S2.09.A03

Visual overview

Establish the concept

A NIC connects a device to a wired network; a WNIC connects it wirelessly. A wireless access point (WAP) bridges wireless devices into the wired LAN. Cables carry signals between wired interfaces.

A switch learns and uses link-layer addresses to forward frames to the required LAN port. A server provides network services or resources such as authentication, files, printing or web content.

These devices perform different jobs even when several functions share one physical case. Name the device and the exact forwarding, connection or service role it performs.

Give each device one clear responsibility

ComponentRole in this LAN
NIC / WNICConnects a device to the network through a wired / wireless interface. The link uses its MAC address.
WAPProvides wireless access and bridges traffic into the wired LAN; it does not inherently replace a router.
CablingCarries signals on each physical wired link, including the independent switch links.
ServerProvides an application or shared resource; its NIC still needs a network connection.
SwitchUses destination MAC information and its forwarding table to select a LAN output port.

Swipe horizontally to compare every column →

Local request and response with a known table

  1. Given state: Laptop MAC L is reachable via WAP on switch p1; desktop D on p2; server S on p3; gateway on p4. The laptop already knows S’s address and the forwarding table is correct.
  2. Send request: The laptop sends a frame addressed to S through its WNIC and WAP. The frame enters the switch on p1.
  3. Forward: The switch finds S on p3 and forwards the frame there. It does not send this known unicast frame to every port.
  4. Return result: The server sends a response frame addressed to L. It enters p3; the table selects p1; WAP delivers it to the laptop by radio.
  5. Check the boundary: The router is not needed for this same-LAN exchange. If an address is not yet known, extra discovery/forwarding behaviour would be needed; that is not silently assumed in this trace.

Core explanation · Exam essentials

  • NIC/WNIC supplies the interface; WAP supplies wireless access; a server provides the service.
  • A switch forwards a known local unicast frame using its destination MAC and port table.
Common misconception

A WAP provides wireless LAN access; it is not simply another name for the router.

Check your understanding

Why is p4 not used for the example laptop-to-server request?

Check your answer

The destination server is on the same LAN via p3. The gateway on p4 is not needed for this local delivery.

02

A bridge connects and filters between LAN segments

S2.09.A04

Visual overview

Establish the concept

A bridge connects LAN segments and learns which link-layer or MAC addresses are reachable through each side. It uses that information to decide whether a frame needs to cross the bridge.

A frame whose destination remains on its source segment is filtered rather than copied to the other segment. A frame required on the other segment is forwarded across the bridge.

A bridge makes a link-layer forwarding decision inside a LAN; it does not replace the router that forwards IP packets between different networks.

Filter one frame; forward another

  1. Given state: A and B occupy the left segment, attached through bridge port 1. C occupies the right segment through port 2. The learned table contains A→1, B→1 and C→2.
  2. A sends to B: The bridge receives the frame on port 1. B is also on port 1, so the bridge filters it: no copy crosses to port 2. B can receive the frame on the left segment.
  3. A sends to C: The next frame arrives on port 1 but C is known on port 2. The bridge forwards it through port 2, where C receives it.
  4. Consequence: Local traffic need not consume the other segment. Filtering here is a destination-based forwarding decision, not a firewall rule rejecting an unauthorised user.

Connect the devices without merging their jobs

A bridge joins LAN segments and decides which frames need to cross. A switch applies the same broad link-level forwarding principle across multiple ports. Both decisions differ from a router choosing the next network using an IP destination.

Core explanation · Exam essentials

  • A bridge uses destination MAC location to filter local-segment traffic or forward it across segments.
  • Filtering at the bridge does not prevent delivery within the original segment.
Common misconception

A bridge connects LAN segments and filters frames; it is not the router for every external network.

Check your understanding

C sends to A with the same known table. What does the bridge do?

Check your answer

It receives on port 2, finds A on port 1 and forwards through port 1.

03

A repeater regenerates a weakened signal

S2.09.A04

Visual overview

Establish the concept

As a signal travels through a medium, attenuation and distortion can make it too weak or unclear to continue reliably. A repeater receives that weakened signal and regenerates the intended signal pattern.

The restored signal is retransmitted so it can travel farther along the network medium. The repeater extends the usable transmission distance; it does not create a new destination.

A repeater does not inspect a MAC or IP destination and does not choose a route. Its job is signal regeneration rather than selective forwarding.

Why regeneration is needed

As a signal travels, attenuation weakens it and distortion can make its states harder to distinguish. A repeater receives a still-decodable signal and regenerates it for the next segment, restoring its usable shape and strength rather than merely amplifying every disturbance. It must be placed where the incoming signal is still recoverable.

Trace the useful case and its boundary

Suppose the first segment delivers a weakened but readable binary signal. The repeater recognises the bits, emits regenerated signalling onto the next segment, and the receiving device obtains the carried data. If the incoming signal is too corrupted to decode correctly, regeneration cannot infer the originally intended bits. A repeater also cannot choose a less congested route or supply missing service capacity.

Core explanation · Exam essentials

  • A repeater regenerates a weakened but recoverable signal to extend a link.
  • It does not filter by destination or route between IP networks.
Common misconception

A repeater regenerates a signal; it does not forward frames by address or route packets.

Check your understanding

Can a repeater choose whether the destination is on the left or right LAN?

Check your answer

No. It regenerates signals; a bridge or switch makes link-level destination decisions.

04

The router crosses a network boundary

S2.10.A01S2.10.A02

Visual overview

Establish the concept

A router connects different networks. It inspects the destination IP address, consults routing information and forwards the packet toward the next network or next hop.

A switch normally decides which LAN port should receive a frame; a router decides which network path should receive a packet. A home device may combine switch, WAP, router and modem functions in one case, but the roles remain distinct.

Send from this LAN to a server on another network

  1. Given state: The laptop has determined that the server’s IP is outside its local subnet. The gateway’s MAC address and a valid onward route are already known; assume no NAT in this private-network example.
  2. Local link: The IP packet names the remote server as destination. Its LAN frame instead names the gateway interface as immediate destination and travels WNIC → WAP → switch p1 → p4 → router.
  3. Network boundary: The router reads the destination IP, consults its routing information and forwards towards the destination network in an appropriate outgoing link frame. Link-level recipient information can change at a boundary.
  4. Delivery and response: On the destination network, the packet reaches the server. The reply names the original laptop as destination and uses suitable return routes; on the home LAN the gateway sends towards L via switch p4 → p1 → WAP.

Prepare the next lesson without hiding the mechanism

The destination network decision is introduced here and calculated with an address and subnet mask in Lesson 014. Routing does not imply that the router stores the requested web page, converts every access signal like a modem, or always changes the IP destination into the gateway’s address.

Core explanation · Exam essentials

  • A router forwards between networks using destination IP and routing information.
  • For a remote packet, the immediate LAN recipient is the gateway while the final IP destination is the remote host.
Common misconception

A router does not replace the switch’s internal LAN forwarding role.

Check your understanding

For a remote request, is the destination IP replaced with the gateway IP?

Check your answer

No in the routing example. The gateway is the immediate link-level recipient; the packet’s destination remains the remote server.

05

CSMA/CD detects a collision, stops, waits and retries

S2.11.A01S2.11.A02S2.11.A03

Visual overview

Establish the concept

Ethernet (IEEE 802.3) carries data in frames on many wired LANs. On a traditional shared or half-duplex Ethernet medium, two stations can begin transmitting close together and their signals can collide.

CSMA/CD means Carrier Sense Multiple Access with Collision Detection. A station listens first, transmits if the medium is idle, monitors for collision, stops and sends/recognises a jam signal if a collision occurs, waits for a random backoff period and then tries again.

Independent random waits reduce the chance that both stations retry at the same instant, but the selected waits may be equal and another collision may occur. CSMA/CD does not guarantee that a collision never happens; modern switched full-duplex Ethernet normally gives separate collision-free links, but the syllabus mechanism models the shared-medium case.

Explain why an idle check is insufficient

Two stations on a shared half-duplex medium can both sense idle and start nearly together. The first signal takes time to reach the other station, so carrier sensing cannot prevent every collision. While transmitting, each station monitors the medium; detecting a collision shows that the current attempt cannot be relied on.

Trace a collision to two successful transmissions

  1. Sense and start: A and B each observe idle before the other’s signal arrives and begin transmitting. The signals overlap on the shared medium.
  2. Detect and stop: They detect the collision, stop the attempted frames and send a jam signal so the collision is recognised.
  3. Choose waits: Each chooses a random backoff. In this selected attempt A has a shorter wait; the waits are not guaranteed to differ.
  4. A retries: When its wait ends, A senses again. The medium is idle, so A transmits while monitoring for another collision. This time it completes.
  5. B defers and retries: If B’s wait ends while A is transmitting, B must defer because the medium is busy. Once idle under the access rules, B can retry and complete.
  6. Equal-wait boundary: If both choose the same wait and start together again, another collision is possible; they detect it and repeat the backoff process. Random delay reduces repeated conflict but does not guarantee the next attempt succeeds.

Core explanation · Exam essentials

  • CSMA/CD senses, transmits while monitoring, detects collision, stops/jams, waits randomly and senses again.
  • Apply it to shared half-duplex Ethernet, not modern switched full-duplex links.
Common misconception

Carrier sensing reduces risk but cannot prevent two near-simultaneous transmissions from colliding.

Check your understanding

A station’s random wait expires while another is transmitting. Must it transmit immediately?

Check your answer

No. It senses a busy medium and defers. Timer expiry alone is not permission to transmit.

Question 1 · Command word: Explain6 teacher marks

A student describes shared Ethernet as follows: “Transmit immediately without listening. Check for a collision only after sending the whole frame. After a collision, every station waits exactly the same fixed time and retries immediately.” Explain three errors in this description of CSMA/CD, giving a correction and its purpose for each.

S2.11.A01S2.11.A02S2.11.A03
Answer and checking points — teacher-written
  1. Sense the shared medium and transmit only if it is idle.
  2. Listening avoids starting a transmission while another station is already using the medium.
  3. Monitor during transmission; if a collision is detected, stop and send a jam signal.
  4. This stops sending a corrupted frame and ensures stations recognise the collision.
  5. Choose an independent random backoff, then sense the medium again before retrying.
  6. Randomisation reduces repeated simultaneous retries; it cannot guarantee that the two waits differ.

Common error: Collision detection must operate during transmission, and a completed wait does not make a busy medium free.

Question 2 · Command word: Describe4 teacher marks

Describe both directions of a local exchange. A switch already knows MAC L via WAP on p1 and server MAC S on p3; a router is on p4. The laptop already knows S’s MAC. State the incoming and outgoing switch ports for the request and response, and explain why the router is unused.

S2.09.A01S2.09.A02S2.09.A03S2.10.A02
Answer and checking points — teacher-written
  1. The laptop sends through its WNIC and WAP, so the request frame enters p1.
  2. The known destination S selects output p3.
  3. The server response addressed to L enters p3 and is forwarded through p1, then WAP to the laptop.
  4. The server is on the same LAN, so this exchange does not cross a routed network boundary.

Common error: The response also needs a complete path; do not send the local request through the router.

Question 3 · Command word: Explain5 teacher marks

Explain why two shared half-duplex Ethernet stations can collide after both sense idle. After the collision, A chooses a shorter random wait than B. B’s wait ends while A is transmitting. Describe B’s next action and what could happen if both had chosen the same wait.

S2.11.A01S2.11.A02S2.11.A03
Answer and checking points — teacher-written
  1. Signal propagation takes time, allowing each station to sense idle before the other’s transmission arrives.
  2. After detecting collision, each stops its attempted frame and sends a jam signal.
  3. Each selects a random backoff before retrying.
  4. B senses again; because A is transmitting, B defers until the medium becomes available under the access rules.
  5. Equal waits can lead to simultaneous retries and another collision; random backoff reduces but cannot eliminate that possibility.

Common error: Wait expiry does not override carrier sensing; this scenario is not full-duplex switched Ethernet.

Original question · Cambridge 9618/12

1. Describe Ethernet beyond the cable

Cambridge 9618/12 · May/June 2023 · 1(d) · 3 marks

Selected parts: 1(d) [3].

Reading the question — teacher guidance

Ethernet is a communication standard/protocol family. Supply technical features of transmission, not merely a cable name.

Solution / model answer — teacher-written

Ethernet is a protocol suite for transmitting data over standard wired network connections. It carries data in frames. Frames include source and destination addressing and error-checking information.

Official mark scheme
Why this earns marks — teacher explanation

The scheme awards up to three marks from its listed features. Protocol suite, standard wired connections and transmission in frames provide three distinct points. Its CSMA/CD alternative applies to shared half-duplex Ethernet; switched full-duplex links do not use collision detection to arbitrate normal traffic.

Common mistakes — teacher analysis

Do not define all networking, Wi-Fi or internet access as Ethernet. In an Ethernet frame the link-layer source and destination are MAC addresses; do not teach the scheme’s broad IP/MAC wording as a rule that IP and MAC are interchangeable.

Original question · Cambridge 9618/12

2. Sequence collision-handling tasks

Cambridge 9618/12 · October/November 2023 · 7(c) · 3 marks

Selected parts: 7(c) [3].

Reading the question — teacher guidance

The question asks for three tasks in CSMA/CD. Choose actions, and keep the order of detection, stopping and retrying coherent.

Solution / model answer — teacher-written

Monitor the shared communication channel and transmit only when it is idle.

If a collision is detected, stop the data transmission and send a jamming signal.

Calculate a random back-off delay before attempting retransmission; check the channel again before sending.

Official mark scheme
Why this earns marks — teacher explanation

The scheme awards a maximum of three marks from the listed channel-monitoring, collision and retry actions. A sentence can contain more than one listed action; sentence count is not the marking rule.

Common mistakes — teacher analysis

An identical fixed delay can make both devices collide again. Waiting does not grant permission to transmit into a busy channel.
