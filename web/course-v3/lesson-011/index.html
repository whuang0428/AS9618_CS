LAN hardware, routers and Ethernet

Follow one frame or packet through each device, then model how shared Ethernet handles a collision.

A laptop reaches a school server and then the internet. Which device connects it, which device forwards inside the LAN, which crosses the network boundary, and what happens if two stations transmit together on a shared Ethernet medium?

Before you start

Which device forwards frames inside a LAN, and which forwards packets between networks?

Check your answer

A switch forwards frames inside a LAN; a router forwards packets between networks using destination IP information.

Teaching checkpoints
  • After the router unit, use Q1, Q2 and Q4 to check device functions and a complete path across two networks. In the router diagram, the two /24 labels identify different subnets; prefix calculations are taught in the addressing lesson.
  • Teach Ethernet and CSMA/CD separately. Use Q3 to diagnose errors before attempting the complete collision-and-retry explanation in Exam Question 3.

01

Concept teaching

Visual overview and core explanation

01

Every LAN device has a specific job

S2.09.A01S2.09.A02S2.09.A03

Visual overview

Core explanation

A NIC connects a device to a wired network; a WNIC connects it wirelessly. A wireless access point (WAP) bridges wireless devices into the wired LAN. Cables carry signals between wired interfaces.

A switch learns and uses link-layer addresses to forward frames to the required LAN port. A server provides network services or resources such as authentication, files, printing or web content.

These devices perform different jobs even when several functions share one physical case. Name the device and the exact forwarding, connection or service role it performs.

One wireless request to a local server

  1. Laptop WNICCreates the wireless network connection
  2. WAPConnects the wireless device into the wired LAN
  3. SwitchForwards the frame to the server port
  4. ServerChecks access and provides the requested resource
Common misconception

A WAP provides wireless LAN access; it is not simply another name for the router.

02

A bridge connects and filters between LAN segments

S2.09.A04

Visual overview

Core explanation

A bridge connects LAN segments and learns which link-layer or MAC addresses are reachable through each side. It uses that information to decide whether a frame needs to cross the bridge.

A frame whose destination remains on its source segment is filtered rather than copied to the other segment. A frame required on the other segment is forwarded across the bridge.

A bridge makes a link-layer forwarding decision inside a LAN; it does not replace the router that forwards IP packets between different networks.

Common misconception

A bridge connects LAN segments and filters frames; it is not the router for every external network.

03

A repeater regenerates a weakened signal

S2.09.A04

Visual overview

Core explanation

As a signal travels through a medium, attenuation and distortion can make it too weak or unclear to continue reliably. A repeater receives that weakened signal and regenerates the intended signal pattern.

The restored signal is retransmitted so it can travel farther along the network medium. The repeater extends the usable transmission distance; it does not create a new destination.

A repeater does not inspect a MAC or IP destination and does not choose a route. Its job is signal regeneration rather than selective forwarding.

Signal regeneration

  1. ReceiveAccept the weakened signal after transmission loss
  2. RegenerateRestore the intended signal pattern
  3. RetransmitSend the restored signal farther along the medium
Common misconception

A repeater regenerates a signal; it does not forward frames by address or route packets.

04

The router crosses a network boundary

S2.10.A01S2.10.A02

Visual overview

Core explanation

A router connects different networks. It inspects the destination IP address, consults routing information and forwards the packet toward the next network or next hop.

A switch normally decides which LAN port should receive a frame; a router decides which network path should receive a packet. A home device may combine switch, WAP, router and modem functions in one case, but the roles remain distinct.

From LAN to another network

  1. HostRecognises the destination is not local
  2. Switch/WAPCarries the frame to the default router
  3. RouterReads destination IP and consults routing information
  4. Next networkPacket is forwarded on the selected route
Common misconception

A router does not replace the switch’s internal LAN forwarding role.

05

CSMA/CD detects a collision, stops, waits and retries

S2.11.A01S2.11.A02S2.11.A03

Visual overview

Core explanation

Ethernet (IEEE 802.3) carries data in frames on many wired LANs. On a traditional shared or half-duplex Ethernet medium, two stations can begin transmitting close together and their signals can collide.

CSMA/CD means Carrier Sense Multiple Access with Collision Detection. A station listens first, transmits if the medium is idle, monitors for collision, stops and sends/recognises a jam signal if a collision occurs, waits for a random backoff period and then tries again.

Independent random waits reduce the chance that both stations retry at the same instant, but the selected waits may be equal and another collision may occur. CSMA/CD does not guarantee that a collision never happens; modern switched full-duplex Ethernet normally gives separate collision-free links, but the syllabus mechanism models the shared-medium case.

CSMA/CD timeline

  1. Carrier senseListen to the shared medium
  2. TransmitSend only when it appears idle
  3. DetectMonitor while transmitting
  4. Stop / jamStop when collision is detected and ensure stations recognise it
  5. Random backoffEach station waits for an independently selected random backoff period
  6. RetrySense again, then retransmit when allowed
Common misconception

Carrier sensing reduces risk but cannot prevent two near-simultaneous transmissions from colliding.

Command word: Describe8 marks

Describe one LAN role of each of the following: switch, server, NIC, WNIC, WAP, cable, bridge and repeater.

S2.09.A01S2.09.A02S2.09.A03S2.09.A04
Answer and marking points
  1. A switch forwards frames to the required LAN port.
  2. A server provides a shared service or resource to clients.
  3. A NIC provides the device interface to a wired network.
  4. A WNIC provides the device interface to a wireless network.
  5. A WAP connects wireless devices to the wired LAN.
  6. A cable carries electrical or optical signals between wired network components.
  7. A bridge connects LAN segments and filters or forwards frames between them.
  8. A repeater regenerates a weakened signal for onward transmission.

Common error: Give the specific function of each component rather than repeating “connects devices”.

Command word: Describe4 marks

Describe the path of a packet from a wireless laptop to a server on another network using WNIC, WAP, switch and router.

S2.09.A01S2.09.A02S2.09.A03S2.10.A01S2.10.A02
Answer and marking points
  1. The WNIC sends data by radio to the WAP.
  2. The WAP passes it into the wired LAN over its cable.
  3. The switch forwards the frame to the router port.
  4. The router uses the destination IP address and routing information to forward the packet toward the other network.

Common error: The WAP supplies LAN access; inter-network route selection belongs to the router.

Command word: Explain6 marks

A student describes shared Ethernet as follows: “Transmit immediately without listening. Check for a collision only after sending the whole frame. After a collision, every station waits exactly the same fixed time and retries immediately.” Explain three errors in this description of CSMA/CD, giving a correction and its purpose for each.

S2.11.A01S2.11.A02S2.11.A03
Answer and marking points
  1. Sense the shared medium and transmit only if it is idle.
  2. Listening avoids starting a transmission while another station is already using the medium.
  3. Monitor during transmission; if a collision is detected, stop and send a jam signal.
  4. This stops sending a corrupted frame and ensures stations recognise the collision.
  5. Choose an independent random backoff, then sense the medium again before retrying.
  6. Randomisation reduces repeated simultaneous retries; it cannot guarantee that the two waits differ.

Common error: Collision detection must operate during transmission, and a completed wait does not make a busy medium free.

Command word: Explain4 marks

Explain why a switch and router are both needed in a school LAN connected to the internet.

S2.09.A01S2.10.A01S2.10.A02
Answer and marking points
  1. Switch forwards frames among LAN ports.
  2. Uses LAN/link addresses.
  3. Router connects the LAN to other networks.
  4. Uses destination IP/routing information.

Common error: One combined physical box can perform both roles, but the functions must remain distinct.

Question 1 · Command word: Explain · 5 marks

A long LAN has a weak signal at its far end, and two busy LAN segments exchange only occasional traffic. Explain how a repeater and a bridge solve the two different problems.

Answer and marking points
  • A repeater receives a weakened signal and regenerates it before forwarding it along the medium.
  • Regeneration extends the usable transmission distance but does not choose a destination for each frame.
  • A bridge connects the two LAN segments and learns or examines link-layer addresses.
  • The bridge forwards frames that must cross between segments and filters local frames that do not need to cross.
  • Filtering unnecessary cross-segment traffic reduces traffic on the other segment.

Common error: Do not interchange the devices: a repeater regenerates signals, whereas a bridge makes frame-forwarding decisions between segments.

Question 2 · Command word: Compare · 4 marks

Compare the network connection of a wired desktop with a wireless laptop on the same LAN, including the interfaces, access device and continuing role of the switch.

Answer and marking points
  • The laptop uses a WNIC to transmit and receive LAN data by radio instead of using the desktop's wired NIC and end cable.
  • A wireless access point provides the laptop's wireless connection to the LAN.
  • The access point normally connects by cable to a port on the existing wired LAN.
  • The switch still forwards frames between the access point, wired devices and other required LAN ports.

Common error: Do not state that a WNIC connects directly to the internet; it first provides the laptop's interface to the wireless LAN.

Question 3 · Command word: Describe · 6 marks

Two devices using CSMA/CD detect a collision after transmitting at almost the same time. Describe the complete sequence from carrier sensing to a successful retry.

Answer and marking points
  • Each device listens to the shared medium and transmits only when it senses that the medium is idle.
  • The near-simultaneous transmissions collide and each transmitting device detects the collision.
  • The devices stop transmitting and send or recognise a jam signal so all stations know that a collision occurred.
  • Each device waits for a randomly selected backoff period.
  • After the backoff, a device senses the medium again before retrying the transmission.
  • Different random delays reduce the chance of the same devices colliding again on the retry.

Common error: Do not omit carrier sensing, collision detection or the second carrier check after the random backoff.
