Follow data through a computer

You already know how data is represented and transferred. Now follow a recording from its first input to a saved file, and discover why a computer needs several different kinds of hardware.

Hardware / 01

Record, use, save and play

Look closely

Why can an unsaved edit disappear while the saved recording survives?

A recorder saves a reading of 23. You change the displayed value to 24 but do not save again. The recorder then loses power. Follow the two values through the diagram before predicting what returns after restart.

Step 1 / 5

Get data into the system

The sensor supplies the reading: this is input. A button can also supply an instruction, such as Save. Input devices give the computer data or instructions from outside it. The processor follows the recording program and works on the incoming data.

Step 2 / 5

Keep the current work close to the processor

The processor needs instructions and data while it works. Primary memory provides this directly accessible working resource. RAM holds changing values such as the current reading. ROM can hold instructions that must survive power loss. Primary memory is not another name for volatile memory.

Step 3 / 5

Make the result useful

The display presents the reading to a person: this is output. A speaker can produce sound, and a motor can produce movement. An output device communicates a result or causes an action. A touchscreen combines output from its display with input from its touch sensor.

Step 4 / 5

Separate working data from a completed save

Saving writes a persistent copy to secondary storage, such as flash storage or a hard disk. A completed save of 23 stays there after shutdown. Changing a RAM value to 24 changes the current work; it does not automatically replace the saved copy. On restart, the recorder can load 23 again.

Step 5 / 5

Make a copy that can leave the system

Removable secondary storage can be disconnected and used to transfer a file or keep a separate copy. A USB drive copied after the completed save contains 23. It does not receive later edits while disconnected. The purpose is persistent storage and portability, rather than extra working RAM.

Explain it yourself · Teacher-written check

A saved sound file survives shutdown. Does that prove the RAM kept its contents?

Check your reasoning

No. The saved file is on non-volatile secondary storage. RAM loses its working contents without power; the computer can load the saved file into RAM after restarting.

Apply the idea · Teacher-written practice
Question 1 · Command word: Explain4 teacher marks

Explain what a recorder can recover after this sequence: a reading of 31 is saved successfully, a RAM-only correction changes it to 32, and power is lost before another save. State what a separately completed removable copy made before the correction contains.

S3.01.A03S3.01.A04S3.01.A05
Answer and checking points — teacher-written
  1. The volatile RAM-only value 32 is lost when power is removed.
  2. The last completed saved file still contains 31.
  3. On restart, the recorder can load 31 into new working RAM.
  4. The separately completed removable copy also contains 31; it does not automatically receive later RAM edits.

Common error: A displayed or edited value is not necessarily the value last written to persistent storage.

Keep this idea

Input supplies data, the processor uses primary memory to work on it, output presents a result, and secondary storage keeps completed saves.

The same roles can fit inside a larger device, even when there is no visible desktop computer.

Hardware / 02

Find the computer inside the device

Look closely

Where is the computer in a washing machine?

Imagine selecting a wash program and watching the machine fill, turn its drum and display the time remaining. Identify one input, one decision and one output within that single appliance.

Step 1 / 4

Draw the boundary of the larger device

The washing machine contains a controller as one of its parts. This controller is an embedded computer system: a computer built into a larger device for a dedicated function or a closely related set of functions. Washing, rinsing and spinning belong to its purpose.

Step 2 / 4

Follow one input

The program selector supplies the chosen wash setting. A sensor can supply information such as water level. The controller receives these inputs and runs stored instructions. The water-level sensor measures; it does not itself decide which washing program should run.

Step 3 / 4

Locate memory and processing

Memory retains the operating instructions and provides working space for current readings and progress. The processor follows those instructions to decide the next output. A microcontroller can combine processor, memory and input/output interfaces in one chip, making this arrangement compact.

Step 4 / 4

Follow the output back into the appliance

An output may open a valve, operate the drum motor or update the display. These actions serve the washing task. An embedded system is identified by its place and purpose, not simply by small size: a small general-purpose laptop is still designed to run many unrelated applications.

Explain it yourself · Teacher-written check

A bicycle has a built-in controller for electronic gear changes. Give two facts that make it an embedded system.

Check your reasoning

It is incorporated into the larger bicycle gear mechanism, and it performs the dedicated gear-control task. Its small size alone would not establish either fact.

Apply the idea · Teacher-written practice
Question 1 · Command word: Describe4 teacher marks

A washing machine contains an embedded controller. Describe why it is an embedded system and how input, processing, memory and output support its dedicated function.

S3.02.A01
Answer and checking points — teacher-written
  1. The controller is built into the larger washing machine.
  2. It performs a dedicated washing-control function.
  3. Inputs provide data such as a selected program or sensor reading.
  4. The controller executes stored instructions and produces outputs such as operating the motor or valve.

Common error: Do not identify the system only by its size; link it to the larger device and dedicated function.

Keep this idea

Identify the larger device, the dedicated function, and the input → processing → output path inside it.

A design that is well suited to one task also has limits when the task changes.

Hardware / 03

Explain the consequences of a dedicated design

  1. 1Begin with the actual job
  2. 2Connect the design to a benefit
  3. 3Change the requirement
  4. 4Consider repair and continued use

Look closely

Would a controller chosen for a simple timer also suit a new camera feature?

A battery-powered watering timer opens a valve at set times. Its owner now wants it to recognise plants from camera images. Compare what the old task and the proposed task need.

  1. 1Begin with the actual job
  2. 2Connect the design to a benefit
  3. 3Change the requirement
  4. 4Consider repair and continued use

Step 1 / 4

Begin with the actual job

A timer needs a clock, stored settings and a way to operate a valve. Its designer can choose only the processing, memory and interfaces needed for that work. A dedicated design can therefore use fewer components and less power than a more capable general-purpose system chosen for the same job.

Step 2 / 4

Connect the design to a benefit

Lower power consumption can make the batteries last longer. A compact controller fits inside the timer. Making many identical controllers can reduce unit cost. Each benefit follows from a design choice and a requirement; none is guaranteed merely because the word embedded appears in the description.

Step 3 / 4

Change the requirement

A camera supplies much more data than a clock setting. Image recognition may need more memory, processing capacity and a new input interface. The existing controller may lack those resources. Adding the feature could require replacing hardware, rather than installing only new instructions.

Step 4 / 4

Consider repair and continued use

A controller failure can stop the larger appliance from working. Repair or upgrades may require specialist parts and access to the embedded hardware. When evaluating a system, name the limitation and explain its consequence for that particular device instead of reciting an unsupported list of advantages and disadvantages.

Explain it yourself · Teacher-written check

Improve this explanation: “The embedded controller is good because it is small.”

Check your reasoning

Its compact hardware can fit inside the watering timer while providing the processing, memory and interfaces required for its dedicated timing task. This explains why size helps this device.

Apply the idea · Teacher-written practice
Question 1 · Command word: Explain4 teacher marks

Explain one benefit and one limitation of a dedicated embedded controller in a small ticket validator. It must scan tickets on battery power; a proposed upgrade would analyse camera images. Link each point to these requirements.

S3.02.A01S3.02.A02S3.02.A03
Answer and checking points — teacher-written
  1. The controller is incorporated into the validator for its dedicated ticket-checking function.
  2. Hardware sized for the scanning task can avoid unnecessary general-purpose resources and support low-power operation.
  3. Image analysis may require more working memory, processing capacity or a different input interface.
  4. The proposed upgrade may therefore require replacement hardware rather than only changing the instructions.

Common error: State how the claimed benefit or limitation follows from the specific task.

Use the factory-machine context. Two features are requested, followed by one drawback; a list of machine examples would not answer either task.

Reasoning and model answer — teacher-written

1(c)(i): An embedded system is built into a larger machine and is dedicated to a single task or a limited set of functions.

1(c)(ii): It can be difficult for an ordinary user to update or adapt its firmware for a different task.

Official mark scheme
Why this earns marks — teacher explanation

Each distinct feature can earn one mark, up to two. The drawback has a separate one-mark limit. The scheme allows other limitations such as specialist repair or upgrading.

Common mistakes — teacher analysis

Small size alone does not explain the system’s embedded role. A processor, memory and I/O can be present even though the computer is not a separate desktop device.

Explain why a computer system needs input, output, primary memory and secondary storage, including removable storage.

Question 2 · Command word: Explain4 teacher marks

Explain two benefits and two drawbacks of using an embedded system in a washing machine.

S3.02.A02S3.02.A03
Answer and checking points — teacher-written
  1. Dedicated hardware and software can be optimised for the washing functions.
  2. A compact mass-produced design can reduce power use, size or unit cost.
  3. Limited processing, memory or interfaces make unrelated new functions difficult to add.
  4. A failed or obsolete controller can require specialist repair or replacement of part of the larger appliance.

Common error: Link every benefit and drawback to the stated appliance rather than listing unsupported adjectives.
