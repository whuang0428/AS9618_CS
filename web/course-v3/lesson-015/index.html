01

Why a computer system needs input, output, primary memory and secondary storage

S3.01.A01S3.01.A02S3.01.A03S3.01.A04S3.01.A05

Visual overview

Follow data through a system

A computer needs a way to receive data and instructions, process them, and make the result useful. Input can come from a person or a sensor. Output can be information for a person, such as a displayed reading, or a physical action, such as operating a motor. The processor follows instructions; memory holds the instructions and data it needs.

Distinguish the storage roles

Primary memory is available for the processor’s current work. RAM provides changing working space; ROM provides persistent instructions. Primary memory is therefore not defined by being volatile. Secondary storage retains saved programs and user data between sessions. A removable drive is secondary storage that can be disconnected for transfer or a separately held copy. A component can have more than one role: a touchscreen both displays output and senses input.

A complete reading, save and restart example

  1. Initial state: A hand-held recorder has working firmware, empty RAM for the new session and no saved record. Its sensor supplies a reading of 23.
  2. Process and output: The processor stores 23 in RAM, applies the recording instructions and displays 23. The value is currently working data.
  3. Save: The user requests a save. The recorder writes a record containing 23 to its flash file and reports that the write has completed.
  4. Change without saving: A correction changes only the RAM value to 24. The flash file still contains 23. A power interruption now loses the unsaved 24.
  5. Restart and read: Persistent firmware starts the device. The recorder reads the saved file into new RAM workspace and displays 23. It cannot reconstruct the unsaved 24 from that file.
  6. Make an offline copy: While powered, copy the saved record to a removable drive, confirm completion, then disconnect it. The separate copy contains 23; later edits to the recorder do not automatically update it.

State what the example assumes

This is a conceptual hardware/data-state trace, not a file-handling program. Later file lessons specify opening, writing, closing and reading files in pseudocode. Here, the essential condition is that the stated save and copy have completed before power or the drive is removed.

Core explanation · Exam essentials

  • Input supplies data; processing uses stored instructions; output communicates a result or causes an action.
  • Distinguish current working data, persistent firmware and saved user files; a completed removable copy can be held separately.
Common misconception

Primary memory is defined by direct processor access, not by volatility: RAM is volatile but ROM is non-volatile.

Check your understanding

The screen displays 24 but the most recent completed save contains 23. What can the device recover after power is lost?

Check your answer

It can reload 23 from the saved file. Displaying or editing 24 did not itself update that file.

02

What an embedded system is

S3.02.A01

Visual overview

Identify the boundary and purpose

An embedded system is a computer incorporated into a larger device to perform a dedicated function or a related set of functions. It is identified by its role within that device, not merely by its size. A small general-purpose laptop is not made embedded simply by being small. Embedded systems may use a microcontroller combining processor, memory and input/output interfaces, or a more complex processor arrangement.

Trace one electronic bicycle gear change

  1. Given state: The bicycle is in gear 3. Its controller has stored gear-control instructions and working memory for the selected gear.
  2. Input: The rider presses the up-shift button once. The button supplies a request; it does not itself move the gear mechanism.
  3. Processing: The controller interprets the request, checks that a higher gear is available and selects the command for gear 4.
  4. Output: A driver supplies the required electrical power to the gear motor. The motor moves the mechanism to the requested position.
  5. Result and boundary: In this successful case the bicycle reaches gear 4. A position sensor could confirm the result; that feedback decision is developed in Lesson 018. At the highest gear, a further up-shift request must not imply that another physical gear exists.

Connect the structure to the definition

The rider’s button, controller and motor belong to a larger gear-changing system with a dedicated purpose. The stored instructions are software; the processor, memory and interfaces are hardware. Dedicated does not mean that every instruction is permanently unchangeable or that every embedded system must be connected to a network.

Core explanation · Exam essentials

  • Identify the larger device and the controller’s dedicated function.
  • Describe input, stored instructions, working data and output inside that system.
Common misconception

An embedded system is identified by being built into a larger device for a dedicated function, not merely by being small.

Check your understanding

A controller runs several related wash programs. Does that prevent it being embedded?

Check your answer

No. It is incorporated into the washing machine for a related set of washing functions; dedicated does not require one unvarying instruction sequence.

Benefits and drawbacks of embedded systems

S3.02.A02S3.02.A03

Visual overview

Embedded-system benefits and drawbacks

Design factorPotential benefitPotential drawback
Dedicated functionHardware and software can be optimised for one task.The system has limited flexibility for unrelated new tasks.
Size and resourcesA compact design can use less power and fewer components.Limited processing power or memory restricts future features.
Cost and reliabilityMass-produced dedicated hardware can reduce unit cost and unnecessary complexity.A failure can disable the larger device and specialist repair may be required.
UpdatesStable fixed behaviour can make operation predictable.Upgrading hardware or software may be difficult after manufacture.

Swipe horizontally to compare every column →

Explain the consequence of a design choice

The same restriction to a dedicated job can provide a benefit and a drawback. A convincing explanation starts with a requirement, identifies a design property and follows its consequence. Low price, low power and reliability are possible outcomes of a suitable design, not automatic properties of every embedded device.

Evaluate a battery-powered irrigation timer

  1. Requirement: The timer opens one water valve on a schedule, uses a small display and must run for a long period between battery replacements.
  2. Benefit with a cause: A controller with enough memory and interfaces for that limited job avoids the resources of a general-purpose computer. Low-power operation can extend battery life, while a compact repeated design can reduce unit size and cost.
  3. Changed requirement: The owner now wants a camera to classify plants. Image input and processing require different interfaces, more working memory and more processing capacity.
  4. Drawback and judgement: The installed controller may not support that workload. Replacement hardware may be needed. The original design was suitable for valve timing; its suitability does not automatically extend to image processing.

Apply the same reasoning to a second device

In a washing machine, integration can remove unnecessary user controls and make normal operation straightforward. However, a failed controller can stop the whole appliance and may require specialist replacement. A firmware update is possible only when the device has suitable writable storage and an update mechanism; neither ease nor impossibility of updating follows from the word embedded alone.

Core explanation · Exam essentials

  • Link each claimed advantage or limitation to the device’s task and constraints.
  • Dedicated optimisation can reduce resources while restricting later unrelated functions.
Common misconception

A benefit or drawback is not automatic; it must be linked to the dedicated function and constraints of the stated device.

Check your understanding

Why is “embedded systems are always cheaper” an incomplete explanation?

Check your answer

Cost depends on design, production and requirements. Explain how the dedicated device avoids unnecessary resources or gains from repeated manufacture, and recognise development and repair costs.

Question 1 · Command word: Explain5 marks

Explain why a computer system needs input, output, primary memory and secondary storage, including removable storage.

S3.01.A01S3.01.A02S3.01.A03S3.01.A04S3.01.A05
Answer and marking points
  1. Input devices supply data and instructions.
  2. Output devices communicate processed information or cause an action.
  3. Primary memory holds instructions and data required during current processing.
  4. Secondary storage retains programs and data when power is removed.
  5. Removable storage can transfer data or hold an offline copy.

Common error: Do not place embedded-system, microcontroller or control-system detail in this component-role answer.

Question 2 · Command word: Describe4 marks

A washing machine contains an embedded controller. Describe why it is an embedded system and how input, processing, memory and output support its dedicated function.

S3.02.A01
Answer and marking points
  1. The controller is built into the larger washing machine.
  2. It performs a dedicated washing-control function.
  3. Inputs provide data such as a selected program or sensor reading.
  4. The controller executes stored instructions and produces outputs such as operating the motor or valve.

Common error: Do not identify the system only by its size; link it to the larger device and dedicated function.

Question 3 · Command word: Explain4 marks

Explain two benefits and two drawbacks of using an embedded system in a washing machine.

S3.02.A02S3.02.A03
Answer and marking points
  1. Dedicated hardware and software can be optimised for the washing functions.
  2. A compact mass-produced design can reduce power use, size or unit cost.
  3. Limited processing, memory or interfaces make unrelated new functions difficult to add.
  4. A failed or obsolete controller can require specialist repair or replacement of part of the larger appliance.

Common error: Link every benefit and drawback to the stated appliance rather than listing unsupported adjectives.

Question 4 · Command word: Explain4 marks

Explain what a recorder can recover after this sequence: a reading of 31 is saved successfully, a RAM-only correction changes it to 32, and power is lost before another save. State what a separately completed removable copy made before the correction contains.

S3.01.A03S3.01.A04S3.01.A05
Answer and marking points
  1. The volatile RAM-only value 32 is lost when power is removed.
  2. The last completed saved file still contains 31.
  3. On restart, the recorder can load 31 into new working RAM.
  4. The separately completed removable copy also contains 31; it does not automatically receive later RAM edits.

Common error: A displayed or edited value is not necessarily the value last written to persistent storage.

Question 5 · Command word: Explain4 marks

Explain one benefit and one limitation of a dedicated embedded controller in a small ticket validator. It must scan tickets on battery power; a proposed upgrade would analyse camera images. Link each point to these requirements.

S3.02.A01S3.02.A02S3.02.A03
Answer and marking points
  1. The controller is incorporated into the validator for its dedicated ticket-checking function.
  2. Hardware sized for the scanning task can avoid unnecessary general-purpose resources and support low-power operation.
  3. Image analysis may require more working memory, processing capacity or a different input interface.
  4. The proposed upgrade may therefore require replacement hardware rather than only changing the instructions.

Common error: State how the claimed benefit or limitation follows from the specific task.

Question 1 · Command word: Explain · 3 marks

Explain why a portable survey computer needs RAM while editing measurements, flash storage after shutdown, and a removable drive for an offline copy.

Answer and marking points
  • RAM provides writable working space for the measurements currently being edited.
  • Flash storage retains the saved measurements when the survey computer is switched off.
  • The removable drive can be disconnected and kept separately as an offline copy.

Common error: Do not describe RAM as the place that preserves the saved survey after shutdown.

Explain why a bicycle's built-in electronic gear controller is an embedded system. Describe the roles of its shift buttons and gear motor.

04

Lesson review

Summary

Computer-system roles

Input supplies data; processing transforms it; output communicates a result.

Storage roles

Primary memory supports current processing; secondary storage retains data long term.

Embedded system

A computer system built into a larger device for a dedicated function.

Trade-offs

Dedicated design can improve efficiency but reduces flexibility and upgrade capacity.
