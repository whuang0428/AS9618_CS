Section 4 · Processor fundamentals

Follow one instruction.
Understand the processor.

A stored program turns a calculation into a sequence of small actions. Start with addresses and values, follow the CPU as it works, and then change the program to explain a new result.

Start the processor journey →

A connected route through the processor

01

Build a computer that adds two numbers

Start with 18 + 24. Give the computer somewhere to keep the numbers, a sequence of instructions to follow, and components that can carry out each instruction. We will keep returning to this same calculation.

02

Move values and explain performance

Follow one memory read and one write. Then change a bus, cache or processor condition and explain what can improve. Finally, connect the computer to classroom peripherals.

03

Follow one instruction from memory to its result

Use the same 18 + 24 program. First fetch an instruction; then decode and execute it. Connect every arrow in the diagram to a value, a register and a reason for the transfer.

04

Pause for an event, then continue correctly

The processor can do useful work while a peripheral is busy. Follow how an event requests attention, how a handler runs, and how the calculation continues with its original values.

05

Write readable instructions and translate them

Turn the familiar calculation into assembly source. Give its locations meaningful labels, then carry out both assembler passes to produce a complete encoded program and its data.

06

Resolve operands and follow the path actually executed

Start with one load, then add different addressing modes, arithmetic, characters and decisions. Build up to a complete loop trace before attempting the combined past-paper program.

07

Move, test and change individual bits

Treat an eight-bit value as eight separate positions. First move its bits; then combine them with a mask. Finally, use a complete program to test readiness and change one device-control bit.
