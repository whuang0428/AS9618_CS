Public and private cloud computing

Locate control, tenancy and dependence before judging a cloud design.

Concept teaching

Concept explanations and worked examples

01

Cloud computing provides remote resources through a network

S2.06.A01

Visual overview

Establish the concept

Cloud computing provides storage, processing, applications or platforms from remote infrastructure accessed through a network. The organisation uses the service without operating every physical server locally.

A client sends a request across its local network and the internet to provider infrastructure. A virtual server or managed service performs the requested processing or storage operation and returns the result.

Cloud describes where computing resources are provided and accessed; it does not mean that data has no physical location. The resources run on physical provider or organisation-controlled hardware.

Follow a cloud order-processing request

  1. Client input: A shop enters order 501 in a browser. Its application sends the order through the shop connection to a hosted application.
  2. Remote resources: Provider computing executes the application; managed storage retains the order. The client uses those resources through a network interface rather than owning every underlying server.
  3. Response: The service returns an accepted-order result. The shop should distinguish that acknowledgement from a form that has only been typed locally.
  4. Demand changes: More processing or storage can be provisioned as demand grows, subject to the service’s capacity, configuration and charges. Cloud resources are not unlimited or automatically free.

Connect the term to the resources

Cloud computing includes remotely provided processing, applications and storage. Simply copying a file to any other computer does not establish all the management and on-demand service features associated with a cloud platform. The client still needs a suitable access connection and permission to use the service.

Core explanation · Exam essentials

  • Cloud computing supplies computing resources as a service through a network.
  • Follow client request, remote processing or storage, and returned result.
Common misconception

Cloud resources still run on physical computers and storage devices; ‘cloud’ describes remote service provision, not the absence of hardware.

Check your understanding

Does a cloud application mean that no processing occurs on the user’s device?

Check your answer

No. The client still processes input and displays results, and may perform other local work. The cloud supplies specified remote resources.

02

A public cloud uses shared third-party provider infrastructure

S2.06.A02

Visual overview

Establish the concept

A public cloud is operated by a third-party provider. Its underlying physical resources serve multiple customers, while virtualisation, accounts and permissions provide logical separation between customers.

Public cloud describes provider control and multi-customer tenancy. It does not mean that files are open to the public; authentication, permissions and encryption are still required.

Because the provider owns and operates the shared platform, a customer can obtain resources without purchasing all of the underlying hardware but accepts greater dependence on the provider's service and controls.

Shared infrastructure and controlled access

In a public cloud, a third-party provider offers services to multiple customers using its infrastructure. Customer workloads and data need logical separation and access control; shared provider infrastructure does not mean every customer may read everyone else’s files. A shop can obtain capacity without first purchasing and running its own server estate.

Evaluate a changing workload

The benefit is a smaller initial infrastructure commitment and the ability to obtain more resources when needed. The trade-off is ongoing charges and dependence on the provider’s service, terms and security arrangements. A traffic surge may increase both the allocated capacity and the bill. Evaluate those consequences against the shop’s workload instead of assuming public means insecure or free.

Core explanation · Exam essentials

  • Public cloud uses a provider’s infrastructure to serve multiple customers.
  • Shared infrastructure does not imply public access to customer data.
Common misconception

Public cloud does not mean public access; access rights are separate from tenancy.

Check your understanding

A public-cloud document is accessible only to three staff accounts. Is “public cloud” the wrong label?

Check your answer

No. Public describes the cloud service arrangement, not the access permissions of that document.

03

A private cloud is dedicated to one organisation

S2.06.A02

Visual overview

Establish the concept

A private cloud is dedicated to one organisation. It may be operated by that organisation on its own premises or hosted and managed on its behalf by another provider.

Private describes single-organisation tenancy and the potential for greater control or configuration. It does not require every server to be in the organisation's building.

Dedicated infrastructure can support control or compliance requirements, but it usually brings greater cost or management responsibility and still requires authentication, permissions, encryption and backup.

Distinguish tenancy from location

A private cloud is dedicated to one organisation. It may run in the organisation’s own data centre or be hosted and operated for it by a third party. “Private” therefore describes exclusivity and control, not a requirement that all equipment sits inside the office or that access uses the public internet.

Make the control–cost trade-off explicit

A research organisation with specialised access rules may choose a dedicated private cloud to control configuration and resource use. It must still fund capacity and skilled administration, directly or through a hosting contract. Dedicated infrastructure can reduce sharing with other customers, but poor permissions, failed hardware and absent backups remain possible. The choice requires both the control requirement and the cost of delivering it.

Core explanation · Exam essentials

  • A private cloud is dedicated to one organisation and can be on-site or hosted.
  • Greater control still requires administration, capacity planning and recovery arrangements.
Common misconception

Private cloud means dedicated to one organisation; it does not necessarily mean physically on-site or automatically secure.

Check your understanding

Can a private cloud continue serving local staff when the organisation’s internet connection fails?

Check your answer

It can if the cloud is on-site, reachable through the working local network and its required services do not depend on the lost internet connection.

04

Cloud benefits and risks must be connected to dependence

S2.06.A03S2.06.A04

Visual overview

Establish the concept

Benefits can include access from different locations, collaboration, elastic capacity, reduced local hardware, provider maintenance and geographically redundant infrastructure.

Drawbacks can include dependence on broadband and the provider, recurring cost, less direct control, migration difficulty, service outage, data-location/compliance concerns and exposure if accounts or provider controls fail.

A choice depends on sensitivity, required control, expected demand, staff expertise, budget, connection resilience and legal requirements. Cloud storage is not automatically a complete backup strategy.

Recover the order service with a known backup boundary

  1. Before failure: At 12:00 the shop verifies a recoverable backup held independently of the live provider service. Order 501 was confirmed at 12:05. At 12:10 the service becomes unreachable.
  2. Locate the dependency: If another independent connection reaches the service, investigate the shop’s access path. If the provider has an outage, changing only the shop’s connection cannot restore that failed provider service. Confirm status rather than assume the cause from one failed browser request.
  3. Continue essential work: Use the agreed offline form with temporary unique order references and timestamps. Tell staff these records have not yet been accepted by the cloud application.
  4. Restore what exists: The 12:00 backup recovers the captured state, not automatically order 501 or later work. Restore to an available approved service and verify records and access before normal use.
  5. Reconcile and resume: Check which later orders were confirmed or retained elsewhere. Match temporary references and acknowledgements before entering missing records, avoiding duplicate orders. Resume normal submission once the service is verified.

Core explanation · Exam essentials

  • Explain benefits alongside network and provider dependence.
  • Recovery requires usable retained data, an available service and checks for missing or duplicated work.
Common misconception

Data redundancy at a provider is not the same as an independent, tested backup controlled by the organisation.

Check your understanding

Does restoring the verified 12:00 backup prove that order 501, confirmed at 12:05, has been recovered?

Check your answer

No. That order was created after the snapshot. Check later retained records or logs and reconcile it separately.

Cambridge command words

Practice questions

Question 1 · Command word: Define6 marks

Define cloud computing and give two differences between public and private clouds in terms of tenancy and organisational control.

S2.06.A01S2.06.A02
Answer and marking points
  1. Cloud computing provides computing resources such as storage or processing on remote infrastructure.
  2. Users access these resources as services through a network.
  3. Public-cloud physical resources serve multiple customers.
  4. Private-cloud resources are dedicated to one organisation.
  5. A public-cloud customer has less direct control over the shared provider platform.
  6. A private cloud allows greater organisational control over configuration and management.

Common error: Private-cloud infrastructure may be hosted by another provider; it need not be on site.

Question 2 · Command word: Explain4 marks

Explain two benefits of a public cloud for a start-up whose demand changes sharply each month and which has only one IT technician.

S2.06.A03
Answer and marking points
  1. Capacity can be increased or reduced as the workload changes.
  2. The start-up avoids buying hardware for peak demand that would be idle in quieter months.
  3. The provider maintains the underlying server hardware.
  4. The single technician can spend less time on local hardware maintenance and more time supporting the business.

Common error: For each benefit, link the feature to one requirement in the scenario.

Question 3 · Command word: Give6 marks

A clinic considers moving patient records to cloud storage. Give a balanced recommendation covering control, access, availability and cost.

S2.06.A02S2.06.A03S2.06.A04
Answer and marking points
  1. A private cloud is a suitable option when control of the patient-record service is a priority.
  2. Dedicated resources allow the clinic greater control over configuration and access policies.
  3. Authenticated remote access can let authorised staff retrieve the same patient records from different sites.
  4. Staff may lose access during a broadband or hosting-service outage.
  5. Dedicated infrastructure and specialist administration may cost more than a shared public-cloud service.
  6. The clinic still needs permissions, encryption and tested backups; private tenancy alone does not protect records.

Common error: Accept a justified public-cloud recommendation addressing the same factors; do not award a claim that any cloud is completely secure.

Question 4 · Command word: Explain5 marks

Explain a recovery plan for a cloud order service that becomes unavailable at 10:00. An independently stored, verified backup captures 09:30; order 620 was confirmed at 09:40. A separate connection can still reach the live service. State the likely failed dependency, the limit of the backup, and how offline orders should be reconciled.

S2.06.A01S2.06.A03S2.06.A04
Answer and marking points
  1. Successful access through an independent connection points to the original access path as the failed dependency, rather than proving the provider is down.
  2. Use the working independent connection while investigating the original path.
  3. The 09:30 backup alone cannot restore the later order 620.
  4. Record offline orders with unique temporary references and times.
  5. Check confirmed and retained records before entering missing orders, avoiding duplicate submissions.

Common error: A backup does not automatically contain later orders, and one failed connection does not locate the outage.

Question 1 · Command word: Describe · 4 marks

Describe what happens when a student uses a low-specification laptop to run a browser-based simulation whose processing and files are hosted by a cloud provider. Include the effect of losing the network connection.

Answer and marking points
  • The laptop sends a request to remote computing resources through its network connection.
  • Servers at the provider execute the simulation and store the associated files rather than requiring all work to occur locally.
  • The provider returns the simulation output or interface data to the student's browser.
  • Loss of the network connection or provider service prevents or limits access even though the laptop still works.

Common error: Do not describe cloud computing as files floating on the internet; identify the remote servers, network requests and returned results.

Question 2 · Command word: Explain · 4 marks

Explain why the term public cloud does not mean that every member of the public can read a customer's stored files.

Answer and marking points
  • Public describes a provider-operated service whose underlying resources are offered to multiple customers.
  • Each customer uses authenticated accounts and permissions that restrict access to authorised users.
  • Logical separation prevents one customer from being given normal access to another customer's data.
  • The customer still needs correctly configured access controls because shared service provision is not automatic public data access.

Common error: Do not confuse shared provider infrastructure with unrestricted file permissions.

Question 3 · Command word: Suggest · 4 marks

Suggest two measures that could reduce disruption when a provider outage makes a company's cloud-hosted order system unavailable. Explain how each measure helps.

Answer and marking points
  • Maintain and test a replica or recoverable backup outside the affected provider service.
  • This provides an independent copy from which the company can restore or continue access to order data.
  • Provide a tested offline order-entry procedure or an independently hosted failover application.
  • Staff can continue recording orders during the outage and reconcile them when the main service returns.

Common error: Credit other valid measure-and-effect pairs; a backup within the same unavailable service is not an independent recovery route.
