Communicate data · Concept 29

Trace a school task into remotely supplied resources

Observe

Save a shared presentation

  • A teacher edits a presentation through a hosted application.
  • The service processes changes and stores the shared document.
  • A student later retrieves the saved version on another device.

Look, then discuss

Does a completed-looking page on the teacher’s screen prove that the remote service has saved the latest change?

Discuss the observation

Input may exist locally before the remote service accepts it. Trace the request, remote work and acknowledgement instead of treating “cloud” as a place where every action always succeeds.

Explain

Explanation · 1 / 4

Identify computing resources

Cloud computing supplies computing resources through a network as a service. Resources include processing, storage and applications. Physical computers still do the work; the user obtains access to specified resources rather than personally managing every underlying machine.

Explanation · 2 / 4

Follow request, work and response

The school client sends a request containing the document change. The service checks access, performs the required processing and stores the change according to its application. Its response reports the result. A connection or service failure can interrupt that sequence.

Explanation · 3 / 4

Explain resource allocation

A cloud arrangement can provide or increase resources when needed, within the service’s capacity, configuration and charges. This can avoid buying all possible future capacity at the start. It does not mean unlimited resources or a zero-cost service.

Explanation · 4 / 4

Keep client and service responsibilities visible

The client still receives input and displays output, and it may perform additional local work. The cloud supplies the remote part. An on-site private cloud may be reached over the local network; an internet-hosted service also depends on a usable internet connection.

Work together

Check whether an assignment upload finished

A student selects an assignment file. The application shows “uploading”, then the school connection fails before confirmation.

Work together · 1 / 3

Locate the local state

The selected file exists on the student’s device. Selection alone does not prove that the remote service has received it.

Work together · 2 / 3

Locate the uncertain step

The transfer or save acknowledgement may have been interrupted. The student needs a confirmed saved result, not simply an open browser window.

Work together · 3 / 3

Recover using evidence

When access returns, check the service’s saved assignment status before deciding whether another upload is needed.

A remote resource must be reached and the required operation completed before its result can be relied on.

Check

Try it yourself · Teacher-written

Name three kinds of cloud resource and explain why cloud computing still requires physical computers.

Check your reasoning

Cloud services can supply processing, storage and applications. Physical server hardware executes the processing and stores data, even when allocation and management are hidden from the user. The user accesses the specified resources through a network.

Connect

Keep this idea

Cloud computing supplies remote computing resources as services with identifiable requests, results and dependencies.

Different cloud arrangements place control and shared infrastructure in different hands.

Check a common misunderstanding

An available cloud application does not mean that no work happens on the client.

Communicate data · Concept 30

Distinguish public infrastructure from a private document

Observe

The same confidential document, two deployments

DeploymentWho the cloud infrastructure serves
Public cloudA provider offers services to many customer organisations
Private cloudThe cloud is dedicated to one organisation

Look, then discuss

Can a confidential school document be stored in a public cloud without being readable by the public?

Discuss the observation

The deployment model and the document’s access permissions describe different properties. Shared provider infrastructure requires controls that separate customers and users.

Explain

Explanation · 1 / 4

Describe a public cloud

A third-party provider offers cloud services to multiple customers using its infrastructure. The school obtains the resources it needs without first buying and operating the complete server estate. Customer separation and permissions determine who can access particular data.

Explanation · 2 / 4

Describe a private cloud

A private cloud is dedicated to one organisation. It can be operated on the organisation’s site or hosted elsewhere. The organisation can have greater control over configuration and resource use, but it still needs appropriate administration, capacity and protection.

Explanation · 3 / 4

Compare costs and responsibilities

A public service can reduce initial infrastructure commitment and allow capacity to vary, with continuing charges and provider dependence. A private arrangement can meet specific control requirements but may require more investment and management. Neither label guarantees better security or uninterrupted availability.

Explanation · 4 / 4

Keep access and location separate

Public cloud does not mean publicly readable files. Private cloud does not necessarily mean a server inside the school building. Check which organisation the cloud serves, where it is hosted, who operates it and what access rules are applied.

Work together

Classify two school services

Service A is hosted by a provider serving many schools; only authorised staff can read examination files. Service B is a cloud environment hosted off-site but dedicated to this school.

Work together · 1 / 3

Classify A

A uses public-cloud infrastructure. Restricted staff permissions do not change that deployment model.

Work together · 2 / 3

Classify B

B is a private cloud because it is dedicated to one organisation, even though it is off-site.

Work together · 3 / 3

Explain the decision evidence

Readability concerns access controls. Deployment concerns which customer organisations the cloud is dedicated to or offered to.

Use the defining property rather than the everyday meaning of “public” or “private”.

Experiment

Predict which responsibilities and dependencies change when the deployment changes. Read the model’s stated hosting assumptions before comparing a failure.

Check

Try it yourself · Teacher-written

A provider hosts a private cloud for a school outside the school grounds. A second service stores protected files in a public cloud. Explain why both descriptions can be valid.

Check your reasoning

Private cloud means dedicated to one organisation, not necessarily on-site. Public cloud describes provider infrastructure offered to multiple customers; access controls can restrict a particular document to authorised users.

Connect

Keep this idea

Public and private cloud classify service deployment; permissions classify access to a resource.

Use those distinctions to decide which benefits and failures matter for the school’s actual work.

Communicate data · Concept 31

Balance access and capacity against specific dependencies

Observe

The school’s busiest week

  • Many families access reports at once.
  • Staff need the same documents from different locations.
  • The school internet connection is sometimes unavailable.

Look, then discuss

Which cloud benefit helps each requirement, and which failure would prevent it from being used?

Discuss the observation

Remote access depends on a working route and permission. Flexible capacity depends on the service’s allocation and charging arrangements. A general advantage needs these conditions to be meaningful.

Explain

Explanation · 1 / 4

Explain access and collaboration

Authorised users can access the same managed resources from suitable connected devices and locations. This supports shared current files and collaboration. A user without a connection or permission cannot obtain those resources merely because they are in a cloud.

Explanation · 2 / 4

Explain capacity and maintenance

A provider may let the school obtain more storage or processing as demand changes and may maintain underlying infrastructure. That reduces some local hardware work. The school still manages its own accounts, data and chosen service settings, and additional use can increase charges.

Explanation · 3 / 4

Separate independent failure causes

A school connection outage can block access even while the provider is healthy. A provider outage can block service while the school internet works. Data loss is another problem: recovery depends on an actual backup or version-retention arrangement and on its age.

Explanation · 4 / 4

Make the choice conditional

Choose a deployment using control, confidentiality requirements, workload, available expertise, cost and connectivity. Explain mitigation where needed, such as a verified backup or permitted offline copy. Do not promise that a backup restores work created after the last saved recovery point.

Work together

Choose an internet-hosted report service

The school has a reliable connection most days, needs parent access and has limited server-management staff. Its chosen service retains a backup made at 18:00.

Work together · 1 / 3

Explain the benefits

A hosted service supports authorised access from different locations and reduces the school’s need to run all underlying hardware. Capacity can be arranged for the reporting period.

Work together · 2 / 3

State distinct drawbacks

School or provider outages can prevent access. Subscription and extra capacity charges must be budgeted, and permissions and data protection still need management.

Work together · 3 / 3

Test recovery

If data is lost at 19:00, an 18:00 backup may restore the earlier state but cannot guarantee recovery of all changes made during the following hour.

Choose the service together with explicit availability and recovery expectations.

Experiment

Predict the outcome of an internet failure and a server failure separately. Explain which dependency fails in each case before considering the model’s private-cloud alternative.

Check

Try it yourself · Teacher-written

Give two distinct benefits and two distinct drawbacks of using an internet-hosted school cloud service. Explain the mechanism behind each.

Check your reasoning

Benefits include authorised access to managed resources from different connected locations, and obtaining additional resources without buying all server hardware upfront. Drawbacks include loss of access when the school connection fails, and dependence on provider availability or continuing charges. Explain each separately; a backup is a benefit only when the actual service provides and retains a suitable one.

Teacher-written consolidation. Explain your reasoning before opening an answer.

Question 1 · Command word: Define6 teacher marks

Define cloud computing and give two differences between public and private clouds in terms of tenancy and organisational control.

S2.06.A01S2.06.A02
Answer and checking points — teacher-written
  1. Cloud computing provides computing resources such as storage or processing on remote infrastructure.
  2. Users access these resources as services through a network.
  3. Public-cloud physical resources serve multiple customers.
  4. Private-cloud resources are dedicated to one organisation.
  5. A public-cloud customer has less direct control over the shared provider platform.
  6. A private cloud allows greater organisational control over configuration and management.

Common error: Private-cloud infrastructure may be hosted by another provider; it need not be on site.

Question 2 · Command word: Explain4 teacher marks

Explain two benefits of a public cloud for a start-up whose demand changes sharply each month and which has only one IT technician.

S2.06.A03
Answer and checking points — teacher-written
  1. Capacity can be increased or reduced as the workload changes.
  2. The start-up avoids buying hardware for peak demand that would be idle in quieter months.
  3. The provider maintains the underlying server hardware.
  4. The single technician can spend less time on local hardware maintenance and more time supporting the business.

Common error: For each benefit, link the feature to one requirement in the scenario.

Question 3 · Command word: Give6 teacher marks

A clinic considers moving patient records to cloud storage. The provider can restrict access to named staff, encode stored data so it needs a key to read, and keep separate recoverable copies. These are available services, not automatic guarantees. Give a balanced recommendation covering control, shared access, availability and cost.

S2.06.A02S2.06.A03S2.06.A04
Answer and checking points — teacher-written
  1. A private cloud is a suitable option when control of the patient-record service is a priority.
  2. Dedicated resources allow the clinic greater control over configuration and access policies.
  3. Authorised staff at different sites can use the same records, with access limited to the intended staff.
  4. A failed internet connection or an unavailable provider can stop staff reaching records.
  5. Dedicated resources and specialist administration can cost more than shared public-cloud services.
  6. The clinic must confirm which of the stated protective and recovery services are included; private tenancy alone does not guarantee them.

Common error: Accept a justified public-cloud recommendation addressing the same factors; do not award a claim that any cloud is completely secure.

Question 4 · Command word: Explain5 teacher marks

Use after Lesson 037.

Explain a recovery plan for a cloud order service that becomes unavailable at 10:00. An independently stored, verified backup captures 09:30; order 620 was confirmed at 09:40. A separate connection can still reach the live service. State the likely failed dependency, the limit of the backup, and how offline orders should be reconciled.

S2.06.A01S2.06.A03S2.06.A04
Answer and checking points — teacher-written
  1. Successful access through an independent connection points to the original access path as the failed dependency, rather than proving the provider is down.
  2. Use the working independent connection while investigating the original path.
  3. The 09:30 backup alone cannot restore the later order 620.
  4. Record offline orders with unique temporary references and times.
  5. Check confirmed and retained records before entering missing orders, avoiding duplicate submissions.

Common error: A backup does not automatically contain later orders, and one failed connection does not locate the outage.
