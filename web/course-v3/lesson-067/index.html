Build a booking system · Concept 30

Use last in, first out for undo

Observe

Completed actions

  • First: A
  • Next: B
  • Most recent: C
  • The user requests Undo once.

Look, then discuss

After booking A, then B, then C, which completed action should Undo reverse first?

Place action cards A, B and C on a pile in that order. The latest card C is at the top. Undoing the most recent action exposes the previous one.

Recall

Recall an ADT contract

The collection’s rules define where an addition and a removal occur. A stack has a top: both operations act at that end.

Explain

Explanation · 1 / 3

Name the operations

Push adds a new item at the top. Pop removes and returns the current top item. Peek, when provided, reads the top item without removing it.

Explanation · 2 / 3

Explain LIFO

Last in, first out means the most recently added item still in the stack is removed next. It does not mean always removing the greatest value or the item with the greatest identifier.

Explanation · 3 / 3

Connect the rule to a use

An undo history stores completed changes so the latest change can be reversed first. Each entry must contain enough information to restore the previous state. Merely storing the word “undo” is not sufficient.

Work together

Push, pop and add another action

Start empty; push A, push B, push C, pop, then push D.

Work together · 1 / 2

Follow the first removal

After three pushes, the bottom-to-top order is A, B, C. Pop returns C, leaving A, B.

Work together · 2 / 2

Continue from the remaining stack

Push D produces A, B, D from bottom to top. The next pop returns D, followed by B and A. C is no longer present.

Always decide the next removal from the current stack, after all earlier operations have taken effect.

Check

Try it yourself · Teacher-written

Why is a stack suitable for nested return order as well as undo?

Check your reasoning

The most recently started unfinished activity must finish or return first. A stack makes its most recently added remaining entry available first, matching that order.

Connect

Keep this idea

A stack adds and removes at the top, giving last-in-first-out behaviour.

The array implementation records the top position and checks its bounds.

Build a booking system · Concept 31

Maintain the top pointer in an array

Observe

Stack[0:4]; Top points to the last occupied cell

Index01234
DataABunusedunusedunused
StateTop = 1

Look, then discuss

Which array position receives the next pushed value?

Use a five-cell array indexed 0 to 4. Top points to the last occupied cell; an empty stack has Top = -1. State the convention before tracing any operation.

Recall

Recall an out-of-range sentinel

The value -1 is not a legal array index here. It represents an empty stack state and must never be used to read an item. The greatest legal index is 4.

Explain

Explanation · 1 / 4

Describe a checked push

If Top = 4, the array-backed stack is full and the push must fail without changing data or Top. Otherwise increment Top and store the new item at that index. Incrementing first selects the new top slot.

Explanation · 2 / 4

Describe a checked pop

If Top = -1, the stack is empty and no item can be read. Otherwise read or save the item at Top, then decrement Top. The old cell may still show a value but is no longer active.

Explanation · 3 / 4

Describe a permitted edit

If the interface permits editing the exposed top item, replace its data without changing Top. A buried item is not available through an ordinary top-only operation. To reach it using stack operations, pop the items above it, retain them, then restore them in the correct order.

Explanation · 4 / 4

Translate a different pointer convention

A question may use indices 1 to 8 and Top = 0 for empty. The principle is unchanged: check the declared full/empty condition and use the stated meaning of Top. Do not copy the classroom sentinel into a different representation.

Work together

Trace a push and a pop

Array indices are 0:4. Active values are A at 0 and B at 1, so Top = 1.

Work together · 1 / 2

Push C

The stack is not full. Increase Top to 2 and write C to cell 2. The active order is A, B, C.

Work together · 2 / 2

Pop once

Read C from cell 2, then reduce Top to 1. A and B remain active. A second pop would read B, not the stale C in cell 2.

Each successful operation updates the data and top state consistently; each rejected operation preserves them.

Experiment

Predict Top and the returned or written item before each operation. Fill the stack, attempt one extra push, empty it and attempt one extra pop. Check that rejected operations leave the state unchanged.

A stack uses Stack[1:4] and Top as the last occupied index. Top is 2 with values A, B. Describe pushing C, editing the top to D, then popping it.
S10.10.A01S10.10.A04
Answer and checking points — teacher-written
  1. Increase Top to 3 and store C at Stack[3].
  2. Replace Stack[3] with D without changing Top.
  3. Return D and decrease Top to 2, leaving A and B active.
