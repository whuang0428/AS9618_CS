Sequence, selection and iteration

Write straight-line calculations, choose between outcomes and repeat a controlled set of operations.

Which operations always run, which depend on a condition, and which must repeat?

Before you start

For ten marks, should PassCount be set to zero once before the loop or before every mark?

Check your answer

Once before the loop. Resetting it on every iteration discards the count already accumulated.

01

Execute dependent operations in order

S9.06.A01

Visual overview

A sequence with a dependency

OrderOperationValue after operation
1Quantity <- 3Quantity is 3
2Subtotal <- Quantity * 4Subtotal is 12
3Total <- Subtotal + 2Total is 14
4OUTPUT Total14 is displayed

Swipe horizontally to compare every column →

Core explanation

Sequence executes instructions in their written order. A later calculation may depend on an earlier input or assignment, so moving operations can change the result or read an unassigned variable. Follow dependencies when placing statements.

For a price calculation, input the quantity before multiplying it by the unit price, then add any fixed charge before outputting the final amount. Declarations can appear first to document types, but they do not perform those calculations.

Common misconception

Outputting a running intermediate value is not the same as outputting the final result.

Check your understanding

What changes if OUTPUT Total occurs before Total is assigned?

Check your answer

It attempts to read an unavailable value rather than displaying the intended final amount.

02

Choose the correct branch

S9.06.A01

Visual overview

Core explanation

Selection chooses operations according to a Boolean condition. In IF ... THEN ... ELSE ... ENDIF, a true condition selects the THEN block and a false condition selects the ELSE block. Execution continues after ENDIF once the selected block finishes.

Write a condition that matches the exact boundary in the requirement. A pass mark of at least 50 uses Mark >= 50. Mark = 50 would accept only the boundary value and reject higher marks; Mark > 50 would incorrectly reject 50 itself.

Worked example · Select a result at an inclusive boundary

  1. Requirements

    Input one whole-number mark from 0 to 100. Output Pass for marks of at least 50 and Resit otherwise.

  2. Pseudocode
    DECLARE Mark : INTEGER
INPUT Mark
IF Mark >= 50 THEN
    OUTPUT "Pass"
ELSE
    OUTPUT "Resit"
ENDIF
  3. Check

    49 selects Resit; 50 and 80 both select Pass.

Common misconception

A decision must lead to the appropriate distinct actions; drawing two labelled paths to the same action does not implement this rule.

Check your understanding

Which output is selected for Mark 50?

Check your answer

Pass, because the inclusive comparison is true.

03

Repeat with a defined stopping rule

S9.06.A01

Visual overview

Choose a loop from the requirement

RequirementSuitable formStopping behaviour
Read exactly four integersFOR Index <- 1 TO 4 ... NEXT IndexFour repetitions
Count down while positiveWHILE Count > 0 DO ... ENDWHILEZero repetitions if already zero
Read at least once until acceptedREPEAT ... UNTIL AcceptedBody precedes the condition

Swipe horizontally to compare every column →

Core explanation

Iteration repeats a block of operations. A FOR loop is suitable when the number of repetitions is known. A WHILE loop tests a condition before the body, so it may execute zero times. A REPEAT ... UNTIL loop tests after the body and therefore executes at least once.

Initialise totals or counts before the loop, update them inside the loop, and put a final aggregate output after the loop. A condition-controlled loop must make progress towards stopping. In a countdown, decreasing Count eventually makes Count > 0 false.

Worked example · Accumulate four values

  1. Requirements

    Input exactly four integers and output their total once.

  2. Pseudocode
    DECLARE Index : INTEGER
DECLARE Value : INTEGER
DECLARE Total : INTEGER
Total <- 0
FOR Index <- 1 TO 4
    INPUT Value
    Total <- Total + Value
NEXT Index
OUTPUT Total
  3. Check

    Inputs 3, 5, 2, 4 produce running totals 3, 8, 10, 14; the sole output is 14.

Common misconception

FOR upper bounds are inclusive here; 1 TO 4 performs four iterations, not three.

Check your understanding

Why is Total <- 0 placed before FOR?

Check your answer

The loop must build on one initial zero rather than erase the previous total on each repetition.

04

Place a decision inside a repeated task

S9.06.A01

Visual overview

Count passes from ten marks

  1. Before repetitionInitialise PassCount to zero.
  2. Repeated bodyRead a new Mark; increment PassCount only when Mark >= 50.
  3. After ten inputsOutput the accumulated PassCount once.

Core explanation

The three constructs cooperate in a complete solution. Counting passes begins with an initialisation, repeats input and a decision for each mark, and finishes with one output. Indentation shows that the decision is inside the loop while the final output is outside it.

Read each new mark during its iteration. Increase the count only on the qualifying branch and leave it unchanged otherwise. This arrangement counts qualifying inputs rather than counting all iterations or checking one old input repeatedly.

Worked example · Combine sequence, selection and iteration

  1. Requirements

    Read exactly ten integer marks between 0 and 100 and count those at least 50.

  2. Pseudocode
    DECLARE Index : INTEGER
DECLARE Mark : INTEGER
DECLARE PassCount : INTEGER
PassCount <- 0
FOR Index <- 1 TO 10
    INPUT Mark
    IF Mark >= 50 THEN
        PassCount <- PassCount + 1
    ENDIF
NEXT Index
OUTPUT PassCount
  3. Check

    49, 50, 60, 20, 80, 0, 100, 48, 51, 70 contain six passes.

Common misconception

The pass counter is not the FOR-loop counter; they represent different quantities.

Check your understanding

Should a mark of 20 cause PassCount to increase?

Check your answer

No. The condition is false, so that iteration leaves the pass count unchanged.

Practice questions

Question 1 · Command word: Write4 marks

Write pseudocode to input a person's non-negative whole-number age and output "Adult" for an age of at least 18, or "Minor" otherwise. State the outputs at ages 17, 18 and 19.

S9.06.A01
Answer and marking points

One valid pseudocode solution

DECLARE Age : INTEGER
INPUT Age
IF Age >= 18 THEN
    OUTPUT "Adult"
ELSE
    OUTPUT "Minor"
ENDIF
  1. The program inputs Age and tests Age >= 18.
  2. The true branch outputs the literal "Adult".
  3. The false branch outputs the literal "Minor".
  4. The three outputs are Minor, Adult and Adult respectively.

Common error: Age = 18 rejects older adults; use the inclusive inequality.

Question 2 · Command word: Write4 marks

Write pseudocode to input four integers and output their sum once. Explain where the accumulator must be initialised.

S9.06.A01
Answer and marking points

One valid pseudocode solution

DECLARE Index : INTEGER
DECLARE Value : INTEGER
DECLARE Total : INTEGER
Total <- 0
FOR Index <- 1 TO 4
    INPUT Value
    Total <- Total + Value
NEXT Index
OUTPUT Total
  1. Total is set to zero before repetition begins.
  2. A loop performs exactly four inputs.
  3. Each input is added to the current Total inside the loop.
  4. The final Total is output after the loop.

Common error: Do not reset Total during the repeated body.

Question 3 · Command word: Write4 marks

Write pseudocode to read six temperature readings and output the number strictly greater than 80. The readings are integers; all six must be processed.

S9.06.A01
Answer and marking points

One valid pseudocode solution

DECLARE Index : INTEGER
DECLARE Reading : INTEGER
DECLARE WarningCount : INTEGER
WarningCount <- 0
FOR Index <- 1 TO 6
    INPUT Reading
    IF Reading > 80 THEN
        WarningCount <- WarningCount + 1
    ENDIF
NEXT Index
OUTPUT WarningCount
  1. A warning counter starts at zero.
  2. A loop inputs exactly six new readings.
  3. The condition uses Reading > 80.
  4. Only a true comparison increments the warning count, which is output after all readings.

Common error: A reading equal to 80 does not satisfy strictly greater than.

Question 1 · Command word: Write · 4 marks

A supplier charges 7.50 per item when the quantity is at least five, and 8.00 per item otherwise. Write pseudocode to input a positive whole-number quantity and output the total. Calculate the totals for quantities four and five.

Answer and marking points

One valid pseudocode solution

DECLARE Quantity : INTEGER
DECLARE Total : REAL
INPUT Quantity
IF Quantity >= 5 THEN
    Total <- Quantity * 7.50
ELSE
    Total <- Quantity * 8.00
ENDIF
OUTPUT Total
  • The algorithm obtains Quantity and tests Quantity >= 5.
  • The qualifying branch multiplies Quantity by 7.50.
  • The other branch multiplies Quantity by 8.00 and the selected total is output.
  • Four items cost 32.00; five cost 37.50.

Common error: Apply the selected rate to all items under the stated rule.

Question 2 · Command word: Write · 4 marks

Write pseudocode to input a non-negative integer Count, output every positive integer from Count down to 1, then output "Finished". Explain the output when the input is zero.

Answer and marking points

One valid pseudocode solution

DECLARE Count : INTEGER
INPUT Count
WHILE Count > 0 DO
    OUTPUT Count
    Count <- Count - 1
ENDWHILE
OUTPUT "Finished"
  • Count is input before a loop testing Count > 0.
  • Each iteration outputs the current Count.
  • Count decreases by one inside the loop.
  • Finished is output after the loop, and is the only output for zero.

Common error: A pre-condition loop is needed to avoid outputting zero.

Question 3 · Command word: Write · 4 marks

An algorithm reads exactly three integer scores and reports their arithmetic mean. Write pseudocode using iteration and explain why the division belongs after accumulation.

Answer and marking points

One valid pseudocode solution

DECLARE Index : INTEGER
DECLARE Score : INTEGER
DECLARE Total : INTEGER
DECLARE Average : REAL
Total <- 0
FOR Index <- 1 TO 3
    INPUT Score
    Total <- Total + Score
NEXT Index
Average <- Total / 3
OUTPUT Average
  • Total is initialised to zero before the loop.
  • Three scores are obtained and added to Total.
  • Average <- Total / 3 occurs after all additions.
  • The program outputs Average; dividing the final sum uses all three values.

Common error: Do not output three separate partial means.

04

Lesson review

Summary

Sequence

Place dependent calculations after the values they read.

Selection

Translate inclusive and exclusive boundaries accurately and give each branch its proper action.

Iteration

Initialise once, obtain and process new values inside the loop, then output aggregates afterwards.
