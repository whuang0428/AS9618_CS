Character encoding: ASCII, extended ASCII and Unicode

Understand how a character set maps symbols to numeric codes, then distinguish ASCII, extended ASCII and Unicode.

How does a computer store character data as binary, and why do different character sets support different collections of symbols?

Before you start

A display shows 01000001. Can you identify a character without knowing the encoding?

Check your answer

No. A character encoding is needed to map the stored code to a character; ASCII maps this code to A.

01

Character sets and internal binary representation

S1.07.A01

Visual overview

Core explanation

Code and appearance

A character set defines its characters and assigns each a numeric code. That code identifies the character independently of the font used to draw it.

From character to stored bits
  1. Look up the code: Use the agreed character set or encoding. ASCII uppercase A has code 65.
  2. Represent the number: 65 is 1000001 in 7 bits, or 01000001 with an 8-bit storage width.
  3. Interpret consistently: Software must use the agreed encoding to recover the intended character from the bits.

From character to stored bits

  1. CharacterThe user enters or the program selects a symbol.
  2. Numeric codeThe character set assigns that symbol a number.
  3. Binary storageThe number is encoded as a bit pattern in memory.
  4. InterpretationSoftware decodes the bits using the agreed encoding.

Worked example · Store a character when its code is provided

  1. Read the supplied code

    The question states that the character A has numeric code 65.

  2. Convert the code

    Convert 65 to the 8-bit pattern 01000001.

  3. Store the bits

    The computer stores 01000001 rather than a drawn picture of A.

  4. Interpret the bits

    Software uses the agreed encoding to map that code back to the character A.

Common misconception

A computer stores a character code, not the visual shape drawn by a particular font.

Check your understanding

A is code 65 and B is code 66. Which code is stored first for BA?

Check your answer

66 for B; retain the order of the characters.

02

ASCII

S1.07.A02

Visual overview

Core explanation

Standard ASCII is a 7-bit character set, so it provides 2⁷ = 128 possible character codes numbered 0 to 127.

Its repertoire includes common English letters, digits, punctuation and control characters. The limited number of codes means it cannot represent the full range of writing systems used worldwide.

Worked example · Check whether a supplied code fits standard ASCII

  1. Use the width

    A 7-bit code can represent values from 0 to 127.

  2. Inspect the supplied value

    The supplied code value is 65, which lies inside that range.

  3. Write seven bits

    65 is written as the 7-bit pattern 1000001.

  4. State the conclusion

    The supplied character code can be represented in standard ASCII.

Common misconception

ASCII does not provide 256 codes; standard ASCII uses 7 bits and therefore provides 128 codes.

Check your understanding

What is the largest numeric code in seven-bit standard ASCII?

Check your answer

127; the 128 codes include zero.

03

Extended ASCII

S1.07.A03

Visual overview

Core explanation

Extended ASCII uses 8-bit character codes, so it provides 2⁸ = 256 possible code values numbered 0 to 255.

The additional codes can represent extra accented letters and symbols, but 256 values are still insufficient for all world writing systems. Different extended-ASCII code pages may assign different characters to some of the added code values.

Worked example · Use a supplied extended-ASCII code

  1. Read the supplied code page

    The question supplies an 8-bit code page in which a character has code value 233.

  2. Check the range

    233 lies within the 8-bit range 0 to 255.

  3. Convert the value

    233 is stored as the 8-bit pattern 11101001.

  4. Keep the interpretation

    The selected code page determines which character that upper-range value represents.

Common misconception

Extended ASCII is not a single universal worldwide repertoire; an 8-bit code still provides only 256 values.

Check your understanding

Why must two systems agree on which extended ASCII character set they use?

Check your answer

Different extensions can assign different characters to codes above 127.

04

Unicode

S1.07.A04

Visual overview

Core explanation

Unicode assigns code points to characters from a very wide range of languages, symbol systems and modern character collections. This makes it suitable for multilingual data and communication.

Unicode code points can be stored using encodings such as UTF-8 or UTF-16. It is inaccurate to claim that every Unicode character is always stored using exactly the same number of bits.

Worked example · Choose a character set for a multilingual website

  1. Identify the requirement

    The website must store English, Chinese and Arabic text as well as symbols.

  2. Compare the repertoires

    The ASCII repertoires do not provide codes for all of those characters.

  3. Choose Unicode

    Unicode has code points for the required writing systems and symbols.

  4. State the storage detail

    A Unicode encoding such as UTF-8 converts those code points into stored bytes.

Common misconception

Unicode is not restricted to exactly 16 bits per character; the stored length depends on the encoding and character.

Check your understanding

Does Unicode mean every character occupies exactly 16 bits in a file?

Check your answer

No. The encoding, such as UTF-8 or UTF-16, determines how code points are stored.

Explain why standard ASCII provides 128 possible codes and state one limitation.

Answer and marking points
  1. Seven bits give 2^7 = 128 different patterns.
  2. The repertoire cannot represent all characters used in the world's writing systems.

Question 1 · Command word: Explain · 4 marks

A system needs unique codes for 150 symbols. Explain whether standard ASCII has enough codes, calculate the minimum fixed bit width required, and state whether an 8-bit character set provides enough patterns.

Answer and marking points
  • Seven bits provide 2^7 = 128 different patterns.
  • A set of 150 symbols cannot be represented uniquely by only 128 patterns.
  • Eight bits provide 2^8 = 256 patterns.
  • The minimum fixed width is therefore 8 bits.

Common error: Do not assume that seven bits can store values from 0 to 150; seven bits provide only 128 distinct patterns in total.

Question 2 · Command word: Describe · 4 marks

Using the character codes C = 67, A = 65 and T = 84, describe how the text CAT is represented as three 8-bit binary codes.

Answer and marking points
  • Look up or use the numeric code assigned to each character in sequence.
  • The code 67 for C is stored as 01000011.
  • The code 65 for A is stored as 01000001.
  • The code 84 for T is stored as 01010100.

Common error: Do not store the appearance of each letter; the file stores the numeric codes selected by the character set.

Question 3 · Command word: Compare · 4 marks

Compare extended ASCII with Unicode for exchanging English, Arabic, Chinese and emoji text between computers, and justify the more suitable character set.

Answer and marking points
  • Extended ASCII provides only 256 code patterns and different extensions may assign the upper codes differently.
  • That limited repertoire cannot assign codes to all of the required writing systems and emoji.
  • Unicode defines a much larger common repertoire of code points for characters from many writing systems.
  • Unicode is more suitable because the sender and receiver can interpret the multilingual text using the same character assignments.

Common error: Do not claim that every Unicode character is stored in exactly 16 bits; the task concerns repertoire and consistent character assignment.
