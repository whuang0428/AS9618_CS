Address, data and control buses

Core explanation

The address bus carries the address that selects a memory location or an addressed interface. In the basic processor-controlled model it travels outwards from the processor. The data bus carries instructions and data between components and must support reads and writes.

The control bus is a set of coordinating signal lines. Read and write signals travel from the processor; signals such as interrupt requests travel towards it. Calling the control bus bidirectional describes the collection of lines, not a claim that every individual control signal travels both ways.

Worked example · Read then modify a value

  1. Read

    For Memory[300]=8, the processor selects address 300 and issues read; the data bus returns 8.

  2. Calculate

    An internal addition increases the value to 9.

  3. Write

    The processor selects address 300 again, places 9 on the data bus and issues write. The stored value becomes 9.

Common misconception

The address bus does not carry the instruction or data value being fetched.

Check your understanding

Why does writing to a location still need an address?

Check your answer

Memory must know which location should accept the value on the data bus.

Factors affecting processor performance

Core explanation

Processor type matters because instruction sets and internal organisation differ. Designs may use different instruction complexity, pipelining, cache arrangements and amounts of work per clock cycle. A comparison needs a specified workload; a higher clock frequency alone does not establish which different processor is faster.

Additional cores can execute independent tasks or parallel parts of a program concurrently. Sequential dependencies and communication overhead limit the benefit. A wider data bus can transfer more bits at once; a faster clock provides more cycles per second. Neither removes all memory or input/output delays.

Cache stores copies of recently or frequently needed instructions and data close to the processor. A hit avoids a slower main-memory access. Increased cache capacity can help when it retains more of the working set, but performance depends on access patterns and hit rate as well as size.

Worked example · A transfer-bound calculation

  1. Given

    A calculation needs 256 bits transferred over a bus once; ignore protocol overhead.

  2. Compare widths

    At 32 bits per transfer it takes 8 transfers; at 64 bits it takes 4.

  3. Limit the claim

    This halves the transfer count for these data, not necessarily the total program time, which also includes computation and other waits.

Common misconception

Extra cores, clock speed or cache do not guarantee a fixed proportional speed-up.

Check your understanding

Why might doubling cores leave one dependent calculation nearly unchanged?

Check your answer

Its next operation may need the previous result, leaving little work for the extra cores to run concurrently.

USB, HDMI and VGA connections

Swipe horizontally to compare every column →

Core explanation

A port provides a physical and electrical interface for a peripheral connection. The device and computer need compatible signals and protocols. Adapters may convert signals; a connector that fits mechanically is not by itself proof of compatibility.

USB carries digital peripheral data and can provide power. HDMI carries digital video and audio to a compatible display. VGA carries analogue video and does not carry the display's audio. USB capabilities depend on the version, cable and devices, so one speed should not be assigned to every USB connection.

Worked example · A presentation station

  1. Requirements

    A laptop must receive mouse input and send a presentation with sound to an HDMI display.

  2. Connections

    Use USB for the compatible mouse and HDMI for the display.

  3. Legacy alternative

    If only VGA video input is available, a suitable video conversion may be required and sound needs a separate path.

Common misconception

VGA is not a digital audio/video interface.

Check your understanding

Which listed display connection can carry picture and sound together?

Check your answer

HDMI carries both digital video and digital audio.

Practice questions

Question 1 · Command word: Describe5 marks

Describe a processor read from Memory[420] and a write of 27 to Memory[421]. Identify what travels on each bus and its direction.

S4.04.A01
Answer and marking points
  1. For the read, address 420 travels from the processor on the address bus.
  2. The control bus carries the read signal to memory; the data bus returns Memory[420] to the processor.
  3. For the write, address 421 travels from the processor on the address bus.
  4. The data bus carries 27 towards memory and the control bus carries the write signal.
  5. The data bus supports both transfer directions; control-bus lines include signals to and from the processor.

Common error: Do not place the contents of location 420 on the address bus.

Question 2 · Command word: Explain4 marks

Explain why a four-core processor may improve the time to compress four independent files but may give little improvement for a single sequential calculation. Explain why different processor types cannot be ranked using clock speed alone.

S4.05.A01S4.05.A02
Answer and marking points
  1. Independent compression tasks can run concurrently on separate cores.
  2. The sequential calculation may have dependencies that prevent useful parallel execution.
  3. Processor types can differ in instruction set and internal organisation.
  4. They may perform different amounts of useful work per cycle, so workload and architecture also affect completion time.

Common error: Four cores do not guarantee four times the speed for every program.

Question 3 · Command word: Calculate5 marks

Calculate the minimum number of data-bus transfers needed for 128 bits using a 32-bit bus and a 64-bit bus. Explain how a higher clock frequency and a larger effective cache can affect execution, with one condition for each claim.

S4.05.A03S4.05.A04S4.05.A05
Answer and marking points
  1. A 32-bit bus requires 128/32 = 4 transfers.
  2. A 64-bit bus requires 128/64 = 2 transfers.
  3. A higher frequency allows more processor cycles per second, if the architecture and other constraints are comparable.
  4. A cache hit supplies reused instructions or data faster than main memory, reducing processor waiting.
  5. A larger cache helps only when it improves useful hits; misses and other bottlenecks still limit performance.

Common error: Bus width is bits per transfer; clock frequency is cycles per second.

Question 4 · Command word: Suggest4 marks

Suggest a port for each connection and justify your choice: a USB keyboard, a digital display with integrated speakers, and a legacy VGA-only monitor. Compare the signals carried by HDMI and VGA.

S4.06.A01S4.06.A02S4.06.A03S4.06.A04
Answer and marking points
  1. Use USB for the keyboard's peripheral data connection; the connection can also supply power.
  2. Use HDMI for a compatible digital display and its audio over one connection.
  3. Use VGA for the specified legacy monitor's analogue video input.
  4. HDMI carries digital video and audio; VGA carries analogue video and needs a separate audio connection.

Common error: A connector shape alone does not determine every supported USB version or transfer speed.

Question 1 · Command word: Describe · 4 marks

A processor writes the 16-bit value 0000000000010011 to location 900. Describe the roles of the address, data and control buses. Explain why bidirectional data transfer is still needed even if this particular operation is a write.

Answer and marking points
  • The address bus identifies destination location 900.
  • The data bus carries the specified 16-bit value from the processor towards memory.
  • A memory-write control signal tells memory to accept that value.
  • Later reads, including instruction fetches, require data to travel from memory towards the processor.

Common error: Write direction for one transaction does not make the whole data bus unidirectional.

Question 2 · Command word: Explain · 5 marks

Two processors use the same instruction set and clock frequency. P has eight cores and a small cache; Q has four cores and a larger cache. Explain why P may be faster for eight independent jobs but Q may be faster for a single program that repeatedly accesses a working set that fits Q's cache only.

Answer and marking points
  • P can allocate more of the independent jobs to cores at the same time.
  • The independent jobs have useful parallel work, so its extra cores can reduce total completion time.
  • The single program may not expose enough parallel work to use P's extra cores.
  • Q can retain the specified working set in cache and avoid more main-memory waits.
  • Equal clock frequency and instruction-set compatibility do not make the two internal cache/core organisations equally fast for every workload.

Common error: Use the given workload to justify a choice; do not declare one processor universally faster.

Question 3 · Command word: Identify · 5 marks

A museum computer must connect a USB barcode scanner, an HDMI display with sound and an old VGA projector. Identify a suitable connection for each. Explain why carrying display data on a 64-bit internal data bus does not imply that every external connector transfers 64 bits in parallel.

Answer and marking points
  • The scanner uses a compatible USB port for peripheral data.
  • The display uses HDMI to carry its digital picture and audio.
  • The projector uses VGA for analogue video, with a separate audio connection if sound is required.
  • Internal data-bus width describes bits carried in one internal transfer.
  • External interfaces use their own signalling and protocols; USB and HDMI links do not simply extend that internal parallel bus.

Common error: Keep internal bus width separate from the properties of an external port.
