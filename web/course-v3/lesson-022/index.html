4.1.6

Processor type and number of cores

Two CPU designs perform the same calculation

Both examples start with Memory[4] = 18 and Memory[5] = 24 and store 42 at address 6. These snippets show the calculation and store only. CPU A uses the accumulator model from 4.1.2: ADD reads ACC and writes its result back to ACC without naming that register.

CPU A · accumulator model
LDD 4
ADD 5
STO 6

CPU B names its working registers

CPU B is a separate illustrative design, not Cambridge assembly syntax. LOAD and STORE access memory; arithmetic uses registers. Here [4] means the contents of memory address 4. In ADD R3, R1, R2, R1 and R2 supply 18 and 24, and R3 receives 42.

CPU B · general-purpose register model
LOAD R1, [4]
LOAD R2, [5]
ADD R3, R1, R2
STORE [6], R3

Instruction formats reflect the programmer-visible design

Compare the additionCPU A: ADD 5CPU B: ADD R3, R1, R2
First sourceACC is implied by the instructionR1 is explicitly named
Second sourceRead memory address 5Read R2, loaded by an earlier instruction
DestinationACC is implied by the instructionR3 is explicitly named
Information to encodeOperation and memory addressOperation, destination register and two source registers
Result of these snippetsACC = 42; Memory[6] = 42R3 = 42; Memory[6] = 42

These designs define different operand forms and memory-access rules. Each needs an encoding that its decoder understands; sharing the mnemonic ADD does not make their machine code interchangeable. The A snippet uses three instructions and B uses four, but counts alone do not establish which is faster: elapsed time also depends on the work and time taken by each instruction and on memory access.

Different hardware can implement the same instruction set

An instruction set architecture (ISA) specifies the operations, encodings and programmer-visible rules, including register use. A microarchitecture is the internal hardware design that implements those rules. Two processors can use different internal circuits while supporting the same instructions; their different internal structure does not by itself imply a different instruction set. At the instruction level, code is compatible when the required instructions and modes are supported; a complete application also needs the appropriate system environment. In 4.2.1, the assembler must target the chosen instruction set. The next example compares another possible difference: an instruction that works on one value versus one that works on several values.

Arm: instruction set architecture and microarchitecture

Two hole punches doing the same job

A processor with a vector instruction can apply one arithmetic operation to several independent pixels at once. Like the four-hole punch, it saves repetitions when the work fits the operation.

How much useful work does an instruction do?

WorkloadOne pixel per arithmetic instructionFour pixels per vector arithmetic instruction
Brighten eight independent pixels8 arithmetic instructions2 vector arithmetic instructions
Brighten just one pixel1 arithmetic instruction1 vector arithmetic instruction with one active lane

Apply the same adjustment to every requested pixel. In this example, the vector processor can turn unused lanes off. The counts cover the arithmetic. Loading pixels, issuing instructions and storing the results also take time. Processor type affects elapsed time through the instructions available and the time each takes.

Two proofreaders divide four independent pages

Each proofreader represents a core. Two cores can divide the independent work, but both need the result of the serial preparation. They also spend time communicating and combining their corrections. Those four extra minutes turn a 60-minute finish into a 64-minute finish.

Why twice as many cores can deliver less than twice the performance

Work for one jobOne core · time unitsTwo cores · elapsed time units
Prepare the shared correction key2020
Check four independent pages8080 ÷ 2 = 40
Exchange and combine results04
Total elapsed time20 + 80 = 10020 + 40 + 4 = 64

Divide the original time by the new time to find the speedup, 100 ÷ 64 ≈ 1.56×. Both cores need the shared key before they can start checking pages. Communicating their results takes a further four units.

4.1.7

Bus width and transfer capacity

A wider ferry carries more crates per crossing

Count the transfers

Block to sendData-bus widthTransfers needed
256 bits32 bits per transfer256 ÷ 32 = 8 transfers
256 bits64 bits per transfer256 ÷ 64 = 4 transfers

At the same transfer rate, the wider bus finishes sending this block in half the time. A program that mostly calculates with data in registers may spend little of its running time moving blocks.

Width can describe two different limits

BusQuestion it answersExample
Data busHow many bits can cross in one transfer?A 32-bit bus needs three transfers for 65 bits. The last transfer carries the remaining bit.
Address busHow many distinct locations can the CPU select?Eight address lines encode 2⁸ = 256 addresses. If each location holds one byte, the addressable capacity is 256 bytes.

4.1.8

Clock speed and time to finish a task

Six beats on two metronomes

Convert cycles to time

Clock frequencyTime for one cycleTime for a six-cycle task
1 GHz1 ns6 × 1 ns = 6 ns
2 GHz0.5 ns6 × 0.5 ns = 3 ns

Clock frequency counts cycles per second. The example assumes the same processor design, the same six cycles of work and no additional stalls. A different processor can need a different number of cycles for that task.

4.1.9

Cache memory and the cost of a repeated read

A desk shelf keeps the book you just used

Trace the next four reads

ReadAlready cached?How the CPU gets the valueCached afterwards
1 · ANo · missRead A from main memory and cache a copy.A
2 · AYes · hitRead the cached copy of A.A
3 · BNo · missRead B from main memory and cache a copy.A, B
4 · AYes · hitRead the cached copy of A.A, B

The cache starts empty and can retain both A and B. The sequence is miss, hit, miss, hit. Two of the four reads require a trip to main memory.

When does a larger cache help?

A larger cache can hold more of the program’s working data and instructions. Reusing a retained item saves a slower main-memory access. When a program reads every item just once and gains no useful neighbouring data from fetched blocks, increasing the cache may give little improvement.

Processor performance

Original question · Cambridge 9618/12

1. Explain two separate processor improvements

Cambridge 9618/12 · October/November 2025 · 3(c) · 4 marks

Selected parts: 3(c) [4].

Reading the question — teacher guidance

Both processors are dual-core: the number of cores has not increased. Explain the clock-speed and cache changes separately.

Solution / model answer — teacher-written

The higher clock speed permits more fetch-execute cycles per second, so more instructions can be processed in a given time.

The larger cache can hold more frequently used instructions close to the processor. More accesses can therefore be served from cache instead of slower RAM, reducing waiting time.

Official mark scheme
Why this earns marks — teacher explanation

The four marks are capped at two for clock speed and two for cache. A detailed answer about only one factor cannot earn all four.

Common mistakes — teacher analysis

The cache capacity doubles, but that does not establish that total computer performance doubles. Neither change adds processor cores.

Original question · Cambridge 9618/11

2. Explain the speed of two cores on the same workload

Cambridge 9618/11 · October/November 2023 · 5(c)(ii) · 5 marks

Selected parts: 5(c)(ii) [5].

Reading the question — teacher guidance

The clock frequency per core is held at 2.1 GHz. Consider how much work the program can divide, what information each core needs and how quickly memory can supply it.

Solution / model answer — teacher-written

If the next calculation depends on the result of the previous one, one core can be idle during that part. Even where both cores have work, they may spend time passing results between them and waiting for shared data. Both may also wait when the memory system cannot supply their requests quickly enough. Adding a core therefore need not halve the running time.

Official mark scheme
Why this earns marks — teacher explanation

Link each cause to its effect. Limited parallel work can leave one core idle. Communication consumes time, and slow memory can delay both cores. The scheme allows up to five marks.

Common mistakes — teacher analysis

Each core still uses a 2.1 GHz clock. Adding the frequencies does not give the speed of a serial instruction sequence.

Original question · Cambridge 9618/11

3. Explain how bus width affects a computer

Cambridge 9618/11 · May/June 2025 · 6(a)(iii) · 2 marks

Selected parts: 6(a)(iii) [2].

Teacher solution and explanation

The specifications belong to two complete computers. Focus on the two meanings of width: bits moved by a data transfer and bits available to select an address.

With equal transfer timing, a wider data bus moves more bits at once. A fixed block that previously needed multiple transfers can then arrive in fewer transfers, reducing time spent waiting for data. A wider address bus can encode more distinct addresses and therefore select more memory locations directly.

The scheme awards up to two points. For the data bus, connect the larger amount per transfer to its effect on waiting. For the address bus, connect additional address bits to the number of directly selectable locations.

A wider address bus increases the range of addresses. The data-bus width determines how many bits of the stored value travel together.

USB — Universal Serial Bus

USB Standard-A and Type-C sockets

A computer exchanges digital data with a USB drive in both directions and supplies power to the drive. A USB 2.0 Standard-A connection uses four contacts: VBUS and GND for power, and D+ and D− for data.

Peripheral interfaces

Original question · Cambridge 9618/12

1. Use the monitor’s resolution and speakers in an explanation

Cambridge 9618/12 · October/November 2024 · 3(b) · 4 marks

Selected parts: 3(b) [4].

Reading the question — teacher guidance

The monitor has 2560 × 1600 pixels and built-in speakers. Link interface features to these given requirements.

Solution / model answer — teacher-written

HDMI can carry both the video and the audio for the built-in speakers, so a separate audio cable is not needed as it would be with VGA. It supports the monitor’s high-resolution image and transfers a digital signal, avoiding conversion of the image to analogue and back.

Official mark scheme
Why this earns marks — teacher explanation

The scheme awards up to four listed benefits or linked consequences. The answer supplies combined audio/video, no separate sound cable, high-resolution support and the digital-signal benefit. Additional acceptable points do not raise the total.

Common mistakes — teacher analysis

“HDMI is better” is not a mechanism. Do not invent a transfer-rate multiplier or claim that every HDMI/VGA version has the same maximum resolution.

2. Identify the port and explain automatic device recognition

Cambridge 9618/11 · October/November 2024 · 3(b)(ii) · 3 marks

Selected parts: 3(b)(ii) [3].

Reading the question — teacher guidance

The key event is plugging a flash drive into a running computer. Follow the connection from detection to the driver that lets the OS use the device.

Solution / model answer — teacher-written

Use a USB port. The host detects an electrical change as the drive is attached. During enumeration it obtains identifying information from the device. The OS uses that information to select and load an appropriate driver.

Official mark scheme
Why this earns marks — teacher explanation

Naming USB earns one mark. Two further marks are available for stages in detection and recognition, such as sensing the voltage change and receiving the device identification.

Common mistakes — teacher analysis

Describing a plug as reversible or naming its shape does not explain how the computer recognises a drive.

Consider the kind of signal reaching the monitor and the content one cable can carry.

The computer transmits a stream of digital video to the monitor. Audio for its speakers can travel in the same cable. HDMI provides the bandwidth needed to carry these streams.

Additional teacher-written practice
Question 1 · Command word: Describe5 teacher marks

Describe a processor read from Memory[420] and a write of 27 to Memory[421]. Identify what travels on each bus and its direction.

S4.04.A01
Answer and checking points — teacher-written
  1. For the read, address 420 travels from the processor on the address bus.
  2. The control bus carries the read signal to memory; the data bus returns Memory[420] to the processor.
  3. For the write, address 421 travels from the processor on the address bus.
  4. The data bus carries 27 towards memory and the control bus carries the write signal.
  5. The data bus supports both transfer directions; control-bus lines include signals to and from the processor.

Common error: Do not place the contents of location 420 on the address bus.

Question 2 · Command word: Explain4 teacher marks

Explain why a four-core processor may improve the time to compress four independent files but may give little improvement for a single sequential calculation. Explain why different processor types cannot be ranked using clock speed alone.

S4.05.A01S4.05.A02
Answer and checking points — teacher-written
  1. Independent compression tasks can run concurrently on separate cores.
  2. The sequential calculation may have dependencies that prevent useful parallel execution.
  3. Processor types can differ in instruction set and internal organisation.
  4. They may perform different amounts of useful work per cycle, so workload and architecture also affect completion time.

Common error: Four cores do not guarantee four times the speed for every program.

Question 3 · Command word: Calculate5 teacher marks

Calculate the minimum number of data-bus transfers needed for 128 bits using a 32-bit bus and a 64-bit bus. Explain how a higher clock frequency and a larger effective cache can affect execution, with one condition for each claim.

S4.05.A03S4.05.A04S4.05.A05
Answer and checking points — teacher-written
  1. A 32-bit bus requires 128/32 = 4 transfers.
  2. A 64-bit bus requires 128/64 = 2 transfers.
  3. A higher frequency allows more processor cycles per second, if the architecture and other constraints are comparable.
  4. A cache hit supplies reused instructions or data faster than main memory, reducing processor waiting.
  5. A larger cache helps only when it improves useful hits; misses and other bottlenecks still limit performance.

Common error: Bus width is bits per transfer; clock frequency is cycles per second.

Question 4 · Command word: Suggest4 teacher marks

Suggest a port for each connection and justify your choice: a USB keyboard, a digital display with integrated speakers, and a legacy VGA-only monitor. Compare the signals carried by HDMI and VGA.

S4.06.A01S4.06.A02S4.06.A03S4.06.A04
Answer and checking points — teacher-written
  1. Use USB for the keyboard's peripheral data connection; the connection can also supply power.
  2. Use HDMI for a compatible digital display and its audio over one connection.
  3. Use VGA for the specified legacy monitor's analogue video input.
  4. HDMI carries digital video and audio; VGA carries analogue video and needs a separate audio connection.

Common error: A connector shape alone does not determine every supported USB version or transfer speed.

Question 5 · Command word: Identify3 teacher marks

An empty cache can hold both A and B. Reads occur in the order A,A,B,A; a miss fetches and retains the item, with no eviction or memory writes. Identify each hit or miss and calculate the number of RAM reads. Explain what changes for A,B,C,D when the cache has room for all four.

S4.05.A05
Answer and checking points — teacher-written
  1. The first A misses; the second A hits; B misses; the final A hits.
  2. There are two RAM reads.
  3. A,B,C,D has four misses and four RAM reads because every request is a first access.

Common error: A first access is still a miss even with enough capacity.

Question 6 · Command word: Calculate4 teacher marks

A system has 10 address bits and stores two bytes at each addressed location. Calculate its maximum addressable capacity in bytes. Calculate how many transfers carry 100 bits over a 32-bit data bus, ignoring overhead, and explain why this does not give the program time.

S4.04.A01S4.05.A03
Answer and checking points — teacher-written
  1. 2^10=1024 locations.
  2. 1024×2=2048 bytes.
  3. Four transfers are needed because three carry only 96 bits.
  4. Total time also includes computation, timing and other waits; a transfer count alone is insufficient.

Common error: Locations and bytes are different units unless byte addressing is specified.
