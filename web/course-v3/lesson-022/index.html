01

Address, data and control buses

S4.04.A01

Visual overview

The address bus carries the address that selects a memory location or an addressed interface. In the basic processor-controlled model it travels outwards from the processor. The data bus carries instructions and data between components and must support reads and writes.

The control bus is a set of coordinating signal lines. Read and write signals travel from the processor; signals such as interrupt requests travel towards it. Calling the control bus bidirectional describes the collection of lines, not a claim that every individual control signal travels both ways.

A read does not move the address into ACC. The CPU first selects the location through the address bus and requests a read through a control line. The stored contents return on the data bus and can be copied from MDR into ACC. Reading normally leaves the stored contents unchanged.

A write needs both a destination and a value: MAR supplies the address, MDR supplies the data, and the CU issues write. The same data wires can carry values in opposite directions on different transactions; they do not mean both components drive different values onto them at once.

For the shared calculation, reading Memory[4] sends address 4 outward and value 18 inward. Writing the result sends address 6 and value 42 outward, on different buses. A peripheral interrupt request is a control signal towards the CPU, illustrating why the control bus contains lines in both directions.

Worked example · Read then modify a value

  1. Read

    For Memory[300]=8, the processor selects address 300 and issues read; the data bus returns 8.

  2. Calculate

    An internal addition increases the value to 9.

  3. Write

    The processor selects address 300 again, places 9 on the data bus and issues write. The stored value becomes 9.

Core explanation · Exam essentials

  • Address selects a location; data carries its instruction/value; control coordinates the transaction. A read and a write reverse the data direction.
Common misconception

The address bus does not carry the instruction or data value being fetched.

Check your understanding

Why does writing to a location still need an address?

Check your answer

Memory must know which location should accept the value on the data bus.

Swipe horizontally to compare every column →

Address width and data width answer different questions. Each address bit doubles the number of address patterns, so n bits provide 2^n distinct addresses numbered 0 to 2^n−1. This is a useful calculation model for understanding buses; a location is not automatically a byte.

To convert addressable locations to a byte capacity, multiply by the stated bytes per location. To count data transfers, divide the number of bits by the bits carried per transfer and round up if the last transfer is partial. Neither calculation gives the whole program’s running time.

Worked example · A partial final transfer

  1. Conditions

    Transfer 100 bits using a 32-bit data bus; ignore protocol overhead.

  2. Count

    Three transfers carry only 96 bits, so a fourth is required.

  3. Interpret

    Four transfers suffice. This does not imply that four instructions or four clock cycles complete the entire task.

Core explanation · Exam essentials

  • An n-bit address selects up to 2^n locations. Data-bus width gives bits per transfer; capacity also depends on bytes per addressed location.
Common misconception

A location is not necessarily one byte; data-bus width does not determine the number of address patterns.

Check your understanding

A 10-bit address selects two-byte locations. What is the capacity?

Check your answer

2^10=1024 locations; 1024×2=2048 bytes, or 2 KiB.

03

Cache hits, misses and repeated reads

S4.05.A05

Visual overview

A processor may need the same instruction or data many times. Cache keeps copies close to the processor so a later access can avoid the longer main-memory path. SRAM/DRAM storage mechanisms were introduced in the memory lesson; here the focus is what this does to execution time.

For this read-only example, the cache starts empty, has room for both items A and B, and loads an item on a miss. No item is evicted and main memory does not change. Count each requested item as one cache lookup; ignore block-fetch details so the state changes are explicit.

The first A and first B cannot hit an empty cache. After each miss the fetched item is retained, so the next A and B can hit. Only two of the four requests need main-memory reads. A stream of different items, each used once, would not gain these repeated-read hits.

Worked example · Change the workload

  1. Compare

    With enough space and an empty cache, A,B,A,B has two misses and two hits. A,B,C,D has four misses because no item is reused.

  2. Conclude

    A larger cache may retain more useful data, but does not make a first access a hit. Fewer slow reads can reduce memory waiting; total speed-up still depends on the rest of the program.

Core explanation · Exam essentials

  • A cache hit supplies a retained copy; a miss requires main-memory access. Benefit depends on reuse and whether needed items remain in cache.
Optional extension · why nearby or repeated accesses can help

Repeated access to the same item is temporal locality; accessing nearby items is spatial locality. These ideas explain why caches can be useful. This optional connection stops at access patterns; replacement policies, cache mapping and coherence protocols are outside this lesson.

Common misconception

Increasing cache capacity does not make a first access a hit.

Check your understanding

Starting empty with space for A and B, which requests miss in A,A,B,A?

Check your answer

The first A and first B miss; the second and final A hit. There are two RAM reads.

Factors affecting processor performance

S4.05.A01S4.05.A02S4.05.A03S4.05.A04S4.05.A05

Visual overview

Workload and limiting condition

FactorPotential improvementCondition
Processor typeMore suitable operations or work per cycleCompare architecture and actual workload
Number of coresMore simultaneous computationEnough parallel work exists
Data-bus widthMore bits per transferTransfers are a relevant bottleneck
Clock speedMore cycles per secondOther factors remain comparable
Cache memoryFewer slow main-memory readsNeeded items produce useful cache hits

Swipe horizontally to compare every column →

Identify what is limiting the task before choosing a factor. Independent jobs may use extra cores; a chain in which each calculation needs the previous result has less parallel work. Waiting for memory is different from doing arithmetic inside a core.

Clock frequency is cycles per second, not instructions per second. With comparable processors and the same cycle count, more cycles per second can reduce time. Between different processor types the amount of useful work per cycle may differ, so clock frequency alone cannot rank them.

Use a conditional explanation: extra cores can reduce the time for independent work because multiple cores execute it concurrently; this depends on software exposing that work and not spending the gain on coordination. A statement that eight cores always run a task twice as fast as four ignores those conditions.

Worked example · A transfer-bound calculation

  1. Given

    A calculation needs 256 bits transferred over a bus once; ignore protocol overhead.

  2. Compare widths

    At 32 bits per transfer it takes 8 transfers; at 64 bits it takes 4.

  3. Limit the claim

    This halves the transfer count for these data, not necessarily the total program time, which also includes computation and other waits.

Core explanation · Exam essentials

  • Justify performance using the workload: processor type, cores, data-bus width, clock frequency and cache affect different parts of execution.
Optional extension · work per cycle

Two processors can complete the same task using different numbers of cycles because their instructions and internal organisation differ. Compare an actual workload to see the consequence. Detailed pipelines and RISC/CISC comparisons are not required for this AS explanation.

Common misconception

Extra cores, clock speed or cache do not guarantee a fixed proportional speed-up.

Check your understanding

Why might doubling cores leave one dependent calculation nearly unchanged?

Check your answer

Its next operation may need the previous result, leaving little work for the extra cores to run concurrently.

05

USB, HDMI and VGA connections

S4.06.A01S4.06.A02S4.06.A03S4.06.A04

Visual overview

A port provides a physical and electrical interface for a peripheral connection. The device and computer need compatible signals and protocols. Adapters may convert signals; a connector that fits mechanically is not by itself proof of compatibility.

USB carries digital peripheral data and can provide power. HDMI carries digital video and audio to a compatible display. VGA carries analogue video and does not carry the display's audio. USB capabilities depend on the version, cable and devices, so one speed should not be assigned to every USB connection.

Choose a port from the required signal and the connected equipment. A display needing sound through the same connection can use compatible HDMI. VGA alone cannot satisfy that sound requirement. A USB scanner exchanges peripheral data rather than using VGA’s analogue picture signals.

A connector’s appearance is evidence about how it fits, not a complete specification of its capability. USB versions, cables and devices differ. Avoid assigning one speed to all USB ports or treating an internal data-bus width as the number of parallel wires in every external connection.

If an adapter is needed, determine whether the signal has to be converted. Digital HDMI and analogue VGA use different signal forms; a purely mechanical change of plug is not enough to establish compatibility.

Worked example · A presentation station

  1. Requirements

    A laptop must receive mouse input and send a presentation with sound to an HDMI display.

  2. Connections

    Use USB for the compatible mouse and HDMI for the display.

  3. Legacy alternative

    If only VGA video input is available, a suitable video conversion may be required and sound needs a separate path.

  • USB: digital peripheral data and possible power; HDMI: digital video/audio; VGA: analogue video with separate audio. Match both device and interface.
Common misconception

VGA is not a digital audio/video interface.

Check your understanding

Which listed display connection can carry picture and sound together?

Check your answer

HDMI carries both digital video and digital audio.

Practice questions

6 core tasks · 25 teacher marks · 20–25 minutes (teacher estimate). Explain your reasoning before checking the answer.

Question 1 · Command word: Describe5 teacher marks

Describe a processor read from Memory[420] and a write of 27 to Memory[421]. Identify what travels on each bus and its direction.

S4.04.A01
Answer and checking points — teacher-written
  1. For the read, address 420 travels from the processor on the address bus.
  2. The control bus carries the read signal to memory; the data bus returns Memory[420] to the processor.
  3. For the write, address 421 travels from the processor on the address bus.
  4. The data bus carries 27 towards memory and the control bus carries the write signal.
  5. The data bus supports both transfer directions; control-bus lines include signals to and from the processor.

Common error: Do not place the contents of location 420 on the address bus.

Question 2 · Command word: Explain4 teacher marks

Explain why a four-core processor may improve the time to compress four independent files but may give little improvement for a single sequential calculation. Explain why different processor types cannot be ranked using clock speed alone.

S4.05.A01S4.05.A02
Answer and checking points — teacher-written
  1. Independent compression tasks can run concurrently on separate cores.
  2. The sequential calculation may have dependencies that prevent useful parallel execution.
  3. Processor types can differ in instruction set and internal organisation.
  4. They may perform different amounts of useful work per cycle, so workload and architecture also affect completion time.

Common error: Four cores do not guarantee four times the speed for every program.

Question 3 · Command word: Calculate5 teacher marks

Calculate the minimum number of data-bus transfers needed for 128 bits using a 32-bit bus and a 64-bit bus. Explain how a higher clock frequency and a larger effective cache can affect execution, with one condition for each claim.

S4.05.A03S4.05.A04S4.05.A05
Answer and checking points — teacher-written
  1. A 32-bit bus requires 128/32 = 4 transfers.
  2. A 64-bit bus requires 128/64 = 2 transfers.
  3. A higher frequency allows more processor cycles per second, if the architecture and other constraints are comparable.
  4. A cache hit supplies reused instructions or data faster than main memory, reducing processor waiting.
  5. A larger cache helps only when it improves useful hits; misses and other bottlenecks still limit performance.

Common error: Bus width is bits per transfer; clock frequency is cycles per second.

Question 4 · Command word: Suggest4 teacher marks

Suggest a port for each connection and justify your choice: a USB keyboard, a digital display with integrated speakers, and a legacy VGA-only monitor. Compare the signals carried by HDMI and VGA.

S4.06.A01S4.06.A02S4.06.A03S4.06.A04
Answer and checking points — teacher-written
  1. Use USB for the keyboard's peripheral data connection; the connection can also supply power.
  2. Use HDMI for a compatible digital display and its audio over one connection.
  3. Use VGA for the specified legacy monitor's analogue video input.
  4. HDMI carries digital video and audio; VGA carries analogue video and needs a separate audio connection.

Common error: A connector shape alone does not determine every supported USB version or transfer speed.

Question 5 · Command word: Identify3 teacher marks

An empty cache can hold both A and B. Reads occur in the order A,A,B,A; a miss fetches and retains the item, with no eviction or memory writes. Identify each hit or miss and calculate the number of RAM reads. Explain what changes for A,B,C,D when the cache has room for all four.

S4.05.A05
Answer and checking points — teacher-written
  1. The first A misses; the second A hits; B misses; the final A hits.
  2. There are two RAM reads.
  3. A,B,C,D has four misses and four RAM reads because every request is a first access.

Common error: A first access is still a miss even with enough capacity.

Question 6 · Command word: Calculate4 teacher marks

A system has 10 address bits and stores two bytes at each addressed location. Calculate its maximum addressable capacity in bytes. Calculate how many transfers carry 100 bits over a 32-bit data bus, ignoring overhead, and explain why this does not give the program time.

S4.04.A01S4.05.A03
Answer and checking points — teacher-written
  1. 2^10=1024 locations.
  2. 1024×2=2048 bytes.
  3. Four transfers are needed because three carry only 96 bits.
  4. Total time also includes computation, timing and other waits; a transfer count alone is insufficient.

Common error: Locations and bytes are different units unless byte addressing is specified.

Original question · Cambridge 9618/12

1. Use the monitor’s resolution and speakers in an explanation

Cambridge 9618/12 · October/November 2024 · 3(b) · 4 marks

Selected parts: 3(b) [4].

Reading the question — teacher guidance

The monitor has 2560 × 1600 pixels and built-in speakers. Link interface features to these given requirements.

Solution / model answer — teacher-written

HDMI can carry both the video and the audio for the built-in speakers, so a separate audio cable is not needed as it would be with VGA. It supports the monitor’s high-resolution image and transfers a digital signal, avoiding conversion of the image to analogue and back.

Official mark scheme
Why this earns marks — teacher explanation

The scheme awards up to four listed benefits or linked consequences. The answer supplies combined audio/video, no separate sound cable, high-resolution support and the digital-signal benefit. Additional acceptable points do not raise the total.

Common mistakes — teacher analysis

“HDMI is better” is not a mechanism. Do not invent a transfer-rate multiplier or claim that every HDMI/VGA version has the same maximum resolution.

Original question · Cambridge 9618/12

2. Explain two separate processor improvements

Cambridge 9618/12 · October/November 2025 · 3(c) · 4 marks

Selected parts: 3(c) [4].

Reading the question — teacher guidance

Both processors are dual-core: the number of cores has not increased. Explain the clock-speed and cache changes separately.

Solution / model answer — teacher-written

The higher clock speed permits more fetch-execute cycles per second, so more instructions can be processed in a given time.

The larger cache can hold more frequently used instructions close to the processor. More accesses can therefore be served from cache instead of slower RAM, reducing waiting time.

Official mark scheme
Why this earns marks — teacher explanation

The four marks are capped at two for clock speed and two for cache. A detailed answer about only one factor cannot earn all four.

Common mistakes — teacher analysis

The cache capacity doubles, but that does not establish that total computer performance doubles. Neither change adds processor cores.
