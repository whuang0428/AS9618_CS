Processor fundamentals · Concept 01

A memory transfer needs address, value and control

Observe

Start with a question

How does memory know whether to send 24 or receive 42?

First the processor reads address 5. Later it writes to address 6. Both actions select a location, but the transferred value moves in a different direction.

Explain

Explanation · 1 / 4

Select a location

The address bus carries the address of the selected memory location or peripheral interface. In the basic processor-controlled model, this information travels from the CPU towards memory or the interface. Reading address 5 sends 5 on the address bus, not 24.

Explanation · 2 / 4

Transfer the contents

The data bus carries instruction words or data. During a read, a value travels from memory to the CPU. During a write, it travels from the CPU to memory. It must therefore support both directions, although a particular transfer has one direction.

Explanation · 3 / 4

Specify and coordinate the operation

The control bus carries signals such as memory read and memory write. A read signal tells memory to supply the selected contents; a write signal tells it to accept the supplied value. Other lines carry requests towards the CPU. The collection has signals in both directions; each individual line has its own role.

Explanation · 4 / 4

Read a complete transaction

A useful explanation includes the selected address, the value and its direction, and the control signal. These are cooperating parts of one transaction, not three alternative ways of sending the same number.

TransactionAddress busData busControl
Read Memory[5]CPU → memory: 5Memory → CPU: 24Read
Write Memory[6]CPU → memory: 6CPU → memory: 42Write

The CU issues the write signal. Memory[6] becomes 42; ACC can still contain 42.

Apply the idea · Teacher-written practice
Question 1 · Command word: Describe5 teacher marks

Describe a processor read from Memory[420] and a write of 27 to Memory[421]. Identify what travels on each bus and its direction.

S4.04.A01
Answer and checking points — teacher-written
  1. For the read, address 420 travels from the processor on the address bus.
  2. The control bus carries the read signal to memory; the data bus returns Memory[420] to the processor.
  3. For the write, address 421 travels from the processor on the address bus.
  4. The data bus carries 27 towards memory and the control bus carries the write signal.
  5. The data bus supports both transfer directions; control-bus lines include signals to and from the processor.

Common error: Do not place the contents of location 420 on the address bus.

Connect

Keep this idea

Address bus selects; data bus transfers; control bus coordinates.

The number of lines affects how many addresses or data bits can be represented at once.

Check a common misunderstanding

The control bus is a collection of signals, not a second data bus.

Processor fundamentals · Concept 02

Distinguish address capacity from transfer width

Observe

Start with a question

Does doubling the data-bus width double the number of memory addresses?

Compare carrying 100 data bits in packets of 8 bits and packets of 32 bits. Separately, list the addresses that can be selected using only three binary address lines.

Explain

Explanation · 1 / 4

Count binary addresses

Each address line carries one bit, which can be 0 or 1. Three address bits form eight patterns from 000 to 111, so they select eight locations numbered 0 to 7. In general, n address bits can distinguish 2^n locations.

Explanation · 2 / 4

Check the size of a location

A location is not necessarily one byte. If 10 address bits select 1024 locations and each location holds two bytes, total addressable capacity is 2048 bytes. State the unit instead of automatically turning a number of locations into bytes.

Explanation · 3 / 4

Count data transfers

A w-bit data bus carries up to w bits in one transfer in this simple model. Divide the amount of data by w and round up because a final partial transfer still takes a transfer. Moving 100 bits over a 32-bit bus needs four transfers; three transfers carry only 96 bits.

100-bit itemBits per transferTransfers required
Same item813
Same item167
Same item324

Explanation · 4 / 4

Limit the performance claim

A wider data bus can reduce the transfers required for the same data. It does not itself increase the number of address patterns. Total program time also includes calculation and waiting, so a transfer-count improvement is not automatically the same improvement in the entire program.

Work together

Transfer 256 bits

Ignore protocol overhead and compare 32-bit and 64-bit data buses.

Work together · 1 / 2

Calculate both counts

256 ÷ 32 = 8 transfers; 256 ÷ 64 = 4 transfers.

Work together · 2 / 2

Explain precisely

The wider bus halves the number of transfers for this item. There is not enough information to claim that the whole program runs in half the time.

Use address bits for locations and data-bus bits for the amount transferred.

Question 1 · Command word: Calculate4 teacher marks

A system has 10 address bits and stores two bytes at each addressed location. Calculate its maximum addressable capacity in bytes. Calculate how many transfers carry 100 bits over a 32-bit data bus, ignoring overhead, and explain why this does not give the program time.

S4.04.A01S4.05.A03
Answer and checking points — teacher-written
  1. 2^10=1024 locations.
  2. 1024×2=2048 bytes.
  3. Four transfers are needed because three carry only 96 bits.
  4. Total time also includes computation, timing and other waits; a transfer count alone is insufficient.

Common error: Locations and bytes are different units unless byte addressing is specified.

Connect

Keep this idea

n address bits select 2^n locations. A wider data bus can transfer more bits at a time.

Avoiding a transfer can also help. Cache makes some repeated main-memory reads unnecessary.

Check a common misunderstanding

Do not confuse data-bus width with address-bus width, or locations with bytes.

Processor fundamentals · Concept 03

Keep a nearby copy for the next read

Observe

Start with a question

Why can reading the same item again take less time?

An empty cache has space for both A and B. The processor asks for A, A, B, A. For each request, predict whether it must go to main memory.

Explain

Explanation · 1 / 4

Locate the two possible sources

Cache is small, fast memory close to or within the processor. It stores copies of instructions and data from main memory. Accessing a useful cached copy can be faster than obtaining the item from RAM.

Explanation · 2 / 4

Follow a miss

If the required item is absent, the access is a cache miss. The item must be obtained from main memory and can be retained in cache. A larger empty cache does not make a first access a hit.

Explanation · 3 / 4

Follow a hit

If the required item is already present, the access is a cache hit. The retained copy can supply the request. In our read-only example, with enough space and no eviction, A, A, B, A produces miss, hit, miss, hit.

RequestCache beforeResultRAM read?
AEmptyMiss; retain AYes
AAHitNo
BAMiss; retain BYes
AA and BHitNo

Explanation · 4 / 4

Change the access pattern

Larger capacity can retain more useful items and reduce future misses. But reading A, B, C, D for the first time still gives four misses even when all four fit. The benefit depends on reuse and the items that can remain in cache, not just its advertised capacity.

Work together

Count the slower reads

Cache starts empty, retains A and B, and nothing is written or evicted.

Work together · 1 / 2

Apply the sequence

For A, B, A, B, only the first A and first B require RAM. There are two misses and two hits.

Work together · 2 / 2

Explain the improvement

The later requests use nearby copies, reducing the number of slower main-memory accesses from four to two in this model.

Cache helps when the retained copies are actually needed again.

Apply the idea · Teacher-written practice
Question 1 · Command word: Identify3 teacher marks

An empty cache can hold both A and B. Reads occur in the order A,A,B,A; a miss fetches and retains the item, with no eviction or memory writes. Identify each hit or miss and calculate the number of RAM reads. Explain what changes for A,B,C,D when the cache has room for all four.

S4.05.A05
Answer and checking points — teacher-written
  1. The first A misses; the second A hits; B misses; the final A hits.
  2. There are two RAM reads.
  3. A,B,C,D has four misses and four RAM reads because every request is a first access.

Common error: A first access is still a miss even with enough capacity.

Connect

Keep this idea

Cache retains frequently or recently used instructions and data, reducing slower main-memory accesses when hits occur.

Check a common misunderstanding

Doubling cache capacity does not prove that total performance doubles.

Processor fundamentals · Concept 04

Explain what limits this workload

Observe

Start with a question

Why might four cores fail to finish one calculation four times faster?

One task must calculate a value before the next calculation can begin. Another task contains four independent calculations. Compare what extra processing cores can do in the two cases.

Explain

Explanation · 1 / 4

Start with the work

A workload is the work that a computer is asked to perform. Performance describes how quickly or how much of that work is completed. The next step of our running calculation depends on the previous result; it cannot simply be performed before that result exists.

Explanation · 2 / 4

Explain clock frequency

Clock speed is the number of clock cycles per second. With otherwise comparable conditions, a higher frequency provides more cycles in the same time and can complete the required processing sooner. Instructions can require different numbers of cycles, and memory delays can still make the processor wait.

Explanation · 3 / 4

Explain cores and processor type

A core is a processing unit that can execute instructions. More cores can carry out independent tasks or parallel parts of a program at the same time. A dependent sequence has less work to share. Processor type also matters: different instruction sets and internal designs can do different amounts of useful work per cycle.

Explanation · 4 / 4

Connect transfers and reuse

A wider data bus can move more bits per transfer. Cache can supply retained instructions and data more quickly than main memory. Explain whether the workload needs those transfers or reuses those items, instead of promising a fixed speed increase.

Work together · 1 / 2

Explain the clock change

More clock cycles are available per second, so the same required cycles can take less time.

More useful instructions and data may remain close to the processor, increasing hits and reducing slower RAM accesses.

Question 1 · Command word: Explain4 teacher marks

Explain why a four-core processor may improve the time to compress four independent files but may give little improvement for a single sequential calculation. Explain why different processor types cannot be ranked using clock speed alone.

S4.05.A01S4.05.A02
Answer and checking points — teacher-written
  1. Independent compression tasks can run concurrently on separate cores.
  2. The sequential calculation may have dependencies that prevent useful parallel execution.
  3. Processor types can differ in instruction set and internal organisation.
  4. They may perform different amounts of useful work per cycle, so workload and architecture also affect completion time.

Common error: Four cores do not guarantee four times the speed for every program.

Question 2 · Command word: Calculate5 teacher marks

Calculate the minimum number of data-bus transfers needed for 128 bits using a 32-bit bus and a 64-bit bus. Explain how a higher clock frequency and a larger effective cache can affect execution, with one condition for each claim.

S4.05.A03S4.05.A04S4.05.A05
Answer and checking points — teacher-written
  1. A 32-bit bus requires 128/32 = 4 transfers.
  2. A 64-bit bus requires 128/64 = 2 transfers.
  3. A higher frequency allows more processor cycles per second, if the architecture and other constraints are comparable.
  4. A cache hit supplies reused instructions or data faster than main memory, reducing processor waiting.
  5. A larger cache helps only when it improves useful hits; misses and other bottlenecks still limit performance.

Common error: Bus width is bits per transfer; clock frequency is cycles per second.

Both processors are dual-core: the number of cores has not increased. Explain the clock-speed and cache changes separately.

Reasoning and model answer — teacher-written

The higher clock speed permits more fetch-execute cycles per second, so more instructions can be processed in a given time.

The larger cache can hold more frequently used instructions close to the processor. More accesses can therefore be served from cache instead of slower RAM, reducing waiting time.

Processor fundamentals · Concept 05

Connect the classroom computer to its devices

Observe

Start with a question

Which connection can carry the picture and sound to the classroom screen?

The laptop needs a mouse for input and a large display with speakers for output. Compare USB, HDMI and VGA by the signals each connection can carry.

Explain

Explanation · 1 / 4

Identify what a port provides

A port is a connection interface between a computer and another device. Compatible electrical signals and communication rules allow information to cross it. A connector fitting physically does not by itself establish that all required features are supported.

Explanation · 2 / 4

Connect a peripheral with USB

Universal Serial Bus, USB, carries digital data serially between compatible devices and can also supply power. A mouse, keyboard, printer or external drive can use USB. Capabilities depend on the devices, version and cable; USB is not one fixed transfer speed.

Explanation · 3 / 4

Send digital picture and sound with HDMI

High Definition Multimedia Interface, HDMI, carries digital video and audio to a compatible display. One connection can supply both the image and the sound for the display speakers. A supported display mode avoids unnecessary conversion to an analogue video signal.

Explanation · 4 / 4

Recognise VGA

Video Graphics Array, VGA, carries analogue video. The display may need to convert that signal for a digital panel, and audio requires a separate connection. Choose using the stated display and cable capabilities rather than assuming a universal maximum resolution.
