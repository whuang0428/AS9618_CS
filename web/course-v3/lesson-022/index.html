Knowledge block 1 / 4

How does the CPU read and write memory?

THINK

Memory[300] is 8. On a read, which direction do the address and the 8 travel?

LEARN

Run READ and WRITE as ordered address, control and data transfers. The active line and direction change at each step.

APPLY

Immediate check

Why does a write still use the address bus?

Reveal answer

Memory needs the destination location as well as the value to store.

Exam transfer · teacher-written

Question 1 · Command word: Describe5 teacher marks

Describe a processor read from Memory[420] and a write of 27 to Memory[421]. Identify what travels on each bus and its direction.

S4.04.A01
Answer and checking points — teacher-written
  1. For the read, address 420 travels from the processor on the address bus.
  2. The control bus carries the read signal to memory; the data bus returns Memory[420] to the processor.
  3. For the write, address 421 travels from the processor on the address bus.
  4. The data bus carries 27 towards memory and the control bus carries the write signal.
  5. The data bus supports both transfer directions; control-bus lines include signals to and from the processor.

Common error: Do not place the contents of location 420 on the address bus.

DISTILL

Core idea
Address selects a location; data transfers an instruction or value; control coordinates the operation.
What you must be able to explain
Describe the directions of all three paths in a read and write.
Exam wording
A read returns data from memory; a write sends data to memory.
Common trap
The control bus is a collection of lines, not one bidirectional wire.
30-second recall
Which path carries 300, and which carries 8?
Knowledge block 2 / 4

What does bus width change?

THINK

Does an 8-bit address bus guarantee exactly 256 bytes of memory?

LEARN

Change address bits, bytes per location and data bus width independently.

APPLY

Immediate check

A 10-bit address selects 2-byte locations. What is capacity?

Reveal answer

1024 locations × 2 bytes = 2048 bytes.

Exam transfer · teacher-written

Question 3 · Command word: Calculate5 teacher marks

Calculate the minimum number of data-bus transfers needed for 128 bits using a 32-bit bus and a 64-bit bus. Explain how a higher clock frequency and a larger effective cache can affect execution, with one condition for each claim.

S4.05.A03S4.05.A04S4.05.A05
Answer and checking points — teacher-written
  1. A 32-bit bus requires 128/32 = 4 transfers.
  2. A 64-bit bus requires 128/64 = 2 transfers.
  3. A higher frequency allows more processor cycles per second, if the architecture and other constraints are comparable.
  4. A cache hit supplies reused instructions or data faster than main memory, reducing processor waiting.
  5. A larger cache helps only when it improves useful hits; misses and other bottlenecks still limit performance.

Common error: Bus width is bits per transfer; clock frequency is cycles per second.

Official Cambridge question · Cambridge 9618/12 · October/November 2025 · 3(c) →

DISTILL

Core idea
n address bits identify 2^n locations; a data bus carries its stated bits per transfer.
What you must be able to explain
Calculate capacity only after bytes per location are stated.
Exam wording
A 64-bit data bus can carry 256 bits in four ideal transfers.
Common trap
An addressable location is not necessarily one byte.
30-second recall
Which width changes address count?
Knowledge block 3 / 4

What limits this workload?

THINK

Would eight cores automatically speed up one dependent calculation chain?

LEARN

Choose a workload and a proposed hardware change, then test A, A, B, A in a small cache.

APPLY

Immediate check

Which requests miss in A, A, B, A when the cache starts empty and holds both items?

Reveal answer

The first A and first B miss; the other requests hit.

Exam transfer · teacher-written

Question 2 · Command word: Explain4 teacher marks

Explain why a four-core processor may improve the time to compress four independent files but may give little improvement for a single sequential calculation. Explain why different processor types cannot be ranked using clock speed alone.

S4.05.A01S4.05.A02
Answer and checking points — teacher-written
  1. Independent compression tasks can run concurrently on separate cores.
  2. The sequential calculation may have dependencies that prevent useful parallel execution.
  3. Processor types can differ in instruction set and internal organisation.
  4. They may perform different amounts of useful work per cycle, so workload and architecture also affect completion time.

Common error: Four cores do not guarantee four times the speed for every program.

Official Cambridge question · Cambridge 9618/12 · October/November 2025 · 3(c) →

DISTILL

Core idea
Performance benefit depends on the work and its bottleneck.
What you must be able to explain
Relate cores, clock, cache, bus width and processor design to a specific workload.
Exam wording
A cache hit avoids a RAM read for a retained item.
Common trap
More cores or more clock cycles do not guarantee a fixed application speedup.
30-second recall
When does a wider data bus help most?
Knowledge block 4 / 4

Which port fits the signal?

THINK

A projector needs picture and sound from one cable. Would VGA meet both needs?

LEARN

Select a device need and a connector. Check the signal and whether a separate audio path is needed.

APPLY

Immediate check

Why can HDMI serve a display with built-in speakers over one connection?

Reveal answer

HDMI carries digital video and audio.

Exam transfer · teacher-written

Question 4 · Command word: Suggest4 teacher marks

Suggest a port for each connection and justify your choice: a USB keyboard, a digital display with integrated speakers, and a legacy VGA-only monitor. Compare the signals carried by HDMI and VGA.

S4.06.A01S4.06.A02S4.06.A03S4.06.A04
Answer and checking points — teacher-written
  1. Use USB for the keyboard's peripheral data connection; the connection can also supply power.
  2. Use HDMI for a compatible digital display and its audio over one connection.
  3. Use VGA for the specified legacy monitor's analogue video input.
  4. HDMI carries digital video and audio; VGA carries analogue video and needs a separate audio connection.

Common error: A connector shape alone does not determine every supported USB version or transfer speed.

Official Cambridge question · Cambridge 9618/12 · October/November 2024 · 3(b) →

DISTILL

Core idea
USB carries peripheral data and may supply power; HDMI carries digital video and audio; VGA carries analogue video.
What you must be able to explain
Select a connector by the required signal, not only its shape.
Exam wording
VGA needs a separate audio connection.
Common trap
A connector type does not by itself prove every device feature.
30-second recall
Which interface can carry video and sound together?

Exam Challenge

Bring together the model and the written explanation. Attempt the task before revealing the teacher’s answer.

Memory[300]=8. Describe the three bus paths for a read, then state the effect of an 8-bit address bus if each location contains two bytes.

Teacher-written model answer
  1. Address 300 travels CPU to memory; READ control travels towards memory; value 8 returns on the data bus.
  2. An 8-bit address has 256 patterns and selects 256 locations.
  3. At two bytes each, capacity is 512 bytes in the stated model.

Original question · Cambridge 9618/12

1. Use the monitor’s resolution and speakers in an explanation

Cambridge 9618/12 · October/November 2024 · 3(b) · 4 marks

Selected parts: 3(b) [4].

Reading the question — teacher guidance

The monitor has 2560 × 1600 pixels and built-in speakers. Link interface features to these given requirements.

Solution / model answer — teacher-written

HDMI can carry both the video and the audio for the built-in speakers, so a separate audio cable is not needed as it would be with VGA. It supports the monitor’s high-resolution image and transfers a digital signal, avoiding conversion of the image to analogue and back.

Official mark scheme
Why this earns marks — teacher explanation

The scheme awards up to four listed benefits or linked consequences. The answer supplies combined audio/video, no separate sound cable, high-resolution support and the digital-signal benefit. Additional acceptable points do not raise the total.

Common mistakes — teacher analysis

“HDMI is better” is not a mechanism. Do not invent a transfer-rate multiplier or claim that every HDMI/VGA version has the same maximum resolution.

Original question · Cambridge 9618/12

2. Explain two separate processor improvements

Cambridge 9618/12 · October/November 2025 · 3(c) · 4 marks

Selected parts: 3(c) [4].

Reading the question — teacher guidance

Both processors are dual-core: the number of cores has not increased. Explain the clock-speed and cache changes separately.

Solution / model answer — teacher-written

The higher clock speed permits more fetch-execute cycles per second, so more instructions can be processed in a given time.

The larger cache can hold more frequently used instructions close to the processor. More accesses can therefore be served from cache instead of slower RAM, reducing waiting time.

Official mark scheme
Why this earns marks — teacher explanation

The four marks are capped at two for clock speed and two for cache. A detailed answer about only one factor cannot earn all four.

Common mistakes — teacher analysis

The cache capacity doubles, but that does not establish that total computer performance doubles. Neither change adds processor cores.
