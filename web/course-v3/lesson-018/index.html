Concept teaching

Visual overview and core explanation

01

Monitoring and control systems compared

S3.08.A01S3.08.A02

Visual overview

Core explanation

A monitoring system uses sensors to collect data for recording, display or an alert. It reports the measured condition and does not necessarily change it.

A control system uses sensor data and a stored rule or target to decide an output. It sends an output signal to an actuator, which changes the physical condition.

Common misconception

A system does not become a control system merely because it uses a sensor; it must use the data to cause a physical change.

02

Named sensors and their uses

S3.09.A01

Visual overview

CIE-named sensors

  • Temperature sensorMeasures temperature; for example, greenhouse or heating-system monitoring.
  • Pressure sensorMeasures pressure or applied force; for example, tyre-pressure monitoring or a pressure mat.
  • Infra-red sensorDetects infra-red radiation; for example, a remote-control receiver or beam alarm.
  • Sound sensorDetects sound waves or sound level; for example, a noise-monitoring system.

Core explanation

Select a sensor by matching the physical quantity it detects to the data required by the system. The official syllabus names temperature, pressure, infra-red and sound sensors.

Common misconception

A sensor supplies an input signal representing a physical property; it does not decide the response or perform the corrective action.

03

How sensors, a microprocessor and actuators form a control system

S3.09.A02

Visual overview

Core explanation

A sensor measures a physical condition and sends a signal representing the reading. If the signal is analogue, an ADC converts it into digital data before a microprocessor can process it.

The microprocessor compares the reading with a stored target or rule and sends an output signal to an actuator. The actuator converts that signal into a physical action, such as operating a motor, heater, valve or alarm.

Common misconception

The actuator does not choose the action; the controller decides the output and the actuator produces the physical effect.

04

The importance of feedback

S3.08.A03

Visual overview

Why feedback matters

  1. Measure againObtain a new sensor reading after the actuator changes the condition.
  2. Compare with targetUse the new reading to find the remaining difference from the target.
  3. Correct or stopChange the output or stop the actuator according to that difference.
  4. RepeatContinue the cycle so disturbances and incomplete actions can be corrected.

Core explanation

Feedback is a new sensor reading obtained after an actuator has changed the physical condition. It tells the controller the actual effect of the previous output rather than assuming that the required change occurred.

By repeatedly comparing new readings with the target, the controller can continue, adjust or stop the actuator. Without feedback, a disturbance or an ineffective actuator could leave the condition away from the target with no automatic correction.

Common misconception

Feedback is the new information returned to the controller; it is not simply the output signal sent to the actuator.

Cambridge command words

Practice questions

Question 1 · Command word: Compare4 marks

Compare a monitoring system with a control system.

S3.08.A01S3.08.A02
Answer and marking points
  1. Both can obtain data from sensors.
  2. Monitoring records, displays or alerts about measured data.
  3. Control compares a reading with a stored rule or target.
  4. Control sends an output to an actuator to change the physical condition.

Common error: Do not call a system control when it only measures and reports data.

Question 2 · Command word: Identify4 marks

Identify an appropriate named sensor for each of these uses and explain the match: greenhouse temperature, tyre pressure, remote-control signal and classroom noise level.

S3.09.A01
Answer and marking points
  1. A temperature sensor measures the greenhouse temperature.
  2. A pressure sensor measures the tyre pressure.
  3. An infra-red sensor detects the remote-control radiation.
  4. A sound sensor detects the classroom sound level.

Common error: Use the four sensor types named in the official syllabus and match each to the physical quantity detected.

Question 3 · Command word: Describe5 marks

Describe how a temperature sensor, microprocessor and heater actuator work together in a control system.

S3.09.A02
Answer and marking points
  1. The sensor measures temperature and sends a signal representing the reading.
  2. The signal is converted to digital data if necessary.
  3. The microprocessor compares the reading with the target.
  4. The microprocessor sends an output signal to the heater actuator.
  5. The actuator changes the physical temperature.

Common error: The sensor measures, the microprocessor decides and the actuator acts; do not swap these roles.

Question 4 · Command word: Explain4 marks

Explain why feedback is important in a closed-loop temperature-control system.

S3.08.A03
Answer and marking points
  1. A new sensor reading reports the actual temperature after the actuator operates.
  2. The controller compares the new reading with the target.
  3. The output can be continued, adjusted or stopped according to the remaining difference.
  4. Disturbances or incomplete changes can be detected and corrected.

Common error: Feedback is the new sensor information returned to the controller, not the output sent to the actuator.

Question 5 · Command word: Explain5 marks

Explain how a controller should respond to these temperature readings when it switches a heater on below 18 °C and off at or above 20 °C: 17 °C, 19 °C, 20 °C. Between the thresholds it retains the previous state. Identify which readings provide feedback after the heater starts.

S3.08.A01S3.08.A02S3.08.A03S3.09.A01S3.09.A02
Answer and marking points
  1. A temperature sensor provides the readings for the controller's stored rule.
  2. At 17 °C the controller switches the heater actuator on.
  3. At 19 °C it keeps the heater on because the upper switching threshold has not been reached.
  4. At 20 °C it switches the heater off.
  5. The later 19 °C and 20 °C readings provide feedback about the actual effect of heating.

Common error: Apply the given thresholds and previous state rather than inventing a single target.

Question 1 · Command word: Compare · 4 marks

Compare these two cold-store systems: System A logs temperatures and displays an alert; System B also switches refrigeration on when too warm. Identify the sensor both require and explain the extra control function in System B.

Answer and marking points
  • Both systems need a temperature sensor to obtain the measured condition.
  • System A performs monitoring because it records or reports the readings.
  • System B compares the reading with its stored switching rule and decides a corrective output.
  • Its output operates refrigeration equipment to change the physical temperature, so it also performs control.

Common error: Displaying an alert does not itself regulate the measured temperature.

Question 2 · Command word: Explain · 4 marks

Explain the effect of a pressure sensor becoming stuck at a low reading in a pump system that stops pumping only when its measured pressure reaches a target. Identify the actuator and explain why this fault prevents reliable feedback.

Answer and marking points
  • The pump motor is the actuator that raises the physical pressure.
  • The controller continues to receive a reading below the stopping target.
  • It may therefore keep the pump operating even when the actual pressure is already high.
  • The returned measurement no longer represents the effect of pumping, so the loop cannot reliably correct or stop from that measurement.

Common error: The actuator's output signal is not evidence that the intended physical result occurred.

Question 3 · Command word: Identify · 4 marks

Identify suitable sensors to detect an interrupted infra-red beam and excessive workshop noise. Explain why adding a sounder to the noise monitor does not automatically make it a closed-loop noise-reduction system.

Answer and marking points
  • An infra-red sensor detects the beam and the change when the beam is interrupted.
  • A sound sensor measures the workshop noise level.
  • The sounder provides an alert but does not itself reduce the noise being monitored.
  • A closed-loop noise-reduction system needs a corrective action and subsequent noise readings used to adjust that action.

Common error: An output or alarm alone is not sufficient evidence of feedback regulating the measured condition.

Lesson review

Summary

Monitoring

Measure, record or report the physical condition.

Control

Compare a reading with a rule and operate an actuator to change the condition.

Sensors

Match temperature, pressure, infra-red or sound sensing to the required physical input.

Feedback

Use new readings to judge the actual result and adjust or stop the action.
