01

Assign a meaning to each dimension

S10.04.A01

Visual overview

Core explanation

Choose a two-dimensional array when two independent positions identify an element. In Scores[Row, Column], let rows represent pupils and columns represent tests. DECLARE Scores : ARRAY[1:2, 1:3] OF INTEGER stores six scores, with the first index selecting the pupil and the second selecting the test.

Rows run horizontally across a displayed table and columns vertically down it. Scores[2,3] is the second pupil's third test score, not the third pupil's second test. State each dimension's meaning before writing code so every reference uses the same convention.

Common misconception

A displayed table does not reverse the index order: use the declared row, column convention consistently.

Check your understanding

In the diagram, what value is Scores[1,2]?

Check your answer

7: row 1, column 2.

Traverse rows with a nested loop

S10.05.A01

Visual overview

Swipe horizontally to compare every column →

Core explanation

Use one loop per dimension

The outer loop chooses Row; the inner loop visits every Column for that row. With ascending bounds, the visit order is (1,1), (1,2), (1,3), then (2,1), (2,2), (2,3). The column loop restarts from 1 for each new row, so the second row is not traversed backwards.

Reset each row total at the correct level

RowTotal is reset at the start of each outer iteration because each row needs a separate total. Input and addition occur inside the inner loop, while OUTPUT RowTotal occurs after NEXT Column but before NEXT Row. To calculate column totals, choose a column in the outer loop and vary the row in the inner loop instead.

Worked example · Input six scores and output two row totals

  1. Task

    Input two rows of three INTEGER scores using ascending row and column indices. Display one total per row.

  2. Pseudocode
    DECLARE Scores : ARRAY[1:2, 1:3] OF INTEGER
DECLARE Row : INTEGER
DECLARE Column : INTEGER
DECLARE RowTotal : INTEGER
FOR Row <- 1 TO 2
    RowTotal <- 0
    FOR Column <- 1 TO 3
        INPUT Scores[Row, Column]
        RowTotal <- RowTotal + Scores[Row, Column]
    NEXT Column
    OUTPUT RowTotal
NEXT Row
  3. Result

    Inputs 4, 7, 2, 8, 1, 6 produce 13, then 15.

Common misconception

A single reset before both loops would produce a cumulative total instead of a separate total for each row.

Check your understanding

Which outputs result if RowTotal is reset only once before both loops?

Check your answer

13 and then 28, because row 2 would include row 1's total.

Question 1 · Command word: Select2 marks

A cinema has 6 rows of 10 seats and records whether each seat is occupied. Select and declare an array and explain the two indices.

S10.04.A01
Answer and marking points
  1. DECLARE Occupied : ARRAY[1:6, 1:10] OF BOOLEAN.
  2. The first index selects the row and the second the seat within that row.

Common error: Each element is a logical occupancy state, not a seat count.

Question 2 · Command word: State2 marks

State the positions visited and both outputs from the supplied 2D algorithm for inputs 2, 3, 5, 1, 0, 4.

Use this complete algorithm in the question.

DECLARE Scores : ARRAY[1:2, 1:3] OF INTEGER
DECLARE Row : INTEGER
DECLARE Column : INTEGER
DECLARE RowTotal : INTEGER
FOR Row <- 1 TO 2
    RowTotal <- 0
    FOR Column <- 1 TO 3
        INPUT Scores[Row, Column]
        RowTotal <- RowTotal + Scores[Row, Column]
    NEXT Column
    OUTPUT RowTotal
NEXT Row
S10.05.A01
Answer and marking points
  1. The positions are [1,1], [1,2], [1,3], [2,1], [2,2], [2,3].
  2. The row totals output are 10 and 5.

Common error: The inner loop restarts at column 1.

Question 3 · Command word: Write4 marks

Write pseudocode to input a 2 by 3 INTEGER array Scores and output a separate total for each row.

S10.05.A01
Answer and marking points

One valid pseudocode solution

DECLARE Scores : ARRAY[1:2, 1:3] OF INTEGER
DECLARE Row : INTEGER
DECLARE Column : INTEGER
DECLARE RowTotal : INTEGER
FOR Row <- 1 TO 2
    RowTotal <- 0
    FOR Column <- 1 TO 3
        INPUT Scores[Row, Column]
        RowTotal <- RowTotal + Scores[Row, Column]
    NEXT Column
    OUTPUT RowTotal
NEXT Row
  1. Declare the 2D array, loop indices and row total.
  2. Loop over rows 1 to 2 and reset RowTotal within that outer loop.
  3. Loop over columns 1 to 3, input Scores[Row, Column] and accumulate it.
  4. Output each completed row total after the inner loop.

Common error: Do not output a partial total for every cell.

Question 2 · Command word: Write · 5 marks

Write pseudocode to input two rows of three INTEGER values into Sales[1:2,1:3], then output a total for each column.

Answer and marking points

One valid pseudocode solution

DECLARE Sales : ARRAY[1:2, 1:3] OF INTEGER
DECLARE Row : INTEGER
DECLARE Column : INTEGER
DECLARE Total : INTEGER
FOR Row <- 1 TO 2
    FOR Column <- 1 TO 3
        INPUT Sales[Row, Column]
    NEXT Column
NEXT Row
FOR Column <- 1 TO 3
    Total <- 0
    FOR Row <- 1 TO 2
        Total <- Total + Sales[Row, Column]
    NEXT Row
    OUTPUT Total
NEXT Column
  • Declare the array, two INTEGER indices and a total.
  • Use nested loops to input all six indexed values.
  • For each column 1 to 3, initialise Total to zero.
  • Add Sales[Row, Column] for rows 1 to 2 while holding Column fixed.
  • Output the total once for each completed column.

Common error: A column total varies the row index.

Question 3 · Command word: State · 3 marks

A matrix contains rows [3, 8, 1] and [4, 2, 9]. State the outputs when each column is totalled, then explain why resetting Total inside the inner row loop gives incorrect results.

Answer and marking points
  • The three column totals are 7, 10 and 10.
  • Resetting inside the row loop discards the first row's contribution.
  • That faulty version outputs only 4, 2 and 9.

Common error: Column totals combine values at the same column index across rows.

04

Lesson review

Summary

Dimensions

Define what each index means; rows are horizontal and columns are vertical.

Nested loops

The inner loop completes before the outer index advances; both indices stay within their own bounds.

Totals

Reset once per required group and output only after that group's elements have been accumulated.
