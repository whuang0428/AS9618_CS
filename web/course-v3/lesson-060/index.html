Array terminology, indices and bounds

Explicit indices and inclusive bounds make every array access precise.

Which indices select valid elements, and how many elements exist?

Before you start

Does ARRAY[3:7] contain seven elements?

Check your answer

No. Both bounds are inclusive, so it contains 7 − 3 + 1 = 5 elements.

01

Distinguish the array, an element and an index

S10.03.A01

Visual overview

One collection, many selected values

An array is a collection of elements of the same data type, stored under one identifier. An index selects a particular element. In Ages[4], Ages names the array and 4 is the index; the value stored in that element might be 17 and is independent of its index.

Dimensions and element types

A one-dimensional array uses one index. A two-dimensional array uses two indices to locate each element. The element type applies to every position, and a declared element must receive a value before an algorithm relies on that value.

Read Ages[4] <- Ages[3] + 3

  1. Locate the source: Index 3 currently stores 15.
  2. Evaluate the right side: 15 + 3 gives 18.
  3. Select the destination: Index 4 is valid, so replace its old value 17 with 18.
  4. Check the other cells: The values at indices 3, 5, 6 and 7 stay 15, 16, 15 and 18.

Distinguish storage from initial data

Two cells can store equal values while remaining different elements. Index expressions such as Index + 1 are allowed only when they produce a valid integer index. An array declaration provides a fixed set of positions but does not supply the data shown in a trace: those values must be given or assigned.

Worked example · Read and replace one element

  1. Read

    Ages[4] is 17. The index is 4, not 17.

  2. Assignment

    Ages[4] <- Ages[3] + 3 replaces 17 with 18 at index 4 and leaves Ages[3] unchanged.

  3. Result

    Only the selected element is overwritten; the declared bounds remain 3 and 7.

Core explanation · Exam essentials

  • An index selects an element; it is not the stored value.
  • All elements have the declared element type, and an access must use the correct number of indices.
Common misconception

An index is a position selector, not the data value stored at that position.

Check your understanding

In Ages[6] = 15, which number is the index?

Check your answer

6 is the index; 15 is the stored value.

Use inclusive lower and upper bounds

S10.03.A02

Count both endpoints

The lower bound is the smallest permitted index and the upper bound is the largest. For inclusive bounds L and U, the number of elements is U − L + 1. Cambridge declarations specify these bounds explicitly; an array does not always start at zero or one.

Check each dimension separately

A complete traversal visits each permitted index and stops before exceeding the upper bound. Accessing an out-of-range index is invalid. In two dimensions, both indices must satisfy their own bounds, and capacity is the product of the two dimension lengths.

Derive the capacity of ARRAY[3:7]

  1. List the positions: 3, 4, 5, 6, 7 are permitted.
  2. Count the gaps: 7 − 3 gives four gaps between five positions.
  3. Include the first position: Add one: 7 − 3 + 1 = 5 elements.

Choose a complete traversal

BoundsFirst and last accessIncorrect shortcut
[3:7]Visit indices 3 through 7 inclusive.Starting at 1 reads positions that do not exist.
[0:4]Visit indices 0 through 4 inclusive.Visiting 1 through 5 misses 0 and exceeds 4.
[1:2, 0:3]Visit both rows, and all four columns per row.Accepting a valid row does not make column 4 valid.

Protect the access itself

A statement can be out of range even if its result would have a suitable data type. Check the index before accessing the element; attempting the read and checking afterwards is too late.

Core explanation · Exam essentials

  • Capacity is upper bound − lower bound + 1 for each dimension.
  • Multiply dimension lengths for 2D capacity; check every index against its own inclusive bounds.
Common misconception

The upper bound is not necessarily the element count, especially when the lower bound is not 1.

Check your understanding

How many elements are in ARRAY[2:4, 5:8]?

Check your answer

(4 − 2 + 1) × (8 − 5 + 1) = 3 × 4 = 12.

Practice questions

Question 1 · Command word: Identify2 teacher marks

For Ages : ARRAY[3:7] OF INTEGER with values 15, 17, 16, 15, 18 in index order, identify the array name, the index in Ages[5], and its stored value.

S10.03.A01
Answer and checking points — teacher-written
  1. The array name is Ages.
  2. The index is 5 and the stored value is 16.

Common error: Keep position and value distinct.

Question 2 · Command word: Calculate2 teacher marks

Calculate the capacity of ARRAY[−2:2] OF INTEGER and state whether indices −3, 0 and 2 are valid.

S10.03.A02
Answer and checking points — teacher-written
  1. 2 − (−2) + 1 = 5 elements.
  2. −3 is invalid; 0 and 2 are valid.

Common error: Inclusive bounds can be negative.

Question 3 · Command word: State2 teacher marks

Grid is ARRAY[1:3, 0:4] OF CHAR. State its number of dimensions, total capacity and the two upper bounds.

S10.03.A01S10.03.A02
Answer and checking points — teacher-written
  1. It has two dimensions and holds 3 × 5 = 15 CHAR elements.
  2. The upper bounds are 3 for the first index and 4 for the second.

Common error: Do not add the dimension lengths to calculate capacity.

Original question · Cambridge 9618/22

1. Count array elements using inclusive bounds

Cambridge 9618/22 · May/June 2025 · 1(d)(i), 1(d)(ii), 1(d)(iii) · 4 marks

Selected parts: 1(d)(i) [1]; 1(d)(ii) [1]; 1(d)(iii) [2].

Reading the question — teacher guidance

Both dimensions start at zero. Count allowed index values, not the number printed as the upper bound.

Solution / model answer — teacher-written

1(d)(i): Two dimensions.

1(d)(ii): (99 − 0 + 1) × (9 − 0 + 1) = 100 × 10 = 1000 elements.

DECLARE Product : ARRAY[0:99, 0:9] OF INTEGER
Official mark scheme
Why this earns marks — teacher explanation

The first two answers earn one mark each. The declaration has one mark for both correct ranges and one for the remaining declaration syntax and INTEGER type.

Common mistakes — teacher analysis

99 × 9 omits the zero-indexed row and column. Replacing the ranges with 1:100 and 1:10 changes the required indexing even though the element count is the same.

Lesson review

Summary

Terminology

The array name identifies the collection; an index selects an element containing a value.

Bounds

Inclusive bounds give U − L + 1 positions, and every index must remain within its dimension's limits.
