Separate an index from the value it selects

Observe

Request

Index12345
Value83531

Look, then discuss

In Request[2] = 3, which number is the position and which is the stored request?

Five request cards contain 8, 3, 5, 3 and 1. Label their positions 1 to 5 above the cards. The second and fourth cards contain the same value but occupy different positions.

Recall

Recall a collection

An array groups elements of one declared type under one identifier. Each element is a storage location. An index selects a particular element.

Explain

Explanation · 1 / 3

Read the whole array and one element

Request names the collection. Request[2] names its second indexed element. That element currently contains 3. The index 2 and value 3 have different roles.

Request
Index12345
Stored value83531

Explanation · 2 / 3

Use a variable as the index

When Index contains 4, Request[Index] selects Request[4], whose value is 3. Changing Index changes which location is selected; it does not move the stored values.

Explanation · 3 / 3

Update one selected element

Request[2] <- 9 replaces the value at index 2. It does not change the lower bound, the array length or the value at index 4.

DECLARE Request : ARRAY[1:5] OF INTEGER
Request[2] <- 3
Request[2] <- 9
OUTPUT Request[2]

Work together

Evaluate two accesses

Use the original five cards: [8, 3, 5, 3, 1]. Index contains 4.

Work together · 1 / 2

Read the first expression

Request[Index] selects position 4 and gives 3.

Work together · 2 / 2

Evaluate the index expression first

Request[Index - 1] uses index 3 and gives 5. Subtracting 1 from the index is not the same as subtracting 1 from the stored value.

Evaluate the expression inside the brackets first, then read the selected element.

Check

Try it yourself · Teacher-written

Request[1] is 8. What changes after Request[1] <- Request[1] + 2?

Check your reasoning

The value at index 1 becomes 10. The index remains 1, and no other element changes.

Connect

Keep this idea

An index identifies a position; the element at that position holds a value.

The declaration defines which index values are legal.

Build a booking system · Concept 10

Count inclusive bounds and reject invalid positions

Observe

A declaration with non-zero lower bound

  • DECLARE Names : ARRAY[3:7] OF STRING
  • Proposed accesses: Names[2], Names[3], Names[7], Names[8]

Look, then discuss

How many elements are declared by ARRAY[3:7]?

Write the legal labels 3, 4, 5, 6 and 7. There are five positions even though the upper bound is 7. The first legal index need not be zero or one.

Recall

Recall inclusive counting

Both endpoints are included in an array’s declared bounds. Upper minus lower measures the gaps; add one to count the positions.

Explain

Explanation · 1 / 3

Identify each bound

In ARRAY[3:7], 3 is the lower bound and 7 is the upper bound. Legal indices satisfy Index >= 3 AND Index <= 7. An access using 2 or 8 is outside the declaration.

Explanation · 2 / 3

Calculate the capacity

The number of elements is upper bound - lower bound + 1. Here that gives 7 - 3 + 1 = 5. Capacity counts available positions, not how many meaningful values the program has entered so far.

BoundsLegal indicesElements
1:51, 2, 3, 4, 55
0:40, 1, 2, 3, 45
3:73, 4, 5, 6, 75

Explanation · 3 / 3

Initialise before reading

A declaration does not explicitly supply every initial value. This complete example assigns an empty string to every legal element before displaying or changing it.

DECLARE Names : ARRAY[3:5] OF STRING
DECLARE Index : INTEGER
FOR Index <- 3 TO 5
    Names[Index] <- ""
NEXT Index
Names[4] <- "Mina"
FOR Index <- 3 TO 5
    OUTPUT Names[Index]
NEXT Index

Work together

Check a proposed final access

Names is declared ARRAY[3:5] OF STRING. A programmer proposes Names[6] <- "Mina".

Work together · 1 / 2

Count the elements

There are 5 - 3 + 1 = 3 elements, labelled 3, 4 and 5.

Work together · 2 / 2

Reject the access by its index

Index 6 is greater than the upper bound. The fact that "Mina" is a valid STRING does not make that array position valid.

Check both the selected position and the element type.

Question 1 · Command word: Identify2 teacher marks
For Ages : ARRAY[3:7] OF INTEGER with values 15, 17, 16, 15, 18 in index order, identify the array name, the index in Ages[5], and its stored value.
S10.03.A01
Answer and checking points — teacher-written
  1. The array name is Ages.
  2. The index is 5 and the stored value is 16.
Common error: Keep position and value distinct.
Question 2 · Command word: Calculate2 teacher marks
Calculate the capacity of ARRAY[−2:2] OF INTEGER and state whether indices −3, 0 and 2 are valid.
S10.03.A02
Answer and checking points — teacher-written
  1. 2 − (−2) + 1 = 5 elements.
  2. −3 is invalid; 0 and 2 are valid.
Common error: Inclusive bounds can be negative.
Question 3 · Command word: State2 teacher marks
Grid is ARRAY[1:3, 0:4] OF CHAR. State its number of dimensions, total capacity and the two upper bounds.
S10.03.A01S10.03.A02
Answer and checking points — teacher-written
  1. It has two dimensions and holds 3 × 5 = 15 CHAR elements.
  2. The upper bounds are 3 for the first index and 4 for the second.
Common error: Do not add the dimension lengths to calculate capacity.
