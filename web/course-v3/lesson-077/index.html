Core explanation

Inclusive bounds and loop syntax

A FOR loop is suitable when the iteration count is known before entering the loop. Write FOR Index <- Start TO End and close it with NEXT Index. With the default step of one, the body uses Start, Start + 1 and so on up to End inclusive. Let the loop manage its control variable.

Place initialisation, input and output correctly

FOR Index <- 1 TO Count performs Count iterations for a non-negative Count. Count zero gives no iterations, and Count one gives exactly one. Initialise an accumulator before the loop; obtain each new value and add it inside; report the total afterwards. A zero-item total remains the initial zero without a special loop branch.

Worked example · Total a specified number of integers

  1. Pseudocode
    DECLARE Count, Index, Value, Total : INTEGER
INPUT Count
Total <- 0
FOR Index <- 1 TO Count
    INPUT Value
    Total <- Total + Value
NEXT Index
OUTPUT Total
  2. Trace and check

    Count 3 followed by 2, 4, 6 outputs 12; Count 0 outputs 0 without reading any Value.

Common misconception

Starting beyond the end with a positive step does not force a first iteration.

Check your understanding

For Index 2 TO 5, how many body executions occur?

Check your answer

Four: Index 2, 3, 4 and 5.

Use an explicit step and direction

S11.04.A03

Visual overview

Core explanation

Choose the bounds and step together
  • Positive STEP: Move upward and stop before the value exceeds the endpoint.
  • Negative STEP: Move downward and stop before the value falls below the endpoint.
  • STEP 0: Makes no progress and is unsuitable.
Count the values actually visited

6 TO 0 STEP -2 visits 6, 4, 2, 0. Starting at 5 visits 5, 3, 1 and stops before -1. The endpoint is inclusive only when the sequence reaches it exactly; write the visited values before counting body executions.

Worked example · Trace a descending loop

  1. Pseudocode
    DECLARE Index : INTEGER
FOR Index <- 6 TO 0 STEP -2
    OUTPUT Index
NEXT Index
  2. Trace and check

    The four outputs are 6, 4, 2 and 0.

Common misconception

An inclusive endpoint does not imply that every step sequence lands on it.

Check your understanding

What does 8 TO 2 STEP -3 visit?

Check your answer

8, 5 and 2.

Practice questions

Question 1 · Command word: State2 marks

State the control-variable values and number of iterations for FOR Index <- 3 TO 6.

S11.04.A03
Answer and marking points
  1. The values are 3, 4, 5 and 6.
  2. There are four iterations.

Common error: Both bounds are included.

Question 2 · Command word: Write2 marks

Write a FOR loop that outputs 10, 8, 6, 4 and 2 in that order.

S11.04.A03
Answer and marking points
  1. Use FOR Index <- 10 TO 2 STEP -2.
  2. Place OUTPUT Index in the body and close with NEXT Index.

Common error: A positive step cannot move down from 10 to 2.

Question 3 · Command word: State2 marks

State the output of the supplied total program for Count 0 and for Count 1 followed by Value 9. State how many Value inputs each run reads.

Use this complete program for the stated task.

DECLARE Count, Index, Value, Total : INTEGER
INPUT Count
Total <- 0
FOR Index <- 1 TO Count
    INPUT Value
    Total <- Total + Value
NEXT Index
OUTPUT Total
S11.04.A03
Answer and marking points
  1. Count 0 reads no Value and outputs 0.
  2. Count 1 reads one Value and outputs 9.

Common error: Initialisation still occurs when the loop body is skipped.

Question 1 · Command word: Write · 3 marks

Write pseudocode that inputs exactly four real prices and outputs their total once. Include declarations and initialise the total.

Answer and marking points
  • Declare Index as INTEGER and Price and Total as REAL; assign Total <- 0 before repetition.
  • Use FOR Index <- 1 TO 4 with INPUT Price and Total <- Total + Price in the body.
  • Close with NEXT Index and output Total after the loop.

Common error: Reading Price before the loop would repeat one value four times.

Question 2 · Command word: State · 2 marks

State every output of FOR Position <- 9 TO 1 STEP -3 with body OUTPUT Position. Explain why 1 is not output.

Answer and marking points
  • The outputs are 9, 6 and 3.
  • The next value would be 0, beyond the descending endpoint; the step never reaches 1.

Question 3 · Command word: State · 2 marks

A program sets Total <- 0, executes FOR Index <- 1 TO Count with body Total <- Total + 2, then outputs Total. State the outputs for Count 0, 1 and 5, and explain whether Count 0 requires a separate branch to prevent a body execution.

Answer and marking points
  • The outputs are 0, 2 and 10.
  • No extra branch is required: with Count 0 the start exceeds the end under the default positive step.

Common error: FOR does not have REPEAT's guaranteed first execution.

Lesson review

Summary

Count inclusive values

The loop body uses each reachable value within the bounds.

Check direction

STEP controls the increment; a negative step counts downward.

Place accumulation correctly

Initialise once, add inside the loop and output the result afterwards.
