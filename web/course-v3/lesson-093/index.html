Practice

Retrieve, apply, then answer like an exam

Retrieval8 marks

Write Cambridge pseudocode for a linear search of Name[1:20] and an ascending bubble sort of Score[1:20].

Answer and marking points
  1. linear search initialises Found and Index
  2. linear search loops within indexes 1 to 20 until found or exhausted
  3. linear search compares Name[Index] with the target and records a match
  4. bubble sort uses repeated passes
  5. compares adjacent Score[Index] and Score[Index + 1] within valid bounds
  6. uses Temp or an equivalent safe three-step swap
  7. reduces the unsorted range or uses a valid no-swap stopping condition
  8. all constructs close coherently in Cambridge pseudocode

Common error: For the command word write, perform that exact action; do not replace it with an unrelated fact.

Application3 marks

Explain one common error from Section 11: Programming, and give the corrected reasoning.

Answer and marking points
  1. Define and use a procedure
  2. explain when the use of a procedure is appropriate
  3. use parameters with none, one or more values passed by reference or by value.

Common error: Do not repeat the same point in different words; each mark needs a separate idea or method step.

Application4 marks

Compare two closely related ideas from Section 9: Algorithm design and problem-solving.

Answer and marking points
  1. Use stepwise refinement to develop an algorithm from a high-level solution to a level of detail from which a program can be written
  2. each level must preserve the parent purpose.

Common error: Do not copy the worked example unchanged; transfer the method and check it against the new context.

Exam-style4 marks

Apply one method from Section 12: Software development to a fresh exam context.

Answer and marking points
  1. Candidates should understand the purpose of a program-development lifecycle and the need for different lifecycles depending on the program being developed
  2. Compare the principles, benefits and drawbacks of waterfall, iterative and Rapid Application Development (RAD)
  3. Lifecycle stages are analysis, design, coding, testing and maintenance.
