Section 1 · Information representation

How can bits represent a world of information?

Start with two distinguishable states. Learn to represent numbers, text, pictures and sound, then explain how representation changes accuracy and storage size. No previous computer science is needed.

Start with two states →

Follow the ideas

  1. Begin with two states, then measure stored data

    A word, a photograph and a sound look different to us. Discover how two distinguishable states can record choices, then count how many bits and bytes a file needs.

    Begin this part →

  2. Give a bit pattern a numerical meaning

    Begin with familiar decimal place values. Build binary and hexadecimal, then see why digit codes and negative-number representations need different interpretation rules.

    Begin this part →

  3. Calculate in binary and recognise limits

    Build carrying and borrowing from place values. Apply the same addition process to signed values, then separate the stored pattern from a mathematical result that may not fit.

    Begin this part →

  4. Encode characters using a shared table

    Turn a short message into ordered character codes. Compare what ASCII, its eight-bit extensions and Unicode can represent, while keeping a character distinct from its appearance and stored bytes.

    Begin this part →

  5. Build pictures from pixels or drawing instructions

    Reconstruct a bitmap from ordered colour codes, vary its detail and calculate its data size. Then build the same kind of visible shape from a vector drawing list and compare how the two representations scale.

    Begin this part →

  6. Sample sound, then choose what to compress

    Measure a changing sound signal at separate times, round each measurement to an available level and encode it. Then compare ways of reducing data while keeping either the exact original or an acceptable approximation.

    Begin this part →

Suggested 45-minute sessions

Allow time for explanation, prediction, experiments and paper practice. Repeat or extend a session whenever a check shows that an idea needs another example. A session can include more than one page.

  1. Session 1 · 45 minutes suggested

    Two states and enough patterns

    Use lamp choices, build powers of two and distinguish a count from the largest unsigned value.

    • How can two states carry a message? →
    • Count possibilities before assigning values →
  2. Session 2 · 45 minutes suggested

    Units, capacity and a first paper question

    Compare byte quantities, keep prefix scales separate, count complete files and attempt E001.

    • Compare quantities using the same unit →
  3. Session 3 · 45 minutes suggested

    Binary place value and conversion

    Move from denary weights to binary, convert both ways and verify every result.

    • Build binary from familiar place values →
    • Choose binary weights for a denary value →
  4. Session 4 · 45 minutes suggested

    Hexadecimal and four-bit groups

    Convert binary, denary and hexadecimal with complete working; explain a practical use.

    • Read four binary bits as one hexadecimal digit →
  5. Session 5 · 45 minutes suggested

    Decimal digit codes

    Encode and decode BCD, explain a digit-display application and contrast BCD with ordinary binary.

    • Keep decimal digits separate with BCD →
  6. Session 6 · 45 minutes suggested

    One’s complement and a mixed paper task

    Introduce signed widths, inversion and two zeros, then attempt E002 after recalling hexadecimal.

    • Represent negatives with one’s complement →
  7. Session 7 · 45 minutes suggested

    Two’s complement

    Use negative place value, encode and decode both signs, check the range and attempt E003.

    • Give the leftmost bit a negative weight →
  8. Session 8 · 45 minutes suggested

    Choose a representation independently

    Interpret unchanged bits under several rules, convert without changing a value and explain invalid codes.

    • Ask what the pattern is meant to represent →
  9. Session 9 · 45 minutes suggested

    Binary addition and visible carries

    Trace each carry, practise unfamiliar operands and check sums by decoding.

    • Carry when a binary column reaches two →
  10. Session 10 · 45 minutes suggested

    Binary subtraction and borrowing

    Trace a borrow through zero columns and verify differences by adding the subtracted value back.

    • Borrow across binary places →
  11. Session 11 · 45 minutes suggested

    Signed arithmetic and a subtraction paper task

    Add and subtract both signs using two’s complement, then attempt E004 with its full teacher explanation.

    • Add positive and negative fixed-width integers →
  12. Session 12 · 45 minutes suggested

    Overflow depends on the representation

    Compare signed and unsigned ranges, test carry counterexamples and attempt E005.

    • Decide whether the answer fits its representation →
  13. Session 13 · 45 minutes suggested

    Character codes and standard ASCII

    Encode and decode a small table, then distinguish ASCII code width from a byte container.

    • Store the characters, then recover the message →
    • Use seven-bit ASCII codes →
  14. Session 14 · 45 minutes suggested

    Character-set limits and Unicode

    Explain extension-table mismatches and the wider Unicode repertoire, then attempt E006.

    • Add an eighth bit, but keep the table agreed →
    • Represent text across writing systems →
  15. Session 15 · 45 minutes suggested

    Reconstruct a bitmap

    Decode ordered pixel codes, explain header information and draw small images from supplied data.

    • Reconstruct a bitmap from its stored codes →
  16. Session 16 · 45 minutes suggested

    Colour choices and spatial detail

    Change one parameter at a time and distinguish colour precision, stored dimensions and screen resolution.

    • Give each pixel more colour choices →
    • Distinguish the stored grid from the display grid →
  17. Session 17 · 45 minutes suggested

    Calculate bitmap data size

    Derive the formula from pixel counts and units, include only stated overhead and attempt E007.

    • Build the bitmap-size calculation from units →
  18. Session 18 · 45 minutes suggested

    Draw from a vector list

    Read coordinates and properties, reconstruct the list and attempt both representation parts of E008.

    • Draw an image from objects and properties →
  19. Session 19 · 45 minutes suggested

    Scale and choose image representations

    Calculate scaled geometry, compare enlargement and justify choices for unfamiliar image tasks.

    • Choose a representation for the task →
  20. Session 20 · 45 minutes suggested

    Sample, quantise and encode sound

    Keep timing, level rounding and encoding separate; decode a supplied sample sequence.

    • Turn a continuous signal into stored sample codes →
  21. Session 21 · 45 minutes suggested

    Two independent sound-quality controls

    Vary rate and depth independently, explain each mechanism and attempt E009.

    • Change how often the signal is measured →
    • Change the amplitude choices for each sample →
  22. Session 22 · 45 minutes suggested

    Sound size and mixed-media calculations

    Count samples and channels, convert units and contrast the sound formula with bitmap size.

    • Count samples, bits and channels →
  23. Session 23 · 45 minutes suggested

    Why compress, and what must survive?

    Calculate a practical storage or transfer benefit, then judge exact versus approximate reconstruction.

    • Reduce the data needed to store or transfer a file →
    • Use reconstruction to distinguish the methods →
  24. Session 24 · 45 minutes suggested

    Run-length encoding round trips

    Encode and decode ordered runs, count field overhead, test an ineffective case and attempt E010.

    • Encode repeated neighbouring values as runs →
  25. Session 25 · 45 minutes suggested

    Lossless compression across media

    Explain exactly what text, bitmap, vector and sound decoders must reconstruct, with a dictionary extension if ready.

    • Preserve text, pixels, objects and sample values exactly →
  26. Session 26 · 45 minutes suggested

    Lossy delivery copies and justified choices

    Compare original and reconstructed values, explain information loss and justify compression for a new set of tasks.

    • Choose what a delivery copy may sacrifice →
