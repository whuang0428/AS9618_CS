Carry when a binary column reaches two

Observe

How many ones fit in one binary digit?

Addition in one columnWrite in this columnCarry to the next column
0 + 000
0 + 110
1 + 101
1 + 1 + 111

Look, then discuss

Why does 1 + 1 produce 10 rather than a digit 2?

Two ones are exchanged for one two. The same exchange happens in every position: two units of the current weight become one unit of the next weight.

Explain

Explanation · 1 / 3

Align equal weights

Write operands at the same width and align them on the right. Add from the least significant bit, the rightmost position, towards the left. Leading zeros help keep corresponding weights together.

Explanation · 2 / 3

Include the incoming carry

At each position add the operand bits and the carry from the previous column. A total of 2 is binary 10: write 0 and carry 1. A total of 3 is binary 11: write 1 and carry 1.

Explanation · 3 / 3

Show the carry as evidence

Write or record carries as you go. A correct final pattern alone does not show how you handled a difficult column. Afterward, decode the result to check the arithmetic, and check whether it fits the stated width.

Work together

Add 13 and 7 at eight bits

13 = 00001101 and 7 = 00000111.

Work together · 1 / 3

Start with the low four columns

1s: 1 + 1 = 2, write 0 carry 1. 2s: 0 + 1 + 1 = 2, write 0 carry 1. 4s: 1 + 1 + 1 = 3, write 1 carry 1. 8s: 1 + 0 + 1 = 2, write 0 carry 1.

Work together · 2 / 3

Finish the remaining columns

16s: 0 + 0 + 1 = 1. All higher columns are zero. The result is 00010100.

Work together · 3 / 3

Check the value

00010100 = 16 + 4 = 20, and 13 + 7 = 20. It fits eight-bit unsigned storage.

A carry changes the next column, not the already written bit.

Experiment

Before each column is revealed, predict its total, written bit and carry. Begin with 13 + 7, then choose a case with no carries.

Predict the exact answer and whether it fits. Then follow carries or borrows from right to left.

Check your reasoning

Connect

Keep this idea

Binary column addition exchanges two units of one weight for one unit of the next.

Subtraction reverses this exchange: one unit of a higher weight can be borrowed as two of the next weight.

Borrow across binary places

Observe

Subtract 3 from 10

  • 10 = 00001010
  • 3 = 00000011
  • The rightmost column needs 0 − 1.

Look, then discuss

Where can the missing one be obtained?

The 2s position contains a 1. Borrowing it supplies two ones. The total value of the top row stays ten; we have regrouped it.

Explain

Explanation · 1 / 3

Subtract from the right

Align the operands at a stated width. In a column where the upper digit is at least the lower digit, subtract normally. If the column requires 0 − 1, borrow from a higher position.

Explanation · 2 / 3

Exchange a borrowed unit

Borrowing one 2 supplies two 1s; borrowing one 4 supplies two 2s. Reduce the donor by one and record the borrowed amount. A column containing two units after borrowing can produce 2 − 1 = 1.

Explanation · 3 / 3

Pass a borrow through zero columns

If the next column is zero, find a higher column containing a 1 and pass the borrow down through each intervening column. Keep each change visible. After completing the operation, add the difference to the subtracted operand to recover the starting value.

Work together

Follow 10 − 3 one column at a time

Use 00001010 − 00000011.

Work together · 1 / 3

Borrow for the 1s

Borrow from the 2s column. It becomes 0 and the 1s becomes 2. Calculate 2 − 1 = 1.

Work together · 2 / 3

Borrow across the empty 4s

The 2s column now needs 0 − 1. Borrow the 1 from the 8s column into the 4s column, then pass one 4 down as two 2s. The 8s becomes 0 and the 4s retains 1. In the 2s column, 2 − 1 = 1.

Work together · 3 / 3

Finish and verify

The 4s column gives 1 − 0 = 1. The result is 00000111 = 7. Check 7 + 3 = 10.

Borrowing changes neighbouring columns, so use their updated values.

Experiment

Try a subtraction whose borrow crosses a zero, such as 10 − 3. Predict which columns change before revealing the next step.

Represent information · Concept 13

Add positive and negative fixed-width integers

Observe

A temperature changes by −5

  • Starting temperature: +12
  • Change: −5
  • Final temperature: 12 + (−5)

Look, then discuss

Can ordinary binary column addition calculate this change?

Encode both operands as eight-bit two’s complement first. The negative operand will look large if incorrectly read as unsigned; keep the signed interpretation throughout.

Explain

Explanation · 1 / 3

Encode each operand at the same width

Positive two’s-complement values use ordinary binary with a leading 0. Negative values use the stated signed rule. For 12 + (−5), the operands are 00001100 and 11111011.

Explanation · 2 / 3

Use the same column-addition rules

Add bit by bit, including carries. Retain only the stated eight positions. A carry beyond them is outside the stored byte. Separately compare the mathematical signed answer with the signed range; a carry-out alone does not establish signed overflow.

Explanation · 3 / 3

Turn subtraction into addition

A − B is A + (−B). For 7 − 12, encode +7 and −12, then add. If subtracting a negative, reverse its sign: 7 − (−3) = 7 + 3. The sign of the operand is not the same as the operation symbol.

Work together

Calculate 7 − 12 at eight bits

Use two’s complement for both operands and the result.

Work together · 1 / 3

Encode the operands

+7 = 00000111. +12 = 00001100; invert and add one to get −12 = 11110100.

Work together · 2 / 3

Add the patterns

00000111 + 11110100 = 11111011.

Work together · 3 / 3

Decode and check

11111011 = −128 + 64 + 32 + 16 + 8 + 2 + 1 = −5. The mathematical answer 7 − 12 is −5, which fits −128 to +127.

The same addition process works because the operands and result use the same signed representation.

Experiment

Compare +12 + (−5) with +7 + (−12). Predict the sign, then trace the columns. Use the signed range to check the stored result.

Calculate −9 + (−6), then calculate −9 − (−6), using eight-bit two’s complement.

  01100100
+ 11110110
-----------
1 01011010

Retained eight-bit result: 01011010 = 64 + 16 + 8 + 2 = 90.

For direct subtraction, borrow from the 4s column to the 2s column, then from the 32s column through the 16s column to the 8s column. Both methods give 01011010.

Official mark scheme
Why this earns marks — teacher explanation

The three marks cover correct operand conversion, a valid subtraction method, and the correct result. The leading carry in the addition method is outside the retained byte; it is not evidence that the result 90 is out of range.

Common mistakes — teacher analysis

Giving only denary 90 misses the required binary method. If using a negative operand, keep all eight bits during inversion and addition.

Decide whether the answer fits its representation

Observe

Keep only eight bits

CalculationMathematical answerEight retained bits
Unsigned 250 + 1026000000100
Two’s complement 100 + 4014010001100

Look, then discuss

Why is a correctly formed eight-bit pattern not always the correct answer?

Unsigned eight-bit storage stops at 255. Signed eight-bit two’s complement stops at +127. Neither row can hold its mathematical answer under the stated rule.

Explain

Explanation · 1 / 4

Define overflow using the range

Overflow occurs when the true arithmetic result is outside the range available in the fixed-width representation. The system may retain low-order bits, but those bits no longer represent the required mathematical result.

Explanation · 2 / 4

Check unsigned addition and subtraction

Unsigned eight-bit addition can produce a ninth bit when its result exceeds 255. That carry shows the result does not fit. Unsigned subtraction also cannot represent a negative difference, such as 3 − 5; check the range rather than assuming that every subtraction is possible.

Explanation · 3 / 4

Use the signed rule for two’s-complement addition

At eight bits the signed range is −128 to +127. Adding two positive values and obtaining a negative retained result indicates overflow. Adding two negatives and obtaining a non-negative retained result also indicates overflow. Opposite-sign addition cannot exceed the range when both operands already fit.

Explanation · 4 / 4

Separate carry-out from signed overflow

−1 + 1 produces 1 00000000, with a carry-out, yet signed zero is correct. +127 + 1 produces 10000000 without a ninth-bit carry, yet signed +128 is out of range. The interpretation determines which limit matters.

Work together

Interpret 01111110 + 00000010 twice

The same bit addition is performed at eight bits.

Work together · 1 / 3

Add once

The retained sum is 10000000.

Work together · 2 / 3

Apply the unsigned reading

126 + 2 = 128. The range is 0 to 255, so 10000000 correctly represents 128. There is no unsigned overflow.

Work together · 3 / 3

Apply the signed reading

126 + 2 is still mathematically 128, but two’s complement allows at most 127. The pattern 10000000 means −128, so signed overflow occurred.

Overflow is about a value failing to fit the chosen representation, not about a pattern looking unusual.

Predict whether 126 + 2 overflows before revealing the result. Compare its unsigned and signed interpretations; the operand bit patterns remain 01111110 and 00000010.
