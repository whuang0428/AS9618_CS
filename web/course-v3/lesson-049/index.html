01

Abstraction, its purpose/benefits and creation of an abstract model

S9.01.A01S9.01.A02S9.01.A03S9.01.A04

Its need and benefits, then produce an abstract model containing only details essential to the problem.

Abstraction removes each irrelevant detail that does not affect the required inputs, rules, constraints or outputs. Producing an abstract model means recording the essential details that remain: the data, relationships and processes needed to solve the problem, not merely listing what was ignored.

Algorithm design review: define an algorithm as a solution expressed as a sequence of defined steps; use abstraction to retain essential details in an abstract model; use decomposition to express the problem as connected modules; and choose meaningful identifiers recorded in an identifier table.

Abstraction decides what belongs in the model; decomposition decides how the retained problem is divided. The modules must connect into one complete solution and must not omit a requirement.

Common misconception

Abstraction removes details irrelevant to the stated problem; it must not remove an input, rule or constraint that changes the required result.

Practice

Retrieve, apply, then answer like an exam

Retrieval6 marks

Write an abstract model for a school meal bill, then decompose it into named program modules and identify one likely procedure and one likely function.

S9.01.A04
Answer and marking points
  1. retains meal choice, quantity and price as essential details
  2. states the calculation and total output in the abstract model
  3. excludes a justified irrelevant detail such as tray colour
  4. expresses the problem as connected modules with distinct responsibilities
  5. identifies a suitable procedure module that performs an action
  6. identifies a suitable function module that returns a value

Common error: For the command word write, perform that exact action; do not replace it with an unrelated fact.

Application8 marks

Develop an abstract, modular algorithm for processing ten valid marks, then show one refinement level and the central validation logic statement.

S9.01.A04S9.01.A01
Answer and marking points
  1. abstract model keeps only essential data, rules and output
  2. decomposition expresses connected program modules
  3. identifier table uses meaningful names, types and purposes
  4. IPO design forms a complete solution
  5. sequence, selection and iteration are used appropriately
  6. one representation is accurate and convertible without changing meaning
  7. stepwise refinement replaces a complex step with implementable substeps
  8. logic statement correctly enforces the required mark range

Common error: Do not repeat the same point in different words; each mark needs a separate idea or method step.
