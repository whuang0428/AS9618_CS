Knowledge block 1 / 3

Where does each bit move?

THINK

In 10110001, what fills the leftmost position after a logical right shift?

LEARN

Compare logical, arithmetic and cyclic shifts one bit at a time; choose amount and direction.

APPLY

Immediate check

What makes arithmetic right different for a byte beginning with 1?

Reveal answer

It repeats the sign bit on the left; logical right inserts zero.

Exam transfer · teacher-written

Question 5 · Command word: Calculate3 teacher marks

Calculate ACC after LSL #2 followed by LSR #3, starting with the unsigned 8-bit value 00101100. Explain what enters each vacated position.

S4.15.A01S4.15.A04S4.15.A13S4.15.A14
Answer and checking points — teacher-written
  1. LSL #2 gives 10110000, which is 176.
  2. LSR #3 then gives 00010110, which is 22.
  3. Logical shifts insert zeros; bits leaving the fixed-width value are discarded.

Common error: The second instruction acts on the first instruction's result.

What does 10101100 AND 00001111 give?

Exam transfer · teacher-written

Question 4 · Command word: Calculate6 teacher marks

Calculate the ACC result for each instruction independently, starting each time with ACC=172 and Memory[700]=15: AND #15, AND 700, OR B00001111, OR 700, XOR &0F, XOR 700. Give every result in 8-bit binary and denary.

S4.15.A05S4.15.A07S4.15.A08S4.15.A09S4.15.A10S4.15.A11S4.15.A12
Answer and checking points — teacher-written
  1. AND #15: 00001100 = 12.
  2. AND 700: 00001100 = 12 because the memory operand is 15.
  3. OR B00001111: 10101111 = 175.
  4. OR 700: 10101111 = 175 using the contents of location 700.
  5. XOR &0F: 10100011 = 163.
  6. XOR 700: 10100011 = 163 using the same mask from memory.

Common error: Reset ACC before each independent calculation; a bare address refers to stored contents.

Knowledge block 3 / 3

Can you change one device bit safely?

THINK

Ready is bit 4 and motor enable bit 2. What happens if you store the AND test result?

LEARN

Test ready, follow the conditional branch, reload the original byte, set bit 2 and store only on the ready path.

APPLY

Immediate check

For 00000001, what is the final byte?

Reveal answer

00000001. Ready is clear, so the write is skipped.

Exam transfer · teacher-written

Question 3 · Command word: Write5 teacher marks

The supplied program uses an 8-bit interface register at 900: ready is bit 4 and motor enable is bit 2. The device does not change the register during the sequence and a write replaces the byte. Give the final byte for separate initial values 00010001, 00000001 and 00010101. Explain the role of JPE and the second LDD.

Initial ACC=0, IX=0, PC=100; comparison result unset. Memory[900]=17. No input is needed. Addresses are denary; each listed instruction or data item occupies one location.

100  LDD 900
101  AND B00010000
102  CMP #0
103  JPE DONE
104  LDD 900
105  OR B00000100
106  STO 900
107  DONE: END
S4.15.A02S4.15.A05S4.15.A06S4.15.A15S4.15.A16
Answer and checking points — teacher-written
  1. 00010001 becomes 00010101.
  2. 00000001 stays 00000001; the zero test causes JPE DONE to skip the write.
  3. 00010101 remains 00010101 because OR leaves the already-set motor bit set.
  4. The second LDD reloads the original value after AND cleared unselected ACC bits, preserving the other stored bits.
  5. DONE labels END at 107, giving both paths a termination point.

Common error: The AND test result is not the full status byte to store.

Official Cambridge question · Cambridge 9618/12 · May/June 2024 · 5(b) →

Core idea

Exam Challenge

Bring together the model and the written explanation. Attempt the task before revealing the teacher’s answer.

An 8-bit interface byte is 00010001. Ready is bit 4; motor enable is bit 2. Give a mask to test ready and a mask to set motor enable while preserving all other bits. What is the final byte?

Teacher-written model answer
  1. AND B00010000 tests ready on a copy and yields 00010000.
  2. Reload the original byte, OR B00000100, then store the result.
  3. The final byte is 00010101; unrelated bits remain unchanged.

Cambridge 9618/12 · May/June 2024 · 5(b) · 3 marks

Reading the question — teacher guidance

ACC is reloaded to 01000110 before each program. Plain 29 is an address; #29 is the denary value 29.

Solution / model answer — teacher-written
ProgramOperand actually usedCalculationACC
XOR 29Memory[29] = 0000111101000110 XOR 0000111101001001
AND #2929 = 0001110101000110 AND 0001110100000100
OR B111111111111111101000110 OR 1111111111111111
Official mark scheme
Why this earns marks — teacher explanation

One mark is awarded for each correct ACC result. Intermediate conversions help avoid operand errors but do not create extra marks.

Common mistakes — teacher analysis

Do not chain the three results: each program starts with the supplied original ACC. AND #29 does not read Memory[29].

Original question · Cambridge 9618/12

2. Write a bitwise odd-number test

Cambridge 9618/12 · October/November 2024 · 8(b)(ii) · 3 marks

Selected parts: 8(b)(ii) [3].

Reading the question — teacher guidance

The required result is a test of the stored integer’s oddness. Isolate only the least significant bit and then interpret the result.

Solution / model answer — teacher-written

All binary place values except the least significant one are even. An odd integer therefore has a least significant bit of 1. AND with 00000001 clears every other bit and preserves that bit.

AND B00000001

Compare the resulting ACC with denary 1: equality means the original number was odd. The supplied example 10011010 would produce 00000000, so that example is even. AND #1 and AND &01 are equivalent immediate forms allowed by this scheme.

Official mark scheme
Why this earns marks — teacher explanation

The explanation is capped at two marks, and the correct masking instruction earns one separate mark. A suitable instruction alone does not explain why it tests oddness.

Common mistakes — teacher analysis

AND 1 uses direct addressing and is not the same as AND #1. Masking changes ACC, so preserve the original elsewhere first if a later program step still needs it.
