4.3.1

Move bits with logical shifts

Shift an unsigned byte

Predict the 8-bit resultStep 0 / 2

Start from 00110100: unsigned 52, or signed two’s complement 52. Shift 1 position. Every experiment starts from this original byte.

All words are exactly 8 bits. Logical shifts discard outgoing bits; arithmetic right copies the sign bit; cyclic shifts wrap bits. Arithmetic left has the same bit movement as logical left but requires signed overflow checking. ASL, ASR, ROL and ROR are descriptive operation labels here, not additional mnemonics in the supplied Cambridge instruction set; LSL and LSR are supplied mnemonics. Changing a setting restarts from the original byte.

Changing a setting restarts this experiment. Predict the change before stepping again.

Read an eight-bit word from bit 7 at the left to bit 0 at the right. Follow the zero entering the empty position and the bit discarded at the far end.

Use the two syllabus shift instructions

InstructionStarting ACCResultWhat happened
LSL #100110100 (52)01101000 (104)Zeros enter on the right.
LSR #201101000 (104)00011010 (26)Two zeros enter on the left.
LSR #100000101 (5)00000010 (2)The outgoing 1 is discarded.

The first two rows form a sequence. Logical left shift doubles an unsigned value when the result fits; logical right shift divides by two and discards the remainder.

Monitor and control a device register

Test the ready bit before enabling the motor

Read the interface byteStep 0 / 6

Bit 4 reports readiness; bit 2 enables the motor. Bit 0 already holds other information.

Eight bits are numbered 7 to 0 from left to right. The model assumes one readable, writable device register at address 900.

Changing a setting restarts this experiment. Predict the change before stepping again.

In this interface at address 900, bit 4 indicates ready, bit 2 enables the motor and bit 0 carries an independent status. Compare ready and busy paths, following ACC separately from the device register.

Trace the instruction that writes back

The AND test discards the other flags in ACC. The ready path reloads the whole register, sets only bit 2 and writes the byte back. The busy path jumps to DONE before any store.

Bit manipulation

Original question · Cambridge 9618/13

1. Distinguish logical and arithmetic right shifts

Cambridge 9618/13 · October/November 2024 · 8(c) · 2 marks

Selected parts: 8(c) [2].

Teacher solution and explanation

Compare what enters the leftmost bit positions. The question asks about right shifts; neither operation wraps the outgoing bits around.

Both operations move bits to the right. A logical right shift fills the vacated leftmost positions with zeros. An arithmetic right shift copies the original sign bit into those positions.

8-bit exampleBeforeAfter one right shift
Logical1001111101001111
Arithmetic1001111111001111

One mark is available for the logical-shift rule and one for the arithmetic-shift rule. The added example illustrates the rules; it is teacher-written and is not part of the original question.

Saying only that an arithmetic shift preserves the sign does not explain how the new bits are filled. A cyclic shift brings outgoing bits back at the other end; that is a different operation.

Original question · Cambridge 9618/12

3. Write a bitwise odd-number test

Cambridge 9618/12 · October/November 2024 · 8(b)(ii) · 3 marks

Selected parts: 8(b)(ii) [3].

Reading the question — teacher guidance

The required result is a test of the stored integer’s oddness. Isolate only the least significant bit and then interpret the result.

Solution / model answer — teacher-written

All binary place values except the least significant one are even. An odd integer therefore has a least significant bit of 1. AND with 00000001 clears every other bit and preserves that bit.

AND B00000001

Compare the resulting ACC with denary 1: equality means the original number was odd. The supplied example 10011010 would produce 00000000, so that example is even. AND #1 and AND &01 are equivalent immediate forms allowed by this scheme.

Official mark scheme
Why this earns marks — teacher explanation

The explanation is capped at two marks, and the correct masking instruction earns one separate mark. A suitable instruction alone does not explain why it tests oddness.

Common mistakes — teacher analysis

AND 1 uses direct addressing and is not the same as AND #1. Masking changes ACC, so preserve the original elsewhere first if a later program step still needs it.

Additional teacher-written practice
Question 1 · Command word: Calculate6 teacher marks

Calculate the six one-place shift results for the 8-bit pattern 10110010: logical left/right, arithmetic left/right, and cyclic left/right. Interpret arithmetic shifts using two's complement and state whether the left arithmetic shift overflows. Discard any bit shifted outside the 8-bit result.

S4.15.A01S4.15.A03S4.15.A04
Answer and checking points — teacher-written
  1. Logical left produces 01100100; logical right produces 01011001.
  2. Arithmetic left produces 01100100, the same bit movement as logical left.
  3. The original signed value is −78; doubling it gives −156, outside −128 to 127, so the arithmetic left result overflows.
  4. Arithmetic right produces 11011001, preserving the sign bit; its signed value is −39.
  5. Cyclic left produces 01100101 by wrapping the old leftmost bit to the right.
  6. Cyclic right produces 01011001 by wrapping the old rightmost bit to the left.

Common error: Arithmetic right repeats the sign bit; cyclic shifts wrap the outgoing bit. Their results can coincide for a particular input.

Question 2 · Command word: Explain5 teacher marks

Explain how to test bit 5 and set bit 1 in an 8-bit device status value without changing unrelated bits in the stored value. Bits are numbered 7 to 0 from left to right. The initial status is 00100100. Give the test result and the updated status, using a fresh copy of the original status for setting.

S4.15.A02S4.15.A05S4.15.A06S4.15.A07S4.15.A11
Answer and checking points — teacher-written
  1. Use AND B00100000 on a copy to isolate bit 5.
  2. The test gives 00100000, so bit 5 is set; a zero result would mean it was clear.
  3. Reload the original status, then use OR B00000010 to set bit 1.
  4. The updated status is 00100110; store that result back to the device register.
  5. The AND test changes ACC, so its result must not overwrite unrelated status bits.

Common error: Testing a bit is not the same as clearing every other bit in the device's stored status.

Question 3 · Command word: Write5 teacher marks

The supplied program uses an 8-bit interface register at 900: ready is bit 4 and motor enable is bit 2. The device does not change the register during the sequence and a write replaces the byte. Give the final byte for separate initial values 00010001, 00000001 and 00010101. Explain the role of JPE and the second LDD.

Initial ACC=0, IX=0, PC=100; comparison result unset. Memory[900]=17. No input is needed. Addresses are denary; each listed instruction or data item occupies one location.

100  LDD 900
101  AND B00010000
102  CMP #0
103  JPE DONE
104  LDD 900
105  OR B00000100
106  STO 900
107  DONE: END
S4.15.A02S4.15.A05S4.15.A06S4.15.A15S4.15.A16
Answer and checking points — teacher-written
  1. 00010001 becomes 00010101.
  2. 00000001 stays 00000001; the zero test causes JPE DONE to skip the write.
  3. 00010101 remains 00010101 because OR leaves the already-set motor bit set.
  4. The second LDD reloads the original value after AND cleared unselected ACC bits, preserving the other stored bits.
  5. DONE labels END at 107, giving both paths a termination point.

Common error: The AND test result is not the full status byte to store.

Question 4 · Command word: Calculate6 teacher marks

Calculate the ACC result for each instruction independently, starting each time with ACC=172 and Memory[700]=15: AND #15, AND 700, OR B00001111, OR 700, XOR &0F, XOR 700. Give every result in 8-bit binary and denary.

S4.15.A05S4.15.A07S4.15.A08S4.15.A09S4.15.A10S4.15.A11S4.15.A12
Answer and checking points — teacher-written
  1. AND #15: 00001100 = 12.
  2. AND 700: 00001100 = 12 because the memory operand is 15.
  3. OR B00001111: 10101111 = 175.
  4. OR 700: 10101111 = 175 using the contents of location 700.
  5. XOR &0F: 10100011 = 163.
  6. XOR 700: 10100011 = 163 using the same mask from memory.

Common error: Reset ACC before each independent calculation; a bare address refers to stored contents.

Question 5 · Command word: Calculate3 teacher marks

Calculate ACC after LSL #2 followed by LSR #3, starting with the unsigned 8-bit value 00101100. Explain what enters each vacated position.

S4.15.A01S4.15.A04S4.15.A13S4.15.A14
Answer and checking points — teacher-written
  1. LSL #2 gives 10110000, which is 176.
  2. LSR #3 then gives 00010110, which is 22.
  3. Logical shifts insert zeros; bits leaving the fixed-width value are discarded.

Common error: The second instruction acts on the first instruction's result.

Question 6 · Command word: Identify5 teacher marks

Identify the instruction label and data label in the supplied program and give their addresses. Explain the difference between FLAGS and the contents at FLAGS, then state the final stored value in binary and denary.

Initial ACC=0, IX=0, PC=20; comparison result unset. Data declarations are included below. No input is needed. Addresses are denary; each listed instruction or data item occupies one location.

020  START: LDD FLAGS
021  OR B00000010
022  STO FLAGS
023  END
024  FLAGS: 129
S4.15.A05S4.15.A11S4.15.A15S4.15.A16
Answer and checking points — teacher-written
  1. START labels the instruction at address 20.
  2. FLAGS labels the data location at address 24.
  3. FLAGS resolves to address 24; its initial contents are 129, or 10000001.
  4. OR B00000010 sets bit 1, producing 10000011 = 131.
  5. STO FLAGS writes 131 into location 24.

Common error: A data declaration reserves a labelled location; it is not another instruction to execute.

Additional past-paper question · Logical shifts

Original question · Cambridge 9618/11

1. Choose the instruction for a two-place left shift

Cambridge 9618/11 · October/November 2025 · 4(a) · 1 marks

Selected parts: 4(a) [1].

Teacher solution and explanation

Follow the original bit positions. The target has two zero bits inserted on the right, so choose the logical left-shift instruction and its shift count.

LSL #2

After one place, 00011110 becomes 00111100. After two places, it becomes 01111000. The operand #2 is the number of places, not the final value of ACC.

The official scheme awards the single mark for LSL #2. The step-by-step explanation is teacher-written.

Do not use LSR, which shifts in the opposite direction. Do not use #4 merely because the unsigned value has been multiplied by four; the operand counts bit positions.
