Processor fundamentals · Concept 01

Move bits and see what falls out

Observe

Start with a question

If we shift left and then right, must the original byte return?

Use eight boxes containing 00110100. Move every bit one place left, discard the bit that leaves the byte, and fill the empty right-hand box with 0.

Explain

Explanation · 1 / 4

State the width and interpretation

A byte has eight bits. For an unsigned byte, positions from left to right have weights 128, 64, 32, 16, 8, 4, 2 and 1. Here 00110100 represents 52. Fixed width matters because outgoing bits cannot remain in the result.

Explanation · 2 / 4

Shift logically left

LSL #n moves the bits in ACC n places left. Zeros enter on the right and outgoing left bits are discarded. LSL #1 changes 00110100 to 01101000. The value doubles from 52 to 104 because this example does not lose a significant 1 bit.

Explanation · 3 / 4

Shift logically right

LSR #n moves the bits in ACC n places right. Zeros enter on the left and outgoing right bits are discarded. Applied after the previous instruction, LSR #2 changes 01101000 to 00011010, giving 26. Use the updated ACC in a sequence.

Explanation · 4 / 4

Check information loss

Starting independently from 10000001, logical left gives 00000010. Logical right of that result gives 00000001, not the original byte: the discarded leading 1 cannot be recovered. Right shifting an unsigned odd value also discards its remainder bit.

Processor fundamentals · Concept 02

Preserve a sign or wrap a bit around

Observe

Start with a question

What should enter the left-hand position when a negative number shifts right?

Start each comparison afresh from 10010111. As unsigned it is 151. As eight-bit two’s complement it is −105: the leftmost bit has weight −128, so −128 + 16 + 4 + 2 + 1 = −105.

Explain

Explanation · 1 / 4

Recover the sign rule

In two’s complement, a leading 1 indicates a negative value. Arithmetic right shift copies the original sign bit into the new left-hand position, preserving the sign. For 10010111 it gives 11001011, which represents −53.

Explanation · 2 / 4

Check the numerical consequence

Arithmetic right shift of a negative odd value rounds down: −105 divided by two is −52.5, and the result is −53. Logical right instead inserts zero and gives 01001011, or positive 75. The two rules therefore have different meanings for this bit pattern.

Explanation · 3 / 4

Check arithmetic left

Arithmetic left shifts the bit pattern like logical left and inserts zero on the right. From 10010111 it gives 00101110, or 46. The intended signed double would be −210, outside the eight-bit range −128 to 127: overflow has occurred. Left shift only behaves as multiplication when the result fits.

Explanation · 4 / 4

Wrap with a cyclic shift

A cyclic shift rotates the outgoing bit to the opposite end instead of discarding it. Cyclic left of 10010111 gives 00101111; cyclic right gives 11001011. Its rule is wrapping, even when a particular result happens to equal an arithmetic result.

Answer and checking points — teacher-written
  1. Logical left produces 01100100; logical right produces 01011001.
  2. Arithmetic left produces 01100100, the same bit movement as logical left.

Processor fundamentals · Concept 03

Apply one logic rule at every bit position

Observe

Start with a question

Which operation keeps, sets or flips the positions marked by a mask?

Align ACC = 10100110 with mask 00001111. Treat each pair of aligned bits independently. Predict the low four output bits for AND, OR and XOR, resetting ACC before each comparison.

Explain

Explanation · 1 / 4

Recall the three single-bit rules

AND produces 1 only when both input bits are 1. OR produces 1 when at least one is 1. XOR produces 1 when exactly one is 1. Bitwise operations apply these rules separately to every corresponding pair of bits.

First bitSecond bitANDORXOR

Explanation · 2 / 4

Choose a mask from the required action

A mask is a bit pattern used to select positions. AND with 1 preserves a bit and AND with 0 clears it. OR with 0 preserves a bit and OR with 1 sets it. XOR with 0 preserves a bit and XOR with 1 toggles it, changing 0 to 1 or 1 to 0.

Explanation · 3 / 4

Resolve the operand before combining

AND, OR and XOR each accept immediate #n, Bn or &n operands, or a direct memory address. AND #15, AND B00001111 and AND &0F use the same immediate mask. AND 700 reads Memory[700] and only uses that same mask if the location contains 15.

Explanation · 4 / 4

Keep independent examples independent

For each row below, start again from 10100110. The result replaces ACC. The AND result is not the input to the following OR row unless a program explicitly gives that sequence.

Processor fundamentals · Concept 04

Test readiness, then change one control bit

Observe

Start with a question

Why must we reload the original byte after testing one bit?

An eight-bit interface value at address 900 contains 00010001. Bit 4 means ready and bit 2 enables a motor. Number bits from 7 on the left to 0 on the right. We must enable the motor only when ready and preserve all other bits.

Explain

Explanation · 1 / 6

Declare the device model

A memory-mapped interface can be read or written using a memory address. Here a read of address 900 gives the current byte and a write replaces it. Assume the device does not independently change this byte during the short sequence. Real interfaces can have different write rules.

Explanation · 2 / 6

Test a copy with AND

Load the byte into ACC, then AND B00010000 to select bit 4. The result is either 00010000, value 16, or 00000000. CMP #0 followed by JPE DONE skips the update when the ready bit is clear. A successful bit test need not produce denary 1.

Explanation · 3 / 6

Recover and update the full value

The AND test cleared other positions in ACC, including the original bit 0. Reload the original byte with LDD 900. OR B00000100 then sets bit 2 while preserving every other position. STO 900 writes the resulting 00010101 back to the interface.

Explanation · 4 / 6

Read the whole program and its label

DONE names the END instruction at address 107. The not-ready branch reaches it without executing a store. The ready path reloads, sets and stores before reaching the same ending. A label identifies an instruction address; it is not an extra instruction.

100  LDD 900
101  AND B00010000
102  CMP #0
103  JPE DONE
104  LDD 900
105  OR B00000100
106  STO 900
107  DONE: END

Explanation · 5 / 6

Apply the same idea to another selected bit

To clear bit 2, AND with 11111011; to toggle it, XOR with 00000100. To test whether an unsigned integer is odd, select bit 0 using AND B00000001: only its weight 1 can make the number odd. The other binary place values are even.

Explanation · 6 / 6

Keep a data label distinct

A source declaration such as FLAGS: 17 names a data location initially containing 17, binary 00010001. LDD FLAGS loads those contents and STO FLAGS changes them. The label continues to name the same address after the stored byte changes, just as TOTAL did in the addition program.

Question 1 · Command word: Explain5 teacher marks

Explain how to test bit 5 and set bit 1 in an 8-bit device status value without changing unrelated bits in the stored value. Bits are numbered 7 to 0 from left to right. The initial status is 00100100. Give the test result and the updated status, using a fresh copy of the original status for setting.

S4.15.A02S4.15.A05S4.15.A06S4.15.A07S4.15.A11
Answer and checking points — teacher-written
  1. Use AND B00100000 on a copy to isolate bit 5.
  2. The test gives 00100000, so bit 5 is set; a zero result would mean it was clear.
  3. Reload the original status, then use OR B00000010 to set bit 1.
  4. The updated status is 00100110; store that result back to the device register.
  5. The AND test changes ACC, so its result must not overwrite unrelated status bits.

Common error: Testing a bit is not the same as clearing every other bit in the device's stored status.

Original question · Cambridge 9618/12

1. Write a bitwise odd-number test

Cambridge 9618/12 · October/November 2024 · 8(b)(ii) · 3 marks

Selected parts: 8(b)(ii) [3].

Hint — reading the question

The required result is a test of the stored integer’s oddness. Isolate only the least significant bit and then interpret the result.

Reasoning and model answer — teacher-written

All binary place values except the least significant one are even. An odd integer therefore has a least significant bit of 1. AND with 00000001 clears every other bit and preserves that bit.

AND B00000001

Compare the resulting ACC with denary 1: equality means the original number was odd. The supplied example 10011010 would produce 00000000, so that example is even. AND #1 and AND &01 are equivalent immediate forms allowed by this scheme.

Official mark scheme
Why this earns marks — teacher explanation

The explanation is capped at two marks, and the correct masking instruction earns one separate mark. A suitable instruction alone does not explain why it tests oddness.

Common mistakes — teacher analysis

AND 1 uses direct addressing and is not the same as AND #1. Masking changes ACC, so preserve the original elsewhere first if a later program step still needs it.
