Visual overview

Core explanation

CONSTANT defines and initialises a fixed named value. DECLARE introduces a variable name and data type. Assignment evaluates the expression on the right of <- and stores the result in the variable on the left.

Arithmetic expressions use +, -, *, /, DIV and MOD and produce numeric results. Comparisons such as =, <>, <, <=, > and >= produce Boolean results; AND, OR and NOT combine or invert Boolean values.

INPUT obtains a value from the keyboard and stores it in the named variable. OUTPUT sends a value or expression result to the console. The declared type must be compatible with every assigned or input value.

Declarations, assignment and input/output

  1. Define constants and typed variablesIntroduce every identifier before use and initialise each constant in its declaration.
  2. Input the required source valuesUse INPUT with a declared variable whose type matches the expected data.
  3. Calculate and assign the resultEvaluate arithmetic or logical operators on the right, then store the result with <-.
  4. Output the required resultUse OUTPUT only after the value has been assigned or calculated.

Worked example · Declare, input, calculate and output without losing an operator

  1. Declare
    CONSTANT TaxRate = 0.20
DECLARE Price : REAL
DECLARE Tax : REAL
  2. Input

    INPUT Price

  3. Calculate

    Tax <- Price * TaxRate

  4. Output

    OUTPUT Tax

  5. Check

    For Price = 50.00, multiplication gives 10.00 and <- stores 10.00 in Tax before it is output.

Common misconception

A declaration introduces an identifier and type; assignment changes a variable's value. The multiplication operator * must not disappear from the expression.

Command word: State2 marks

State one difference between an arithmetic expression and a logical expression, giving one operator example for each.

S11.02.A04S11.02.A03
Answer and marking points
  1. an arithmetic expression produces a numeric result and may use *.
  2. a logical expression produces a BOOLEAN result and may use >= or AND.

Common error: For the command word state, perform that exact action; do not replace it with an unrelated fact.

Command word: Write3 marks

Write an arithmetic assignment for Total from Price and Quantity, then write a logical assignment that is TRUE when Age is at least 18 and Registered is TRUE.

S11.02.A04S11.02.A05
Answer and marking points
  1. Total <- Price * Quantity.
  2. Eligible <- (Age >= 18) AND Registered.
  3. the first result is numeric and the second is BOOLEAN.

Common error: Do not repeat the same point in different words; each mark needs a separate idea or method step.

Command word: Write4 marks

Write a corrected version of the incomplete pseudocode statement Tax <- Price TaxRate and explain the role of the assignment and multiplication operators.

S11.02.A02S11.02.A04
Answer and marking points
  1. Tax <- Price * TaxRate.
  2. * calculates the product on the right.
  3. <- stores that result in Tax.
  4. = would be comparison rather than Cambridge pseudocode assignment.

Common error: Do not copy the worked example unchanged; transfer the method and check it against the new context.

  2. INPUT reads the source values before any expression uses them.
  3. Evaluate arithmetic and comparison expressions on the right before assigning their results with <-.
