Program a booking system · Concept 05

Group a calculation to match the rule

Observe

Two different charging rules

RuleExpression
One fee per booking3 * 12.50 + 2.00
One fee per seat3 * (12.50 + 2.00)

Look, then discuss

Is a 2.00 charge added once per booking or once per seat?

Three seats cost 12.50 each. Compare a receipt with one booking fee against a receipt with a fee on every seat. The same numbers can describe different calculations.

Recall

Recall assignment

An assignment calculates its right side first. Arithmetic uses +, -, * and /. Choose a REAL result when fractional values may occur.

Explain

Explanation · 1 / 3

Apply multiplication and division before addition and subtraction

Without brackets, 3 * 12.50 + 2.00 first gives 37.50 and then adds the single fee. Operators of the same precedence are evaluated left to right in these examples.

Explanation · 2 / 3

Use parentheses for a combined per-item amount

For a fee on every seat, calculate 12.50 + 2.00 before multiplying by 3. Parentheses express that grouping explicitly rather than relying on a verbal description.

Explanation · 3 / 3

Keep real division separate from whole-group counting

The / operator gives real division: 7 / 2 is 3.5. Dividing a booking total by its positive seat count gives a per-seat amount. A divisor must not be zero.

DECLARE Seats : INTEGER
DECLARE Price, Fee, Total : REAL
Seats <- 3
Price <- 12.50
Fee <- 2.00
Total <- Seats * (Price + Fee)
OUTPUT Total

Work together

Explain both receipts

Use Seats 3, Price 12.50 and Fee 2.00.

Work together · 1 / 2

Calculate a single booking fee

3 * 12.50 + 2.00 = 37.50 + 2.00 = 39.50.

Work together · 2 / 2

Calculate a fee on every seat

3 * (12.50 + 2.00) = 3 * 14.50 = 43.50. The 4.00 difference comes from two extra fee charges.

A correct expression implements the wording of the rule, not just a plausible numerical answer.

Check your reasoning

The results are 14 and 20. In the first expression multiplication occurs first; in the second, parentheses require the addition first.

Program a booking system · Concept 06

Separate complete groups from a remainder

Observe

Split a duration

  • Total minutes: 125
  • Minutes per complete hour: 60
  • 125 = 2 * 60 + 5

Look, then discuss

How do 125 booking minutes become 2 hours and 5 minutes?

Make as many complete groups of 60 minutes as possible. Two groups use 120 minutes, leaving 5. A decimal hour value answers a different question.

Recall

Recall integer and real division

125 / 60 is a REAL calculation. When the task asks for a number of complete groups and a remainder, use integer quotient and remainder operations.

Explain

Explanation · 1 / 3

Use DIV for the quotient

Minutes DIV 60 gives the number of complete hours. For non-negative integer Minutes and positive divisor 60, this is 2 for 125. DIV is not rounding to the nearest integer.

Explanation · 2 / 3

Use MOD for what remains

Minutes MOD 60 gives 5. The remainder must be at least 0 and less than 60 in this example. At exactly 120 minutes, it is 0.

Explanation · 3 / 3

Check by rebuilding the original value

Hours * 60 + Remaining must equal Minutes. Both result variables are INTEGER. These examples use non-negative quantities and positive divisors, so no signed-remainder convention is needed.

DECLARE Minutes, Hours, Remaining : INTEGER
INPUT Minutes
Hours <- Minutes DIV 60
Remaining <- Minutes MOD 60
OUTPUT Hours, " hours and ", Remaining, " minutes"

Work together

Test below and at an exact hour

Evaluate durations 59, 60 and 125 minutes.

Work together · 1 / 2

Separate quotient and remainder

59 gives 0 and 59; 60 gives 1 and 0; 125 gives 2 and 5.

Work together · 2 / 2

Reject swapped operators

Using MOD for Hours would report five hours for 125 minutes. Using DIV for Remaining would report two minutes. The reconstruction exposes both errors.

Use the quotient to count complete groups and the remainder to describe the ungrouped part.

Turn a boundary into a Boolean value

Observe

Enough seats?

Requested seatsAvailable seatsDoes the request fit?
56yes
66yes
76no

Look, then discuss

If six seats remain, should a request for exactly six be accepted?

Place requests for 5, 6 and 7 beside an available-seat count of 6. Say the rule in words before choosing the comparison symbol.

Recall

Recall BOOLEAN

A BOOLEAN value is TRUE or FALSE. A comparison evaluates two values and produces one Boolean result. It does not assign a new value unless it is used on the right of an assignment.

Explain

Explanation · 1 / 3

Match the words to the boundary

“At most” uses <= and includes equality. Seats <= Available is TRUE when Seats equals Available. Using < would reject the exact-fit booking.

Explanation · 2 / 3

Recognise the comparison operators

= tests equality; <> tests inequality; < and > are strict; <= and >= include equality. In Allowed <- Seats <= Available, the arrow assigns the result of the comparison.

WordingCondition
Exactly sixSeats = 6
Not sixSeats <> 6
At least oneSeats >= 1
Fewer than sixSeats < 6

Explanation · 3 / 3

Test around the boundary

Choose a value immediately below, at and immediately above the limit. A current correct result is not enough to establish that the rule covers its whole allowed range.

DECLARE Seats, Available : INTEGER
DECLARE Fits : BOOLEAN
Seats <- 6
Available <- 6
Fits <- Seats <= Available
OUTPUT Fits

Work together

Explain an exact-fit request

Available is 6. The condition is Seats <= Available.

Work together · 1 / 2

Substitute each request

5 <= 6 is TRUE; 6 <= 6 is TRUE; 7 <= 6 is FALSE.

Work together · 2 / 2

Expose the wrong operator

With Seats < Available, only the middle result changes to FALSE. Testing only 5 and 7 would miss the exact-fit defect.

The equality part of <= or >= is a requirement, not an optional detail.

Check

Try it yourself · Teacher-written

Check your reasoning

Use Age >= 18. Age = 18 accepts only the single age 18 and rejects older people.

Program a booking system · Concept 08

Combine restrictions with AND, OR and NOT

Observe

Confirmation rules

  • Seats must be at least 1.
  • Seats must be at most 6.
  • Paid must be TRUE.

Look, then discuss

What must be true before the desk confirms a request?

A valid quantity is from 1 to 6 inclusive. Confirmation also requires payment. Examine a paid request for 0 seats: one fact is acceptable, but the whole booking is not.

Recall

Recall comparisons

Each full comparison returns TRUE or FALSE. Write Seats on both sides of a range test: (Seats >= 1) AND (Seats <= 6). Do not use the mathematical shorthand 1 <= Seats <= 6 in Cambridge pseudocode.

Explain

Explanation · 1 / 3

Require every restriction with AND

AND is TRUE only when both operands are TRUE. For a valid paid booking, use ((Seats >= 1) AND (Seats <= 6)) AND Paid. A failure of any restriction makes the whole result FALSE. In the experiment, the adjustable Available value replaces the fixed upper limit 6, so the rule is (Seats >= 1) AND (Seats <= Available) AND Paid.

Explanation · 2 / 3

Accept either alternative with OR

An invalid quantity is (Seats < 1) OR (Seats > 6). Either excluded region makes it invalid. OR is inclusive: if both operands are TRUE, the result is still TRUE.

Explanation · 3 / 3

Reverse a result with NOT

NOT Paid is TRUE when Paid is FALSE. Parentheses make the intended grouping clear. An expression such as Active OR NOT Active is always TRUE, whichever Boolean value Active has.

Work together

Evaluate and then simplify for every input

Seats is 3, Available is 4 and Paid is TRUE. Then consider the general expression (Active OR NOT Active) AND NOT Exempt.

Work together · 1 / 2

Substitute one booking

(Seats <= Available) AND Paid becomes TRUE AND TRUE, so it is TRUE. Changing only Paid to FALSE makes it FALSE.

Work together · 2 / 2

Separate an example result from a general equivalence

Active OR NOT Active is TRUE for Active FALSE and for Active TRUE. The whole general expression is therefore equivalent to NOT Exempt. Writing TRUE would be wrong when Exempt is TRUE.

Evaluate each part before combining it, and justify a simplification for all possible relevant values.
