DDL, DML and the role of SQL

Classify structural changes and record operations, and explain how SQL expresses both.

Does an operation change the table definition or the data stored in that table?

Before you start

Adding a Price column and changing one product's price both change a database. Are they the same kind of change?

Check your answer

No. The first changes the structure; the second changes a stored field value.

01

DDL changes structure

S8.07.A01

Visual overview

Core explanation

Data Definition Language defines and modifies database structure. It can create a database, define a table's attributes and constraints, or alter an existing table definition. These operations determine what data the database can store.

Creating a Loan table does not add a particular loan record. Similarly, adding DueDate changes the permitted structure for loan records rather than choosing the date for one member's loan.

Common misconception

A new table definition is not a new row in an existing table.

Check your understanding

Which category adds a Status field to an existing table?

Check your answer

DDL, because the table definition gains a field.

02

DML retrieves and maintains records

S8.07.A02

Visual overview

Core explanation

Data Manipulation Language works with records in the defined structure. SELECT retrieves specified information. INSERT INTO adds records, UPDATE changes stored field values, and DELETE FROM removes records.

A query can produce a result table without altering the stored rows. Updating one member's phone number changes data while leaving the Member field definitions intact. These are both DML operations in the syllabus classification.

Common misconception

DML includes retrieval even when the stored database values are unchanged.

Check your understanding

Does SELECT become DDL because its result looks like a table?

Check your answer

No. It retrieves a result from the stored data; it does not define a new persistent table here.

03

SQL expresses both kinds of operation

S8.07.A03

Visual overview

Core explanation

Structured Query Language (SQL) is the industry-standard language used for both DDL and DML. The DBMS interprets SQL statements and carries out their requested changes or queries. DDL and DML describe roles within SQL rather than two alternative database products.

Determine the category from the requested effect, not from the word 'change' alone. A SQL statement that changes a column's definition is structural; one that changes the current value in that column operates on data.

Worked example · Follow the database lifecycle

  1. Define

    The developer creates tables and key constraints using SQL DDL.

  2. Populate

    Users add initial records using SQL DML.

  3. Use

    SELECT requests return information from those records.

  4. Maintain

    ALTER TABLE changes a definition; UPDATE changes existing values. Both are SQL, but their roles differ.

Common misconception

SQL is not limited to SELECT statements, and DDL is not another name for a DBMS.

Check your understanding

Can one SQL script contain both DDL and DML?

Check your answer

Yes. It can define a table and then insert records into it, with each statement classified by its effect.

Practice questions

3 core tasks · 8 teacher marks · 7–10 minutes (teacher estimate). Explain your reasoning before checking the answer.

Question 1 · Command word: Identify2 teacher marks

Identify CREATE TABLE and ALTER TABLE as DDL or DML, and describe the kind of object they change.

S8.07.A01
Answer and checking points — teacher-written
  1. Both commands are DDL.
  2. They create or modify a table definition, including its attributes or constraints.

Common error: Do not describe these as editing one existing record.

Question 2 · Command word: Identify3 teacher marks

Identify SELECT, INSERT INTO, UPDATE and DELETE FROM as DDL or DML. State which retrieves information without changing stored rows and which removes records.

S8.07.A02
Answer and checking points — teacher-written
  1. All four commands belong to DML.
  2. SELECT retrieves the requested information.
  3. DELETE FROM removes the selected records.

Common error: Deleting a record differs from removing a column definition.

Question 3 · Command word: Explain3 teacher marks

Explain the relationship between SQL, DDL and DML, using one structural operation and one data operation as examples.

S8.07.A01S8.07.A02S8.07.A03
Answer and checking points — teacher-written
  1. SQL supplies a common language for both definition and manipulation requests.
  2. For example, CREATE TABLE is a definition operation that establishes a structure.
  3. For example, UPDATE is a manipulation operation that changes data within that structure.

Common error: Give effects as well as expanding the abbreviations.

Summary

DDL

Define or alter the organisation of stored data.

DML

Retrieve, insert, update or delete records within that organisation.

SQL

Express both categories of request in one standard language.

Classify precisely

Compare the effect on the definition with the effect on existing values.
