Explanation · 1 / 4

Define a structure with DDL

Data Definition Language creates or changes database structure. CREATE DATABASE establishes a named database; CREATE TABLE defines fields and constraints; ALTER TABLE changes an existing definition. Creating Loan does not itself record a borrowing event.

Explanation · 2 / 4

Retrieve and maintain records with DML

Data Manipulation Language works with records in a defined structure. SELECT retrieves information; INSERT INTO adds records; UPDATE changes field values; DELETE FROM removes records. Retrieval counts as DML in this syllabus even when no stored value changes.

Explanation · 3 / 4

Relate both categories to SQL and the DBMS

Structured Query Language is the industry-standard language used to express both DDL and DML requests. SQL is the language, DDL and DML describe roles within it, and the DBMS is the software that processes the requests. They are not three competing database products.

Explanation · 4 / 4

Classify by effect

“Change” alone is ambiguous. Changing the definition of DueDate is structural; changing loan 201’s current date is a record operation. A SELECT result looks like a table but does not define a new persistent table in these examples.

Work together

Follow one record through its lifecycle

Use a small Loan table with LoanID INTEGER and Returned BOOLEAN.

Work together · 1 / 3

Define and populate

DDL defines the two fields and primary key. The empty table can then receive (201, FALSE) through INSERT, a DML operation.

Work together · 2 / 3

Retrieve and maintain

SELECT can return 201 as an unreturned loan while leaving the row intact. UPDATE changes its Returned value to TRUE. DELETE removes the row; the table definition still exists.

Work together · 3 / 3

Extend the definition

ALTER TABLE adds nullable DueDate DATE. Existing rows have no supplied date initially. A later UPDATE assigns a date to one row. The schema change and value assignment are distinct.

Ask whether the request defines structure, retrieves records or changes records before naming its category.

Check

Explain it yourself · Teacher-written

Classify: add a Phone field to Member; retrieve active members; correct one phone number; create a Member table.

Check your reasoning

Adding Phone and creating Member are DDL because they define structure. Retrieving active members and correcting a phone value are DML. Both categories can be expressed using SQL for a DBMS to process.

Question 1 · Command word: Identify2 teacher marks

Identify CREATE TABLE and ALTER TABLE as DDL or DML, and describe the kind of object they change.

S8.07.A01
Answer and checking points — teacher-written
  1. Both commands are DDL.
  2. They create or modify a table definition, including its attributes or constraints.

Common error: Do not describe these as editing one existing record.

Question 2 · Command word: Identify3 teacher marks

Identify SELECT, INSERT INTO, UPDATE and DELETE FROM as DDL or DML. State which retrieves information without changing stored rows and which removes records.

S8.07.A02
Answer and checking points — teacher-written
  1. All four commands belong to DML.
  2. SELECT retrieves the requested information.
  3. DELETE FROM removes the selected records.

Common error: Deleting a record differs from removing a column definition.

Question 3 · Command word: Explain3 teacher marks

Explain the relationship between SQL, DDL and DML, using one structural operation and one data operation as examples.

S8.07.A01S8.07.A02S8.07.A03
Answer and checking points — teacher-written
  1. SQL supplies a common language for both definition and manipulation requests.
  2. For example, CREATE TABLE is a definition operation that establishes a structure.
  3. For example, UPDATE is a manipulation operation that changes data within that structure.

Common error: Give effects as well as expanding the abbreviations.
