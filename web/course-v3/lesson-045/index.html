8.3.1

Create and modify structure using DDL

Data Definition Language (DDL)

Data Definition Language (DDL) is used to create and modify the structure of a database. A table definition states which attributes exist, their types and their constraints. The DBMS maintains this definition and uses it when accepting data.

ALTER TABLE Member ADD Note VARCHAR(80);
DDL and its effect
StatementWhat changes
CREATE DATABASE LibraryBuildCreates a separate named database.
CREATE TABLE Loan (...)Defines a table and the attributes / constraints in it.
ALTER TABLE Member ADD Note VARCHAR(80)Changes an existing table definition.

Practice question · teacher-written

Explain why adding a Note attribute uses DDL, whereas changing a stored member name uses DML.

Suggested answer

Adding a column changes which attributes the table has: DDL. Changing a name replaces one stored field value within the existing definition: DML.

8.3.2

Query and maintain data using DML

Data Manipulation Language (DML)

Data Manipulation Language (DML) is used to query and maintain the data in a database. Its operations include retrieving, inserting, updating and deleting records.

Effect on the database

SELECT returns a result table without creating a stored table definition. DELETE removes records while retaining the table definition and its constraints.

Practice question · teacher-written

Identify the DML operation required to record that loan 203 has been returned while retaining the borrowing record.

Suggested answer

UPDATE is required to change its Returned value. DELETE would remove the borrowing record.

8.3.3

SQL and the interpretation of statements

Structured Query Language (SQL)

Classification of SQL statements
SQL statementCategoryReason
CREATE TABLE Book (...)DDLDefines a new table structure.
ALTER TABLE Member ADD Note VARCHAR(80)DDLAdds an attribute to a definition.
UPDATE Member SET MemberName = 'Asha Patel' WHERE MemberID = 1DMLChanges a value in a selected record.
SELECT MemberName FROM MemberDMLRetrieves values from existing records.

Practice question · teacher-written

Explain how SQL can be used for both data definition and data manipulation.

Suggested answer

SQL includes DDL statements such as CREATE TABLE and DML statements such as INSERT INTO. A script may contain both types of statement.

Interpret a given SQL statement

SELECT LoanID, Fee
FROM Loan
WHERE Returned = FALSE AND Fee >= 3
ORDER BY LoanID;
Purpose of each SQL clause
PartMeaning
SELECT LoanID, FeeThese two attributes form the result columns.
FROM LoanUse the stored Loan records.
Returned = FALSE AND Fee >= 3A row must satisfy both conditions. Exactly 3 is included.
ORDER BY LoanIDArrange the qualifying result rows by increasing identifier.

Names such as LoanID identify database objects. Values such as 3 and FALSE are literals. Text values use single quotes: MemberName = 'Asha'. The semicolon terminates the statement. Parentheses can make the intended grouping of conditions explicit.

Practice question · teacher-written

State the effect on the result of replacing >= 3 with > 3. State the effect of replacing AND with OR in the original statement.

Suggested answer

With > 3, loan 205 is excluded and only 203 qualifies. With OR in the original statement, a row needs either condition, so loans 201, 202, 203 and 205 qualify. Loan 204 satisfies neither.

Teacher-written practice
Question 1 · Command word: Identify2 teacher marks

Identify CREATE TABLE and ALTER TABLE as DDL or DML, and describe the kind of object they change.

S8.07.A01
Answer and checking points — teacher-written
  1. Both commands are DDL.
  2. They create or modify a table definition, including its attributes or constraints.

Common error: Do not describe these as editing one existing record.

Question 2 · Command word: Identify3 teacher marks

Identify SELECT, INSERT INTO, UPDATE and DELETE FROM as DDL or DML. State which retrieves information without changing stored rows and which removes records.

S8.07.A02
Answer and checking points — teacher-written
  1. All four commands belong to DML.
  2. SELECT retrieves the requested information.
  3. DELETE FROM removes the selected records.

Common error: Deleting a record differs from removing a column definition.

Question 3 · Command word: Explain3 teacher marks

Explain the relationship between SQL, DDL and DML, using one structural operation and one data operation as examples.

S8.07.A01S8.07.A02S8.07.A03
Answer and checking points — teacher-written
  1. SQL supplies a common language for both definition and manipulation requests.
  2. For example, CREATE TABLE is a definition operation that establishes a structure.
  3. For example, UPDATE is a manipulation operation that changes data within that structure.

Common error: Give effects as well as expanding the abbreviations.

Data management

A table stores records about an entity type. Each record contains values for its fields. Select a table to inspect its records, then use the form or SQL to maintain the data.

Add a library member with a form

This form submits an INSERT statement to the database. The DBMS checks access rights and enforces primary key and unique constraints.

Data modelling and logical schema

Data modelling identifies entities, attributes and relationships. A logical schema describes the database design independently of a particular DBMS. The table definitions below implement that design in PostgreSQL.

Table designer: add an attribute

The designer issues ALTER TABLE. Inspect the same attribute in the data dictionary.

Data dictionary

The data dictionary contains metadata, including field names, data types, field sizes and constraints. The DBMS maintains this metadata when a table definition changes. Editing a record changes the stored data, not its field definitions.

Data integrity

Data integrity concerns the accuracy and consistency of stored data. The DBMS enforces validation rules and referential integrity constraints. Access rights control which operations a user may perform; authorised operations must still satisfy the constraints.

A foreign key alone permits NULL unless NOT NULL is also declared. This library requires every loan to identify a member and a copy. Its default referential action rejects deleting a referenced record.

Access rights for individuals and groups

Select a user above. Student inherits SELECT access rights from the library_readers group. Librarian inherits rights to retrieve, insert, update and delete records from library_writers. Administrator can change table definitions and assign access rights to individuals or groups.

Backup and recovery procedures

A backup is a copy of data that can be used to recover from data loss or corruption. Backup procedures specify how often copies are made, where they are stored, how they are protected and retained, and how restoration is tested. This exercise creates and restores a copy of the database at a particular time.

No teaching backup has been made.

A simulated outage hides the live records until recovery. The teaching backup restores the whole database structure, data and grants. Changes after its time are lost from the restored state.

Developer interface and query processor

The developer interface provides tools for defining tables and creating queries. The query processor interprets SQL, checks its syntax and referenced tables and fields, produces an execution plan and carries out the query. The results and errors below are produced by PostgreSQL.
