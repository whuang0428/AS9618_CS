01

Von Neumann architecture and the stored program concept

S4.01.A01

Visual overview

A stored program computer holds its instructions in memory. The processor fetches these instructions, decodes them and carries out the specified operations. Loading another instruction sequence changes the task the computer performs.

The basic Von Neumann model uses one memory for instructions and data. The processor contains a control unit, an arithmetic and logic unit and registers. Buses connect the processor to memory and input/output interfaces; instructions and data share transfer paths.

A memory address answers “where?” and its contents answer “what is stored there?”. The contents are binary patterns. Their role depends on how the processor uses them: fetching an instruction for decoding is different from reading an operand for calculation. A data value is not automatically an instruction just because it is in the same store.

The CPU boundary includes the CU, ALU and registers. Main memory and input/output interfaces are outside that boundary in this model. An interface connects a peripheral to the computer; it does not perform the CPU’s instruction decoding. The clock coordinates operations and the buses carry their addresses, values and control signals.

Use the same four-instruction calculation throughout these lessons. The listing is a readable representation of the encoded instructions in memory. LDD copies a stored value into ACC; ADD adds another stored value; STO copies ACC back to memory; END returns control to the operating system. Each item occupies one address in this teaching model.

Worked example · One store, one complete calculation

  1. Initial state

    Initial ACC=0, IX=0, PC=0; comparison result unset. Memory[4]=18, Memory[5]=24, Memory[6]=0. No input is needed. Addresses are denary; each listed instruction or data item occupies one location.

  2. Instruction memory
    000  LDD 4
001  ADD 5
002  STO 6
003  END
  3. Read and calculate

    LDD 4 reads 18 into ACC. ADD 5 reads 24 and gives ACC=42. Instruction addresses 0 and 1 differ from operand addresses 4 and 5.

  4. Write and finish

    STO 6 writes 42 into Memory[6]. END finishes before any data is fetched as an instruction. Memory[4]=18 and Memory[5]=24 are unchanged; ACC=42, IX=0.

  5. Change the program

    Replacing ADD 5 with SUB 5 makes the stored result −6 in a model that supports that signed value. The operation changes because the stored instruction changes, using the same CPU.

Core explanation · Exam essentials

  • A stored program computer fetches instructions from memory. In the Von Neumann model, instructions and data occupy the same IAS.
Common misconception

The stored program concept concerns instructions held in memory; it does not mean the whole program is held in the CPU's registers.

Check your understanding

Why is a single memory drawn for two different kinds of contents?

Check your answer

In this model, instruction words and data values occupy locations in the same addressable store.

02

ALU, CU, system clock and immediate access store

S4.03.A01

Visual overview

The ALU carries out arithmetic and logical operations. The CU decodes the instruction held in CIR and generates the signals needed to move values and carry out the selected operation. These are processing and coordination roles respectively.

The system clock generates regular pulses that synchronise processor operations. One instruction can require several cycles. The immediate access store (IAS) is the main memory holding instructions and data available to the processor during execution; it is not the same as long-term secondary storage.

To execute ADD 5 in the shared calculation, the CU must arrange for Memory[5] to be read and select addition in the ALU. The ALU combines the old ACC value 18 with the operand 24. The result 42 returns to ACC. Neither the clock nor the IAS decides which arithmetic operation to perform.

Transfers need coordination: the selected address must be available when the read is performed, and the operand must be available before the ALU uses it. Clock pulses provide timing events for those operations. There is no general rule that one pulse completes one instruction.

The IAS is the main working store available during execution. A saved program on an SSD must be made available in main memory for this model to execute it. Registers retain a small amount of current processor state; they do not replace the program’s memory store.

Worked example · Who does what in ADD 5?

  1. Given

    CIR holds ADD 5, ACC=18 and Memory[5]=24. This is the execution part only.

  2. Coordinate

    The CU requests the operand read and selects addition; clocked transfers deliver 24.

  3. Calculate and retain

    The ALU adds 18+24 and ACC receives 42. Memory[5] remains 24. A later STO is needed to change Memory[6].

Core explanation · Exam essentials

  • CU decodes and coordinates; ALU calculates; the clock synchronises operations; IAS supplies stored instructions and data.
Common misconception

Clock frequency counts cycles, not necessarily completed instructions.

Check your understanding

Does the IAS perform the addition?

Check your answer

No. It supplies stored items; the ALU performs the arithmetic.

General-purpose and special-purpose registers

Swipe horizontally to compare every column →

Registers are small, fast storage locations inside the processor. A general-purpose register can hold operands and intermediate results; a special-purpose register has a defined role. In CPU architecture, ACC has the designated accumulator role and appears with the special-purpose registers. In the syllabus's example assembly model, ACC is also the only register available for general data operations; IX supplies an index offset.

During instruction processing, several registers are needed at once: one identifies the next instruction, one retains the current instruction, and others support memory transfers. Status flags record conditions such as zero, carry, sign or overflow, depending on the processor; they are not the complete arithmetic answer.

Several pieces of state must coexist. While CIR retains ADD 5, MAR can hold the operand address 5 and MDR can hold the operand value 24. Keeping those jobs separate lets the CU continue to decode the instruction while memory supplies its data.

After the fetch of ADD 5 at address 1, PC is 2 in this one-location-per-instruction model. This does not say the processor is already executing address 2: CIR still contains ADD 5 until the next fetch. Once a branch executes, its target replaces the sequential next address.

Status flags are separate condition information, not a second copy of the answer. Real instruction sets define which operations update which flags. Later traces explicitly track the result of CMP/CMI; do not infer unspecified flag changes from the numerical sign of ACC.

Worked example · Three different numbers during ADD 5

  1. Given

    PC=1, ACC=18, IX=0; Memory[1] contains ADD 5 and Memory[5]=24. Initial MAR, MDR and CIR are irrelevant because fetch overwrites them; no prior flag is needed.

  2. Fetched instruction

    MAR=1, MDR carries ADD 5, CIR=ADD 5, PC=2.

  3. Operand and execution

    MAR becomes 5; MDR becomes 24. ACC becomes 42, while PC=2, IX=0 and CIR=ADD 5. Address 5, operand 24 and result 42 are distinct.

Core explanation · Exam essentials

  • PC: next instruction address; CIR: current instruction; MAR/MDR: selected address/transferred value; ACC: data/result; IX: index offset; SR: conditions.
Common misconception

PC contains an address, not the current instruction. IX supplies an offset; indexed loading obtains the contents at the resulting address.

Check your understanding

Which two registers distinguish the selected memory location from the value transferred?

Check your answer

MAR holds the selected address; MDR holds the transferred value.

Practice questions

Question 1 · Command word: Explain3 marks

Explain how one main memory containing both instructions and data supports the stored program concept. State how the same processor can carry out a different task.

S4.01.A01
Answer and marking points
  1. Instructions and the data they operate on are held in the same memory as binary patterns.
  2. The processor fetches the stored instructions and executes them.
  3. Loading a different program changes the sequence of operations without rewiring the processor.

Common error: A program is stored inside the system; it is not a sequence supplied manually for each operation.

Question 2 · Command word: Identify8 marks

Identify the register for each role: next instruction address; address of a current memory access; transferred memory value; instruction being decoded; arithmetic result; index offset; condition flags. Compare a general-purpose register with a special-purpose register.

S4.02.A01S4.02.A02S4.02.A03S4.02.A04S4.02.A05S4.02.A06S4.02.A07S4.02.A08
Answer and marking points
  1. Next instruction address: Program Counter (PC).
  2. Address of the current access: Memory Address Register (MAR).
  3. Transferred memory value: Memory Data Register (MDR).
  4. Instruction being decoded: Current Instruction Register (CIR).
  5. Arithmetic result: Accumulator (ACC).
  6. Index offset: Index Register (IX).
  7. Condition flags: Status Register (SR).
  8. A general-purpose register can hold operands or intermediate results; a special-purpose register has a designated control or storage role.

Common error: MAR holds an address; MDR holds the value read or written at that address.

Question 3 · Command word: Describe4 marks

Describe the roles of the ALU, CU, system clock and IAS when a stored program calculates a total.

S4.03.A01
Answer and marking points
  1. The ALU performs the required additions and any logical operations.
  2. The CU decodes each instruction and issues control signals to coordinate its execution.
  3. Clock pulses synchronise the processor's operations.
  4. The IAS holds the program instructions and data currently available for direct access by the processor.

Common error: The clock provides timing; it does not itself calculate the total.

Question 4 · Command word: Explain4 marks

Explain why PC=240 and CIR=LDD 600 can be correct at the same time. State which register will hold the loaded value and which register would supply an offset for indexed access.

S4.02.A02S4.02.A05S4.02.A06S4.02.A07
Answer and marking points
  1. The CIR retains the instruction currently being decoded or executed.
  2. The PC can already point to the next instruction at address 240.
  3. The value loaded by LDD will be placed in ACC.
  4. IX supplies the offset if an indexed instruction is used.

Common error: PC and CIR describe different stages; they need not contain related numeric values.

Question 5 · Command word: State4 marks

In the shared calculation, ADD 5 at address 1 has been fetched. ACC=18 and Memory[5]=24. State the values of PC, MAR, MDR and ACC after execution, and explain why PC is not the current instruction.

S4.02.A02S4.02.A03S4.02.A04S4.02.A05S4.02.A07S4.03.A01
Answer and marking points
  1. PC=2 and CIR still holds ADD 5 after execution.
  2. MAR=5 selects the operand location and MDR=24 holds its contents.
  3. ACC=42 after addition.
  4. PC holds the next instruction address; CIR retains the current instruction.

Common error: Do not substitute the operand address for its value.

Question 1 · Command word: Explain · 4 marks

Explain why a computer can run a newly installed payroll program using its existing processor and main memory. Refer to the stored program concept and the role of the IAS.

Answer and marking points
  • The payroll instructions are loaded into the immediate access store alongside the data needed for processing.
  • Both are represented in binary within the common memory system.
  • The existing processor fetches the new instruction sequence and performs the operations it specifies.
  • Changing this stored sequence changes the task without replacing the processor's physical logic.

Common error: Installing a program changes stored instructions, not the wiring of the ALU.

Question 2 · Command word: Explain · 4 marks

Explain why saving only ACC is insufficient when a processor suspends a program. Refer to PC, IX and the Status Register, giving the information each may need to preserve.

Answer and marking points
  • ACC preserves the current intermediate data result, but does not identify where execution should resume.
  • PC provides the return instruction address.
  • IX may hold the offset needed to continue accessing the same array element.
  • The Status Register contains condition flags that can affect subsequent conditional execution.

Common error: Different registers carry different parts of the program's execution state.

Question 3 · Command word: Describe · 5 marks

Describe how the CU, clock and ALU cooperate to execute an addition after its instruction has reached CIR. Explain why CIR and MDR still have separate roles.

Answer and marking points
  • The CU interprets the addition opcode held in CIR.
  • It issues control signals to select operands and request the ALU addition.
  • Clock pulses coordinate the timing of these internal operations.
  • The ALU produces the arithmetic result.
  • CIR retains the instruction while MDR can hold a separate operand transferred from memory.

Common error: The MDR need not retain the instruction throughout its execution.

Lesson review

Summary

Stored program

Instructions and data share main memory; the processor follows the stored instruction sequence.

Registers

Keep the next address, current instruction, memory-transfer address/value, results, index offset and flags distinct.

Coordination

The CU controls operations, the ALU calculates, and the clock synchronises their timing.
