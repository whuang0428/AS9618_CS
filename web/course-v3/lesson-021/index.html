4.1.2

What makes a program a stored program?

Where does each machine keep the program and its data?

QuestionOriginal ENIAC configurationBasic von Neumann model
Where is the procedure?Patch cables and switches set the sequence of operations.The instructions occupy addresses 0–3 in main memory. At address 1 the CPU finds ADD 5.
Where are the numbers?Electronic storage units hold the numbers used in the calculation.Addresses 4 and 5 in that same main memory hold 18 and 24. Address 6 is reserved for the result.
How would you change addition to subtraction?An operator changes the relevant connections and settings.Replace ADD 5 with SUB 5 at address 1 and run the program again. Both versions read the same data at addresses 4 and 5.

Instructions and data share one main memory

In the von Neumann model, the program’s machine instructions and the data they use share the same main memory. Each address here holds a binary word, shown as a mnemonic or a decimal number for readability. With ADD 5, the CPU calculates 18 + 24 = 42 and STO 6 writes 42 to address 6. Replace the instruction at address 1 with SUB 5 and restart at address 0. Address 5 still holds 24, so this time the CPU calculates 18 − 24 = −6 and stores −6 at address 6.

4.1.3

General-purpose and special-purpose registers

Register storage inside the CPU

A register is a small, fast storage location inside the processor. While adding two numbers, the CPU needs a working value as well as the address of the next instruction. Trace the two branches and compare how the register is used on the next operation.

Two uses of register storage

CompareGeneral-purpose registerSpecial-purpose register
Typical useHolds temporary data, an operand, an address or an intermediate result as the program requires.Has a defined role in the processor, such as tracking the next instruction or buffering a memory transfer.
Who chooses the role?An instruction or compiler can choose an available general register for the current task.The architecture assigns a meaning to the register. Instructions may use some special registers explicitly and others implicitly.
ExampleA register called R1 on a processor with a register bank could hold a running total, then later a loop count.The Program Counter holds the next instruction address. A branch changes this address so execution continues elsewhere.

4.1.4

Seven special-purpose registers

Register roles in the 9618 model

RegisterWhat it holdsWhen it is read or writtenPurpose
Program Counter (PC)Address of the next instruction to fetch.Read at fetch and advanced. A taken branch writes its target here.Selects the next instruction in the program.
Memory Data Register (MDR)An instruction or data word in transit.A memory read fills MDR. Before a memory write, the CPU loads MDR with the word to send.Buffers contents crossing between CPU and memory.
Memory Address Register (MAR)Address of the memory location being accessed.Loaded before a memory read or write. Its value is placed on the address bus.Selects the location, for example address 5 when reading an operand.
Accumulator (ACC)An operand or intermediate result in this accumulator-based processor.A load writes it. An addition reads its old value and writes the result.Keeps the running value: adding 24 to 18 leaves 42 in ACC.
Index Register (IX)An index or offset.A program sets IX. An indexed instruction reads it to calculate the effective address.Accesses an item relative to a base: base 40 plus IX of 2 selects location 42.
Current Instruction Register (CIR)The instruction being decoded and executed.Filled from MDR during fetch. The control unit then reads the opcode and operand.Keeps the current instruction available while MDR handles later transfers.
Status Register (SR)Condition flags, for example zero, negative, carry and overflow.Relevant operations update flags. Conditional control can read a flag before a branch.Records properties of a result, such as whether it is zero.

How processor components and system buses cooperate

Trace a read and a write

Clock and CUStep 0 / 4

A timing signal synchronises the CU. The instruction is already in CIR; each teaching step identifies a transfer, rather than an elapsed clock cycle.

The data bus reverses direction between read and write. The address bus carries a location number. READ and WRITE are command signals on the control bus.

Changing a setting restarts this experiment. Predict the change before stepping again.

Select Read and follow one transaction, then select Write. Track the address, control signal and data separately. Notice which direction changes when the processor stores its result.

What each component contributes

ComponentJobExample
Arithmetic and Logic Unit (ALU)Performs arithmetic, logic and comparisons.Adds two operands and supplies the result and relevant condition flags.
Control Unit (CU)Decodes instructions and coordinates components with control signals.Issues a memory read, then selects the arithmetic operation needed.
System clockProvides pulses that synchronise processor operations.Transfers and calculations are timed in clock cycles. Completing an instruction can take several cycles.
Immediate access store (IAS)Main memory directly accessible by the CPU. It holds instructions and data.Supplies an operand when the CPU reads the selected location and retains the new value after a write.

Track one memory transaction

BusRead from memoryWrite to memory
Address busCPU → memory. The address selects the location to read.CPU → memory. The address selects the destination.
Data busMemory → CPU. The selected instruction or data word returns to MDR.CPU → memory. The word in MDR travels to the selected location.
Control busThe CU asserts READ. Other control lines can carry signals such as a response towards the CPU.The CU asserts WRITE. Control lines identify and coordinate the operation.

1. State what each register holds

Cambridge 9618/12 · October/November 2024 · 3(a) · 4 marks

Selected parts: 3(a) [4].

Reading the question — teacher guidance

Describe the purpose of each named register. Distinguish an address, the contents at an address, and an offset.

Solution / model answer — teacher-written
RegisterPurpose
PCHolds the address of the next instruction to fetch.
MARHolds the address of the memory location being read or written.
MDRHolds the data/instruction read from the location addressed by MAR, or the data to write there.
IXHolds an offset added to an instruction’s operand to form the effective address in indexed addressing.
Official mark scheme
Why this earns marks — teacher explanation

One mark is awarded for each correct purpose. Describing a register only as “temporary storage” does not distinguish its role.

Common mistakes — teacher analysis

MAR holds an address; MDR holds the transferred contents. PC holds the next instruction’s address, not the instruction itself.

Original question · Cambridge 9618/13

3. Compare general-purpose and special-purpose registers

Cambridge 9618/13 · October/November 2023 · 9(a)(ii) · 2 marks

Selected parts: 9(a)(ii) [2].

Teacher solution and explanation

Give two paired differences. Compare the registers’ jobs in one sentence and how instructions use them in another.

A program can reuse a general-purpose register for different temporary values. Each special-purpose register has a designated job, such as holding the next instruction address. Many instructions can use a general-purpose register as an operand. Access to a special-purpose register is tied to particular instructions or processor operations.

One comparison concerns the assigned role and a second concerns which instructions can use the register. Each distinct comparison is worth one mark.

Giving PC and MAR as two examples illustrates two special roles. To earn both marks, compare the two register classes in two different ways.

Additional teacher-written practice
Question 1 · Command word: Explain3 teacher marks

Explain how one main memory containing both instructions and data supports the stored program concept. State how the same processor can carry out a different task.

S4.01.A01
Answer and checking points — teacher-written
  1. Instructions and the data they operate on are held in the same memory as binary patterns.
  2. The processor fetches the stored instructions and executes them.
  3. Loading a different program changes the sequence of operations without rewiring the processor.

Common error: A program is stored inside the system; it is not a sequence supplied manually for each operation.

Question 2 · Command word: Describe4 teacher marks

Describe the roles of the ALU, CU, system clock and IAS when a stored program calculates a total.

S4.03.A01
Answer and checking points — teacher-written
  1. The ALU performs the required additions and any logical operations.
  2. The CU decodes each instruction and issues control signals to coordinate its execution.
  3. Clock pulses synchronise the processor's operations.
  4. The IAS holds the program instructions and data currently available for direct access by the processor.

Common error: The clock provides timing; it does not itself calculate the total.

Question 3 · Command word: Explain4 teacher marks

Explain why PC=240 and CIR=LDD 600 can be correct at the same time. State which register will hold the loaded value and which register would supply an offset for indexed access.

S4.02.A02S4.02.A05S4.02.A06S4.02.A07
Answer and checking points — teacher-written
  1. The CIR retains the instruction currently being decoded or executed.
  2. The PC can already point to the next instruction at address 240.
  3. The value loaded by LDD will be placed in ACC.
  4. IX supplies the offset if an indexed instruction is used.

Common error: PC and CIR describe different stages; they need not contain related numeric values.
