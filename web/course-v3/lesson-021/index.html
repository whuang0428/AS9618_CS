Knowledge block 1 / 3

How can one processor run different programs?

THINK

A laptop runs a browser and then a game without rewiring its CPU. What changed?

LEARN

Load two instruction sequences into one addressable store. Select an instruction cell and a data cell to compare their roles.

APPLY

Immediate check

Memory[4] holds 18. Is 4 an instruction or the value being read?

Reveal answer

4 is the address; 18 is the stored data value.

Exam transfer · teacher-written

Question 1 · Command word: Explain3 teacher marks

Explain how one main memory containing both instructions and data supports the stored program concept. State how the same processor can carry out a different task.

S4.01.A01
Answer and checking points — teacher-written
  1. Instructions and the data they operate on are held in the same memory as binary patterns.
  2. The processor fetches the stored instructions and executes them.
  3. Loading a different program changes the sequence of operations without rewiring the processor.

Common error: A program is stored inside the system; it is not a sequence supplied manually for each operation.

DISTILL

Core idea
Instructions and data occupy the same addressable IAS in this model.
What you must be able to explain
Explain how changing stored instructions changes behaviour without changing the CPU.
Exam wording
The CPU fetches an instruction from memory, decodes it and may then read separate data.
Common trap
A data cell is not automatically executed as an instruction.
30-second recall
What stays fixed when a different program is loaded?
Knowledge block 2 / 3

Who does the work inside the CPU?

THINK

ACC is 18 and Memory[5] is 24. Which part identifies ADD, and which performs the addition?

LEARN

Step through CIR, CU, memory, ALU and ACC while the clock only coordinates timing.

APPLY

Immediate check

Does one clock pulse necessarily complete ADD?

Reveal answer

No. A single instruction may need multiple clocked operations.

Exam transfer · teacher-written

Question 2 · Command word: Describe4 teacher marks

Describe the roles of the ALU, CU, system clock and IAS when a stored program calculates a total.

S4.03.A01
Answer and checking points — teacher-written
  1. The ALU performs the required additions and any logical operations.
  2. The CU decodes each instruction and issues control signals to coordinate its execution.
  3. Clock pulses synchronise the processor's operations.
  4. The IAS holds the program instructions and data currently available for direct access by the processor.

Common error: The clock provides timing; it does not itself calculate the total.

DISTILL

Core idea
CU decodes and coordinates; ALU calculates; the clock synchronises; IAS supplies stored items.
What you must be able to explain
Explain each component’s role in an ADD instruction.
Exam wording
The ALU combines the ACC value and the fetched operand.
Common trap
The clock does not perform arithmetic.
30-second recall
Who computes 18 + 24?
Knowledge block 3 / 3

Why are several registers needed at once?

THINK

After LDD 600 is fetched, PC is 41 and CIR still holds LDD 600. How can both be correct?

LEARN

Advance one micro-operation at a time. Watch the next address, current instruction, selected address and transferred value separate.

APPLY

Immediate check

MAR is 600 and MDR is 27. Which holds the location?

Reveal answer

MAR holds address 600; MDR holds the value 27.

Exam transfer · teacher-written

Question 4 · Command word: Identify8 teacher marks

Identify the register for each role: next instruction address; address of a current memory access; transferred memory value; instruction being decoded; arithmetic result; index offset; condition flags. Compare a general-purpose register with a special-purpose register.

S4.02.A01S4.02.A02S4.02.A03S4.02.A04S4.02.A05S4.02.A06S4.02.A07S4.02.A08
Answer and checking points — teacher-written
  1. Next instruction address: Program Counter (PC).
  2. Address of the current access: Memory Address Register (MAR).
  3. Transferred memory value: Memory Data Register (MDR).
  4. Instruction being decoded: Current Instruction Register (CIR).
  5. Arithmetic result: Accumulator (ACC).
  6. Index offset: Index Register (IX).
  7. Condition flags: Status Register (SR).
  8. A general-purpose register can hold operands or intermediate results; a special-purpose register has a designated control or storage role.

Common error: MAR holds an address; MDR holds the value read or written at that address.

Official Cambridge question · Cambridge 9618/12 · October/November 2024 · 3(a) →

DISTILL

Core idea
PC, MAR, MDR, CIR, ACC, IX and status hold different parts of one running computation.
What you must be able to explain
Trace where an instruction address, current instruction and operand value live.
Exam wording
PC identifies the next fetch; CIR retains the current instruction.
Common trap
MAR is not the data value; MDR is not the address selector.
30-second recall
Why can PC and CIR differ?

Exam Challenge

Bring together the model and the written explanation. Attempt the task before revealing the teacher’s answer.

PC=40, Memory[40]=LDD 600, Memory[600]=27. Predict PC, CIR, MAR, MDR and ACC after the load. Explain which component decodes LDD.

Teacher-written model answer
  1. PC becomes 41; CIR retains LDD 600.
  2. After the data read MAR=600, MDR=27 and ACC=27.
  3. The CU decodes; it coordinates the transfer rather than calculating a result.

Original question · Cambridge 9618/12

1. State what each register holds

Cambridge 9618/12 · October/November 2024 · 3(a) · 4 marks

Selected parts: 3(a) [4].

Reading the question — teacher guidance

Describe the purpose of each named register. Distinguish an address, the contents at an address, and an offset.

Solution / model answer — teacher-written
RegisterPurpose
PCHolds the address of the next instruction to fetch.
MARHolds the address of the memory location being read or written.
MDRHolds the data/instruction read from the location addressed by MAR, or the data to write there.
IXHolds an offset added to an instruction’s operand to form the effective address in indexed addressing.
Official mark scheme
Why this earns marks — teacher explanation

One mark is awarded for each correct purpose. Describing a register only as “temporary storage” does not distinguish its role.

Common mistakes — teacher analysis

MAR holds an address; MDR holds the transferred contents. PC holds the next instruction’s address, not the instruction itself.
