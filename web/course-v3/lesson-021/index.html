Explanation · 1 / 4

Separate a location from its contents

Memory contains addressable locations. An address identifies one location, like the number on a box. The contents are the value currently stored inside it. Address 4 and the value 18 are different pieces of information.

Explanation · 2 / 4

Read a stored value

A read obtains a copy of the contents at a selected address. Reading location 4 supplies 18; it does not empty the location. We write Memory[4] = 18 to mean that location 4 contains 18. The brackets here identify the selected memory location.

Explanation · 3 / 4

Write a new value

A write replaces the contents at the selected address. After storing 42 at address 6, Memory[6] is 42 instead of 0. The address is still 6. Neither reading the inputs nor storing the result changes Memory[4] or Memory[5].

Explanation · 4 / 4

Connect this to earlier memory work

RAM is the working memory that can hold changing instructions and data while a program runs. A number saved in RAM is not automatically a persistent file: RAM normally loses its contents without power. Here we are following a calculation while the computer remains powered.

Explanation · 1 / 4

Give the processor a sequence

A program is a sequence of instructions. The processor, also called the central processing unit or CPU, fetches an instruction from memory and carries out its operation. LDD means load directly from a memory address, ADD adds a value, STO stores the result, and END finishes the program in this teaching instruction set.

Explanation · 2 / 4

Keep a temporary result

The accumulator, abbreviated ACC, is a small storage location inside our processor. LDD 4 copies 18 into ACC. ADD 5 adds Memory[5], which is 24, to the current ACC value. ACC therefore becomes 42. STO 6 copies that result into Memory[6].

Explanation · 3 / 4

Recognise the stored program concept

The instructions themselves are held in memory. Changing the stored instructions changes the work that the processor performs. In the basic Von Neumann model, instructions and data share one memory and the paths used to transfer them. Locations 0 to 6 in our example belong to that one store.

Explanation · 4 / 4

Read the model accurately

The screen shows readable instruction names so that we can follow the program. A real processor uses encoded machine instructions stored as bit patterns. Each instruction or data item occupies one location in this classroom model. The location numbers are addresses, not part of the instruction text.

Processor fundamentals · Concept 03

Separate calculation, control and storage

Observe

Start with a question

Which component adds 18 and 24, and which component tells it to do so?

The instruction ADD 5 is ready to be carried out. ACC holds 18, while memory location 5 holds 24. Follow the tasks needed to turn the instruction into the result 42.

Explain

Explanation · 1 / 5

Supply the instruction and data

The immediate access store, or IAS, is the main memory directly available to the processor during execution. It holds the program and its data. In our example it supplies ADD 5 and the stored value 24. It does not perform the addition.

Explanation · 2 / 5

Interpret and coordinate

The control unit, or CU, decodes the instruction: it identifies the operation and the information needed to perform it. It sends control signals so that the required values move to the right places and the selected operation takes place.

Explanation · 3 / 5

Calculate or make a logical operation

The arithmetic and logic unit, or ALU, performs arithmetic such as addition and subtraction, and logical operations such as AND. For this instruction it combines 18 with 24. The resulting 42 is kept in ACC, ready to be used or stored.

Explanation · 4 / 5

Keep the operations in time

The system clock generates regular pulses that synchronise processor operations. A clock cycle is one period of that clock. Carrying out one complete instruction may take several cycles, so a clock pulse does not mean that an entire instruction has finished.

Explanation · 5 / 5

Connect the parts

Registers are small, fast storage locations inside the CPU. Buses are groups of lines that transfer addresses, values and control signals between components. We will name the individual registers first, then follow those bus transfers.

PartJob during ADD 5
IASHolds the instruction and value 24
CUDecodes ADD and coordinates the work
ALUCalculates 18 + 24
ACCKeeps the result 42
ClockSynchronises operations

The CU coordinates the operand read and selects addition. The ALU performs that arithmetic. ACC receives the result.

Memory provides stored values and clock pulses synchronise transfers. Neither is the component that calculates the sum.

Question 1 · Command word: Describe4 teacher marks

Describe the roles of the ALU, CU, system clock and IAS when a stored program calculates a total.

S4.03.A01
Answer and checking points — teacher-written
  1. The ALU performs the required additions and any logical operations.
  2. The CU decodes each instruction and issues control signals to coordinate its execution.
  3. Clock pulses synchronise the processor's operations.
  4. The IAS holds the program instructions and data currently available for direct access by the processor.

Common error: The clock provides timing; it does not itself calculate the total.

Connect

Keep this idea

ALU: arithmetic and logic. CU: decode and control. Clock: synchronise. IAS: instructions and data.

Several values are needed at the same time. They must be kept in different registers.

Check a common misunderstanding

Do not equate one clock cycle with one completed instruction.

Processor fundamentals · Concept 04

Give each register a distinct job

Observe

Start with a question

Can the processor keep the next instruction address and its running total in the same place?

While ADD 5 is being carried out, the processor needs the current instruction, the address of the next instruction, the operand address 5, the value 24 and the running total. Match each item to a separate job.

Explain

Explanation · 1 / 5

Separate next from current

The Program Counter, PC, holds the address of the next instruction to be fetched. The Current Instruction Register, CIR, holds the instruction being decoded and executed. After fetching ADD 5 from address 1, PC is 2 in our one-location model, while CIR holds ADD 5. PC does not contain that instruction.

Explanation · 2 / 5

Separate the selected address from the transfer

The Memory Address Register, MAR, holds the address of the memory location being accessed. The Memory Data Register, MDR, holds the instruction or data being transferred to or from memory. To read the operand for ADD 5, MAR holds 5 and MDR receives 24.

Explanation · 3 / 5

Keep working data and an index

ACC holds an operand or the result of an arithmetic or logical operation. The Index Register, IX, holds an offset used in indexed addressing. An offset is a distance from a starting address: base address 100 plus IX = 2 selects address 102. The stored value at 102 is a separate item.

Explanation · 4 / 5

Keep condition information

The Status Register, SR, contains flags: bits that record conditions such as zero, sign, carry or overflow, depending on the processor. For example, a zero flag can indicate that an arithmetic result is zero. These flags are information about a result; they are not the complete numerical result.

Explanation · 5 / 5

Distinguish general and special purpose

A general-purpose register can hold data for a variety of operations. A special-purpose register has a defined role, such as PC selecting the next instruction. ACC has a designated accumulator role in this CPU description; the syllabus assembly model uses ACC for general data operations and IX for indexing. Always explain the role in the model being used.
