Implementing ADT operations with arrays

Track active positions and reusable storage as operations change an array-backed structure.

Which representation rules must remain true after an ADT operation?

Before you start

Does an old value left in an unused array cell still belong to an ADT?

Check your answer

No. Membership is determined by the active range, queue state or reachable link chain, not by old bytes alone.

Membership is part of the representation

An array-backed stack and queue can contain inactive cells whose old values are still visible in memory. For a stack with Top as the last occupied index, only positions 1 through Top are active. For a circular queue, Count active positions begin at Front and wrap through the array; Rear identifies the last one when Count is positive.

Check the operation before modifying state

Check representation state before adding, editing or deleting. A full structure cannot accept another item without a specified capacity change; an empty structure cannot supply an item. Value edits preserve membership and order, whereas push/pop or enqueue/dequeue change membership and must update the corresponding state variables.

Check data and control state together

Do not classify a cell as occupied merely because it contains old data. Conversely, storing a new value in an inactive cell does not complete an addition until the state variables or links make it active. The operation must leave one consistent representation, including on rejection.

Worked example · Check an edit against active membership

  1. Given

    Capacity 4. Three items A, B and C occupy slots 3, 4 and 1 in FIFO order; the next removal is at 3.

  2. Edit

    Changing the value at slot 4 to X preserves the active order A, X, C and all three state variables.

  3. Invalid position

    Slot 2 is inactive. Writing there alone does not enqueue an item because Rear and Count were not updated.

Core explanation · Exam essentials

  • Active membership is determined by Top, queue state or the reachable link chain.
  • Check empty, full and active-position conditions before reading or changing a structure.
Common misconception

Storing a value in a spare array cell is not a complete ADT addition; the representation must make that cell active.

Check your understanding

A stack has Top = 2. Does editing Stack[4] edit an existing stack item?

Check your answer

No. Position 4 is outside the active stack.

02

Track free nodes separately from the active list

S10.10.A03S10.10.A04

Visual overview

Track two disjoint chains

A fixed array implementation of a linked list needs a way to find unused nodes. One method links unused positions into a free list with its own Free head pointer. Active and free chains must not share nodes. A null Free pointer means the array has no available slot for another insertion.

Transfer a node without losing the rest

To allocate a node, take the position identified by Free and advance Free to that node's old free link before reusing the link for the active chain. To release a deleted node, remove it from the active chain first, link it to the current free head and make it the new Free head. This reuses storage without shifting surviving node data.

Allocate a free node

  1. Check capacity: Free = 0 means no slot can be allocated. Reject without changing either chain.
  2. Save the free head: Let the allocated slot be the old Free. Advance Free using its old Next link.
  3. Reuse its link: Now set the node’s active successor and connect it to the active list.

Release a deleted node

  1. Unlink: Remove it from the active chain, updating Head or a predecessor as required.
  2. Join the free chain: Point the removed node to the current Free head.
  3. Update Free: Make the removed slot the new free head. Its old data is no longer an active item.

Use a representation check

This free-list model accounts for every array slot exactly once: active or free. After each change, follow both chains to null. Neither should contain a cycle, a repeated node, or a node from the other chain. Free-list management is one chosen array implementation; AS study here is descriptive, not implementation pseudocode.

Worked example · Move a node between chains

  1. Allocate

    Save slot 1 from Free; advance Free from 1 to 3; set Next[1] to 4 and Next[2] to 1.

  2. Delete slot 4

    Set Next[1] to 0 so slot 4 is no longer active.

  3. Release

    Set Next[4] to the old Free value 3, then set Free to 4. The two chains remain disjoint.

Core explanation · Exam essentials

  • Keep active and free chains disjoint; preserve the old free link before reusing it.
  • Unlink before releasing; no free node means insertion is rejected without changing the active data.
Common misconception

Returning a node to the free list before unlinking it from the active list can make both lists use the same slot.

Check your understanding

Why must the old free link be saved before an allocated node's Next field is overwritten?

Check your answer

Otherwise the remaining free nodes may become unreachable, losing track of available capacity.

Practice questions

3 core tasks · 9 teacher marks · 14–19 minutes (teacher estimate). Explain your reasoning before checking the answer.

Question 1 · Command word: State3 teacher marks

A capacity-5 circular queue has Front = 4, Rear = 1 and Count = 3. State its active positions, the position used by the next enqueue and the full condition.

S10.10.A02S10.10.A04
Answer and checking points — teacher-written
  1. The active positions are 4, 5 and 1.
  2. The next enqueue uses position 2 and increases Count to 4.
  3. The queue is full only when Count = 5.

Common error: Rear < Front does not imply that the queue is empty.

Question 2 · Command word: State3 teacher marks

Initially the active chain is 2 → 4 → 0 and the free chain is 1 → 3 → 0. Allocate slot 1 after node 2, then delete node 4. State both final chains and explain why they must be disjoint.

S10.10.A03S10.10.A04
Answer and checking points — teacher-written
  1. The final active chain is 2 → 1 → 0.
  2. The final free chain is 4 → 3 → 0.
  3. Sharing a node would allow an insertion to overwrite an active item's storage.

Common error: Move a node out of its old chain before adding it to the other chain.

Question 3 · Command word: State3 teacher marks

After the lesson's four-slot free-list trace reaches active chain 2→1→4→3→0 and Free = 0, delete node 1, then reuse it as the new head. State both chains after each operation.

S10.10.A03S10.10.A04
Answer and checking points — teacher-written
  1. Delete: set Next[2] = 4; active is 2→4→3→0 and free is 1→0.
  2. Reuse: advance Free to 0, set Next[1] = 2 and Head = 1.
  3. Final active is 1→2→4→3→0; free is 0, with no shared nodes.

Common error: Change the predecessor before returning a node to free storage.

Question 1 · Command word: Describe3 teacher marks

A capacity-5 stack has Top = 3. Describe one pop followed by editing the new top; state which positions remain active.

S10.10.A01S10.10.A04
Answer and checking points — teacher-written
  1. Read Stack[3] and decrease Top to 2.
  2. Edit Stack[2] without changing Top.
  3. Only positions 1 and 2 remain active.

Official mark scheme
Why this earns marks — teacher explanation

The five marking groups are the start pointer, row 2, rows 3 and 4 together, row 5, and rows 7 and 8 together. The diagram’s outlined groups preserve these limits. The scheme accepts null as 0, ∅ or another out-of-bounds index.

Common mistakes — teacher analysis

Data and pointer values have different meanings. A pointer to the next array row is only correct when that row contains the next logical node.

Lesson review

Summary

Active state

Pointers and counts define which array cells belong to the structure; old cell contents do not.

Operation checks

Test full, empty and active-position conditions before changing data or representation state.

Free storage

Keep active and free linked-list chains disjoint when allocating or releasing a node.
