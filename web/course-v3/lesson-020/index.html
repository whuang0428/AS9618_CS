Hardware / 01

Translate a condition without changing its meaning

Look closely

A machine may start when either request is present, but only if there is no fault. What exactly must the circuit accept?

Let A = 1 mean a manual start request, B = 1 an automatic start request, and C = 1 a detected fault. Q = 1 means starting is permitted. Predict the outputs for ABC = 100, 110 and 111. Later, test your predictions in Explore.

Step 1 / 6

Define the active values

State the input meanings before translating the sentence. A and B are requests: 1 means present. C describes a fault: 1 means a fault is detected, so the safe condition is C = 0. The output Q is permission to start, not a claim that a motor has already moved.

Step 2 / 6

Translate the request condition

“Either request is present” includes the case where both requests are present. The condition is therefore A OR B. Give this intermediate signal the name X. XOR would reject A = B = 1 and would change the intended meaning.

Step 3 / 6

Require the absence of a fault

No fault is represented by NOT C. Give this signal the name Y. A request and the absence of a fault are both required, so Q = X AND Y. Substituting the definitions gives Q = (A OR B) AND (NOT C). The brackets make the two input conditions to the final AND clear.

Step 4 / 6

Build from the inner operations

Connect A and B to a two-input OR gate. Connect C to a NOT gate. Feed the OR output and NOT output into a two-input AND gate, then label the output Q. The whole circuit has three independent inputs, but each AND and OR gate still has only two inputs.

Step 5 / 6

Verify all eight combinations

List every input combination before calculating outputs. Find X and Y, then AND them to obtain Q. Trace row 110 carefully: either request is satisfied even when both requests are present, and there is no fault, so Q must be 1.

Step 6 / 6

Return to the original words

The permitted rows are 010, 100 and 110: at least one request is present and the fault input is 0. Every row with C = 1 is rejected. Compare these results with the original statement. Agreement between an expression and a circuit cannot rescue an incorrect translation of the starting words.

Explain it yourself · Teacher-written check

Why is Q = A OR (B AND NOT C) not an equivalent translation? Give one counterexample.

Check your reasoning

For ABC = 101, the incorrect expression gives 1 because A is 1, despite a detected fault. The required expression (A OR B) AND NOT C gives 0, because absence of a fault is required for either kind of request.

Hardware / 02

Name intermediate wires and follow their dependencies

Look closely

Which values must be known before the final gate can be evaluated?

Picture the same start-permission circuit: A and B enter OR, C enters NOT, and their results enter AND. Compare ABC = 110 with 111. Predict which intermediate signal changes and which stays the same, then check the actual connections in Explore later.

Step 1 / 5

Read the actual connections

Identify inputs A, B and C and output Q. Follow the wires to each gate rather than reading symbols simply from top to bottom. A wire branch carries the same signal along both branches. A crossing is a connection only when the diagram indicates a junction; repeated labels represent the same named input.

Step 2 / 5

Name the first results

Let X be the OR output, so X = A OR B. Let Y be the NOT output, so Y = NOT C. The final AND receives X and Y, giving Q = X AND Y. These named intermediate signals give each part of the calculation a clear place. In the starting scenario, X means a request is present and Y means no fault is detected.

Step 3 / 5

Substitute to make the full expression

Replace X and Y with their complete expressions: Q = (A OR B) AND (NOT C). Keep brackets so the scope of each operation is visible. For ABC = 110, X = 1 and Y = 1, so Q = 1. At 111, X stays 1 but Y becomes 0, making Q = 0.

Step 4 / 5

Complete the three-input table

Calculate the same intermediate columns for all eight input rows. The expression and circuit give Q = 1 for 010, 100 and 110. An output-0 row is just as useful when checking a safety condition: every fault row must block permission to start.

Step 5 / 5

Preserve an output inversion

If the final gate were NAND, its output would be NOT (X AND Y), which complements the entire final result. It would not be X AND (NOT Y). Keep the inversion circle attached to the operation it actually follows, especially when substituting intermediate expressions.

Explain it yourself · Teacher-written check

For this circuit, A = 1, B = 0 and C = 1. Why is Q = 0 even though the OR output is 1?

Check your reasoning

NOT C is 0 because a fault is detected. The final AND therefore receives X = 1 and Y = 0, so its output is 0. The request signal alone does not establish permission to start.

Hardware / 03

Build a rule from the accepted rows

Look closely

How can one AND term select exactly one row of a truth table?

Suppose a specification accepts exactly these input combinations: ABC = 010, 100 and 110. Describe each accepted case in words. Which conditions must hold together within one case, and how could the three accepted cases be combined?

Step 1 / 6

Read the required behaviour first

The table is the starting specification. Select the rows with Q = 1, but retain all the rejected rows for later checks. Here 010, 100 and 110 are accepted. Every input has a defined value in each row, so each accepted row can become one complete AND condition.

Step 2 / 6

Translate one accepted row

Row 010 requires A = 0, B = 1 and C = 0. Its term is T1 = ((NOT A) AND B) AND (NOT C). Use a plain variable for a source 1 and its NOT form for a source 0. AND the conditions because all three must hold at the same time to select this one row.

Step 3 / 6

Construct every accepted term

Row 100 gives T2 = (A AND (NOT B)) AND (NOT C). Row 110 gives T3 = (A AND B) AND (NOT C). Accept any of these complete conditions by writing Q = (T1 OR T2) OR T3. Omitting a term rejects one required case; changing a NOT can accidentally accept an unwanted case.

Step 4 / 6

Draw only the allowed gate types

Build each three-condition term with two cascaded two-input AND gates and the required NOT gates. Join T1 and T2 with a two-input OR, then OR that result with T3. Label repeated A, B and C connections as the same respective input signals. No three-input gate is needed.

Step 5 / 6

Verify accepted and rejected cases

Trace every row through the three term circuits and their final OR combination. Exactly one term accepts each required row here. The final output column must match the source table, including all five rejected rows. This establishes correctness without requiring algebraic simplification.

Recognise the shorter equivalent circuit

The accepted rows all require C = 0 and at least one of A and B to be 1. The shorter expression is Q = (A OR B) AND (NOT C), which is the circuit in the explorer. Explain it yourself · Teacher-written check

A student ORs only the terms for 010 and 100. Which required row exposes the missing term?

Check your reasoning

ABC = 110 must also give Q = 1. The two existing terms reject it because they each require one request input to be 0. The 110 term is needed unless a verified equivalent expression such as (A OR B) AND NOT C is used.

Official mark scheme
Why this earns marks — teacher explanation

6(a) groups XOR and the final AND with their connections for one mark, and NOT plus NOR with their connections for the other. In 6(b), the first four correct output rows earn one mark and the last four earn one mark. There is no separate official mark for each row.

Common mistakes — teacher analysis

NOR means NOT of the OR result, not NOT of one input. Completing only one row correctly in each group does not earn the group’s mark.
