Why is the line ‘source → switch → destination’ safer as three steps than as one diagonal drawn through a switch?

01

The topology is the link pattern

S2.04.A01S2.04.A02S2.04.A03S2.04.A04S2.05.A01

Visual overview

Count links first; trace the path second

Bus
  1. Sender places the signal on the shared backbone.
  2. The signal propagates along the common cable.
  3. The addressed host accepts it.
Star
  1. Source sends the frame on its own link to the switch.
  2. The switch reads the destination address.
  3. The switch forwards on the destination’s separate link.
Full mesh
  1. Source router reads the destination.
  2. Routing information selects a direct or indirect route.
  3. A different connected route may be selected after a link failure.
Hybrid: star + mesh
  1. A sends a frame to its local switch S1.
  2. S1 forwards to S2; if that link fails, the available alternative is S1 to S3 to S2.
  3. S2 forwards on its separate link to D.
Technical reading rule

The reviewed image establishes the link pattern. The numbered path is authoritative: count each physical segment and name every forwarding device.

Core explanation

Bus: one shared backbone

A bus connects devices to one shared backbone. A signal travels along the common medium and attached devices inspect it.

Star: separate links to a switch

A star gives each end device a separate link to one central switch. A frame travels from the source to the switch and then from the switch to the destination link.

Mesh: multiple interconnections

A mesh provides multiple interconnections. A full mesh connects every node pair directly; partial meshes retain several, but not all, possible links. Alternative connected routes may remain after one link fails.

Hybrid: combine patterns

A hybrid combines two or more topology patterns. In the example, end devices form stars around S1 and S2, while S1, S2 and S3 form a mesh. A frame is a unit of LAN data; switches forward it on selected links. Assume a loop-free forwarding path, with a spare path available after a failure.

Common misconception

Peer-to-peer is a role model, not a mesh topology.

A star does not contain one device-to-device cable running through the switch.

02

A good choice connects structure to consequence

S2.05.A02S2.05.A03

Visual overview

Core explanation

A star usually isolates one end-device cable failure, but the central switch is a single point of failure for that star.

A bus uses less cable but shares the backbone and traffic; a backbone break can divide or stop the network.

A mesh can offer alternative routes, but extra links and ports increase cost, installation and management.

A hybrid can match different areas, but its failure behaviour depends on the constituent topologies and the links joining them.

Common misconception

‘Mesh is best’ is not a justification; resilience must be weighed against link and management cost.

Answer and marking points
  1. Bus.
  2. Star.
  3. Full mesh.
  4. Hybrid combining star and mesh.

Common error: Identify link patterns, not client and server roles.

Command word: Describe5 marks

In the star + mesh diagram, describe the path of a frame from A to D using the S1–S2 link. That link then fails. Describe an alternative path and explain whether A becomes isolated. Assume the switches can activate the alternative forwarding path.

S2.04.A04S2.05.A01S2.05.A02
Answer and marking points
  1. A sends the frame on its link to S1.
  2. S1 forwards the frame over the S1–S2 link.
  3. S2 forwards the frame on its separate link to D.
  4. After the failure the available path is A → S1 → S3 → S2 → D.
  5. A is not isolated: its local link still works and the mesh provides another connected route.

Common error: Every hop must follow an actual link; the mesh cannot protect A from failure of its own A–S1 cable.

Command word: Suggest6 marks

Suggest a topology for a classroom where cable faults should normally affect only one workstation and new workstations must be easy to add. Include one drawback.

S2.04.A02S2.05.A02S2.05.A03
Answer and marking points
  1. Recommend star.
  2. Each workstation has a separate cable.
  3. One end-device cable failure normally isolates only that workstation.
  4. A new device can be connected to an available switch port.
  5. Frames are forwarded through the central switch.
  6. Central switch failure affects the star or extra switch/cabling costs are stated.

Common error: A named topology without consequences does not justify the choice.

Question 1 · Command word: Identify · 4 marks

Four routers must each have a direct link to every other router. Identify the topology, calculate the number of links, and explain one resilience benefit and one cost drawback.

Answer and marking points
  • The required topology is a full mesh.
  • Four routers require 4 x 3 / 2 = 6 pair-to-pair links.
  • If one link fails, traffic may use another connected route through the remaining links.
  • The extra cables, interfaces and routing configuration increase installation cost and management complexity.

Common error: Do not count each bidirectional link twice; one physical link connects each unordered pair of routers.

Question 2 · Command word: Compare · 4 marks

Compare the effects of a workstation-cable failure and a central-medium failure in bus and star networks.

Answer and marking points
  • A failed drop or workstation connection on a bus may isolate that device while the intact backbone can still carry other traffic.
  • A break in the shared bus backbone can divide the network or stop communication for multiple devices.
  • A failed end-device cable in a star normally isolates only the device on that separate link.
  • Failure of the central switch stops communication through that star even when the end-device cables remain intact.

Common error: Do not claim that every cable failure has the same effect; identify whether the failed component is local, shared or central.

Question 3 · Command word: Describe · 5 marks

A partial mesh has routers P, Q, R and T. Its only links are P–Q, Q–R, R–T and T–P. Describe a route from P to R after P–Q fails. A second failure then removes T–P. Explain whether P can still reach R and what this shows about mesh resilience.

Answer and marking points
  • After P–Q fails, P can send to T over P–T.
  • T can forward to R over T–R, completing the path P → T → R.
  • If T–P also fails, P has no remaining working link.
  • P cannot reach R even though the links Q–R and R–T still work.
  • Resilience depends on the remaining connected paths; a mesh does not survive every combination of failures.

Common error: Use only the four supplied links; there is no direct P–R link.
