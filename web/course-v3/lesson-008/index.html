Communicate data · Concept 13

Follow each physical link from sender to receiver

Observe

The same computers, different links

  • A, B and C can share a backbone cable.
  • They can each have a link to a central switch.
  • Additional links can connect pairs of nodes.

Look, then discuss

For each arrangement, which exact links carry a message from A to C?

Discuss the observation

A topology is the arrangement of connections. The drawing is evidence about which neighbouring nodes can exchange data directly, not a suggestion that a message may jump between any nearby symbols.

Explain

Explanation · 1 / 4

Share a backbone in a bus

In a bus topology, devices attach to a shared backbone. A transmission propagates along that shared medium and the addressed receiver accepts the relevant data. Terminators at its ends reduce signal reflections; they do not select a destination. Shared use requires rules for avoiding or handling competing transmissions.

Explanation · 2 / 4

Use the centre of a star

Each star host has a separate link to a central device. With a switch that knows the destination port, A sends to the switch, which forwards towards C: A → switch → C. These are two distinct physical links. Do not draw a direct A–C link that is absent from the network.

Explanation · 3 / 4

Distinguish full and partial mesh

A full mesh connects every pair of nodes directly. A partial mesh has only some pairwise links. Mesh connections can provide alternative routes, but using an alternative depends on a working forwarding arrangement; the drawing alone does not configure the equipment.

Explanation · 4 / 4

Combine patterns in a hybrid

A hybrid uses more than one arrangement, such as classroom stars connected through meshed links between buildings. Describe the local pattern and the connecting pattern separately. A hybrid label does not tell you which individual host has a spare connection.

Work together

Trace a star and count a full mesh

A, B, C and D each connect to switch S. Compare this with a full mesh among the four hosts.

Work together · 1 / 3

Trace the star

A sends over A–S. S checks the destination and forwards over S–C. The complete route is A → S → C, not A → B → C.

Work together · 2 / 3

List full-mesh links

AB, AC, AD, BC, BD and CD are the six distinct pairwise links.

Work together · 3 / 3

Check the count

Each of four nodes has three connections, giving twelve link ends. Each link has two ends, so 12 ÷ 2 = 6 links. More links need more interfaces, cabling and management.

State the actual path and count each physical link only once.

Experiment

Predict the A-to-C path before revealing it. Compare the star with the available mesh arrangement and name each consecutive link.

Find a path after a failure

Send data from A to C. Choose a topology and remove a link or the central switch.

Change conditions

Predict: Can A still reach C? Point to every working link on the path.

S means the central switch. Mesh nodes in this simplified network can forward data along alternative links. A physical route alone is not enough without forwarding support.

Check

Try it yourself · Teacher-written

In a switched star, explain how data travels from one host to another when the destination port is known. What additional property defines a full mesh?

Check your reasoning

The sending host transmits to the central switch. The switch examines the destination address and forwards through the port leading to the receiving host. A full mesh has a direct link between every pair of nodes; a star does not.

Original question · Cambridge 9618/13

1. Follow a packet through a star topology

Cambridge 9618/13 · May/June 2024 · 5(b) · 2 marks

Selected parts: 5(b) [2].

Hint — reading the question

Describe the path between two devices, rather than just drawing the shape of a star. The central device must do something with the destination address.

Reasoning and model answer — teacher-written

The sending device transmits the packet directly to the central switch. The switch checks the destination address and forwards the packet directly towards the intended receiving device.

Official mark scheme
Why this earns marks — teacher explanation

One mark covers sender-to-centre transmission; the other covers checking the destination and forwarding to the receiving device. The official answer allows a switch, router or central device. In a switched Ethernet LAN the switch uses the destination MAC address.

Common mistakes — teacher analysis

Do not describe a chain through every workstation: that is not the stated star path. A central hub and a switch do not make identical forwarding decisions.

Communicate data · Concept 14

Distinguish a failed host link from a failed centre

Observe

Two failures that sound similar

  • Case 1: the cable from laptop A to its switch fails.
  • Case 2: the central switch fails.
  • Case 3: one inter-building link fails but another route exists.

Look, then discuss

Does “there are spare links” prove that every device keeps communicating after any failure?

Discuss the observation

Resilience depends on the particular failure. A spare link between switches helps only if the sender can still reach its first switch.

Explain

Explanation · 1 / 4

Remove the specified component

Start with the actual network drawing. Cross out the failed cable or device and its unusable connections. Then trace from the sender using only the remaining links. Do not invent a new connection to make the route work.

Explanation · 2 / 4

Compare a bus and a star

A bus backbone is shared, so a break or faulty termination can disrupt the segment. In a star, one host-link failure normally isolates that host while other intact host links remain usable. Failure of the central device removes communication through that centre.

Explanation · 3 / 4

Evaluate an alternative route

A mesh may retain a route after a link fails. State which route remains and whether the network can activate it. Redundant links need suitable configuration so that they do not produce forwarding loops. Exact configuration methods are beyond this activity.

Explanation · 4 / 4

Make a justified design choice

Compare the required availability, number of links, installation cost, maintenance and traffic. A star can make individual host faults easy to isolate. A mesh adds alternative connections at greater cost. Choose the feature that solves the stated requirement and identify what it does not protect.

Work together

Keep a building link failure separate from a laptop failure

A connects only to S1. C connects only to S2. S1–S2, S1–S3 and S3–S2 are available, and suitable forwarding can activate the spare path.

Work together · 1 / 3

Use the normal route

A → S1 → S2 → C uses the direct S1–S2 connection.

Work together · 2 / 3

Remove S1–S2

The available spare route is A → S1 → S3 → S2 → C. It still needs A–S1 and S2–C.

Work together · 3 / 3

Instead remove A–S1

A has no remaining attachment, so the inter-switch links cannot restore its communication. A different protection would be needed for that fault.

Justify resilience against a named failure, not against the word “failure” in general.

Try it yourself · Teacher-written

A school wants other classroom computers to continue when one student’s cable breaks. Explain a suitable topology and one failure it still depends on.

Check your reasoning

A star with separate host cables isolates the broken host cable, so other hosts can continue through the working central switch. Those hosts still depend on the centre; failure of that switch prevents communication through it.

Original question · Cambridge 9618/13

1. Explain a mesh and compare it with a shared bus

Cambridge 9618/13 · May/June 2023 · 2(b)(i), 2(b)(ii) · 4 marks

Selected parts: 2(b)(i) [2]; 2(b)(ii) [2].

Hint — reading the question

First describe mesh connections and paths. Then give two distinct advantages over a shared bus. Keep the network in the university stem as the context.

Reasoning and model answer — teacher-written

In a mesh, devices have interconnections that provide multiple possible routes between devices. An intermediate device can relay a packet towards its destination. A full mesh connects every pair directly; a partial mesh need not.

A mesh with an alternative working path can continue communicating after one link fails. Dedicated point-to-point full-duplex links also avoid the shared-medium collisions of a traditional bus.

Official mark scheme
Why this earns marks — teacher explanation

2(b)(i) awards up to two marks for the stated mesh features. 2(b)(ii) awards up to two for accepted advantages, including an alternative route after a link fails and fewer collisions.

The official scheme also lists security-related alternatives. Separate physical paths are not encryption or a complete security policy; teach the mechanism and its conditions rather than promising security from a topology alone.

Common mistakes — teacher analysis

A mesh is not a single cable connecting all devices in a line. Redundancy helps only when a usable alternate path remains; do not promise that every failure leaves every mesh connected.

Question 2 · Command word: Describe5 teacher marks

In the star + mesh diagram, describe the path of a frame from A to D using the S1–S2 link. That link then fails. Describe an alternative path and explain whether A becomes isolated. Assume the switches can activate the alternative forwarding path.

S2.04.A04S2.05.A01S2.05.A02
Answer and checking points — teacher-written
  1. A sends the frame on its link to S1.
  2. S1 forwards the frame over the S1–S2 link.
  3. S2 forwards the frame on its separate link to D.
  4. After the failure the available path is A → S1 → S3 → S2 → D.
  5. A is not isolated: its local link still works and the mesh provides another connected route.

Common error: Every hop must follow an actual link; the mesh cannot protect A from failure of its own A–S1 cable.

Question 3 · Command word: Suggest6 teacher marks

Suggest a topology for a classroom where cable faults should normally affect only one workstation and new workstations must be easy to add. Include one drawback.

S2.04.A02S2.05.A02S2.05.A03
Answer and checking points — teacher-written
  1. Recommend star.
  2. Each workstation has a separate cable.
  3. One end-device cable failure normally isolates only that workstation.
  4. A new device can be connected to an available switch port.
  5. Frames are forwarded through the central switch.
  6. Central switch failure affects the star or extra switch/cabling costs are stated.

Common error: A named topology without consequences does not justify the choice.

Question 4 · Command word: Calculate4 teacher marks

Calculate the number of links in a four-node full mesh by naming each link for nodes A, B, C and D. State a route from A to B after direct link A–B fails, and explain why an alternate route still needs a forwarding assumption.

S2.04.A03S2.05.A01S2.05.A02
Answer and checking points — teacher-written
  1. The distinct links are AB, AC, AD, BC, BD and CD.
  2. There are six links; equivalently 4 × 3 / 2 = 6.
  3. A valid remaining route is A–C–B or A–D–B.
  4. The network must be configured to select and use the working alternate route; extra physical links alone do not prove recovery.

Common error: Count each undirected pair once and use only links that actually exist.
