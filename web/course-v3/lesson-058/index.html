Choose a type from the meaning of the value

Core explanation

INTEGER represents whole numbers; REAL can represent fractional values. CHAR holds one character, whereas STRING holds a sequence of zero or more characters. BOOLEAN has only TRUE and FALSE. DATE represents a valid calendar date. Select a type from the permitted values and required operations, rather than from how a value happens to look.

Cambridge pseudocode declares a variable with DECLARE Identifier : Type. A CHAR literal uses single quotes and a STRING literal uses double quotes. A date is normally written dd/mm/yyyy; state that it is a DATE and specify the format. An assignment stores a value in a declared variable and must be compatible with its type.

Worked example · Declare and assign a booking

  1. Declarations
    DECLARE Seats : INTEGER
DECLARE Fare : REAL
DECLARE Zone : CHAR
DECLARE Confirmed : BOOLEAN
  2. Assignments
    Seats <- 3
Fare <- 12.50
Zone <- 'C'
Confirmed <- TRUE
  3. Check

    Seats supports counting; Fare supports fractional currency; Zone contains exactly one character; Confirmed stores a logical state.

Common misconception

The appearance of digits does not make a value suitable for arithmetic: a code such as 0072 is normally text.

Check your understanding

Which type suits an empty message, and why?

Check your answer

STRING permits a sequence of zero characters; CHAR requires exactly one character.

Recognise ARRAY and FILE in pseudocode

S10.01.A06

File closureCLOSEFILE "Names.txt"Finish using that file

Swipe horizontally to compare every column →

Core explanation

An array groups elements of one specified type under a common identifier and selects elements by index. Its declaration gives the bounds and element type. An array is useful when a program needs a fixed set of indexed values during processing.

A file stores data for later use, beyond one execution of a program. The text-file commands in Cambridge pseudocode refer to a file by its name, such as OPENFILE "Names.txt" FOR READ. The quoted file name is a STRING literal identifying a file; it is not a declaration that makes the file's contents a STRING variable.

Common misconception

A filename and the file it identifies are different: the filename is text, while the file contains stored data.

Check your understanding

How many elements does ARRAY[1:5] contain?

Check your answer

Five elements, indexed 1, 2, 3, 4 and 5.

Cambridge command words

Practice questions

Question 1 · Command word: State2 marks

State suitable types for a number of pupils and a measured temperature of 18.6 °C. Justify each choice.

S10.01.A01S10.01.A02
Answer and marking points
  1. INTEGER suits a pupil count because only whole pupils are counted.
  2. REAL suits temperature because fractional degrees are permitted.

Common error: A sample whole-number temperature does not exclude later fractional readings.

Question 2 · Command word: Write2 marks

Write declarations and assignments for Grade containing the single letter A and AccountCode containing 0048.

S10.01.A03
Answer and marking points
  1. DECLARE Grade : CHAR followed by Grade <- 'A'.
  2. DECLARE AccountCode : STRING followed by AccountCode <- "0048".

Common error: Double quotes distinguish a string from a character literal.

Question 3 · Command word: State2 marks

State suitable types for IsOpen and an appointment date, and give one valid value for each. Use dd/mm/yyyy for the date.

S10.01.A04S10.01.A05
Answer and marking points
  1. IsOpen has type BOOLEAN and may contain TRUE.
  2. The appointment has type DATE, for example 09/04/2027 in dd/mm/yyyy format.

Common error: A BOOLEAN is not the text string "TRUE".

Question 4 · Command word: Describe2 marks

Describe what DECLARE Prices : ARRAY[1:8] OF REAL creates and why a shop might also use a file.

S10.01.A06
Answer and marking points
  1. Prices groups eight REAL elements accessed with indices 1 through 8.
  2. A file retains the prices so another execution can load them.

Common error: An array declaration alone does not save data to secondary storage.

Question 1 · Command word: State · 4 marks

A weather station stores SamplesTaken, Rainfall in millimetres and AlarmRaised. State a suitable type for each and justify the type chosen for Rainfall.

Answer and marking points
  • SamplesTaken: INTEGER.
  • Rainfall: REAL.
  • AlarmRaised: BOOLEAN.
  • Rainfall may contain a fractional number of millimetres.

Common error: Select types for the permitted data, not just one example reading.

Question 2 · Command word: Write · 4 marks

A library stores a shelf letter, an ISBN that may contain leading zeros, and a return date. Write a declaration for each and explain why the ISBN should not be INTEGER.

Answer and marking points
  • DECLARE Shelf : CHAR.
  • DECLARE ISBN : STRING.
  • DECLARE ReturnDate : DATE.
  • The ISBN is an identifier whose leading zeros must be preserved; arithmetic is not required.

Common error: A calendar date needs DATE even if it is displayed using digits.

Question 3 · Command word: Describe · 3 marks

A logger uses DECLARE Reading : ARRAY[0:9] OF REAL and opens "Log.txt" FOR APPEND. Describe the role of the array, the role of the file, and the type of the literal "Log.txt".

Answer and marking points
  • Reading holds ten REAL values indexed 0 to 9 while the program processes them.
  • The file retains logged values after the program terminates.
  • "Log.txt" is a STRING literal naming the file.

Common error: Do not confuse a filename with an array of file contents.

Lesson review

Summary

Value types

Choose types from permitted values and operations: counts, measurements, characters, text, logical states and dates.

Declarations

Declare an identifier before using it and assign a value compatible with its type.

Collections and storage

Arrays provide indexed elements; files retain data for later executions.
