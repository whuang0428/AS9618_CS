Logic statements and boundary conditions

Translate conditions with relational operators, AND, OR and NOT, then test their truth values.

Which exact input combinations should make this part of the algorithm true?

Before you start

For a permitted range from 10 to 20 inclusive, does Value >= 10 OR Value <= 20 exclude anything?

Check your answer

No. Every number satisfies at least one of those comparisons. Both bounds must hold, so the range uses AND.

Core explanation

Translate the exact comparison

A relational expression compares values and produces TRUE or FALSE. Use = for equal, <> for not equal, < and > for strict bounds, and <= or >= when the boundary is included. Read words such as at least, at most, below and above before selecting an operator.

Test the boundary and its neighbours

Logical conditions define where an algorithm takes an action or accepts a value. Test the value at the boundary and nearby values on either side. For an integer age requirement of at least 18, 17 must fail while 18 and 19 must pass.

Common misconception

Equality at one value is not a substitute for an inclusive lower bound.

Check your understanding

What expresses a quantity greater than five?

Check your answer

Quantity > 5; Quantity >= 5 would also admit five.

02

Combine whole conditions

S9.09.A01

Visual overview

Core explanation

Combine complete Boolean conditions
  • AND: Both operands must be true.
  • OR: Either or both operands can be true.
  • NOT: Reverses the Boolean value.
Translate the requirement precisely

Use parentheses to show grouping. Adulthood with no suspension is (Age >= 18) AND NOT Suspended. A child-or-member discount is (Age < 12) OR Member. The requirement decides the connector; replacing AND with OR changes who qualifies.

Worked example · Implement a combined eligibility rule

  1. Requirements

    Input a non-negative integer Age and a Boolean Suspended. Output whether the person is at least 18 and not suspended.

  2. Pseudocode
    DECLARE Age : INTEGER
DECLARE Suspended : BOOLEAN
DECLARE Eligible : BOOLEAN
INPUT Age
INPUT Suspended
Eligible <- (Age >= 18) AND NOT Suspended
OUTPUT Eligible
  3. Check

    (18, FALSE) gives TRUE; (17, FALSE) and (19, TRUE) give FALSE.

Common misconception

Write both comparisons in a range: Temperature >= -20 AND <= 50 omits the second operand's identifier.

Check your understanding

If both operands are true, is OR false?

Check your answer

No. OR is inclusive here and is true when both are true.

Core explanation

Relate valid and invalid range conditions

An inclusive range needs the lower and upper comparisons joined by AND. Values outside that range satisfy a below-lower or above-upper test joined by OR. Negating the entire valid-range expression gives the same invalid-range condition.

Exercise values on both sides of a limit

Use a table of chosen inputs and expected truth values before putting a condition into a larger algorithm. Include both endpoints, one value outside each endpoint and an internal value. For compound eligibility rules, also vary each Boolean input so a missing NOT or wrong connector cannot hide behind one successful example.

Worked example · Express a permitted interval

  1. Requirements

    Read an integer Temperature and output whether it lies from -20 to 50 inclusive.

  2. Pseudocode
    DECLARE Temperature : INTEGER
DECLARE Valid : BOOLEAN
INPUT Temperature
Valid <- (Temperature >= -20) AND (Temperature <= 50)
OUTPUT Valid
  3. Check

    The endpoint values -20 and 50 are accepted; -21 and 51 are rejected.

Common misconception

Do not test only an interior value; incorrect strict operators often agree there and fail at the endpoints.

Check your understanding

Write the condition for a temperature outside this permitted interval.

Check your answer

(Temperature < -20) OR (Temperature > 50).

Practice questions

3 core tasks · 6 teacher marks · 11–15 minutes (teacher estimate). Explain your reasoning before checking the answer.

Question 1 · Command word: Write2 teacher marks

Write a logic expression that is true when Mark is between 0 and 100 inclusive. State its values for -1, 0, 100 and 101.

S9.09.A01
Answer and checking points — teacher-written
  1. (Mark >= 0) AND (Mark <= 100) requires both inclusive bounds.
  2. The four truth values are FALSE, TRUE, TRUE and FALSE.

Common error: OR would admit out-of-range values.

Question 2 · Command word: Write2 teacher marks

Write a condition for a discount given to anyone under 12 or anyone with Member TRUE. Complete the result column for the supplied cases.

Answer and checking points — teacher-written

One valid pseudocode solution

DECLARE Age : INTEGER
DECLARE Member : BOOLEAN
DECLARE Discount : BOOLEAN
INPUT Age
INPUT Member
Discount <- (Age < 12) OR Member
OUTPUT Discount
  1. (Age < 12) OR Member expresses the rule.
  2. The rows (11, FALSE), (12, FALSE) and (30, TRUE) give TRUE, FALSE and TRUE.

Common error: Membership qualifies regardless of age in this rule.

Question 3 · Command word: Write2 teacher marks

Write a condition for login when PasswordCorrect is TRUE and Locked is FALSE. Explain why replacing AND with OR changes the rule.

S9.09.A01
Answer and checking points — teacher-written
  1. PasswordCorrect AND NOT Locked requires the correct password and an unlocked account.
  2. Using OR would allow an unlocked account even when the password is wrong, or a locked account with a correct password.

Common error: NOT must apply to Locked, not PasswordCorrect.

Original question · Cambridge 9618/21

1. Diagnose a bonus flowchart

Cambridge 9618/21 · May/June 2025 · 2(a)(i), 2(a)(ii) · 2 marks

Selected parts: 2(a)(i) [1]; 2(a)(ii) [1].

Reading the question — teacher guidance

Trace a value from the failing range through the actual arrows. Then change the decisions while preserving the pay bands in the table.

Solution / model answer — teacher-written

2(a)(i): For a value from 2000 to 4000, the first test ValueOfSales > 4000 is false, so the path bypasses the second decision and returns the initial bonus of 0.

2(a)(ii): Swap the two decision tests. First test ValueOfSales >= 2000; on its YES path test ValueOfSales > 4000. This gives 0 below 2000, 10 from 2000 through 4000, and 100 above 4000.

Official mark scheme
Why this earns marks — teacher explanation

Each subpart has one mark. The scheme accepts identifying the wrong first decision for (i) and swapping the two decision boxes or specifying both corrected tests for (ii).

Common mistakes — teacher analysis

Changing > 4000 to >= 4000 alone does not repair the middle band. Check 1999, 2000, 4000 and 4001 after the change.

Lesson review

Summary

Read the boundary

Use strict or inclusive comparisons according to the stated words.

Combine deliberately

AND requires every condition; OR allows alternatives; NOT reverses truth.

Challenge the rule

Test endpoints, outside values and relevant Boolean combinations.
