01

Logic statements

S9.09.A01

A logic statement defines a Boolean decision, repetition condition or assignment. Cambridge pseudocode comparisons include =, <>, <, <=, > and >=; compound conditions use AND, OR and NOT.

Translate each requirement into a comparison first, then combine the comparisons. Use parentheses when grouping could be unclear, and test values that make each component true and false before trusting the complete condition.

Mechanism in examinable order

  1. Write each atomic comparisonTurn each condition into an explicit comparison using the correct relational operator.
  2. Join conditions with Boolean operatorsUse AND when every condition is required, OR when either is sufficient and NOT to invert a Boolean result.
  3. Check decisive truth casesChoose values that isolate each part and verify that the full statement has the required truth value.

Worked example · Construct and test an eligibility condition

  1. Requirement

    A user is eligible when Age is at least 18 and the account is not suspended.

  2. Logic statement

    Eligible <- (Age >= 18) AND NOT Suspended

  3. True case

    Age = 18 and Suspended = FALSE makes both required parts true, so Eligible becomes TRUE.

  4. False cases

    Age = 17 fails the age comparison; Suspended = TRUE is inverted to FALSE. Either case makes the AND result FALSE.

Common misconception

A compound logic statement must use the stated comparison and Boolean operators with correct grouping; AND and OR cannot be swapped without changing the truth conditions.

Practice

Retrieve, apply, then answer like an exam

Retrieval5 marks

Write and explain a logic statement that accepts an integer Temperature from -20 to 50 inclusive, then state its value for -21, -20, 50 and 51.

S9.09.A01
Answer and marking points
  1. uses Temperature >= -20
  2. uses AND Temperature <= 50
  3. states FALSE for -21
  4. states TRUE for -20 and 50
  5. states FALSE for 51

Common error: For the command word write, perform that exact action; do not replace it with an unrelated fact.
