Practice

Retrieve, apply, then answer like an exam

Retrieval5 marks

Describe one verification method used during data entry and two methods used during data transfer.

Answer and marking points
  1. visual check against source or double entry with comparison
  2. byte parity uses an agreed odd/even parity bit and checks it at the receiver
  3. block parity checks rows and columns / can locate many single-bit errors
  4. checksum is recalculated from received block and compared
  5. methods detect many errors but do not prove truth or automatically correct every error

Common error: For the command word describe, perform that exact action; do not replace it with an unrelated fact.

Application3 marks

Explain one common error from Section 8: Databases, and give the corrected reasoning.

Answer and marking points
  1. Each named item remains core.

Common error: Do not repeat the same point in different words; each mark needs a separate idea or method step.

Compare two closely related ideas from Section 3: Hardware.

  1. Use the standard symbols and define the functions of NOT, AND, OR, NAND, NOR and XOR (EOR)
  2. all gates except NOT have two inputs
  3. Construct circuits, truth tables and expressions from each of the other stated representations: problem statement, logic expression, logic circuit and truth table.
