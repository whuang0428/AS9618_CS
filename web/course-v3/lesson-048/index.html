Before you start

An 8-bit unsigned calculation gives 1 00000000. A student stores 00000000 and says that a matching checksum proves the result correct. Identify both mistakes.

Check your answer

The true result 256 exceeds the unsigned byte range, so the stored byte has overflowed. A matching checksum means no error was detected by that check; it cannot prove the calculation or source data correct.

Command word: Describe5 marks

Describe one verification method used during data entry and two methods used during data transfer.

Answer and marking points
  1. visual check against source or double entry with comparison.
  2. byte parity uses an agreed odd/even parity bit and checks it at the receiver.
  3. block parity checks rows and columns / can locate many single-bit errors.
  4. checksum is recalculated from received block and compared.
  5. methods detect many errors but do not prove truth or automatically correct every error.

Common error: For the command word describe, perform that exact action; do not replace it with an unrelated fact.

Command word: Calculate4 marks

Calculate the unsigned binary value 10110110 to hexadecimal and denary, showing both methods.

Answer and marking points
  1. Split 10110110 into the nibbles 1011 and 0110.
  2. The nibbles map to hexadecimal B and 6, so the hexadecimal value is B6.
  3. For denary, add the place values of the 1 bits: 128 + 32 + 16 + 4 + 2.
  4. The denary value is 182.

Common error: Do not copy the worked example unchanged; transfer the method and check it against the new context.

Command word: Calculate6 marks

Interpret the unchanged pattern 11110101 in denary as unsigned, one’s complement and two’s complement. Then calculate 01111110 + 00000010 at eight bits and explain the overflow decision for unsigned and two’s-complement interpretations.

S1.03.RS1.02.RS1.04.RS1.05.R
Answer and marking points
  1. Unsigned: 245.
  2. One’s complement: invert to 00001010, giving −10.
  3. Two’s complement: −128 + 64 + 32 + 16 + 4 + 1 = −11.
  4. The retained sum is 10000000.
  5. Unsigned 128 fits 0–255, so no overflow occurs.
  6. Signed +128 exceeds +127; the retained pattern means −128, so signed overflow occurs.

Common error: State the interpretation each time; carry out is not a universal overflow test.

Command word: Calculate6 marks

Calculate raw data bytes for a 48 × 20 bitmap at 4 bits per pixel, and a 3-second mono recording at 6000 Hz and 8 bits per sample. Exclude headers. A vector line joins (2,3) to (6,3), thickness 1: state its properties after scaling everything by 3. Explain whether RLE helps the bitmap row 000000111111000000 when each run uses an 8-bit count and 1-bit value.

S1.01.RS1.08.RS1.09.RS1.10.RS1.11.R
Answer and marking points
  1. Bitmap: 48 × 20 × 4 / 8 = 480 bytes.
  2. Sound: 3 × 6000 × 8 × 1 / 8 = 18,000 bytes.
  3. The line joins (6,9) to (18,9).
  4. Its thickness becomes 3 under the stated scaling rule.
  5. The row has three runs: (6,0), (6,1), (6,0).
  6. The original 18 bits becomes 3 × (8 + 1) = 27 bits; RLE increases its size by 9 bits.

Common error: State the field costs before claiming that a repeated pattern compresses well.

Command word: Explain8 marks

Explain a design for a museum with two distant sites and 30 terminals using central accounts. Staff must edit exhibit images during internet outages. Identify LAN/WAN scope, a service model and a client type; explain why cloud-only storage would need an offline-work arrangement. Two buildings at one site are 500 m apart across electrically noisy workshops, and each room uses a star. Recommend a link medium and distinguish one host-cable failure from central-switch failure.

S2.01.RS2.02.RS2.03.RS2.04.RS2.05.RS2.06.RS2.07.RS2.08.R
Answer and marking points
  1. Each managed site has a LAN; the link joining the distant sites is part of a WAN.
  2. Client-server supports the shared centrally managed accounts.
  3. Thick clients can perform the image processing locally.
  4. Offline editing requires the application, authorised working data and required access to be available locally.
  5. Cloud-only access depends on the connection, so prepared local copies/offline records and later reconciliation are needed.
  6. Fibre is suitable for the 500 m factory link because it supports the distance and its light carrier is unaffected by electromagnetic interference.
  7. One failed host cable isolates that host while the other star links can continue.
  8. Failure of the central switch prevents communication through that star for its attached hosts.

Common error: Scope, service roles and processing location are independent design decisions.

Command word: Describe5 marks

Describe a local request from a wireless laptop to a server: the laptop is reached via WAP on switch p1 and the server via p3; all needed addresses and ports are known. Then consider a separate shared half-duplex Ethernet segment: two stations collide, wait randomly and one finds the medium busy at retry time. Explain its next action and why the collision was possible.

S2.09.RS2.10.RS2.11.R
Answer and marking points
  1. The request travels WNIC → WAP → switch p1 → p3 → server using the server’s local destination MAC.
  2. The response travels server → p3 → p1 → WAP → laptop, without a router for this local exchange.
  3. Propagation delay can let both half-duplex stations sense idle before the other signal reaches them.
  4. Collision detection causes the attempted frames to stop and jam before random backoff.
  5. At retry time the station senses busy and defers; it must not transmit merely because its timer ended.

Common error: The shared-medium collision scenario is separate from switched full-duplex communication.

Command word: Calculate5 marks

Calculate a live-stream buffer trace with capacity 40 Mbit, initial reserve 12 Mbit and playback already running at 6 Mbit/s. Arrival is 8 Mbit/s for 4 s and then 4 Mbit/s. State the reserve after 4 s and total time from the start until it empties if the lower rate continues. Explain one response to that sustained deficit.

S2.12.R
Answer and marking points
  1. First gain is (8 − 6) × 4 = 8 Mbit.
  2. After 4 s the reserve is 12 + 8 = 20 Mbit.
  3. The later deficit is 6 − 4 = 2 Mbit/s, so the 20 Mbit lasts 10 more seconds.
  4. The buffer empties at total time 14 s.
  5. Pause/rebuffer or choose a suitable lower-rate stream; capacity alone cannot sustain an indefinite deficit.

Common error: State total elapsed time rather than only the duration of the second interval.

Command word: Explain8 marks

Explain retrieval of https://archive.example.org/exhibits/map.html by host 192.168.20.150/26 with gateway 192.168.20.129. Assume no cached DNS entry, successful services and routing, and an appropriate NAT arrangement for internet access. In this hypothetical network DNS returns documentation address 203.0.113.60. State the source subnet and next hop, then trace name resolution, resource request and returned content. Distinguish the returned WWW resource from the internet infrastructure. If a phone retrieves it over cellular access instead, describe the phone’s access path.

S2.13.RS2.14.RS2.15.RS2.16.R
Answer and marking points
  1. The source subnet is 192.168.20.128/26, using mask 255.255.255.192.
  2. DNS is asked for archive.example.org and returns the hypothetical address 203.0.113.60.
  3. That destination is outside the local subnet, so traffic goes via gateway 192.168.20.129.
  4. The packet targets the remote server while its immediate LAN recipient is the gateway; the stated NAT arrangement supports this public-side exchange.
  5. The browser contacts the web service and requests /exhibits/map.html.
  6. The server returns the resource through the network for the browser to display; DNS does not send the page.
  7. The page is a WWW resource carried using the internet, not the internet infrastructure itself.
  8. The phone sends by radio to a serving base station, then through the operator network for onward internet access.

Common error: A correct DNS response locates the server; the subsequent web exchange obtains the resource.

Command word: Explain5 marks

Explain two faults in a museum recording kiosk: the moving-coil microphone’s diaphragm cannot move, and the laser printer produces the correct label pattern but the toner rubs off. Identify the failed conversion or stage in each and explain why a functioning ADC or laser respectively does not resolve it.

S3.03.R
Answer and marking points
  1. The microphone needs sound-driven diaphragm and coil motion to induce the analogue signal.
  2. An immobilised diaphragm prevents normal acoustic-to-electrical conversion before the ADC.
  3. A working ADC cannot recreate the voice signal that the transducer did not supply.
  4. The printer’s faulty stage is fusing by heat and pressure.
  5. The laser forms the drum’s electrostatic image; it does not permanently fix transferred toner on the paper.

Common error: Locate the failed physical stage before changing a later or unrelated stage.

Explain why an embedded environmental recorder uses RAM for changing readings, persistent firmware storage and separate saved files. Its firmware must be rewritten electrically while installed. A capacity-three buffer starts with R1–R3 while R4 waits at the paused sender; one block is removed and then R4 is accepted. State the new buffer contents and what survives shutdown after a completed file save.

S3.01.RS3.02.RS3.04.RS3.05.RS3.07.R
Answer and marking points
  1. RAM supplies read/write working data; persistent firmware provides the recorder’s dedicated instructions after restart.
  2. EEPROM meets the stated electrical firmware-update requirement; PROM cannot be repeatedly reprogrammed and EPROM needs UV erasure.
  3. A buffer is temporary transfer storage and does not increase the receiver’s sustained speed.
  4. Removing R1 and accepting R4 leaves R2, R3, R4.
  5. Ordinary RAM loses unsaved working values, while the completed non-volatile saved file and firmware remain.

Common error: Keep the stored role, update technology and temporary waiting state distinct.

Command word: Explain5 marks

Explain why a pressure-controlled pump can keep running past the actual target if its sensor is stuck low. Compare this with an accurate sensor reporting no pressure rise because the motor is faulty, and state why a pressure display alone is monitoring.

S3.08.RS3.09.R
Answer and marking points
  1. The controller compares the measured pressure, not an independently known actual value, with the target.
  2. A stuck-low reading can keep commanding pumping after actual pressure is high.
  3. An accurate unchanged reading with a faulty motor is feedback that the commanded action did not achieve the intended pressure change.
  4. Feedback supplies evidence but does not by itself repair the failed component.
  5. A pressure display reports a condition; without corrective action it does not regulate the pressure.

Common error: Separate measurement accuracy from actuator effectiveness.

Question 1 · Command word: Explain · 4 marks

The 8-bit unsigned binary value 10110110 is stored in a register. Explain how to convert it to hexadecimal and denary.

Marking points

  • split the binary value into the nibbles 1011 and 0110.
  • 1011 represents hexadecimal B and 0110 represents hexadecimal 6.
  • the hexadecimal value is B6.
  • adding the binary place values 128 + 32 + 16 + 4 + 2 gives denary 182.

Question 2 · Command word: Describe · 5 marks

An alarm uses the logic expression Q = (Door AND NOT Key) OR Smoke. Describe how to construct a complete truth table for this expression.

Marking points

  • create input columns for Door, Key and Smoke and list all eight input combinations.
  • add an intermediate column for NOT Key by inverting each Key value.
  • add a column for Door AND NOT Key that is 1 only when both inputs to the AND gate are 1.
  • OR that intermediate result with Smoke to obtain Q.
  • Q is 1 whenever Smoke is 1 or Door is 1 while Key is 0.

Question 3 · Command word: Explain · 5 marks

A customer account number is entered twice and a data block is then sent with a checksum. Explain how these two verification methods detect errors and give one limitation of each.

Marking points

  • double entry compares two independently entered account numbers and flags a mismatch.
  • matching entries can still both be wrong, so double entry does not prove that the value is true.
  • the sender calculates a checksum from the data block and sends it with the data.
  • the receiver recalculates the checksum and compares it with the received checksum.
  • a matching checksum does not guarantee error-free data because some different error patterns can produce the same checksum.
