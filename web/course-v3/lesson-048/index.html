Start with the information and business rules: identify entities, choose candidate and primary keys, then show relationship cardinalities. Diagnose repeated data and dependency problems before decomposing tables into 3NF. Retain foreign keys that allow the original facts to be reconstructed.

Connect the design to its DBMS implementation. The dictionary describes fields and constraints; access rights and recovery procedures protect use and availability. Command word: Describe5 marks

Describe one verification method used during data entry and two methods used during data transfer.

Answer and marking points
  1. visual check against source or double entry with comparison.
  2. byte parity uses an agreed odd/even parity bit and checks it at the receiver.
  3. block parity checks rows and columns / can locate many single-bit errors.
  4. checksum is recalculated from received block and compared.
  5. methods detect many errors but do not prove truth or automatically correct every error.

Common error: For the command word describe, perform that exact action; do not replace it with an unrelated fact.

Command word: Compare4 marks

Compare AND and OR gates, including their output conditions and the result for the input pair 1, 0.

Answer and marking points
  1. An AND gate outputs 1 only when both inputs are 1.
  2. An OR gate outputs 1 when at least one input is 1.
  3. For inputs 1 and 0, AND outputs 0.
  4. For inputs 1 and 0, OR outputs 1.

Common error: Do not copy the worked example unchanged; transfer the method and check it against the new context.

Command word: Calculate4 marks

Calculate the unsigned binary value 10110110 to hexadecimal and denary, showing both methods.

Answer and marking points
  1. Split 10110110 into the nibbles 1011 and 0110.
  2. The nibbles map to hexadecimal B and 6, so the hexadecimal value is B6.
  3. For denary, add the place values of the 1 bits: 128 + 32 + 16 + 4 + 2.
  4. The denary value is 182.

Common error: Do not copy the worked example unchanged; transfer the method and check it against the new context.

Command word: Explain3 marks

Explain the roles of OS security management, backup software and a program library in a shared editing application: restrict who may overwrite files, recover an earlier document and reuse an existing spell-check routine.

S5.01.RS5.02.RS5.03.R
Answer and marking points
  1. OS permissions reject overwrite requests from accounts without the required right.
  2. A recoverable earlier backup supplies a document version that can be restored.
  3. The application calls the library's spell-check routine instead of implementing that routine afresh.

Common error: Match each of the three needs to the software that performs the operation.

Command word: Explain3 marks

Explain why repeated use can favour a native compiled executable, then describe why a Java class file still needs a compatible JVM.

S5.04.RS5.05.RS5.06.R
Answer and marking points
  1. The native executable can be reused without translating the original source for every run.
  2. A Java class file instead contains virtual-machine bytecode.
  3. The JVM supplies the platform-appropriate execution of those bytecode instructions.

Common error: Do not treat JVM bytecode as the same native executable for every processor.

Command word: Describe3 marks

A program should double 6 but produces 8. Describe how a breakpoint, single stepping and variable inspection can help locate the faulty calculation.

S5.07.R
Answer and marking points
  1. Pause at a breakpoint before the suspect calculation, when its input values can be checked.
  2. Step through the calculation and inspect the changed variable.
  3. Compare the observed 8 with the required 12 and investigate the executed operator and operands.

Common error: Syntax correctness alone cannot establish that doubling was implemented.

Command word: Explain3 marks

A systems analyst hides a known emergency-contact error to avoid delaying a client demonstration. Explain why this conflicts with professional ethics, give a consequence of reporting it, and explain how professional-body membership could help the analyst respond.

S7.01.RS7.02.RS7.03.R
Answer and marking points
  1. Concealing a known fault prevents the client from judging whether emergency contacts can be relied upon.
  2. Reporting allows correction before an emergency, although the demonstration may be postponed.
  3. Guidance from a professional code or experienced members can support an honest escalation of the concern.

Common error: Use the supplied fault and both professional responsibility and practical support.

Command word: Explain3 marks

A student claims, 'Copyright ends when source is published, and shareware can always be used forever without paying.' Explain the two errors and state why a paid open-source product can still be commercial software.

S7.04.RS7.05.R
Answer and marking points
  1. Publication does not itself surrender rights in source code; permissions depend on the licence.
  2. A shareware offer can limit trial time or features and require a purchase for continued full use.
  3. Selling software is business activity even if the licence retains open-source freedoms.

Common error: Keep ownership, price, trial terms and modification rights separate.

Command word: Justify3 marks

An archive needs to adapt an indexer and distribute it to partner archives. Licence A supplies source and permits both acts if notices remain. Licence B permits one unmodified installation. Justify a choice and state a continuing responsibility.

S7.05.R
Answer and marking points
  1. A authorises the adaptation needed for the archive's index format.
  2. A permits distribution to partners whereas B's single-installation condition does not cover that plan.
  3. The archive must retain the specified notices in its distributed versions.

Common error: Use the permissions in the question rather than guessing from the licence name.

Command word: Describe4 marks

A transport service uses AI to recognise spoken destinations. Describe this application and explain one social benefit, one economic cost and one environmental cost.

S7.06.R
Answer and marking points
  1. The system interprets passengers' audio to produce recognised destination information for journey planning.
  2. Voice input may help passengers who cannot conveniently use a keyboard or touch screen.
  3. The service must fund development or purchase, integration and continued support of recognition.
  4. Processing speech and operating the supporting equipment consumes electricity and hardware resources.

Common error: Distinguish the AI task from its consequences in each requested dimension.

Command word: Explain4 marks

A school stores each pupil's address in separate club files. Pupil(PupilID, PupilName, Address) and Membership(PupilID, ClubID) are proposed; Club(ClubID, ClubName) already exists. Explain how the design reduces inconsistent addresses, state the Membership key assuming one membership per pupil per club, and describe the two relationships and referential-integrity rules.

S8.01.RS8.02.RS8.03.R
Answer and marking points
  1. One Pupil row stores the address, so an address update need not be repeated in each club file.
  2. The pair (PupilID, ClubID) uniquely identifies a Membership row.
  3. Pupil to Membership and Club to Membership are each one-to-many.
  4. Each Membership foreign key must match an existing identifier in its referenced Pupil or Club table.

Common error: Neither foreign key alone uniquely identifies a membership.

Command word: Explain3 marks

Parcel(ParcelID, DepotID, DepotName) has atomic values and primary key ParcelID. Each depot has one name and handles many parcels. Explain why the table is not in 3NF, then give a 3NF design with keys and explain how to recover a parcel's depot name.

S8.04.R
Answer and marking points
  1. DepotName depends on the non-key DepotID, creating a transitive dependency from ParcelID.
  2. Use Parcel(ParcelID PK, DepotID FK) and Depot(DepotID PK, DepotName).
  3. Match Parcel.DepotID with Depot.DepotID to recover the depot name for each parcel.

Common error: Splitting tables without retaining DepotID in Parcel loses the relationship.

Command word: Define5 marks

A developer uses a DBMS interface to define Courier(CourierID INTEGER, CourierName VARCHAR(30), PRIMARY KEY (CourierID)). Explain the roles of the developer interface, data dictionary and query processor. Identify the language category used to create this table and state what the definition permits and prevents.

S8.05.RS8.06.RS8.07.RS8.08.RS8.09.R
Answer and marking points
  1. The developer interface provides tools through which the developer submits definitions or builds the application.
  2. The dictionary records metadata such as Courier's fields, data types and key constraint.

Question 1 · Command word: Explain · 4 marks

The 8-bit unsigned binary value 10110110 is stored in a register. Explain how to convert it to hexadecimal and denary.

Marking points

  • split the binary value into the nibbles 1011 and 0110.
  • 1011 represents hexadecimal B and 0110 represents hexadecimal 6.
  • the hexadecimal value is B6.
  • adding the binary place values 128 + 32 + 16 + 4 + 2 gives denary 182.

Question 2 · Command word: Describe · 5 marks

An alarm uses the logic expression Q = (Door AND NOT Key) OR Smoke. Describe how to construct a complete truth table for this expression.

Marking points

  • create input columns for Door, Key and Smoke and list all eight input combinations.
  • add an intermediate column for NOT Key by inverting each Key value.
  • add a column for Door AND NOT Key that is 1 only when both inputs to the AND gate are 1.
  • OR that intermediate result with Smoke to obtain Q.
  • Q is 1 whenever Smoke is 1 or Door is 1 while Key is 0.

Question 3 · Command word: Explain · 5 marks

A customer account number is entered twice and a data block is then sent with a checksum. Explain how these two verification methods detect errors and give one limitation of each.

Marking points

  • double entry compares two independently entered account numbers and flags a mismatch.
  • matching entries can still both be wrong, so double entry does not prove that the value is true.
  • the sender calculates a checksum from the data block and sends it with the data.
  • the receiver recalculates the checksum and compares it with the received checksum.
  • a matching checksum does not guarantee error-free data because some different error patterns can produce the same checksum.
