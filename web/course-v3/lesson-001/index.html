From two states to information

A bit is one binary digit, 0 or 1. Two distinguishable physical states can represent these alternatives. Bits do not identify their own meaning: an agreed representation determines whether a pattern stands for a number, a character, a colour or something else.

Read the unit and the meaning

A nibble contains four bits and a byte contains eight bits. Lower-case b means bit; upper-case B means byte. A capacity counts available storage, whereas the value represented by one stored pattern depends on its encoding.

Explain the power of two

Appending one independent bit doubles the possibilities. Eight bits therefore have 256 patterns, but the largest unsigned value is 255 because zero uses one pattern. These same pattern counts will determine character capacity, colour choices and sound levels.

Two scales for the same quantity

Each binary prefix level multiplies by 1024; each decimal level multiplies by 1000. The prefix attaches a multiplier to the unit: KiB counts bytes, while Kib counts bits. Keep the i and the case when copying a specification.

Worked example: express a 4 MiB file in bytes and MB

  1. Convert to bytes: 4 × 2²⁰ = 4,194,304 bytes. Multiplication expands the larger unit into individual bytes.
  2. Convert to MB: 4,194,304 ÷ 1,000,000 = 4.194304 MB. Division groups those bytes into decimal megabytes.
  3. Reverse-check: 4.194304 × 1,000,000 = 4,194,304 bytes. Both labels describe exactly the same file.

Worked example: how many complete files fit?

  1. State the model: A device has 1 KiB = 1024 bytes available. Every file occupies exactly 300 bytes, with all overhead already included.
  2. Compare complete multiples: 3 × 300 = 900 fits; 4 × 300 = 1200 does not. Three complete files fit.
  3. Find the remainder: 1024 − 900 = 124 bytes remain. A fractional fourth file is not a complete saved file.

Check dimensions and plausibility

For a mixed-unit calculation, convert bits to bytes as well as converting the prefix. For example, 24,000 bits ÷ 8 = 3000 bytes = 3 kB. Check that the final unit answers the question; a result in bits is eight times its numerical value in bytes.

Core explanation · Exam essentials

  • Binary prefixes use powers of 1024; decimal prefixes use powers of 1000.
  • Convert through bytes when changing byte units; 1 B = 8 b.
  • n bits provide 2ⁿ patterns, representing unsigned values 0 to 2ⁿ − 1.
Common misconception

Kilo is the decimal multiplier 1000; kibi is the binary multiplier 1024. They are not interchangeable labels for the same quantity.

Check your understanding

Four bits provide 16 patterns. Why is their largest unsigned value 15?

Check your answer

The patterns represent 0 through 15 inclusive; zero occupies one of the 16 patterns.

Command word: State4 marks

State the number of bytes represented by 1 GiB and explain why 1 GB represents a different number of bytes.

S1.01.A01S1.01.A02
Answer and marking points
  1. 1 GiB = 2^30 = 1,073,741,824 bytes.
  2. Gibi uses successive factors of 1024.
  3. 1 GB = 10^9 = 1,000,000,000 bytes.
  4. Giga uses successive factors of 1000.

Common error: Keep the binary symbol GiB distinct from the decimal symbol GB.

Command word: Calculate2 marks

Calculate the size of a 3,000,000-byte file in MB. Show your working.

S1.01.A01S1.01.A02
Answer and marking points
  1. Divide the byte count by 1,000,000 bytes per MB.
  2. 3,000,000 / 1,000,000 = 3 MB.

Common error: MB uses a decimal divisor; dividing by 1,048,576 would give a value in MiB.

Command word: State4 marks

State the byte multiplier for each pair of prefixes: kibi and kilo; mebi and mega; gibi and giga; tebi and tera.

S1.01.A01S1.01.A02
Answer and marking points
  1. Kibi: 2^10; kilo: 10^3.
  2. Mebi: 2^20; mega: 10^6.
  3. Gibi: 2^30; giga: 10^9.
  4. Tebi: 2^40; tera: 10^12.

Common error: Each step multiplies by 1024 for binary prefixes and by 1000 for decimal prefixes.

Command word: Calculate3 marks

Calculate how many complete 600-byte files fit into 2 KiB of available storage and how many bytes remain. Each stated file size includes all overhead.

S1.01.A01S1.01.A02
Answer and marking points
  1. 2 KiB = 2048 bytes.
  2. Three files fit because 3 × 600 = 1800 and 4 × 600 = 2400 exceeds 2048.
  3. 2048 − 1800 = 248 bytes remain.

Common error: Round down to complete files and retain the correct prefix multiplier.

Question 1 · Command word: Explain · 4 marks

A storage manufacturer labels a drive as 512 GB, but system software reports approximately 477 GiB. Explain why the numerical values differ even though no storage capacity has been lost.

Answer and marking points
  • The label GB uses the decimal prefix giga, so 1 GB equals 10^9 bytes.
  • The software value GiB uses the binary prefix gibi, so 1 GiB equals 2^30 bytes.
  • The same byte capacity is divided by two different unit sizes, producing different numerical values.
  • Because one GiB is larger than one GB, the numerical value in GiB is lower.

Common error: Do not claim that the operating system deleted capacity; the two displays use different unit definitions.

Question 2 · Command word: Calculate · 3 marks

Calculate the number of bytes in 2 MiB and in 2 MB, then calculate the difference between the two capacities.

Answer and marking points
  • 2 MiB = 2 × 2^20 = 2,097,152 bytes.
  • 2 MB = 2 × 10^6 = 2,000,000 bytes.
  • The difference is 2,097,152 − 2,000,000 = 97,152 bytes.

Common error: Do not use 1024 as the value of mebi; one mebibyte is 1024 squared bytes.

Question 3 · Command word: Describe · 3 marks

A network specification states a transfer amount in gigabytes while a memory specification states a capacity in gibibytes. Describe the multiplier represented by each prefix and explain why the unit symbols must not be treated as interchangeable.

Answer and marking points
  • Giga is the decimal multiplier 10^9 and uses the symbol G in GB.
  • Gibi is the binary multiplier 2^30 and uses the symbol Gi in GiB.
  • The multipliers have different byte values, so replacing GB with GiB changes the stated capacity rather than only changing its spelling.

Common error: Do not state that giga and gibi are synonyms or give them the same multiplier.

Question 4 · Command word: Calculate · 3 marks

Calculate how many complete 500-byte records fit in 4 KiB of free space. Each record includes all overhead. Give the unused byte count.

Answer and marking points
  • 4 KiB = 4096 bytes.
  • Eight records require 4000 bytes and fit; nine require 4500 and do not.
  • 4096 − 4000 = 96 bytes remain.

Common error: Storage holds complete records; a decimal prefix would give a different capacity.
