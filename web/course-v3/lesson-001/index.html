Represent information · Concept 01

How can two states carry a message?

Observe

Three things to keep

  • A letter on a card
  • The colours and shapes of a leaf photograph
  • The changing sound of a vibrating tuning fork

Look, then discuss

Could one on/off lamp tell us which of these three things was chosen?

An agreed rule could make off mean “letter” and on mean “photograph”. There is no third state left for “sound”. The problem is the number of distinguishable messages, not the brightness of the lamp.

Explain

Explanation · 1 / 4

Start with an agreed meaning

A representation uses one thing to stand for another. If both people agree that a raised hand means “yes”, the hand position carries information. The same physical position could mean something else under a different agreement.

Explanation · 2 / 4

Name the smallest binary choice

A bit is a binary digit: 0 or 1. A computer can use two distinguishable physical states to represent those alternatives. The printed symbols 0 and 1 describe the states; the computer does not need to store tiny pictures of these digits.

Explanation · 3 / 4

Combine bits into ordered patterns

Two bits make four patterns: 00, 01, 10 and 11. We could assign 00 to the letter, 01 to the photograph and 10 to the sound, leaving 11 unused. The order matters: 01 and 10 are different patterns.

PatternAgreed meaning in this activity
00Letter
01Photograph
10Sound
11Unused

Explanation · 4 / 4

Separate the pattern from its meaning

A bit pattern has no built-in label saying “number”, “letter” or “colour”. A representation rule tells the receiver how to interpret it. Throughout this section, ask both what is stored and which rule gives it meaning.

Work together

Send one choice with two lamps

The left lamp is off and the right lamp is on. Off represents 0 and on represents 1.

Work together · 1 / 2

Record the order

Read from left to right: the pattern is 01.

Work together · 2 / 2

Use the agreed table

The table assigns 01 to the photograph. Reading the lamps in reverse would give 10 and the wrong message.

The two states create a code only when a shared rule defines their meaning and order.

Experiment

Use two bits. Predict how many different patterns can be made, then click through them. Which pattern would you reserve for an unused choice?

Check

Try it yourself · Teacher-written

A switch has only two states. Can it uniquely identify three answers without any extra information?

Check your reasoning

No. One bit has two patterns, so two answers can be assigned distinct patterns. Three answers require at least two bits, which provide four patterns.

Connect

Keep this idea

Bits record two alternatives. A shared representation gives an ordered bit pattern its meaning.

Before representing larger choices, we need a reliable way to count the patterns made by several bits.

Represent information · Concept 02

Count possibilities before assigning values

Observe

Add one independent choice

BitsAll possible patterns
10, 1
200, 01, 10, 11
3000, 001, 010, 011, 100, 101, 110, 111

Look, then discuss

Why does adding one bit double the number of patterns?

Take each two-bit pattern twice: put 0 in front of one copy and 1 in front of the other. No old choice disappears, and every old choice now has two versions.

Recall

Read powers as repeated multiplication

2³ means 2 × 2 × 2, which is 8. The raised 3 is an exponent: it counts three factors of 2. It does not mean 2 × 3. We use 2⁰ = 1 later for the rightmost number position.

Revisit: How can two states carry a message?

Explain

Explanation · 1 / 3

Multiply independent choices

Each bit can be 0 or 1 independently of the other bits. Three bits therefore give 2 × 2 × 2 = 8 patterns. In general, n bits provide 2ⁿ patterns.

Explanation · 2 / 3

Distinguish a count from a largest value

If eight patterns label the whole numbers beginning at zero, they label 0 through 7. Zero takes one pattern too. Thus n bits provide 2ⁿ patterns but their largest unsigned integer is 2ⁿ − 1. “Unsigned” means that the representation has no negative values.

Explanation · 3 / 3

Group bits into familiar units

A nibble contains four bits. A byte contains eight bits. Lower-case b means bit and upper-case B means byte. One byte therefore holds one of 256 patterns; it is not a container holding 256 separate numbers at once.

4 bits = 1 nibble2⁴ = 160 to 15
8 bits = 1 byte2⁸ = 2560 to 255
16 bits = 2 bytes2¹⁶ = 65,5360 to 65,535

A school needs one distinct bit pattern for each of six colours.

2² = 4 patterns. Four codes cannot label six different colours.

Work together · 2 / 2

2³ = 8 patterns. Six can label the colours and two can remain unused. Three bits are sufficient and two are not.

Try it yourself · Teacher-written

How many bits are needed for 20 distinct labels? If five-bit patterns instead represent unsigned integers, what is the largest value?

Check your reasoning

Four bits give only 16 labels. Five bits give 32, so five bits are needed. Five-bit unsigned integers range from 0 to 31; 32 is the pattern count, not the maximum value.

Connect

Keep this idea

n bits provide 2ⁿ patterns. Assigning them to unsigned integers gives values 0 to 2ⁿ − 1.

Files contain many bytes. Prefixes let us describe large byte counts without writing every digit.

Represent information · Concept 03

Compare quantities using the same unit

Observe

Two labels on the same file

  • File A: 1 MiB
  • File B: 1 MB
  • Both use B for bytes. The extra i changes the multiplier.

Look, then discuss

Do these labels describe equal amounts of data?

First compare a smaller pair: 1 KiB is 1024 bytes, while 1 kB is 1000 bytes. The prefixes follow two different scales. Neither label changes the size of a byte.

Explain

Explanation · 1 / 4

Follow the decimal scale

Kilo, mega, giga and tera use successive factors of 1000. For example, one megabyte is 1000 × 1000 = 1,000,000 bytes. Multiplication expands a large unit into individual bytes.

Explanation · 2 / 4

Follow the binary scale

Kibi, mebi, gibi and tebi use successive factors of 1024. The i in KiB or MiB identifies this scale. One mebibyte is 1024 × 1024 = 1,048,576 bytes.

LevelBinary prefix and byte multiplierDecimal prefix and byte multiplier
1kibi: KiB = 2¹⁰ B = 1024 Bkilo: kB = 10³ B = 1000 B
2mebi: MiB = 2²⁰ B = 1,048,576 Bmega: MB = 10⁶ B = 1,000,000 B
3gibi: GiB = 2³⁰ Bgiga: GB = 10⁹ B
4tebi: TiB = 2⁴⁰ Btera: TB = 10¹² B

Explanation · 3 / 4

Convert through a common unit

To compare different sizes, convert them all to bytes. To express a byte count in MB, divide by 1,000,000. To express it in MiB, divide by 1,048,576. Also check b versus B: divide a bit count by eight to get bytes.

Explanation · 4 / 4

Count complete files

Capacity asks how much data fits. After converting the capacity and file size to the same unit, divide. If only whole files may be saved, round down. Include headers or other overhead only when their cost is supplied or already included in the stated size.

Work together

Save complete 600-byte files in 2 KiB

The available capacity is exactly 2 KiB. Each complete file occupies 600 bytes including all overhead.

Work together · 1 / 3

Convert the capacity

2 × 1024 = 2048 bytes.

Work together · 2 / 3

Test complete multiples

3 × 600 = 1800 bytes fits. 4 × 600 = 2400 bytes does not. Three complete files fit.

Work together · 3 / 3

Find the unused space

2048 − 1800 = 248 bytes remain. This is smaller than another 600-byte file.

Check both the number of complete files and the remaining capacity.

Check

Try it yourself · Teacher-written

Which is larger: 2 MB or 1900 KiB? Show a common-unit comparison.

Check your reasoning

2 MB = 2,000,000 bytes. 1900 KiB = 1900 × 1024 = 1,945,600 bytes. Therefore 2 MB is larger by 54,400 bytes.
