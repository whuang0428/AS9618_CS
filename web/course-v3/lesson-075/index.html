Follow a numeric function from input to result

Observe

Supplied numeric contracts

CallArgumentReturned value
INT(X)REALINTEGER part of X
RAND(X)Positive INTEGER boundREAL value at least 0 and less than X

Look, then discuss

Why does RAND(6) alone not produce a whole-number desk label from 1 to 6?

A simulation chooses one of six demonstration desks. First inspect the supplied contract: RAND(6) can produce a fractional number from 0 inclusive to 6 exclusive.

Recall

Recall an expression value

An expression produces a value for assignment, output or another expression. A function call can occupy that position because it returns a value. The values supplied inside its parentheses are arguments.

Explain

Explanation · 1 / 3

Read accepted types and the result

A built-in function is provided by the language environment; a library routine supplies a reusable operation through its documented interface. For either, check the arguments and result before use. INT(4.8) returns the INTEGER 4 under the supplied contract. RAND(6) returns a REAL, so 2.75 is a possible result but 6 is excluded.

Explanation · 2 / 3

Evaluate an inner call before its enclosing call

In INT(RAND(6)), first generate a real value. INT then takes its integer part. For these non-negative results, the possible integers are 0, 1, 2, 3, 4 and 5.

Explanation · 3 / 3

Shift the range after conversion

Adding 1 gives the required 1 to 6 inclusive. Generate a fixed target once before a guessing loop if every attempt is meant to find the same target.

DECLARE Desk : INTEGER
Desk <- INT(RAND(6)) + 1
OUTPUT Desk

Work together

Check the extreme possible outcomes

Consider generated values 0.0 and 5.999.

Work together · 1 / 2

Follow the lower outcome

INT(0.0) gives 0; adding 1 gives desk 1.

Work together · 2 / 2

Follow the upper end

INT(5.999) gives 5; adding 1 gives desk 6. RAND never supplies 6, so the expression cannot produce desk 7.

Follow each returned value and its type; the outside operation receives the inside result.

Check

Try it yourself · Teacher-written

What are the smallest and largest results of INT(RAND(4)) + 2?

Check your reasoning

2 and 5. INT produces 0 through 3, then adding 2 shifts the interval.

Connect

Keep this idea

Use the supplied numeric contract to derive both the result type and its possible range.

Extract a part of a booking code

Observe

Code = "ART0072"

Position1234567
CharacterART0072

Look, then discuss

Which arguments extract 0072 from the booking code ART0072?

Number the characters from 1. The first digit is at position 4 and four digits must be retained, including both leading zeros.

Recall

Recall STRING and CHAR

A STRING is a sequence of characters; a CHAR is one character. A one-character STRING and a CHAR are different types unless the supplied task explicitly permits interchange. An extracted digit string does not automatically become a number.

Explain

Explanation · 1 / 3

Read LENGTH as a character count

LENGTH(Code) returns 7. Spaces and punctuation count as characters too. LENGTH("") returns 0 for an empty string.

Explanation · 2 / 3

Use the MID start and count correctly

For the supplied MID(Text, Start, Count), Start is one-based and Count is the number of characters, not an ending position. MID(Code, 4, 4) returns "0072". Keep the requested range within the string unless a task defines other behaviour.

Explanation · 3 / 3

Distinguish extraction from conversion

RIGHT(Code, 2) returns "72", a STRING. The character routines UCASE(Letter) and LCASE(Letter) accept a CHAR and return its upper- or lower-case CHAR under the Cambridge guide: UCASE('b') gives 'B' and LCASE('Q') gives 'q'. The experiment instead supplies TO_UPPER(Text) for a STRING; read that separate interface before calling it.

DECLARE Code, Digits : STRING
Code <- "ART0072"
Digits <- MID(Code, 4, 4)
OUTPUT LENGTH(Code)
OUTPUT Digits
OUTPUT RIGHT(Code, 2)

The outputs are integer 7, string "0072" and string "72". Quotation marks in this explanation identify the types; they need not be printed as part of the displayed output.

Program a booking system · Concept 26

Build a stored label by concatenation

Observe

Three pieces of one label

  • Prefix: "ART"
  • Separator: "-"
  • Digits: "0072"

Look, then discuss

How can ART0072 become the label ART-0072 without treating its digits as a number?

Separate the three-letter activity code from the four-digit identifier, then place a hyphen between the two strings.

Recall

Recall an assignment result

The right side of an assignment may itself contain function calls. Each call supplies a returned value, then the surrounding expression combines those values.

Explain

Explanation · 1 / 3

Use & to concatenate strings

Concatenation places the second string directly after the first. "ART" & "-" gives "ART-". The operator does not add an automatic space or punctuation.

Explanation · 2 / 3

Keep text joining separate from arithmetic and logic

"00" & "72" gives "0072". It does not calculate the number 72. & joins strings; AND combines Boolean values. Do not interchange those operators.

Explanation · 3 / 3

Store the complete label when it will be reused

Build Label using extracted parts, then OUTPUT Label. An OUTPUT statement with comma-separated items can display a similar result, but does not itself create a stored combined STRING.

DECLARE Code, Prefix, Digits, Label : STRING
Code <- "ART0072"
Prefix <- MID(Code, 1, 3)
Digits <- RIGHT(Code, 4)
Label <- Prefix & "-" & Digits
OUTPUT Label

Work together

Predict both contents and length

Use Code "ART0072".

Work together · 1 / 2

Follow the intermediate strings

Prefix becomes "ART", Digits becomes "0072" and Label becomes "ART-0072".

Work together · 2 / 2

Check the character count

The label has 3 + 1 + 4 = 8 characters. The hyphen counts; leading zeros remain part of the final string.

Construct a label from explicitly ordered strings and separators.

Check

Try it yourself · Teacher-written

What is LENGTH("A" & " " & "B")? Would omitting " " give the same string?

Check your reasoning

The length is 3 and the string is "A B". Omitting the space gives "AB", whose length is 2.

Connect

Keep this idea

Concatenation combines strings in order; every separator must be supplied explicitly.

Read an unfamiliar routine before calling it

Observe

An unfamiliar supplied function

Interface factDefinition
NameTAKE
Ordered parametersText : STRING, Count : INTEGER
ResultSTRING containing the first Count characters
Example argument values"NETWORK", 4

Look, then discuss

Can you use TAKE(Text, Count) even if you have never seen that function name before?

The supplied definition says TAKE returns the first Count characters of a STRING. The name alone is insufficient, but the contract gives the order, types and result.

Recall

Recall arguments and returned values

Arguments are the values supplied by a call. A function returns a value used by its caller. These facts are enough to use a supplied routine before learning how to define your own.

Explain

Explanation · 1 / 3

Find every part of the interface

Read the name, argument order, accepted types, returned type and any bounds or position convention. TAKE("NETWORK", 4) follows the stated order and returns "NETW".

Explanation · 2 / 3

Evaluate nested calls from inside outward

If TO_LOWER(Text) returns a lower-case STRING, TO_LOWER(MID("ZGAC001", 3, 1)) first extracts "A" and then returns "a". Do not lower-case the wrong character by assuming zero-based positions.

Explanation · 3 / 3

Let the supplied definition settle differences

The original paper insert for the following task defines its own functions and permits a CHAR and a one-character STRING to be used interchangeably where stated. That permission belongs to the supplied contract; do not assume every language or every routine makes the same allowance.

Work together

Combine a string result with a Boolean comparison

ID is "ZGAC001", Tries is 9 and Sorted is FALSE. Use the supplied LENGTH, MID and TO_LOWER definitions.

Work together · 1 / 2

Calculate string and numeric parts first

MID(ID, 3, 1) is "A"; TO_LOWER gives "a". LENGTH(ID & "xx") is 7 + 2 = 9. Tries MOD 4 is 1.

Work together · 2 / 2

Complete the conditions

9 >= Tries is TRUE. Tries < 10 AND NOT Sorted becomes TRUE AND TRUE, which is TRUE. A returned string, integer and Boolean play different roles in these expressions.

Use the exact supplied contract, then track the type and value after each operation.

Question 4 · Command word: Write4 teacher marks

Write complete pseudocode that inputs a code of exactly eight characters: two letters, four digit characters, then two letters. MID(S, Start, Count) returns Count characters from one-based Start; RIGHT(S, Count) returns the final Count characters. Output the four digit characters, a hyphen and the final letters as one STRING. State the result for IT0007XY.

S11.03.A01S11.03.A03
Answer and checking points — teacher-written

One valid Cambridge pseudocode solution

DECLARE Code, Digits, Suffix, Label : STRING
INPUT Code
Digits <- MID(Code, 3, 4)
Suffix <- RIGHT(Code, 2)
Label <- Digits & "-" & Suffix
OUTPUT Label
  1. Declare the input and result identifiers as STRING, then input Code.
  2. MID(Code, 3, 4) obtains the four digit characters and RIGHT(Code, 2) obtains the final letters.
  3. Join the two results with an explicit "-" using &, then output the resulting STRING.
  4. IT0007XY produces "0007-XY"; the leading zeros are retained.

Common error: Do not turn the digit characters into an INTEGER and lose the stated formatting.

Question 5 · Command word: State3 teacher marks

State LENGTH("A B!"), UCASE('7') and "Ada" & " " & "Lovelace". LENGTH counts all characters; UCASE accepts one CHAR and returns non-lower-case characters unchanged. Explain why UCASE("ab") does not match this interface.

S11.03.A01S11.03.A03
Answer and checking points — teacher-written
  1. LENGTH("A B!") is 4 and UCASE('7') is '7'.
  2. The concatenation produces "Ada Lovelace", including the explicit space.
  3. "ab" is a STRING, whereas this UCASE interface requires a CHAR.

Common error: A space is a character and a function’s accepted type is part of its contract.
