Does ORDER BY Fee DESC remove loans with fee zero? What clause would remove them?

Cambridge 9618/13 · October/November 2025 · 5(c) · 5 marks

Selected parts: 5(c) [5].

Use PRODUCT for the name and rating, and COMPLAINT for the complaint details. Include rating 5 and sort highest qualifying rating first.

Reasoning and model answer — teacher-written
SELECT PRODUCT.ProductID, ProductName, ComplaintDetails
FROM PRODUCT INNER JOIN COMPLAINT
ON PRODUCT.ProductID = COMPLAINT.ProductID
WHERE Rating <= 5

Topic recap
  • Choose the information a result should show

    SELECT chooses result fields; FROM identifies the source; retrieval leaves these stored records intact.

  • Test each row against a precise condition

    WHERE filters rows; AND, OR, comparison boundaries and parentheses determine which rows qualify.

  • Arrange the result and resolve ties

    ORDER BY controls output order; later fields resolve ties under earlier fields.

  • Calculate a total, count and mean

    Calculate over the correct rows and distinguish counting records from counting known field values.

  • Make one summary for each member

    GROUP BY partitions the selected records and lets aggregates produce one result for each group.

  • Match a loan with its member

    INNER JOIN returns matching record pairs according to ON; parent values can repeat across different children.

  • Build a complete two-table summary

    Build a combined query from a precise output requirement and verify each stage against the data.

  • Add a new record in the defined field order

    INSERT adds records; the field list and values must correspond and all declared constraints still apply.

  • Change a value without losing the event
