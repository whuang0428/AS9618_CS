Hardware / 01

Give data somewhere to wait

Look closely

How can a fast sender pass a short burst to a slower receiver?

A computer prepares a short burst of page data faster than a printer can use it. Where could the extra data wait, and what would happen if that waiting space filled? Make a prediction now; later, use Explore to trace the waiting blocks.

Step 1 / 5

Identify the rate mismatch

A computer can prepare printing data faster than a printer can put it on paper. If every block had to be processed immediately, the sender would often wait. A buffer is temporary storage between the producer and consumer that lets blocks wait until the receiving component is ready.

Step 2 / 5

Trace actual blocks

For a four-block buffer, imagine four blocks arriving at once and the receiver removing one per second. After one second three remain; after two seconds two remain, if no more arrive. The buffer lets the sender finish that burst while the receiver continues its work. Count waiting blocks separately from completed blocks.

Step 3 / 5

Use a clear event order

When input and output happen during the same model step, apply the displayed event order. Removing a block can free a slot before a new block is accepted. The queue in this model serves the oldest waiting block first. A trace must state both the current contents and the rule used to update them.

Step 4 / 5

Explain full and empty states

A finite buffer can fill if incoming data repeatedly exceeds outgoing data. In a system that supports flow control, the sender can pause until space is available. Other systems may drop data or report an overrun. An empty buffer gives the receiver nothing to consume, so it may wait. Use the policy stated for the particular system.

Step 5 / 5

Separate capacity from sustained speed

A bigger buffer can absorb a larger temporary burst. It does not make the printer mechanism print faster or solve an unlimited excess input rate. Predict the longer-term result, then test different rates when you reach Explore. Keep capacity, transfer rate and total completed work separate.

Explain it yourself · Teacher-written check

A sender continuously supplies 4 blocks/s while the receiver removes 2 blocks/s. Can a finite buffer prevent waiting or loss forever?

Check your reasoning

No. The waiting data grows by 2 blocks each second while those rates continue. A finite buffer eventually fills, so the system must slow or pause the sender, drop data, or apply another stated policy.

Hardware / 02

Distinguish RAM, ROM and saved files

Look closely

After a camera restarts, why can it keep its instructions but lose an unfinished edit?

Sort three items by their job: the current pixels being edited, instructions for starting the camera, and a saved photograph. Then decide which must still exist after power is removed.

Step 1 / 4

Give changing work a writable space

RAM, Random Access Memory, supports reading and writing during normal processing. It can hold the program currently running, measurements, image data and temporary results. Ordinary SRAM and DRAM are volatile: their contents are lost without power. A changing working image is therefore a suitable use of RAM.

Step 2 / 4

Keep instructions for the next start

ROM, Read Only Memory, retains its contents without power. It supplies persistent instructions or data, such as firmware used to start or operate a device. Normal program execution reads these contents rather than treating them as everyday scratch space. Some ROM-family technologies permit special programming or update operations.

Step 3 / 4

Separate retention from the storage role

Both firmware and saved photographs can be persistent, but they do different jobs. Firmware provides instructions; a saved photograph is user data in secondary storage. A flash technology can be used for either role. Name the role and the required behaviour before naming the physical memory technology.

Step 4 / 4

Apply the distinction to another device

A router needs persistent firmware after restart and RAM for current packet data and working tables. A camera needs firmware, writable workspace and storage for completed photographs. Explaining a choice means linking read/write behaviour and power-loss behaviour to the specific item being stored.

Explain it yourself · Teacher-written check

A device stores persistent firmware and saved sound files in different regions of one flash chip. Do those regions have the same role?

Check your reasoning

No. One supplies operating instructions; the other retains user files. They can share a storage technology and non-volatility while serving different purposes.

Apply the idea · Teacher-written practice
Question 1 · Command word: Explain4 teacher marks

Explain two differences between RAM and ROM and give one use of each.

S3.05.A01S3.05.A02
Answer and checking points — teacher-written
  1. RAM is normally volatile whereas ROM is non-volatile.
  2. RAM is read/write working memory whereas ROM is normally read during operation.
  3. RAM holds active programs and data.

Keep this idea

RAM supports changing current work; ROM provides persistent contents normally read in use. Saved user files have a separate storage role.

Two common RAM technologies make different compromises between speed, capacity and cost.

Hardware / 03

Why one kind of RAM needs refreshing

Look closely

What happens if a memory bit slowly loses the charge used to represent it?

Compare the powered two-state circuit and the charged capacitor in the diagram. Predict which stored state needs regular restoration and whether either could survive removal of power. Later, use Explore to examine refresh and power loss.

Step 1 / 5

Store a bit in a stable powered circuit

SRAM means Static RAM. It uses a bistable circuit: a circuit with two stable states that can represent 0 and 1. While power is supplied, the circuit maintains the selected state until it is written differently. Static refers to this retention during powered operation, not to non-volatility.

Step 2 / 5

Store a bit using capacitor charge

DRAM means Dynamic RAM. A typical cell uses a capacitor to represent a bit by its charge state, with a transistor controlling access. The cell can be small, allowing many bits in a chip. However, stored charge leaks away over time even while the memory system is powered.

Step 3 / 5

Restore the state before it is lost

DRAM needs periodic refresh to restore its stored charge states before leakage makes them unreliable. Refresh preserves the existing data; it is not the same as a program intentionally writing a new value. SRAM does not need this periodic capacitor refresh. Both technologies still lose their data when power is removed.

Step 4 / 5

Connect construction to the trade-off

SRAM uses more circuitry per bit, giving lower density and a higher cost per bit, but it generally provides faster access. DRAM has higher density and a lower cost per bit, making large capacities practical. Compare the technologies under the same purpose instead of claiming that one is best for every task.

Step 5 / 5

Choose for cache and main memory

A processor cache is relatively small and must respond quickly, so SRAM is a suitable choice. Main memory needs much more capacity at an affordable cost, so DRAM is widely used. A correct justification connects the workload to access speed, density or cost; merely naming a technology does not explain the choice.

Explain it yourself · Teacher-written check

A student says SRAM keeps its contents after shutdown because it does not need refresh. Correct the reasoning.

Check your reasoning

SRAM maintains a stable state only while it is powered. It does not need periodic DRAM-style refresh, but it is still volatile and loses its contents when power is removed.

Apply the idea · Teacher-written practice
Question 1 · Command word: Compare5 teacher marks

Compare SRAM and DRAM and explain why each is used for a different primary-memory role.

S3.06.A01S3.06.A02S3.06.A03S3.06.A04
Answer and checking points — teacher-written
  1. SRAM stores bits in flip-flop circuits whereas DRAM stores charge in capacitors.
  2. SRAM does not require refresh whereas DRAM requires periodic refresh.
  3. SRAM is faster but more expensive and less dense.
  4. SRAM is used for cache because fast access is required.
  5. DRAM is used for main memory because lower cost and greater density support large capacity.

Common error: Do not confuse SRAM with solid-state flash storage.

Keep this idea

Powered SRAM holds a bistable state; DRAM holds charge that needs refresh. The physical difference helps explain speed, density, cost and use.

Hardware / 04

Choose how persistent instructions can be updated

Look closely

Which memory allows a device to receive new calibration instructions while it remains installed?

Compare three update requirements: program a blank chip once after manufacture; erase it with ultraviolet light before programming again; or erase and rewrite it electrically while installed. Which difference would determine your choice for a device that needs repeated updates?

Step 1 / 5

Keep the common property in view

PROM, EPROM and EEPROM are non-volatile. All can retain programmed contents without continuous power. That shared property explains why they can hold persistent instructions, but it does not tell us whether or how the contents can be changed. The update method is the deciding difference.

Step 2 / 5

Program once with PROM

Programmable ROM is supplied unprogrammed and can be programmed once. In a fuse-based example, the programmer uses electrical pulses to change selected fuse links and establish the bit pattern. That change is permanent in the device, so it is unsuitable when the same chip must receive repeated updates.

Step 3 / 5

Erase with ultraviolet light using EPROM

Erasable Programmable ROM can be cleared using ultraviolet light through a window in the package, then programmed again electrically. Erasure normally clears the chip rather than replacing a single chosen byte. Access to the window and erasing equipment makes this different from an ordinary update while sealed inside an appliance.

Step 4 / 5

Erase electrically using EEPROM

Electrically Erasable Programmable ROM supports electrical erasing and programming. It can therefore allow updates without ultraviolet exposure or chip removal, where the device provides the required circuitry. Calibration settings that must survive shutdown and be updated electrically are a suitable example.

Step 5 / 5

Justify the choice against every requirement

For repeated installed updates, EEPROM satisfies both retention and electrical rewriting. PROM fails the repeated-update requirement. EPROM permits reprogramming, but its ultraviolet erasure fails the specified electrical update method. A complete comparison gives the relevant reason for accepting or rejecting each option.

Explain it yourself · Teacher-written check

Why is “EEPROM is non-volatile” insufficient to distinguish it from PROM and EPROM?

Check your reasoning

All three retain data without power. EEPROM meets the additional requirement of electrical erasure and rewriting; PROM is programmed once, and EPROM requires ultraviolet erasure before reprogramming.

Common error: State the different erase or rewrite method for each memory type.

Hardware / 05

Combine buffering with a justified memory choice

Look closely

Does saying “the device uses RAM” explain both what the memory does and how it stores bits?

A printer accepts a burst of page data, a processor uses a small fast cache, and a controller keeps updateable calibration instructions. Identify the role first, then the behaviour and technology needed for each.

Step 1 / 4

Name the role before the chip

A buffer is temporary waiting space between components with different transfer rates. For optical recording, the computer places data in the buffer and the drive removes it at the rate it can accept. After sending its burst, the computer can do other work. Finite capacity still limits how much can wait. RAM can provide the buffer; buffering describes its role.

Step 2 / 4

Use the mechanism to explain a RAM choice

For a small low-latency cache, SRAM offers fast access without periodic capacitor refresh. For large affordable working space, DRAM offers greater density and lower cost per bit. Both are volatile. A buffer should be chosen for its actual capacity, timing and cost requirements; its name alone does not force one RAM technology.

Step 3 / 4

Keep persistent contents separate

The controller needs its calibration instructions after restart. If these must be updated electrically while installed, EEPROM meets the update requirement. The saved user files, changing working values and firmware each have distinct roles even when a system uses related physical technologies for more than one of them.

Step 4 / 4

Build the explanation as a chain

Start with the stated requirement, identify the relevant property and explain the consequence. For example: a fast sender can place a short burst in the buffer; the receiver then removes data at its own rate. Finite capacity limits the burst. This complete chain is more useful than listing “fast”, “cheap” or “temporary” without context.

Explain it yourself · Teacher-written check

A larger printer buffer is installed, but the printing mechanism is unchanged. Which improves: the size of an absorbable burst or the sustained page-printing rate?

Check your reasoning

The buffer can hold a larger burst before filling. The printing mechanism still has the same sustained rate. A finite buffer cannot absorb an indefinitely faster input without a full-buffer response.

Explain suitable memory choices for a small controller’s low-latency workspace, a large affordable image-editing workspace, and calibration instructions that must be rewritten electrically while installed. State what each retains after power loss.

S3.06.A01S3.06.A02S3.06.A03S3.06.A04S3.07.A03
Answer and checking points — teacher-written
  1. SRAM suits the small low-latency workspace because its powered bistable storage provides fast access without periodic refresh.
  2. DRAM suits the large workspace because high density and lower cost per bit support capacity; its capacitor charge needs refresh.
  3. Both workspaces are volatile and lose unsaved data when power is removed.
  4. EEPROM meets the stated electrical update requirement and retains the calibration instructions without power.

Common error: Explain the particular workload and update condition; non-volatility alone does not distinguish ROM variants.

Original question · Cambridge 9618/13

1. Compare RAM types and explain a disk buffer

Cambridge 9618/13 · October/November 2024 · 2(a), 2(b) · 6 marks

Selected parts: 2(a) [2]; 2(b) [4].

Hint — reading the question

Part (a) requires paired differences. In (b), identify which device sends faster and follow data through temporary storage to the slower disk.

Reasoning and model answer — teacher-written

2(a): DRAM needs periodic refreshing; SRAM does not need refreshing while power is maintained. DRAM generally has a slower access time than SRAM.

2(b): The computer can supply data faster than the magnetic hard disk can write it. It first places data in a memory buffer, which stores it temporarily. The computer can continue other work while the disk removes data from the buffer at its slower rate. A finite buffer can fill, so further transfers must wait when there is no free capacity.

Official mark scheme
Why this earns marks — teacher explanation

Part (a) awards one mark per difference. In (b), up to four points cover the speed mismatch, temporary storage, fast transfer into the buffer, reduced waiting and slower transfer out. The capacity qualification explains the limit; it is not an additional official mark.

Common mistakes — teacher analysis

Both RAM types are volatile. Refresh is not the same as retaining data after power is removed. A buffer does not increase the physical disk’s write speed.

Original question · Cambridge 9618/11

2. Read optical data and explain the transfer buffer

Cambridge 9618/11 · October/November 2024 · 3(d)(i), 3(d)(ii) · 7 marks

Selected parts: 3(d)(i) [4]; 3(d)(ii) [3].

Hint — reading the question

Part (i) concerns the optical device. Part (ii) concerns data waiting in memory during transfer. Keep the reading and writing process separate from the reason for the buffer.

Reasoning and model answer — teacher-written

3(d)(i): The disc rotates. An optical head positions a laser over its spiral track. During reading, a detector measures variations in the reflected light. The circuitry interprets the resulting signal to recover binary data. During recording, the write laser changes selected parts of the recording layer so that they can be distinguished when read later.

3(d)(ii): The computer and the optical drive transfer data at different rates. The buffer temporarily holds data from the computer. The drive removes the waiting data at the slower rate that it can accept. This reduces the time the computer spends waiting for the drive, so it can perform other work.

On a pressed disc, pits and lands form the reading pattern. A recordable disc instead uses laser-induced changes in its recording layer. Both provide optical differences for later reading.

Official mark scheme
Why this earns marks — teacher explanation

Part (i) awards up to four marks for distinct points about rotation, laser positioning, the spiral track and the optical reading or writing process. The official scheme uses the simplified phrase "burns pits" for recording. Distinguish the physical recording medium when explaining that phrase.

Part (ii) awards up to three marks. Link the different transfer rates to temporary storage and to the computer or drive being able to work at its own rate. A finite buffer can eventually fill; it does not increase the drive's sustained write speed.

Common mistakes — teacher analysis

A buffer is temporary memory; it is not an extra track on the optical disc. Do not claim that every pit is one bit or that the buffer makes the physical recording mechanism faster.
