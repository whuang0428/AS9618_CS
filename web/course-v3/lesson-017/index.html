01

Buffers absorb temporary differences in transfer rate

S3.04.A01

Visual overview

Core explanation

Temporary storage between different rates

A buffer temporarily holds data during transfer. It lets a sender’s burst wait while a receiver consumes data at its own rate.

Capacity and related roles
  • Finite capacity: Buffer capacity is finite. If arrivals keep exceeding removals, it fills. The sender must wait or data may be lost; buffering does not increase the receiver’s sustained rate.
  • Printer example: The printer receives blocks into a buffer while the CPU does other work. A device driver translates device-specific commands; a print queue orders waiting jobs. Neither role is the buffer itself.

02

Why RAM changes while ROM remains stable

S3.05.A01S3.05.A02

Visual overview

Core explanation

RAM is read/write primary memory used for programs and data currently being processed. Its contents change as programs start, data is edited and intermediate results are produced; ordinary RAM is volatile, so its contents are lost when power is removed.

ROM is non-volatile primary memory used for instructions that must remain available when power is removed, such as firmware or start-up instructions. During normal operation its contents are read rather than repeatedly changed, so they remain stable.

Common misconception

RAM and ROM are both primary memory. ROM is not ordinary secondary storage for a user's files.

03

SRAM and DRAM: storage method, performance and use

S3.06.A01S3.06.A02S3.06.A03S3.06.A04

Visual overview

Core explanation

SRAM stores each bit in a flip-flop circuit and does not need refresh while power is supplied. It is fast but uses more components per bit, giving lower density and higher cost per bit, so it is used for processor cache.

DRAM stores each bit as charge in a capacitor. Charge leaks, so the cells require periodic refresh; DRAM is slower but denser and cheaper per bit, so it is used for large-capacity main memory.

Common misconception

SRAM is a form of volatile primary memory; the word static does not mean non-volatile solid-state secondary storage.

04

PROM, EPROM and EEPROM

S3.07.A01S3.07.A02S3.07.A03

Visual overview

Core explanation

PROM is supplied blank and can be programmed once. EPROM can be erased using ultraviolet light and then reprogrammed, normally after removal from the system.

EEPROM can be erased and reprogrammed electrically, often while it remains in the system. All three are non-volatile ROM technologies, but their erase and rewrite methods differ.

Common misconception

PROM, EPROM and EEPROM are not interchangeable names: their programming and erasing methods are different.

02

Cambridge command words

Practice questions

Question 1 · Command word: Explain4 marks

Explain why a printer buffer can help a computer send a short burst of data to a slower printer. Explain what happens if the buffer fills.

S3.04.A01
Answer and marking points
  1. The buffer temporarily holds print data that has arrived but is not yet consumed.
  2. The printer removes that data at its own rate while the processor can perform other work.
  3. The buffer smooths a temporary difference between the sending and receiving rates.
  4. Once the buffer is full, transfer must pause or further arriving data may be lost.

Common error: Temporary storage does not make the printer's physical mechanism faster.

Question 2 · Command word: Explain4 marks

Explain two differences between RAM and ROM and give one use of each.

S3.05.A01S3.05.A02
Answer and marking points
  1. RAM is normally volatile whereas ROM is non-volatile.
  2. RAM is read/write working memory whereas ROM is normally read during operation.
  3. RAM holds active programs and data.
  4. ROM holds persistent firmware or start-up instructions.

Common error: Do not introduce SRAM and DRAM when the question asks only for RAM and ROM.

Question 3 · Command word: Compare5 marks

Compare SRAM and DRAM and explain why each is used for a different primary-memory role.

S3.06.A01S3.06.A02S3.06.A03S3.06.A04
Answer and marking points
  1. SRAM stores bits in flip-flop circuits whereas DRAM stores charge in capacitors.
  2. SRAM does not require refresh whereas DRAM requires periodic refresh.
  3. SRAM is faster but more expensive and less dense.
  4. SRAM is used for cache because fast access is required.
  5. DRAM is used for main memory because lower cost and greater density support large capacity.

Common error: Do not confuse SRAM with solid-state flash storage.

Question 4 · Command word: Explain3 marks

Explain the difference between PROM, EPROM and EEPROM.

S3.07.A01S3.07.A02S3.07.A03
Answer and marking points
  1. PROM can be programmed once.
  2. EPROM is erased using ultraviolet light before it can be reprogrammed.
  3. EEPROM is erased and reprogrammed electrically.

Common error: State the different erase or rewrite method for each memory type.

Question 1 · Command word: Explain · 4 marks

Explain how a four-block buffer handles this transfer: the sender supplies four blocks immediately, then supplies no more; the receiver removes one complete block per second. State the buffer contents after two seconds and explain whether the buffer changes the receiver's sustained rate.

Answer and marking points
  • All four blocks can wait temporarily in the buffer after the initial burst.
  • After two seconds, two blocks have been removed and two blocks remain.
  • The receiver can consume blocks at its own pace while the sender has finished its burst.
  • The receiver still removes one block per second; the buffer changes waiting capacity, not that sustained rate.

Common error: Count blocks that are still waiting; do not also count blocks already removed by the receiver.

Question 2 · Command word: Suggest · 5 marks

Suggest suitable memory for each of these requirements and justify each choice: a camera's changing working image, a processor's small low-latency cache, and a desktop computer's large affordable main memory. Compare the storage mechanism of the last two choices.

Answer and marking points
  • Use RAM for the working image because processing repeatedly reads and changes its pixel data.
  • Use SRAM for the cache because its fast access helps reduce processor waiting time.
  • Use DRAM for main memory because its higher density and lower cost per bit support the required capacity.
  • SRAM maintains a bit in a powered bistable circuit, whereas DRAM represents a bit by capacitor charge.
  • DRAM charge leaks and must be refreshed; powered SRAM maintains its state without periodic refresh.

Common error: Relate each choice to its particular workload; static RAM is still volatile.

Question 3 · Command word: Explain · 3 marks

Explain which of PROM, EPROM and EEPROM is suitable for calibration instructions that must survive shutdown and be updated electrically in the installed device. Give a reason for rejecting each of the other two types.

Answer and marking points
  • EEPROM is suitable because it retains the instructions without power and permits electrical rewriting.
  • PROM cannot meet repeated-update requirements because it is programmed only once.
  • EPROM requires ultraviolet erasure rather than the required electrical erase process in the installed device.

Common error: Non-volatility alone cannot distinguish these three choices.

04

Lesson review

Summary

Buffer

A finite store handles bursts and temporary rate differences during transfer.

RAM and ROM

RAM holds changing working data; ROM retains firmware across shutdown.

SRAM and DRAM

Latch storage favours low latency; capacitor storage favours density and cost, but needs refresh.

ROM variants

PROM: program once. EPROM: ultraviolet erase. EEPROM: electrical erase and rewrite.
