Hardware / 01

Choose the rule before memorising the symbol

Look closely

Does “either input is on” include the case where both are on?

Compare the six gate symbols. Find the output circles and the extra curved input line on XOR. For inputs 00 and 11, predict which rules might give different outputs. Later, switch inputs in Explore to check each prediction.

Step 1 / 5

Read inputs, operation and output

A logic gate applies a fixed rule to binary inputs and produces one binary output. Follow each symbol from its input connections to its output. NOT has one input; each other named gate here has two. A small circle at an output means inversion: the result is changed from 0 to 1 or from 1 to 0.

Step 2 / 5

Start with NOT and AND

NOT reverses one input: NOT 0 is 1, and NOT 1 is 0. Its symbol is a triangle with an output circle. AND requires both inputs to be 1. It has a flat input side and curved output side. If either required condition is missing, the AND output is 0.

Step 3 / 5

Compare OR with XOR

OR produces 1 when at least one input is 1, including 11. XOR, also called EOR, produces 1 when exactly one of its two inputs is 1, so it rejects 11. The OR symbol has a curved input edge; XOR adds a second curved line on the input side. That extra line is not an inversion circle.

Step 4 / 5

Invert a complete AND or OR result

NAND is NOT AND: find the AND output, then invert it. NOR is NOT OR: find the OR output, then invert it. Their symbols add an output circle to AND and OR respectively. Inverting the final result is different from placing a NOT on only one input.

Step 5 / 5

Use a row that distinguishes the rules

At AB = 11, OR gives 1 while XOR gives 0. At AB = 00, NOR gives 1 while OR gives 0. Testing only AB = 10 would not distinguish OR from XOR because both give 1. Choose a revealing example to check your explanation, then verify every possible combination.

Explain it yourself · Teacher-written check

What is the NAND output for AB = 00? Explain the operations in order.

Check your reasoning

AND of 0 and 0 is 0. NAND inverts that complete result, giving 1. It does not mean that only one input is inverted before an AND operation.

Answer and checking points — teacher-written
  1. NOT has a triangular body, one input and an output inversion circle.
  2. AND has a flat input side and rounded output side, with two inputs.
  3. OR has a curved input side and pointed output side, with two inputs.
  4. NOT outputs the opposite of its input.
  5. AND is 1 only when both inputs are 1.
  6. OR is 1 when one or both inputs are 1.

Build every row of a truth table

Look closely

How can a table prove that no input case has been overlooked?

Write the four input combinations AB = 00, 01, 10, 11. Predict which row AND accepts, then which rows NAND accepts. What evidence would show that your table includes every possible input case?

Step 1 / 5

Count independent input choices

A truth table lists every possible input combination and its output. Each binary input has two possible values, so n independent inputs produce 2ⁿ rows. One input requires two rows; two inputs require four; three require eight. Intermediate wires and extra gates do not create additional independent inputs.

Step 2 / 5

Build AND, then NAND

Step 4 / 5

Give NOT only the rows it needs

NOT has a single input A, so its table needs only two rows. A second independent input would add unnecessary duplicate cases. Keep the number of input columns tied to the circuit actually specified.

Step 5 / 5

Check completeness and behaviour separately

First check that every input combination appears once. Then check each output against the required rule. Zero-output rows matter because they show cases that must be rejected. A table with only the successful cases cannot establish correct behaviour for the remaining inputs.

Explain it yourself · Teacher-written check

A circuit contains six gates but has only three independent inputs. How many truth-table rows are required, and why?

Check your reasoning

Eight rows, because three independent binary inputs have 2³ combinations. The gates calculate intermediate values from those same inputs rather than introducing independent choices.

Hint — reading the question

Give the complete condition for output 1 or output 0, with the other cases accounted for. These are individual gates, not a request for a compound circuit.

Reasoning and model answer — teacher-written
GateOperation
NANDOutput 0 only when both inputs are 1; otherwise output 1.
NOROutput 1 only when both inputs are 0; otherwise output 0.
XOROutput 1 when the two inputs differ; otherwise output 0.
OROutput 0 only when both inputs are 0; otherwise output 1.
Official mark scheme
Why this earns marks — teacher explanation

Each correct gate operation earns one mark. Equivalent complete wording is acceptable; repeating a gate’s name does not describe its operation.

Common mistakes — teacher analysis

For XOR, “one input is 1” needs to exclude both being 1. OR does include the both-1 case.
