Logic gates, symbols and truth tables

Recognise six standard symbols, apply each gate's function and construct complete single-gate truth tables.

Which gate matches an exact output rule, and which input row proves the choice?

Before you start

For inputs 1 and 1, do OR and XOR give the same output?

Check your answer

No. OR gives 1; XOR (EOR) gives 0 because its two inputs are equal.

Teaching checkpoints

  • Build the two-input rows in order before filling the gate outputs in Q3 and Q4. Use the three independent exam tasks after checking misconceptions.

Visual overview

Core explanation

A logic gate maps binary inputs to one binary output. Read a symbol from input connections to output. NOT inverts its single input; the other gates used here each have two inputs.

AND requires both inputs to be 1. OR includes any case with at least one 1. XOR, also called EOR, accepts exactly one 1: its output is 0 when the two inputs are equal.

An output circle denotes inversion. NAND complements the complete AND result; NOR complements the complete OR result. The extra curved line on the input side distinguishes XOR from OR.

Common misconception

OR and XOR differ for 11. A NAND output is not the same as inverting only one AND input.

Core explanation

For n independent binary inputs there are 2^n combinations. A NOT table has two rows. Every other individual gate in this syllabus has four rows, conventionally 00, 01, 10, 11.

Copy the input combinations first and apply the gate's rule separately to each row. Do not omit a row whose output is 0. A compact output sequence is meaningful only when the input order is stated.

Worked example · Build the NOT table

  1. Inputs

    List A = 0, then A = 1.

  2. Apply inversion

    For A = 0 write Q = 1; for A = 1 write Q = 0.

  3. Check

    Both possible inputs have been included exactly once.

Common misconception

Two inputs mean four combinations, not two. The number of gates in a circuit does not determine its number of input rows.

Cambridge command words

Practice questions

Question 1 · Command word: Draw6 marks

Draw and label the symbols for NOT, AND and OR. State the output condition for each.

S3.10.A01S3.10.A02S3.10.A03
Answer and marking points
  1. NOT has a triangular body, one input and an output inversion circle.
  2. AND has a flat input side and rounded output side, with two inputs.
  3. OR has a curved input side and pointed output side, with two inputs.
  4. NOT outputs the opposite of its input.
  5. AND is 1 only when both inputs are 1.
  6. OR is 1 when one or both inputs are 1.

Common error: Connections must meet the correct sides of the symbols.

Question 2 · Command word: Draw3 marks

Draw and label NAND, NOR and XOR symbols. Explain how each is distinguished from its related AND or OR symbol.

S3.10.A04S3.10.A05S3.10.A06
Answer and marking points
  1. NAND uses the AND outline with a small output circle.
  2. NOR uses the OR outline with a small output circle.
  3. XOR uses the OR outline with an extra curve on the input side and no output circle.

Common error: An extra curve is not an inversion bubble.

Question 3 · Command word: Construct4 marks

Construct the truth tables for NAND and NOR using input order 00,01,10,11. State the NOT outputs for input order 0,1.

S3.10.A07
Answer and marking points
  1. The two-input tables contain 00, 01, 10 and 11.
  2. NAND outputs are 1, 1, 1, 0.
  3. NOR outputs are 1, 0, 0, 0.
  4. NOT outputs are 1, 0.

Common error: Invert the gate result after evaluating AND or OR.

Question 4 · Command word: Construct4 marks

Construct an XOR truth table. Compare it with OR and identify the input combination that distinguishes the two gates.

S3.10.A06S3.10.A07
Answer and marking points
  1. The input rows are 00, 01, 10 and 11.
  2. XOR gives 0, 1, 1 and 0.
  3. OR gives 0, 1, 1 and 1.
  4. Only row 11 distinguishes the two output columns.

Common error: The word ‘or’ in ordinary language must be interpreted against the stated output rule.

Question 1 · Command word: Draw · 4 marks

Draw the symbol for a NAND gate and label its two inputs A and B and output Q. State Q for A,B = 1,1 and explain the role of the small output circle.

Answer and marking points
  • The main gate outline is the standard AND shape with two input connections.
  • A small inversion circle is placed at its output before the Q connection; inputs are labelled A and B.
  • Q is 0 when both inputs are 1.
  • The circle complements the AND result, giving the NAND function.

Common error: The inversion circle must be on the output, not on just one input.

Question 2 · Command word: Identify · 5 marks

Identify the two-input gate for each rule and justify the choice: P is 1 only when both inputs are 0; R is 1 when at least one input is 1, including when both are 1. State the output of a NOT gate for input 0.

Answer and marking points
  • P uses NOR.
  • NOR produces 1 for 00 and 0 for the other three combinations.
  • R uses OR.
  • OR includes the 11 combination, unlike XOR.
  • The NOT output is 1.

Common error: Use the complete rule, especially the both-inputs-equal cases.

Question 3 · Command word: Construct · 4 marks

Construct truth tables for Q = A AND B and R = A XOR B, using input order 00, 01, 10, 11. Identify every row where Q and R differ.

Answer and marking points
  • The four input combinations appear once each in the stated order.
  • The AND output column Q is 0, 0, 0, 1.
  • The XOR output column R is 0, 1, 1, 0.
  • The outputs differ at 01, 10 and 11.

Common error: A truth table must include all input rows, including 00.

04

Lesson review

Summary

Symbol clues

An output circle inverts; an extra input curve identifies XOR.

Output rules

AND: both; OR: at least one; XOR: exactly one of two.

Inverted functions

NAND is NOT AND; NOR is NOT OR.

Complete tables

Use both NOT rows and all four rows for each two-input gate.
