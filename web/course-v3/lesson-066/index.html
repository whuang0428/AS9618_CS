The definition and purpose of an abstract data type

S10.08.A01

Visual overview

Core explanation

An abstract data type (ADT) is a collection of data and a set of operations on those data. The permitted operations and their effects define the ADT; its internal storage can change without changing that behaviour. Stack, queue and linked list are examples of ADTs.

An abstract data type is a collection of data and a set of operations on those data. Stack, queue and linked list are examples whose permitted operations define their behaviour.

Common misconception

An abstract data type is defined by its permitted operations and behaviour, not by one fixed implementation such as an array.

Command word: Describe6 marks

For array implementations of a stack, queue and linked list, describe how data is added, edited and deleted while preserving each ADT's rule.

S10.08.A01
Answer and marking points
  1. stack push/pop uses the top position and stack pointer.
  2. queue enqueue/dequeue uses rear and front in FIFO order.
  3. linked-list add obtains a free index and changes links.
  4. edit changes a stored data field without corrupting order or links.
  5. linked-list delete bypasses the node and returns its index to the free list.
  6. distinguishes conceptual operations from the non-required task of writing their pseudocode.

Common error: Do not repeat the same point in different words; each mark needs a separate idea or method step.

Command word: Write2 marks

Must candidates write pseudocode for stack, queue and linked-list operations?

S10.08.A01
Answer and marking points
  1. No.
  2. They must be able to add, edit and delete data and describe array implementations, but operation pseudocode is not required by the syllabus.

Common error: Do not copy the worked example unchanged; transfer the method and check it against the new context.
