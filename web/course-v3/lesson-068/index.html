Queues and FIFO operations

Arrival order remains consistent even when a circular array reuses earlier positions.

How does a queue preserve arrival order when array positions are reused?

Before you start

Jobs A, B and C arrive in that order at a first-come, first-served printer. Which is removed first?

Check your answer

A, the earliest job still waiting. This is FIFO.

Core explanation

A queue is a first-in, first-out structure. ENQUEUE adds at the rear and DEQUEUE removes and returns the front item. A new arrival joins behind the items already waiting, so serving the front preserves arrival order.

A first-come, first-served print queue or service desk suits FIFO. The requirement concerns waiting items: a job already removed is no longer in the queue. An ordinary FIFO queue does not automatically move a later urgent job ahead of earlier arrivals; that would require different scheduling rules.

Worked example · Serve arrivals without reordering

  1. Arrivals

    Requests 12, 15 and 18 join the rear in that order.

  2. Service

    Two dequeues return 12, then 15.

  3. Later arrival

    Enqueue 21 leaves 18 at the front and 21 at the rear.

Common misconception

A queue does not remove the newest arrival first; that is stack behaviour.

Check your understanding

After A is served and C joins behind B, which item is next?

Check your answer

B remains at the front and is served before C.

Use front, rear and count consistently

Core explanation

Swipe horizontally to compare every column →

Maintain FIFO when indices wrap
  1. ENQUEUE: If not full, advance Rear, wrapping from capacity to 1; store the item and increase Count.
  2. DEQUEUE: If not empty, read Front; advance it with wrap-around and decrease Count.
Keep logical order separate from storage order

An allowed edit changes an active item’s value without changing its arrival position or Count. Physical array order can differ from FIFO order: start at Front and follow the active circular positions. Inactive cells are not waiting items.

Common misconception

Physical array order need not equal FIFO order after wrapping; begin at Front and follow the circular positions.

Check your understanding

In the final diagram state, what are the next three dequeue results?

Check your answer

B, C, D: start at Front = 2, then use indices 3 and 1.

Question 1 · Command word: State2 marks

A queue receives ENQUEUE 6, ENQUEUE 2, DEQUEUE, ENQUEUE 9, DEQUEUE. State both returned values and the remaining item.

S10.09.A02
Answer and marking points
  1. The dequeues return 6 and then 2.
  2. 9 remains waiting.

Common error: Remove the earliest item still present.

Question 2 · Command word: Describe3 marks

A circular queue has capacity 3 with Front = 2, Rear = 3, Count = 2; indices 2 and 3 hold B and C. Describe enqueueing D.

S10.10.A02S10.10.A04
Answer and marking points
  1. Rear wraps from 3 to 1 and D is stored at index 1.
  2. Count becomes 3 and Front remains 2.
  3. The logical order is B, C, D.

Common error: Wrapping does not make D the next item to be served.

Question 3 · Command word: State3 marks

An allowed edit changes a queued job's filename without changing its position. State which data changes and which of Front, Rear and Count change. Explain why FIFO is preserved.

S10.09.A02S10.10.A02S10.10.A04
Answer and marking points
  1. Only the filename stored in the selected active item changes.
  2. Front, Rear and Count remain unchanged.
  3. The job remains in the same arrival position, so dequeue order is preserved.

Common error: Editing a value is not the same operation as removing and re-enqueueing a job.

Question 1 · Command word: State · 3 marks

Three patients arrive at an appointment desk in order Kim, Lee, Mo. The desk serves Kim, then Pat joins. State the order of the next three services and justify a suitable ADT for the stated first-come, first-served rule.

Answer and marking points
  • The next services are Lee, Mo and Pat, in that order.
  • A queue adds Pat at the rear and removes the earliest waiting patient from the front.
  • FIFO therefore preserves the arrival order of the remaining patients.

Common error: No priority rule has been specified; do not introduce one.

Question 2 · Command word: State · 4 marks

A circular queue uses indices 1 to 4. Front = 4, Rear = 2 and Count = 3; positions 4, 1, 2 hold J, K, L. State the returned value and final pointers, count and logical order after one dequeue followed by enqueue M.

Answer and marking points
  • Dequeue returns J and wraps Front to 1; Count becomes 2.
  • Enqueue advances Rear to 3 and stores M there.
  • Final Front = 1, Rear = 3 and Count = 3.
  • The logical order is K, L, M.

Common error: Advance the pointer belonging to the operation being performed.

Question 3 · Command word: Explain · 3 marks

A capacity-4 circular queue has Count = 4. Explain how it should handle an enqueue, then describe how an allowed edit of the front item's value differs from a dequeue.

Answer and marking points
  • Reject enqueue because all four positions are active; do not overwrite a waiting item.
  • An edit overwrites the value at Front but leaves Front and Count unchanged.
  • A dequeue returns and removes that item, advances Front and decreases Count.

Common error: A full queue may still permit an in-place value edit.

04

Lesson review

Summary

FIFO

Enqueue at the rear and dequeue from the front to preserve arrival order.

Circular storage

Wrap indices to reuse space and use Count to distinguish empty and full states.

Logical order

Read active items from Front, even when their array positions wrap around.
