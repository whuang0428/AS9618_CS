Knowledge block 1 / 4

Where does the operand value come from?

THINK

Memory[100]=150 and Memory[150]=7. What does LDI 100 load?

LEARN

Choose immediate, direct, indirect, indexed or relative; inspect every followed address before revealing the result.

APPLY

Immediate check

For LDI 100 in that memory, is ACC 150 or 7?

Reveal answer

ACC becomes 7 after following the pointer at 100 to address 150.

Exam transfer · teacher-written

Question 3 · Command word: Calculate6 teacher marks

Calculate the loaded operand value for immediate #200, direct 200, indirect 200 and indexed 200 with IX=3, given Memory[200]=250, Memory[250]=18 and Memory[203]=44. Calculate a relative target using a supplied PC base of 90 and displacement −6. Explain the distinction between an effective address and its contents.

S4.14.A01S4.14.A02
Answer and checking points — teacher-written
  1. Immediate #200 supplies value 200 without a memory lookup.
  2. Direct 200 loads Memory[200], which is 250.
  3. Indirect 200 follows address 250 and loads Memory[250], which is 18.
  4. Indexed 200 uses effective address 203 and loads value 44.
  5. Relative target = 90 + (−6) = 84.
  6. An effective address identifies a location; the operand value is the data obtained from that location when the operation reads memory.

Common error: For relative addressing use the stated PC base, not an assumed before-fetch or after-fetch convention.

Knowledge block 2 / 4

Which machine state changes?

THINK

Does CMP #0 change ACC, and does JPN mean a negative number?

LEARN

Select an official instruction. Inspect its operand source, destination and changed state.

APPLY

Immediate check

After ACC=5 and CMP #5, what changes?

Reveal answer

The comparison becomes True; ACC remains 5.

Exam transfer · teacher-written

Question 6 · Command word: Identify5 teacher marks

Identify the instruction group for each set: LDM/LDD/LDI/LDX/LDR/MOV/STO; IN/OUT; ADD/SUB/INC/DEC; JMP/JPE/JPN; CMP/CMI. Distinguish unconditional from conditional control within the fourth set.

S4.12.A01S4.12.A02S4.12.A03S4.12.A04S4.12.A05
Answer and checking points — teacher-written
  1. LDM, LDD, LDI, LDX, LDR, MOV and STO: data movement.
  2. IN and OUT: input and output of data.
  3. ADD, SUB, INC and DEC: arithmetic operations.
  4. JMP is unconditional control; JPE and JPN are conditional control.
  5. CMP and CMI: compare operations, which supply the result used by conditional jumps.

Common error: A comparison records a result; it does not by itself change PC to a branch target.

Exam Challenge

Bring together the model and the written explanation. Attempt the task before revealing the teacher’s answer.

Memory[100]=150, Memory[150]=7. A program executes LDI 100, CMP #7, JPN 20, OUT, END. Assume ACC initially 0 and output uses ASCII. Identify the loaded value, branch path and output issue.

Teacher-written model answer
  1. LDI follows 100 to 150 and loads 7 into ACC.
  2. CMP #7 gives True without changing ACC, so JPN is not taken.
  3. OUT attempts ASCII code 7, a control character rather than the printed digit 7; input/output values need character interpretation.

Original question · Cambridge 9618/12

1. Trace an indexed loop with character input and output

Cambridge 9618/12 · October/November 2023 · 9(b) · 4 marks

Selected parts: 9(b) [4].

Reading the question — teacher guidance

Input is the character “1”, whose supplied ASCII value is 49. Follow executed addresses, including the second visit to 13–15. The comparison does not change ACC.

Solution / model answer — teacher-written

LDR sets IX to 0. IN places 49 in ACC, and STO 101 saves it. The first indexed load reads location 110 + 0 = 110, giving 51. This does not equal Memory[100]=0, so JPE is not taken. The program reloads 49, adds 16 to obtain 65, increments IX to 1 and stores 65 in location 100.

On the second visit, LDX reads location 111 and gets 65. It now equals Memory[100], so JPE goes to 21. OUT emits the character with ASCII code 65, which is A, and END returns control to the operating system.

Official mark scheme
Why this earns marks — teacher explanation

The official answer awards one mark for each of four groups of rows, identified by its bands: addresses 10–12; first 13–16; 17–20; then the second 13–15 and 21–22. It does not give a mark for each instruction or each filled cell. Keep the complete grouped official table when checking the trace.

Common mistakes — teacher analysis

Using numeric 1 instead of ASCII 49 changes the calculation. Forgetting the new IX makes the second LDX read the wrong cell. OUT prints A, not the digits 65.
