Processor fundamentals · Concept 01

Use the operand itself or read a location

Observe

Start with a question

Why do LDM #4 and LDD 4 give different answers?

Memory[4] contains 18. One instruction gives the processor the number 4 directly; the other uses 4 to find a stored value. Predict ACC after each instruction independently.

Explain

Explanation · 1 / 4

Read an immediate value

An immediate operand supplies the value itself. LDM #4 copies the denary value 4 into ACC without a data-memory read for that value. Fetching the instruction is still a separate memory access. The # prefix means denary in the supplied syntax.

Explanation · 2 / 4

Read a directly addressed value

Direct addressing uses the operand as the address of the data. LDD 4 selects address 4, then loads its contents, 18. The selected location is called the effective address. The effective address and the value obtained there are different things.

Explanation · 3 / 4

Recognise three immediate notations

The example instruction set uses # for denary, B for binary and & for hexadecimal immediate values. #15, B00001111 and &0F all represent the value fifteen. With an instruction that accepts those forms, they provide the same immediate value.

InstructionHow the operand is usedACC afterwards
LDM #4Use value 44
LDD 4Read Memory[4]18
LDM B00001111Use binary value fifteen15
LDM &0FUse hexadecimal value fifteen15

Explanation · 4 / 4

Keep the source

A load copies a value. LDD 4 does not empty Memory[4]. A later STO 6 copies ACC into Memory[6] without clearing ACC. Record only the destination that the instruction changes.

Processor fundamentals · Concept 02

Follow a pointer or add an index

Observe

Start with a question

Does the first memory read give the data, or tell us where the data is?

In this separate addressing example, Memory[100] = 150, Memory[150] = 7 and Memory[102] = 9. IX = 2. Compare direct, indirect and indexed loads using operand 100.

Explain

Explanation · 1 / 4

Follow an indirect address

A pointer is a value used as the address of another location. LDI 100 first reads Memory[100], obtaining pointer 150. It then reads Memory[150], obtaining 7 for ACC. The first read gives the effective address; the second gives the data.

Explanation · 2 / 4

Add an index

Indexed addressing adds the index register to the instruction’s base address. LDX 100 with IX = 2 forms effective address 102 and reads the value 9. It does not follow the pointer 150 at address 100, and it does not load 102 as the final data value.

Explanation · 3 / 4

Walk along adjacent items

If a list starts at address 100, IX = 0 selects the first item, IX = 1 selects the next, and IX = 2 selects the third in this one-location-per-item model. Changing IX allows the same LDX instruction to access a different item.

Explanation · 4 / 4

Compare from the same initial state

Reset the example before each independent load. Direct uses the specified address; indirect follows the stored pointer; indexed calculates a location using IX.

Processor fundamentals · Concept 03

Change the index and locate a relative target

Observe

Start with a question

Which register changes when the instruction says LDR #2 or MOV IX?

ACC = 9 and IX = 0. LDR #2 puts an immediate value into IX; MOV IX then copies ACC into IX. Follow the destination, not just the number in the instruction.

Explain

Explanation · 1 / 4

Distinguish register destinations

LDM #n places n into ACC. LDR #n places n into IX. MOV IX copies ACC into IX, leaving ACC unchanged. The instruction’s defined effect determines the destination; MOV IX does not mean copy IX into ACC.

InstructionEffect
LDM #nACC ← n
LDR #nIX ← n
MOV IXIX ← ACC
LDD aACC ← Memory[a]
LDI aACC ← Memory[Memory[a]]
LDX aACC ← Memory[a + IX]
STO aMemory[a] ← ACC

Explanation · 2 / 4

Recalculate after a change

After LDR #2, an indexed load uses offset 2. If MOV IX then copies ACC = 9 into IX, the next indexed load uses offset 9. Resolve the effective address using the current IX, not the value it had at the start of the program.

Explanation · 3 / 4

Form a relative address

Relative addressing adds a signed displacement to a stated PC base. A displacement is an offset that can be positive or negative. If the given PC base is 40 and the displacement is −5, the target address is 35. For a relative branch, this target selects the next instruction rather than loading Memory[35] into ACC.

Explanation · 4 / 4

State the base convention

Use the PC value specified by the question, including any fetch increment already included in it. The example instruction list does not supply a separate relative-jump mnemonic, so these calculations name the base and displacement explicitly. Without the base, an offset alone does not determine a unique target.

Processor fundamentals · Concept 04

Calculate a value and output its character

Observe

Start with a question

If ACC contains 66, does OUT print B or the digits 66?

Recall that a character code represents a character using a number. In the supplied ASCII subset, A = 65, B = 66 and C = 67. Predict the effect of reading A, adding 1 and outputting the result.

Explain

Explanation · 1 / 4

Resolve before adding or subtracting

ADD and SUB combine ACC with an immediate value or the contents of a direct address and keep the result in ACC. With ACC = 10, ADD B00000101 gives 15 and SUB &03 then gives 12. ADD 330 would instead add Memory[330].

Explanation · 2 / 4

Change only the named register

INC increases the named register by one; DEC decreases it by one. INC IX changes IX, while DEC ACC changes ACC. Retain the other register’s value in a trace. Do not assume an unspecified word width or wrap rule.

Explanation · 3 / 4

Read and output one character

IN reads one character and stores its ASCII value in ACC. OUT outputs the character represented by the value in ACC. Input A supplies 65; ADD #1 makes 66; OUT emits B. This OUT instruction does not convert a number to printed decimal digits.

Explanation · 4 / 4

Terminate explicitly

END finishes the program and returns control to the operating system. A complete trace includes this executed instruction and does not continue into later data or unused instructions.

0  IN
1  ADD #1
2  OUT
3  END

Processor fundamentals · Concept 05

Make a comparison, then choose a path

Observe

Start with a question

Why can JPN take a branch even when ACC is positive?

Compare input A, ASCII 65, with the expected value 65. Now reset and try B, ASCII 66. The decision is equality, not whether the input code is negative.

Explain

Explanation · 1 / 5

Compare without replacing ACC

CMP compares ACC with an immediate value or a directly addressed value. CMI compares ACC with an indirectly addressed value. Both record whether the values are equal; neither loads the compared value into ACC. Keep a separate last-comparison entry in a trace.

Explanation · 2 / 5

Use the comparison

JPE jumps to its target when the preceding comparison is True, meaning equal. JPN jumps when that comparison is False, meaning not equal. If the condition is not met, execution continues at the next sequential address. JMP is unconditional and always chooses its target when executed.

Explanation · 3 / 5

Read a complete decision

The source below reads a character. CMI 340 follows Memory[340] = 341 to Memory[341] = 65. Equal input follows the addition path; unequal input goes to REJECT. SEND names the shared output instruction.

180  IN
181  CMI 340
182  JPN REJECT
183  ADD #1
184  CMP #66
185  JPE SEND
186  REJECT: LDM #63
187  SEND: OUT
188  END

Explanation · 4 / 5

Follow the address actually chosen

For input A, CMI gives True, so JPN is not taken. ADD #1 gives 66; CMP #66 gives True; JPE SEND goes to 187 and skips the rejection assignment. For input B, the first comparison is False and JPN selects 186 immediately.

Explanation · 5 / 5

Retain only executed rows

Record a row for each instruction that executes. A skipped line has no row and no effect. The comparison column records the last explicit CMP or CMI; do not replace it with a guess about a different processor’s flags.

Follow a loop through its final test

Observe

Start with a question

How many trace rows can come from one line of source code?

The countdown starts at 2, subtracts 1, compares with 0 and repeats while unequal. Before calculating the table, predict how many times DEC and JPN execute.

Explain

Explanation · 1 / 5

Write the initial conditions

A trace records the state after each executed instruction. Here PC = 20, ACC = 0, IX = 0 and Memory[90] = 67. No input is needed. Each instruction occupies one address. The initial values belong above the table; do not invent zero for unspecified registers in another question.

020  LDM #2
021  LOOP: DEC ACC
022  CMP #0
023  JPN LOOP
024  LDD 90
025  OUT
026  END

Explanation · 2 / 5

Trace the first loop visit

LDM #2 gives ACC = 2. DEC ACC gives 1. CMP #0 records False. JPN LOOP therefore sets PC to 21. Record all four executed instructions; the next row returns to address 21 rather than moving down the printed listing.

Explanation · 3 / 5

Trace the visit that exits

The second DEC gives 0. CMP #0 now records True. JPN is still executed, but its branch is not taken, so PC becomes 24. A loop trace must include this final condition test; otherwise it does not show why repetition ends.

Explanation · 4 / 5

Continue after the loop

LDD 90 replaces the zero counter with 67. OUT emits C and END terminates. ACC is therefore 67 at the end, even though it was zero at loop exit. IX stays 0 and Memory[90] stays 67.

Explanation · 5 / 5

Use the same method on longer programs

For every row: obtain the instruction at the current PC, resolve its operand using the current registers and memory, apply only its defined changes, and select the next PC. Record stores and output when they occur. Repeated addresses produce repeated rows; skipped addresses produce none.

Original question · Cambridge 9618/12

1. Trace an indexed loop with character input and output

Cambridge 9618/12 · October/November 2023 · 9(b) · 4 marks

Selected parts: 9(b) [4].

Hint — reading the question

Input is the character “1”, whose supplied ASCII value is 49. Follow executed addresses, including the second visit to 13–15. The comparison does not change ACC.

Reasoning and model answer — teacher-written

LDR sets IX to 0. IN places 49 in ACC, and STO 101 saves it. The first indexed load reads location 110 + 0 = 110, giving 51. This does not equal Memory[100]=0, so JPE is not taken. The program reloads 49, adds 16 to obtain 65, increments IX to 1 and stores 65 in location 100.

On the second visit, LDX reads location 111 and gets 65. It now equals Memory[100], so JPE goes to 21. OUT emits the character with ASCII code 65, which is A, and END returns control to the operating system.

Official mark scheme
Why this earns marks — teacher explanation

The official answer awards one mark for each of four groups of rows, identified by its bands: addresses 10–12; first 13–16; 17–20; then the second 13–15 and 21–22. It does not give a mark for each instruction or each filled cell. Keep the complete grouped official table when checking the trace.

Common mistakes — teacher analysis

Using numeric 1 instead of ASCII 49 changes the calculation. Forgetting the new IX makes the second LDX read the wrong cell. OUT prints A, not the digits 65.

Explanation · 1 / 3

Group copies and calculations

Data-movement instructions copy values between registers and memory. Arithmetic instructions calculate a new value. STO is movement because it copies ACC into a memory location; ADD is arithmetic because it changes the working result.

Explanation · 2 / 3

Separate comparison from control

CMP and CMI compare values. JMP, JPE and JPN control which instruction executes next. A comparison may support a decision, but it is not itself a conditional jump.

Explanation · 3 / 3

Identify external input and output

IN obtains a character and OUT emits a character, so they belong to input/output. Writing a value into ordinary working memory with STO does not make STO a character-output instruction.

Answer and checking points — teacher-written
  1. LDM, LDD, LDI, LDX, LDR, MOV and STO: data movement.
  2. IN and OUT: input and output of data.
  3. ADD, SUB, INC and DEC: arithmetic operations.
  4. JMP is unconditional control; JPE and JPN are conditional control.
  5. CMP and CMI: compare operations, which supply the result used by conditional jumps.

Common error: A comparison records a result; it does not by itself change PC to a branch target.

Topic recap
  • Use the operand itself or read a location

    Immediate supplies a value. Direct supplies the address of the value.

  • Follow a pointer or add an index

    Indirect: follow a stored address. Indexed: add IX to the base, then read the selected contents.

  • Change the index and locate a relative target

    Copy to the specified destination. For relative addressing, add the signed displacement to the stated PC base.

  • Calculate a value and output its character

    ADD/SUB update ACC; INC/DEC update the named register; IN/OUT use character codes.

  • Make a comparison, then choose a path

    CMP/CMI establish equality. JPE uses True; JPN uses False; JMP is unconditional.

  • Follow a loop through its final test

    Trace execution order, carry unchanged state forward, repeat loop rows and include termination.

  • Classify instructions by their effects

    Movement, input/output, arithmetic, control and compare are distinct instruction groups.
