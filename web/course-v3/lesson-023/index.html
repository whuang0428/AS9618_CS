Knowledge block 1 / 2

What does register-transfer notation point to?

THINK

PC contains 40. Does MDR ← [[MAR]] copy the address 40 or what is stored at address 40?

LEARN

Follow the pointer from a register’s contents to the memory cell. Copy the cell contents into MDR.

APPLY

Immediate check

If MAR=40 and Memory[40]=LDD 600, what enters MDR?

Reveal answer

LDD 600, the contents of location 40.

Exam transfer · teacher-written

Question 1 · Command word: Use4 teacher marks

Use register-transfer notation to show the fetch stage when PC=120 and Memory[120] contains LDD 500. Instructions occupy one address. Include the read control signal and state PC and CIR after the fetch.

S4.07.A02S4.07.A01
Answer and checking points — teacher-written
  1. MAR ← [PC], so MAR becomes 120.
  2. The CU issues a memory-read signal and MDR ← [[MAR]], loading LDD 500.
  3. CIR ← [MDR], so CIR contains LDD 500.
  4. PC ← [PC] + 1, so PC becomes 121; the increment may overlap other fetch transfers.

Common error: Fetch transfers the instruction to CIR, not to PC.

Knowledge block 2 / 2

How does one instruction flow through the processor?

THINK

After fetching LDD 4, PC is 1. Which instruction is in CIR, and has the data at 4 been loaded yet?

LEARN

Use Next micro-step, Next instruction, Run, Pause and Reset on a shared CPU and memory state.

APPLY

Immediate check

After fetch, why can PC=1 while CIR=LDD 4?

Reveal answer

PC has advanced to the next sequential address; CIR retains the current instruction for execution.

Exam transfer · teacher-written

Question 2 · Command word: Describe4 teacher marks

Describe the decode and execute stages for CIR=STO 510 and ACC=36. Use register-transfer notation for the memory write and state whether the ACC changes.

S4.07.A01S4.07.A02
Answer and checking points — teacher-written
  1. The CU decodes STO as a store operation with destination address 510.
  2. MAR ← 510 and MDR ← [ACC], so MDR becomes 36.
  3. The CU issues a write signal and [[MAR]] ← [MDR], placing 36 at address 510.
  4. ACC remains 36; storing copies its contents to memory.

Common error: A memory write uses MDR as the transferred value, not as the destination address.

Exam Challenge

Bring together the model and the written explanation. Attempt the task before revealing the teacher’s answer.

PC=0 and Memory[0]=LDD 4, Memory[4]=18. Show the fetch transfers and explain why loading the operand needs a further memory read.

Teacher-written model answer
  1. MAR receives [PC]=0; memory read transfers LDD 4 into MDR and CIR; PC advances to 1.
  2. During execute, MAR receives 4 and MDR receives 18 from Memory[4].
  3. ACC becomes 18; the first read fetched the instruction and the second fetched its data.

Original question · Cambridge 9618/13

1. Translate descriptions into register-transfer notation

Cambridge 9618/13 · May/June 2023 · 7(c) · 2 marks

Selected parts: 7(c) [2].

Teacher solution and explanation

An arrow means assignment. Square brackets mean contents, so reading memory via an address held in MAR needs two levels of contents.

StageRegister-transfer notation
Increment PCPC ← [PC] + 1
Read the memory location addressed by MAR into MDRMDR ← [[MAR]]

The inner [MAR] is the stored address. The outer brackets mean the contents of memory at that address.

Each correctly written transfer earns one mark. The second notation expresses a memory read rather than copying the address itself.

MDR ← [MAR] copies the address value, not the memory contents requested. PC ← 1 overwrites the counter instead of incrementing it.

Original question · Cambridge 9618/13

2. Explain MAR and MDR through instruction fetch

Cambridge 9618/13 · October/November 2025 · 6(b) · 4 marks

Selected parts: 6(b) [4].

Reading the question — teacher guidance

Connect the two registers to the fetch-execute sequence. Give the source of the address and the destination of the fetched instruction.

Solution / model answer — teacher-written

MAR holds the address of the memory location to be read or written. During instruction fetch it receives the next instruction address from PC. The instruction at that memory address is read into MDR. It then passes from MDR to CIR for decoding and execution. When executing a data read/write, MAR and MDR carry the required operand address and transferred value.

Official mark scheme
Why this earns marks — teacher explanation

The four listed points are the MAR role, the address from PC, the MDR role and passing the instruction to CIR. The final sentence distinguishes operand access from instruction fetch; it does not add marks.

Common mistakes — teacher analysis

Do not say that the operand address always comes from PC: the PC supplies the instruction address during fetch. MDR does not select a memory location.
