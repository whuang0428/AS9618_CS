Check your answer

01

Fetch using register-transfer notation

S4.07.A01S4.07.A02

Visual overview

Core explanation

Follow the instruction address

In this notation, [PC] means the contents of PC and [[MAR]] means the contents of the memory location whose address is in MAR. The arrow points towards the destination. MAR ← [PC] therefore copies the next instruction address into MAR.

Move the instruction into CIR

The CU issues a memory-read signal; the instruction from the selected location travels to MDR and is copied to CIR. PC advances to the next sequential address. For these examples each instruction occupies one location, so the increment is one. Some fetch operations can overlap; the instruction must reach MDR before it can be copied from MDR to CIR.

Worked example · Fetch from address 200

  1. Given

    PC=200; Memory[200] contains LDD 700; instructions occupy one location.

  2. Address and read

    MAR ← [PC] gives 200. After the read signal, MDR ← [[MAR]] gives LDD 700.

  3. Retain and advance

    CIR ← [MDR] retains LDD 700. PC ← [PC] + 1 gives 201.

Common misconception

There is no MDR → PC instruction transfer in the standard fetch sequence.

Check your understanding

What does [[MAR]] mean when MAR=700?

Check your answer

The value stored in memory location 700, not the number 700 itself.

02

Decode, execute and select the next instruction

S4.07.A01S4.07.A02

Visual overview

Core explanation

The decoded instruction determines the work
  • Load or store: A load reads a value; a store writes a value.
  • Arithmetic: The CU coordinates the necessary transfers and ALU calculation.
  • Jump: A taken jump replaces PC, so the next instruction need not be adjacent.
Distinguish operand access from instruction fetch

The example has already fetched LDD 700 into CIR. Execution reads the operand 45 into MDR and copies it to ACC; it does not increment PC again. At the end of the cycle, check pending enabled interrupts before normal instruction processing continues.

Worked example · Execute the fetched load

  1. Given

    CIR contains LDD 700, PC=201 and Memory[700]=45.

  2. Decode and read operand

    The CU selects load-direct; MAR becomes 700 and a new read transfers 45 to MDR.

  3. Finish

    ACC ← [MDR] gives 45. PC remains 201 unless an interrupt is accepted before normal execution continues.

Common misconception

Fetching an instruction is separate from fetching a data operand needed to execute it.

Check your understanding

Why can a load instruction require two memory reads in one complete cycle?

Check your answer

One fetches the instruction; the other reads the data at its operand address.

Practice questions

Question 1 · Command word: Use4 marks

Use register-transfer notation to show the fetch stage when PC=120 and Memory[120] contains LDD 500. Instructions occupy one address. Include the read control signal and state PC and CIR after the fetch.

S4.07.A02S4.07.A01
Answer and marking points
  1. MAR ← [PC], so MAR becomes 120.
  2. The CU issues a memory-read signal and MDR ← [[MAR]], loading LDD 500.
  3. CIR ← [MDR], so CIR contains LDD 500.
  4. PC ← [PC] + 1, so PC becomes 121; the increment may overlap other fetch transfers.

Common error: Fetch transfers the instruction to CIR, not to PC.

Question 2 · Command word: Describe4 marks

Describe the decode and execute stages for CIR=STO 510 and ACC=36. Use register-transfer notation for the memory write and state whether the ACC changes.

S4.07.A01S4.07.A02
Answer and marking points
  1. The CU decodes STO as a store operation with destination address 510.
  2. MAR ← 510 and MDR ← [ACC], so MDR becomes 36.
  3. The CU issues a write signal and [[MAR]] ← [MDR], placing 36 at address 510.
  4. ACC remains 36; storing copies its contents to memory.

Common error: A memory write uses MDR as the transferred value, not as the destination address.

Question 3 · Command word: Explain3 marks

Explain the error in the proposed fetch transfer PC ← [MDR]. Give the correct instruction destination and explain when a different value may legitimately be loaded into PC.

S4.07.A01S4.07.A02
Answer and marking points
  1. During fetch, MDR contains the instruction read from memory, not normally the next instruction address.
  2. Use CIR ← [MDR] to retain that instruction for decoding.
  3. An executed jump may load its target address into PC to change instruction order.

Common error: Do not confuse a branch during execution with the standard fetch transfers.

Question 1 · Command word: Use · 5 marks

Use register-transfer notation to fetch the instruction ADD 710 from address 88. PC initially contains 88 and instructions occupy one location. Explain how Memory[710]=9 is then added to ACC=4 during execution.

Answer and marking points
  • MAR ← [PC] selects location 88; a read signal causes MDR ← [[MAR]].
  • CIR ← [MDR] retains ADD 710, and PC ← [PC] + 1 gives 89.
  • The CU decodes ADD and sets MAR ← 710 for the operand read.
  • After the read signal, MDR ← [[MAR]] supplies operand 9.
  • ACC ← [ACC] + [MDR] produces 13.

Common error: Fetching ADD 710 and reading its operand require separate memory reads.

Question 2 · Command word: Describe · 4 marks

Describe what happens after JMP 450 has been fetched from location 90. Explain why a trace may show PC=91 during fetch but PC=450 after execution.

Answer and marking points
  • Sequential fetch advances the address with PC ← [PC] + 1, giving 91.
  • The CU decodes the current instruction as an unconditional jump.
  • Execution loads the target with PC ← 450.
  • The next fetch uses address 450 rather than 91.

Common error: A PC increment does not prevent a later jump from replacing the next address.

Question 3 · Command word: Explain · 4 marks

Explain why this proposed memory-write notation is wrong: MAR ← [ACC]; [[MDR]] ← 620. Give the correct transfers for storing ACC=58 at address 620 and identify the control signal.

Answer and marking points
  • MAR must hold the destination address, so use MAR ← 620.
  • MDR must hold the transferred value, so use MDR ← [ACC] to copy 58.
  • Use [[MAR]] ← [MDR] to store 58 in the selected location.
  • The CU issues a memory-write signal on the control bus.

Common error: An address belongs in MAR and the value being written belongs in MDR.

04

Lesson review

Summary

Fetch

Copy the next address to MAR, read the instruction through MDR to CIR, and advance PC.

Decode/execute

The CU identifies the operation and coordinates its required transfers or ALU work.

Control flow

A jump can replace the sequential PC; interrupt checking follows the current instruction.
