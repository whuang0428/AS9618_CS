Knowledge block 1 / 3

What does the processor execute?

THINK

Does the CPU execute the letters in LDD TOTAL?

LEARN

Compare symbolic assembly, resolved assembly and a machine word without inventing official opcode bits.

APPLY

Immediate check

Can opcode bits be inferred from the letters LDD?

Reveal answer

No. A target instruction set must specify its binary encoding.

Exam transfer · teacher-written

Question 3 · Command word: Compare4 teacher marks

Compare assembly language with machine code. Explain why assembly written for one processor instruction set may not run on a processor with a different instruction set.

S4.09.A01
Answer and checking points — teacher-written
  1. Assembly uses mnemonic opcodes and may use symbolic addresses.
  2. Machine code encodes instructions as binary patterns that the processor can execute.
  3. An assembler translates assembly instructions into the corresponding machine instructions.
  4. Different instruction sets define different operations, encodings or operand rules, so the same assembly source may need changes and reassembly.

Common error: Assembly language is a low-level language; its mnemonics are not executed directly as text.

DISTILL

Core idea
Assembly is readable symbolic low-level code; an assembler produces machine instructions.
What you must be able to explain
Distinguish mnemonic, operand, label and encoded word.
Exam wording
TOTAL can resolve to an address before encoding.
Common trap
A symbolic label is not itself an extra processor instruction.
30-second recall

Knowledge block 2 / 3

What does a label name?

THINK

FIRST labels address 4, whose data is 18. Which number belongs in LDD FIRST?

LEARN

Click instruction and data labels in one source listing to see their addresses and stored contents.

APPLY

Immediate check

Does FIRST become 18 in the symbol table?

Reveal answer

No. FIRST maps to address 4; Memory[4] contains 18.

Exam transfer · teacher-written

Question 2 · Command word: Identify4 teacher marks

For the supplied source, identify the instruction and data labels and distinguish TOTAL from its initial and final contents. Explain two errors: defining FIRST twice, and referring to MISSING without any definition.

Initial ACC=0, IX=0, PC=0; comparison result unset. Data declarations are included below. No input is needed. Addresses are denary; each listed instruction or data item occupies one location.

000  START: LDD FIRST
001  ADD SECOND
002  STO TOTAL
003  END
004  FIRST: 18
005  SECOND: 24
006  TOTAL: 0
S4.15.A15S4.15.A16S4.10.A01S4.10.A02
Answer and checking points — teacher-written
  1. START labels instruction address 0; FIRST, SECOND and TOTAL label data addresses 4,5,6.
  2. TOTAL denotes address 6, initially containing 0 and finally containing 42.
  3. A second FIRST definition is a duplicate-label error because a single name has conflicting definitions.
  4. MISSING cannot be resolved and causes an undefined-symbol error; do not substitute an arbitrary address.

Common error: Data values do not belong in the label-to-address symbol table.

DISTILL

Core idea
A label maps a name to an address, whether it names code or data.
What you must be able to explain
Explain why a branch label and a data label are used differently.
Exam wording
LDD FIRST resolves the operand to address 4.
Common trap
A label does not automatically equal the contents at its address.
30-second recall
What does a symbol-table entry store?
Knowledge block 3 / 3

Why does an assembler need two passes?

THINK

The first line refers to FIRST before FIRST is defined. Can pass one already know its final address?

LEARN

Step pass one’s location counter and symbol table; switch to pass two to resolve forward references.

APPLY

Immediate check

What error remains if LDD MISSING has no label definition?

Reveal answer

An undefined label error in pass two; no address should be guessed.

Exam transfer · teacher-written

Question 1 · Command word: Complete5 teacher marks

Complete the pass-one symbol table for the supplied program and give the resolved address operand of each of its first three instructions in pass two. Explain why two passes are useful here.

Initial ACC=0, IX=0, PC=10; comparison result unset. Data declarations are included below. No input is needed. Addresses are denary; each listed instruction or data item occupies one location.

010  BEGIN: LDD LEFT
011  ADD RIGHT
012  STO RESULT
013  END
014  LEFT: 7
015  RIGHT: 9
016  RESULT: 0
S4.10.A01S4.10.A02
Answer and checking points — teacher-written
  1. The symbol table is BEGIN=10, LEFT=14, RIGHT=15, RESULT=16.
  2. At address 10 the resolved instruction is LDD 14.
  3. At address 11 the resolved instruction is ADD 15.
  4. At address 12 the resolved instruction is STO 16.
  5. The first instructions refer to labels defined later; the completed symbol table lets pass two resolve these forward references.

Common error: A label records the address of its item, not that item's stored data value.

Official Cambridge question · Cambridge 9618/12 · May/June 2023 · 3(a) →

DISTILL

Core idea
Pass one assigns locations and records labels; pass two resolves references and emits code/data.
What you must be able to explain
Trace a forward reference through both passes.
Exam wording
The completed symbol table gives FIRST=4 before pass two resolves LDD FIRST.
Common trap
Duplicate and missing labels are errors, not address zero.
30-second recall
Why is a forward reference unresolved at the first line?

Exam Challenge

Bring together the model and the written explanation. Attempt the task before revealing the teacher’s answer.

START: LDD FIRST appears before FIRST: 18. If START is address 0 and FIRST is address 4, what does each pass record or resolve, and what value is loaded when the program runs?

Teacher-written model answer
  1. Pass one records START=0 and FIRST=4 in the symbol table.
  2. Pass two resolves LDD FIRST to LDD 4; actual opcode bits require a supplied encoding.
  3. At run time LDD reads Memory[4]=18 into ACC.

1. Read a many-to-many assembler matching task

Cambridge 9618/12 · May/June 2023 · 3(a) · 3 marks

Selected parts: 3(a) [3].

Reading the question — teacher guidance

“One or more lines” permits an action to connect to both passes. Decide for every action; do not assume three marks means exactly three lines.

Solution / model answer — teacher-written
ActionConnect to
Generates object codeSecond pass
Reads source code one line at a timeFirst and second passes
Removes white spaceFirst pass
Adds labels to the symbol tableFirst pass

Pass one reads the source and builds the symbol information needed to resolve label references. Pass two reads the source again and uses that information when producing object code. The official drawing below shows all five connections.

Official mark scheme
Why this earns marks — teacher explanation

The three scoring groups are: object code to the second pass; line-by-line reading to both passes; both white-space removal and symbol-table labels to the first pass. The final two actions form one scoring group.

Common mistakes — teacher analysis

Connecting source reading to just one pass does not satisfy its group. Counting drawn lines is not the marking rule.
