In LDD TOTAL, is TOTAL necessarily the number to load?

Check your answer

No. TOTAL can be a label for a memory address; LDD loads that location's contents.

Core explanation

Machine instructions are encoded as binary patterns understood by a particular processor. An instruction contains an opcode and, where required, operand information. Assembly language provides readable mnemonics and symbolic names for the same low-level operations.

An assembler translates assembly source into machine code for its target instruction set. An ordinary mnemonic instruction corresponds to a machine instruction; labels and data declarations organise the source and are not additional operations for the processor to execute. Source for a different instruction set is not automatically interchangeable.

Worked example · A supplied encoding

  1. Encoding for this example only

    A 16-bit word uses an 8-bit opcode and an 8-bit address. Let LDD be 00000001.

  2. Resolve the operand

    If TOTAL labels location 6, its 8-bit address is 00000110.

  3. Encode

    LDD TOTAL becomes 00000001 00000110. These bit assignments are invented teaching data, not a binary encoding prescribed by Cambridge.

Common misconception

Readable mnemonics are not the binary instruction bits the processor executes.

Check your understanding

Can the opcode bits be calculated just from the letters LDD?

Check your answer

No. The target instruction set's encoding must be supplied or known.

02

Applying both passes of an assembler

S4.10.A01S4.10.A02

Visual overview

Core explanation

Resolve source in two passes
  1. Pass one: Assign locations and record labels with their addresses in a symbol table. Advance the location counter by each instruction or data item’s size; report duplicate definitions.
  2. Pass two: Use the completed table to resolve symbolic operands, translate mnemonics into opcodes and emit machine instructions and data.
Why a second pass is useful

A forward reference names a label defined later in the source. The completed first pass makes its address available to pass two. A label still undefined after that pass is an error. The diagram’s one-word instructions and starting location are explicit example assumptions.

Worked example · Assemble a complete program

  1. Source and location rule
    Addresses start at 0; each listed item occupies one location.
000  START: LDD FIRST
001  ADD SECOND
002  STO TOTAL
003  END
004  FIRST: 18
005  SECOND: 24
006  TOTAL: 0
  2. Pass one

    Count all seven items, including the three data declarations. Enter START=0, FIRST=4, SECOND=5 and TOTAL=6.

  3. Pass two: resolve

    The instructions become LDD 4; ADD 5; STO 6; END. FIRST and SECOND were forward references.

  4. Supplied teaching encoding

    Use 16-bit words: 8-bit opcode then 8-bit address. LDD=00000001, ADD=00000010, STO=00000011, END=11111111 with operand 0. Data use a full 16-bit unsigned word.

  5. Pass two: emit
    0  00000001 00000100
1  00000010 00000101
2  00000011 00000110
3  11111111 00000000
4  00000000 00010010
5  00000000 00011000
6  00000000 00000000
  6. Check by execution

    The program loads 18, adds 24 and stores 42 at address 6, then ends before the data declarations.

Common misconception

The symbol table contains addresses, not the data values 18, 24 and 0 stored at those addresses.

Check your understanding

Why can pass one not immediately resolve FIRST in the first source line?

Check your answer

FIRST is defined later; completing the first scan provides its address for pass two.

Practice questions

Question 1 · Command word: Compare4 marks

Compare assembly language with machine code. Explain why assembly written for one processor instruction set may not run on a processor with a different instruction set.

S4.09.A01
Answer and marking points
  1. Assembly uses mnemonic opcodes and may use symbolic addresses.
  2. Machine code encodes instructions as binary patterns that the processor can execute.
  3. An assembler translates assembly instructions into the corresponding machine instructions.
  4. Different instruction sets define different operations, encodings or operand rules, so the same assembly source may need changes and reassembly.

Common error: Assembly language is a low-level language; its mnemonics are not executed directly as text.

Answer and marking points
  1. The symbol table is BEGIN=10, LEFT=14, RIGHT=15, RESULT=16.
  2. At address 10 the resolved instruction is LDD 14.
  3. At address 11 the resolved instruction is ADD 15.
  4. At address 12 the resolved instruction is STO 16.

Question 1 · Command word: Complete · 5 marks

Complete the symbol table after pass one and give the resolved operands used by pass two for the supplied program. Explain whether the data value 25 belongs in the symbol table entry for VALUE.

Initial ACC=0, IX=0, PC=60; comparison result unset. Data declarations are included below. No input is needed. Addresses are denary; each listed instruction or data item occupies one location.

060  ENTRY: LDD VALUE
061  STO COPY
062  END
063  VALUE: 25
064  COPY: 0
Answer and marking points
  • ENTRY is entered as address 60.
  • VALUE is entered as address 63 and COPY as address 64.
  • LDD VALUE resolves to LDD 63.
  • STO COPY resolves to STO 64.
  • The symbol table stores VALUE's address 63; the separate data item at that address contains 25.

Common error: Do not resolve LDD VALUE as LDD 25.

Question 2 · Command word: Explain · 4 marks

Explain how a two-pass assembler handles a jump to a label defined later in the source. Describe what it should report if that label is never defined, and why simply substituting address zero is unsafe.

Answer and marking points
  • Pass one assigns addresses and collects label definitions in a symbol table.
  • Pass two looks up the later-defined target using the completed table when generating the jump operand.
  • If no definition exists, the assembler reports an undefined-symbol error.
  • Substituting zero could silently generate a jump to an unintended instruction rather than the requested target.

Common error: A forward reference can be valid; a missing definition is an error.

Question 3 · Command word: Write · 4 marks

Write the 16-bit machine word for LDD 63 when a supplied encoding gives LDD opcode 00000110 followed by an 8-bit address. Explain why another processor's assembler might generate a different word for a load operation, and identify the role of the assembly mnemonic.

Answer and marking points
  • The unsigned 8-bit form of address 63 is 00111111.
  • The resulting word is 00000110 00111111.
  • Another instruction set may assign different opcodes, formats or operand rules.
  • LDD is a readable mnemonic naming the operation for the assembler to encode.

Common error: Use the encoding supplied in this question rather than the different teaching encoding used earlier.
