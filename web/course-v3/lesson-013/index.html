Internet, WWW and connection infrastructure

Keep infrastructure, services and access-link hardware in separate layers.

If a web page, email and voice call all cross the internet, why is only one of them necessarily part of the World Wide Web—and which hardware carries them from the user to the wider network?

Before you start

Is the World Wide Web the same thing as the internet?

Check your answer

No. The internet is the network infrastructure; the WWW is one service providing linked resources over that infrastructure.

Concept explanations and worked examples

01

The internet carries many services; the WWW is one

S2.13.A01S2.13.A02S2.13.A03

Visual overview

Establish the concept

The internet is the global network of interconnected networks, routers and transmission links that carries data using common protocols.

The World Wide Web is one service using that infrastructure. It provides linked resources identified by URLs and normally accessed with browsers and web protocols.

Email, file transfer, online games and voice/video communication can use the internet without being WWW resources. A failed web service does not imply that every internet service has failed.

Place a web request within the wider internet

  1. Infrastructure: The internet interconnects networks using shared communication protocols and routing. Home, school and provider networks are parts of this larger system.
  2. One service: The WWW supplies linked web resources accessed by browsers and served by web servers using HTTP/HTTPS. A web request uses the underlying internet to travel.
  3. Other services: Email, remote access and file-transfer applications can also use the internet without being the WWW. A working internet connection does not prove that a particular web server is available.

Trace which layer of the experience failed

A WiFi connection first establishes local wireless access. The local network still needs a working onward connection, routing and any required service access to reach a remote website. A printer can remain reachable on the LAN while the provider link is down.

Core explanation · Exam essentials

  • The internet is interconnected network infrastructure; the WWW is one service carried over it.
  • Local WiFi, internet reachability and availability of one web service are different conditions.
Common misconception

A browser can provide interfaces to many services, but that does not make every underlying service part of the WWW.

Check your understanding

A local printer works but an external website does not. Does that prove WiFi is broken?

Check your answer

No. The local wireless path may work while the onward connection, DNS or the web service has failed.

02

A modem modulates and demodulates signals

S2.14.A01

Visual overview

Establish the concept

A modem is a modulator-demodulator. For a telephone-line connection, it converts digital data into an analogue signal suitable for transmission and converts received analogue signals back into digital data.

Modulation represents outgoing digital data in an analogue carrier signal. Demodulation recovers digital data from the incoming analogue signal. Keep both directions in an explanation of a modem used with the PSTN.

The modem does not inspect the destination IP address or choose the next network path. That routing decision belongs to the router even when a consumer device combines both functions in one case.

Follow the conversion responsibility

Modulation represents digital data by changes in a carrier signal appropriate to the access medium. Demodulation recovers the carried digital data from the received signal. In the telephone-access example, a sending modem performs modulation and the modem at the receiving end performs demodulation. “Modem” combines those two names because communication normally needs both directions.

Reverse the direction for a returned result

  1. Outward request: The home system supplies digital request data. Its modem modulates it onto the telephone access signal; the provider modem demodulates the received signal for onward digital communication.
  2. Return response: The provider modem now modulates return data. The home modem demodulates the incoming signal and supplies digital data to the home system.
  3. Separate equipment roles: A router chooses where to forward a packet. A modem adapts the access signal. A combined home box may contain both functions without making their definitions identical.

Core explanation · Exam essentials

  • Modulation puts data onto an appropriate carrier; demodulation recovers it.
  • Both ends send and receive, so their conversion roles reverse on the return path.
Common misconception

A modem does not choose the internet route; the router performs the routing decision.

Check your understanding

Which modem demodulates the response arriving back at the home?

Check your answer

The home modem. On this return direction, the provider modem is the sender.

03

PSTN carries signals through switched fixed telephone lines

S2.14.A02

Visual overview

Establish the concept

PSTN means Public Switched Telephone Network. It is the fixed telephone system formed from telephone lines, cables and telephone exchanges that establish a switched path between connected endpoints.

A home telephone connects through a fixed telephone line to a telephone exchange. Further exchanges can switch the call or signal through the PSTN to another connected telephone line.

A computer can use a modem or access equipment to send data through a suitable telephone-line service. The modem is the endpoint conversion device; the PSTN is the wider switched telephone-line network.

Describe the chosen access arrangement

The public switched telephone network connects telephone users through switching infrastructure. In the illustrated dial-up access arrangement, the user establishes a switched telephone connection to a provider’s modem endpoint; the provider supplies onward internet access. Establishing that connection and the limited access data rate are relevant drawbacks for sustained modern media traffic.

Keep the scope of the diagram precise

PSTN names a telephone network, not an assertion that every internal link is analogue. The illustration focuses on the access signal and the modem conversion at its ends; internal transport can be digital. A telephone service, a modem access arrangement and the global internet are related components with different jobs.

Complete the path through to a result

Follow request data from the home system to its modem, across the established telephone connection to the provider modem, then through the provider network to the service. Return data follows a connection back and reverses the modulation/demodulation roles. Losing the telephone access connection breaks this path even if the destination service is still running.

Core explanation · Exam essentials

  • PSTN provides switched telephone connections that can support a modem access example.
  • Explain the access link without claiming that the whole telephone network is analogue.
Common misconception

PSTN is the switched fixed telephone-line network; it is not an IP router mesh or a single server.

Check your understanding

Is “PSTN” another name for the WWW?

Check your answer

No. PSTN is telephone-network infrastructure; the WWW is a service reached through an appropriate internet connection.

04

A dedicated line reserves a connection for one customer or site

S2.14.A03S2.14.A05

Visual overview

Establish the concept

A dedicated line provides a permanent or reserved provider connection for one customer or site rather than establishing a temporary connection only when required.

Reserved capacity can give predictable availability, performance or site-to-site connectivity, which can suit an organisation with continuous or critical communication requirements.

The organisation normally pays higher installation and recurring costs. A sound choice connects that extra cost to the scenario's need for predictable permanent connectivity.

Connect a branch through a dedicated service

  1. Requirement: A branch needs an ongoing connection to its provider or another site with contracted capacity and availability characteristics.
  2. Arrangement: A dedicated line reserves the agreed connection for that customer or site; it need not be dialled anew for each session. Provider infrastructure carries the service.
  3. Exchange: The branch router forwards a request over the line and onward to the destination. The server processes it and sends the response back through the network connection.
  4. Trade-off: The recurring cost can be higher than a shared consumer service. A dedicated access connection can improve predictability under its contract but does not guarantee that every later internet link or remote server is uncongested.

Core explanation · Exam essentials

  • A dedicated line supplies a reserved continuing connection under its service arrangement.
  • Weigh predictable contracted service against cost and remaining end-to-end dependencies.
Common misconception

A dedicated line is a reserved connection; it is not another name for any ordinary fixed telephone line or local Ethernet cable.

Check your understanding

Does a dedicated office access line guarantee that every public website responds immediately?

Check your answer

No. Other network segments, distance and remote-server processing can still delay the response.

05

A cell phone network provides mobile radio access

S2.14.A04S2.14.A05

Visual overview

Establish the concept

A cell phone or cellular network connects a mobile device by radio to a base station. The base station passes the traffic into the cellular provider network and onward to wider networks.

As the user moves, the device can connect through available coverage areas and may transfer between base stations. This provides mobility without a fixed telephone line to the device.

Availability and performance depend on coverage, distance, obstacles, interference, radio conditions and capacity shared with other users. A recommendation must test those constraints against the scenario.

Use and then change the serving cell

  1. Start: A phone with network access transmits by radio to its serving base station. The operator network connects that station onward to the requested internet service.
  2. Return: The service produces a response that returns through the operator and serving station to the phone. A base station supplies access rather than storing every requested internet resource.
  3. Move: As the phone travels, a successful handover transfers its service to a suitable neighbouring base station. The serving radio link changes while communication may continue.
  4. Boundary: Coverage gaps, obstructions or overloaded cells can interrupt or reduce service. Mobility support does not mean a usable signal exists everywhere.

Core explanation · Exam essentials

  • A cellular device uses radio to a base station and operator infrastructure for onward access.
  • Handover supports movement between cells; coverage and capacity remain limits.
Common misconception

A cell phone network is the wider cellular access system; it is not the same as local WiFi through a wireless access point.

Check your understanding

Why can a travelling phone lose service despite supporting handover?

Check your answer

There may be no suitable next cell, or the next cell may lack usable signal or capacity. Handover cannot create missing coverage.

Question 1 · Command word: Explain4 marks

Explain the difference between the internet and the WWW, then classify email and a web page.

S2.13.A01S2.13.A02S2.13.A03
Answer and marking points
  1. Internet is the interconnected network infrastructure.
  2. WWW is one service of linked resources.
  3. Email uses the internet but is not necessarily WWW.
  4. A web page is a WWW resource.

Common error: Do not define the internet as a collection of web pages.

Question 2 · Command word: Describe6 marks

A home uses the telephone-line PSTN access service shown below. Describe the path of a request from a laptop through the home LAN to the provider, distinguishing the router and modem functions and the signal conversion at each end of the telephone link.

S2.14.A01S2.14.A02
Answer and marking points
  1. The laptop sends the request through its network interface and LAN equipment.
  2. The router uses the destination IP address and routing information to forward the packet toward the provider network.
  3. The local modem modulates the digital data into an analogue signal.
  4. The analogue signal travels over the telephone line and public switched telephone infrastructure.
  5. The receiving modem demodulates the analogue signal to recover digital data.
  6. The provider can then forward the packet toward the wider internet.

Common error: A router selects a path between networks; a modem converts signals, even if both functions share a case.

Question 3 · Command word: Suggest6 marks

Suggest a dedicated line or cell phone network for a remote emergency unit that moves weekly but must upload records. Explain how the chosen network provides access and give a balanced comparison.

S2.14.A03S2.14.A04S2.14.A05
Answer and marking points
  1. A cell phone network suits the regularly moving unit, provided suitable coverage exists.
  2. The device connects by radio to a base station and then through the provider network.
  3. The radio connection supports mobility without installing a fixed line at each weekly location.
  4. Coverage gaps or shared cell capacity can interrupt or slow record uploads.
  5. A dedicated line can give a permanent connection with predictable capacity at one site.
  6. Repeated fixed-line installation and rental would conflict with the unit’s frequent relocation.

Common error: Do not claim cellular always has coverage.

Question 4 · Command word: Describe5 marks

Describe a returned web response over the illustrated telephone-access arrangement: home digital system, home modem, telephone/PSTN connection, provider modem and provider network. Identify which end modulates and which demodulates, and distinguish a router’s responsibility.

S2.14.A01S2.14.A02
Answer and marking points
  1. Response data reaches the provider modem through the provider network.
  2. The provider modem modulates the data onto the appropriate access signal.
  3. The telephone connection carries the signal to the home modem.
  4. The home modem demodulates it and supplies digital data to the home system.
  5. A router chooses an onward network using destination information; this differs from modem signal adaptation.

Common error: Reverse the conversion roles for the return direction and do not label the entire PSTN analogue.

Question 1 · Command word: Explain · 4 marks

A student can send email using a dedicated mail application and make a voice-over-IP call, but one website is unavailable. Explain why this does not prove that the whole internet has failed. Refer to the internet, the WWW and one possible fault consistent with these observations.

Answer and marking points
  • The internet is the global infrastructure interconnecting networks and carrying data for several services.
  • The WWW consists of linked web resources accessed through internet infrastructure.
  • Working email and voice-over-IP show that some internet connections and services are still available.
  • The web server for that site may have failed, or a fault may affect only its route or web service.

Common error: The observations narrow the fault; they do not establish its exact cause or prove that every other site works.

Question 2 · Command word: Compare · 5 marks

Compare a PSTN access connection with a dedicated line for a permanent bank branch that requires predictable continuous connectivity, and suggest the more suitable option.

Answer and marking points
  • A PSTN service uses public switched telephone infrastructure and suitable modem or access equipment to adapt signals for that link.
  • Its performance and availability depend on the shared access service provided over the telephone infrastructure.
  • A dedicated line provides a continuously available link reserved for the branch rather than a temporary or shared access path.
  • The dedicated line can offer more predictable capacity and availability but has greater installation and rental cost.
  • The dedicated line is more suitable when the bank values predictable continuous connectivity more than the additional cost.

Common error: Do not claim that the modem chooses packet routes; signal adaptation and inter-network routing are separate roles.

Question 3 · Command word: Describe · 5 marks

Describe how a passenger's phone on a moving bus connects to an internet service through a cellular network, and explain one cause of variable performance.

Answer and marking points
  • The phone transmits and receives radio signals through a nearby cellular base station.
  • The cellular provider carries the data from its access network toward the wider internet service.
  • As the bus moves, the connection may be transferred between cells so that a reachable base station continues to serve the phone.
  • Signal strength changes with distance, buildings, terrain or movement between coverage areas.
  • Shared radio capacity or interference can also make the available data rate vary.

Common error: Do not describe the phone as connected by a dedicated cable; the access path to the base station is a shared radio link.
