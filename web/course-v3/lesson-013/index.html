Communicate data · Concept 17

Distinguish the network from a service that uses it

Observe

Three activities on the same connection

  • Open the school course page in a browser.
  • Send an email using an email application.
  • Use a game service or another non-web network application.

Look, then discuss

If a browser is closed, does the internet stop being used?

Discuss the observation

The same interconnected networks support different services. Closing one application does not remove the underlying infrastructure or every other service.

Explain

Explanation · 1 / 4

Describe the internet

The internet is a global network of interconnected networks that communicate using internet protocols. A school LAN can connect through provider infrastructure to reach other networks. Its paths include physical links and network equipment rather than an invisible cloud with no machinery.

Explanation · 2 / 4

Describe the World Wide Web

The World Wide Web, or WWW, is a system of linked web resources accessed using web technologies. Browsers request resources from web servers, commonly using HTTP or HTTPS. Web pages may contain text, images and links to other resources.

Explanation · 3 / 4

Classify other services

Email, file transfer and other network applications can use the internet without being the WWW. A webmail interface is itself a web application, so classify the actual activity and interface rather than assuming every instance of the word email must be non-web.

Explanation · 4 / 4

Locate a failure precisely

A particular website can fail while the internet connection still supports other services. The school’s internet access can fail while some local LAN services continue. Service availability and network reachability are related but not identical.

Work together

Interpret three test results

The course website does not load. A different website loads, and an email application successfully sends a message.

Work together · 1 / 3

Reject an overbroad conclusion

The evidence does not support saying that the entire internet connection is down, because other remote services work.

Work together · 2 / 3

Identify the narrower possibilities

The course site, its name resolution, a particular route or access rule may have a problem. Further evidence is needed to distinguish them.

Work together · 3 / 3

Classify the services

Both websites are WWW resources. The email application can use a separate internet service over the same infrastructure.

Name the failed service or path as precisely as the evidence allows.

Check

Try it yourself · Teacher-written

Explain the difference between the internet and the WWW, using one non-WWW service as an example.

Check your reasoning

The internet is the interconnected network infrastructure that carries communication among networks. The WWW is one service of linked web resources accessed by browsers and web servers. An email application can use email protocols over the internet without making that exchange a web-page request.

Connect

Keep this idea

The internet connects networks; the WWW is one of the services those networks support.

To leave the school site, the data must use an access link suited to the provider’s physical connection.

Check a common misunderstanding

A browser page, WiFi link and internet connection are three different things.

Learning goals
  • Explain the internet as a global network of networks.
  • Explain the WWW as one internet service of linked resources.
  • Classify non-WWW internet services correctly.

Communicate data · Concept 18

Match data to the signal form required by an access link

Observe

A communication link expects a carrier signal

  • The computer supplies digital data.
  • A transmitter changes suitable carrier properties to represent that data.
  • A receiver interprets those changes to recover the represented data.

Look, then discuss

Why might a communication endpoint need more than an ordinary connector?

Discuss the observation

Equipment must use signals that the particular link can carry. A socket shape alone does not convert data into the required signal form.

Explain

Explanation · 1 / 4

Expand the word modem

Modem combines modulator and demodulator. Modulation represents data by changing suitable properties of a carrier signal. Demodulation interprets received carrier changes to recover the represented data.

Explanation · 2 / 4

Use the telephone-link example

On a traditional analogue telephone access link, the modem converts the computer’s digital data into an appropriate modulated signal for the line. A receiving modem demodulates it back into digital data. This explains the familiar digital-to-analogue and analogue-to-digital description in that context.

Explanation · 3 / 4

Avoid a universal conversion claim

Different access technologies use different signal forms and equipment. Do not claim that every internet link is analogue or that every hop converts digital data into analogue form. Explain the conversion required by the link in the stated example.

Explanation · 4 / 4

Separate modem and router roles

A modem handles the signal requirements of its access link. A router forwards packets between networks using addressing and routing information. One household or school box may combine roles, but combining hardware does not make the roles identical.

Work together

Carry data over an analogue telephone access segment

A sending computer and receiving system communicate through a link that requires a modulated analogue signal.

Work together · 1 / 3

Prepare the outgoing signal

The sending modem modulates the carrier so its changes represent the digital data.

Work together · 2 / 3

Carry it through the relevant segment

The link carries the appropriate physical signal. This statement concerns that segment, not every part of the wider network.

Work together · 3 / 3

Recover the data

The receiving modem demodulates the signal into digital data for further processing.

Describe conversion at the physical link that needs it.

Check

Try it yourself · Teacher-written

State the two operations behind the word modem and explain why the modem role differs from routing.

Check your reasoning

A modem modulates data onto a suitable carrier and demodulates a received carrier to recover data. Routing chooses how packets move between networks using their destination addresses and routing information. The roles can be combined in one device but remain different operations.

Connect

Keep this idea

A modem adapts data to and from the signal requirements of an access link.

The PSTN provides a switched telephone-network context in which that access-link conversion can be understood.

Continue: Trace communication through the public switched telephone network →
Check a common misunderstanding

Do not describe the entire modern internet or telephone network as one analogue link.

Learning goals
  • Explain a modem’s role at an access link.

Communicate data · Concept 19

Trace communication through the public switched telephone network

Observe

A traditional telephone-network access route

  • Local access line
  • Telephone switching infrastructure
  • Provider connection towards other networks

Look, then discuss

Which part of the route requires signal conversion, and which part connects the communication onward?

Discuss the observation

A complete explanation follows the segments. It does not repeat “telephone line” for every device or assume that the whole route uses one signal form.

Explain

Explanation · 1 / 4

Explain the name

PSTN means Public Switched Telephone Network. It is telephone-network infrastructure connecting users through communication lines and switching systems. The switches connect communication through the wider system rather than requiring a dedicated direct line from every user to every other user.

Explanation · 2 / 4

Describe an internet-access use

A suitable telephone access service can carry communication towards a provider that connects to wider networks. The exact technology depends on the service; a traditional dial-up example uses modem signals over an analogue access segment.

Explanation · 3 / 4

Keep line technologies separate

Telephone infrastructure can contain different line and signal technologies. Apply analogue/digital conversion only where the specific segment requires it. The existence of an analogue access example does not mean every switching centre or long-distance link is analogue.

Explanation · 4 / 4

Trace the roles in order

Identify the user endpoint, required access equipment, local line, switching infrastructure and provider connection. Explain what each contributes to moving communication towards its destination; do not substitute the web server’s content job for a network role.

Work together

Explain a stated PSTN access arrangement

A question describes a computer using a modem on a traditional analogue local line to reach a provider.

Work together · 1 / 3

Convert for the stated local line

The modem creates a suitable modulated signal representing the computer’s digital data.

Work together · 2 / 3

Follow the telephone infrastructure

The communication travels through the local line and switching network towards the provider.

Work together · 3 / 3

State the boundary

Other segments may use different technologies. The provider connects onwards; the requested remote service still has its own processing role.

A precise answer describes the supplied access example without generalising it to every modern line.

Check

Try it yourself · Teacher-written

Describe the PSTN’s role in an internet-access example and correct the statement “every PSTN segment is analogue”.

Check your reasoning

The PSTN provides telephone communication lines and switching infrastructure through which a suitable access service can reach a provider and wider networks. It can include different line and signal technologies. Conversion is needed where a particular segment requires it; the whole network is not necessarily analogue.

Original question · Cambridge 9618/12

1. Describe the PSTN’s role in internet transmission

Cambridge 9618/12 · May/June 2024 · 3(c)(ii) · 2 marks

Selected parts: 3(c)(ii) [2].

Hint — reading the question

This selected subpart asks about the telephone-network infrastructure, rather than the router question that precedes it in the paper.

Reasoning and model answer — teacher-written

The PSTN includes different types of communication lines. Where a line requires another signal form, digital data must be converted appropriately, for example to an analogue signal on an analogue segment. Communication is passed through switching centres and service providers towards its destination.

Official mark scheme
Why this earns marks — teacher explanation

The scheme accepts up to two relevant points, including different line types, required conversion, duplex transmission and switching centres/ISPs. Two connected points are sufficient.

Common mistakes — teacher analysis

Do not describe the whole modern PSTN as analogue. Conversion is required where the particular link demands it, not automatically on every segment.

Communicate data · Concept 20

Compare a reserved connection with ordinary shared access

Observe

The school links two permanent sites

  • Both sites exchange important data throughout the day.
  • They need an agreed connection arrangement and capacity.
  • They can pay more than a casual occasional user.

Look, then discuss

What requirement could justify paying for a dedicated line?

Discuss the observation

The useful property is an arranged, reserved connection for the customer or sites. Its value depends on the required service and contract, not on a guarantee that no failure can happen.

Explain

Explanation · 1 / 3

Describe the dedicated arrangement

A dedicated line provides a connection reserved for a particular customer or between specified sites rather than establishing a new ordinary telephone call each time. It can support continuing organisational communication with agreed service characteristics.

Explanation · 2 / 3

Explain the benefit in context

An organisation may choose a dedicated arrangement for predictable capacity, persistent connectivity and suitable service support. The actual rate, availability and repair commitments must come from the service specification rather than from the word dedicated alone.

Explanation · 3 / 3

Explain the cost and fixed nature

Installation and ongoing charges may be higher than suitable shared access. The arrangement serves planned locations and is not a substitute for a moving device’s radio access. A damaged line or failed endpoint can still interrupt service.

Work together

Choose a link for continuous school-site exchange

Two school sites exchange records and teaching materials all day. They require an agreed service level and have fixed endpoints.

Work together · 1 / 3

Match the requirement

A dedicated connection can supply an arranged link between the sites with specified capacity and support.

Work together · 2 / 3

Compare the trade-off

The school pays the installation and service costs and still needs a response to outages.

Work together · 3 / 3

Change the scenario

For a teacher moving around a city, the fixed-site benefit would not solve the mobility requirement; cellular access is a different candidate.

Choose infrastructure from the endpoint locations and service requirements.

Check

Try it yourself · Teacher-written

Explain a reason for a school to choose a dedicated line and one limitation that remains.

Check your reasoning

A school can obtain a reserved fixed-site connection with agreed capacity and service characteristics for continuing communication. It still pays installation or ongoing costs and can lose service if a line or endpoint fails; the label does not promise perfect availability.

Connect

Keep this idea

A dedicated connection can meet fixed organisational requirements at an associated cost.

Moving between locations instead requires access through a mobile radio network.

Continue: Connect a moving phone through cells and base stations →
Check a common misunderstanding

Dedicated does not mean free, wireless, unlimited or immune to failure.

Communicate data · Concept 21

Connect a moving phone through cells and base stations

Observe

A teacher travels to a partner school

  • The phone uses mobile data outside school WiFi coverage.
  • The operator divides the service area into cells.
  • The phone communicates by radio with serving base-station equipment.

Look, then discuss

How can the phone continue using a network while moving away from one base station?

Discuss the observation

The phone has a radio access link into an operator network. As conditions change, the network can arrange a transfer to suitable serving equipment, subject to coverage and capacity.

Explain

Explanation · 1 / 4

Define a cell and its access link

A cellular network divides its coverage into service areas called cells. A phone communicates using radio with base-station equipment serving its area. The radio link replaces a fixed cable to the moving phone; it does not replace every cable in the wider network.

Explanation · 2 / 4

Follow the operator path

The base station connects through the operator’s infrastructure towards other networks and services. For internet use, communication reaches the appropriate external network through the operator. The requested website is not stored in the base station merely because the signal passes through it.

Explanation · 3 / 4

Explain mobility and limits

As the phone moves, a handover can transfer its active connection to other suitable serving equipment. Coverage gaps, interference, congestion or failed infrastructure can still interrupt service. Handover supports movement; it is not a promise of uninterrupted communication everywhere.

Explanation · 4 / 4

Choose between fixed and mobile access

Cellular access suits a moving teacher or a location with suitable coverage where fixed access is unavailable. Check signal coverage, data capacity, usage charges and reliability. A school’s permanent high-demand link may have different requirements from one mobile device.

Work together

Trace a mobile course-page request

The teacher opens the course site while travelling outside the school WiFi network.

Work together · 1 / 3

Use the radio access link

The phone communicates with the serving base station using cellular radio, provided a usable service is available.

Work together · 2 / 3

Pass through the operator

The operator network carries the communication towards the remote service and returns its response.

Work together · 3 / 3

Continue across cells

If the teacher moves, a suitable handover can change the serving radio equipment. The internet service still depends on coverage and the remaining network path.

The complete explanation includes the cell, base station, radio link and onward network.

Check

Try it yourself · Teacher-written

Explain how a cellular network provides internet access to a moving phone and name one limitation.

Check your reasoning

The phone communicates by radio with base-station equipment serving its cell. That equipment connects through the operator network towards the internet. Handover can transfer service as the phone moves, but coverage gaps, congestion, interference or infrastructure failures can still interrupt access.

Original question · Cambridge 9618/12

1. Trace the phone-to-base-station access link

Cambridge 9618/12 · May/June 2025 · 6(b) · 4 marks

Selected parts: 6(b) [4].

Hint — reading the question

The driver is using the cellular network. Explain the local radio link and how the area is organised; simply saying that the phone uses the internet does not describe the access method.

Reasoning and model answer — teacher-written

The coverage area is organised into cells. A base station with an antenna serves a cell and transmits and receives data. The smartphone exchanges data with a serving base station using low-power radio signals. Multiple phones can communicate with that base station using allocated radio resources.

Official mark scheme
Why this earns marks — teacher explanation

The scheme awards up to four marks from its stated cell, tower, radio-link and multiple-device points. It refers to cells designed for line of sight; actual coverage depends on terrain, buildings, frequency and antenna design, so an ideal cell diagram is not a map of exact coverage boundaries.

Common mistakes — teacher analysis

A cellular access link is not a direct radio transmission from the phone to the distant company server. The operator network carries data onward after the base station.

Question 2 · Command word: Describe6 teacher marks

A home uses the telephone-line PSTN access service shown below. Describe the path of a request from a laptop through the home LAN to the provider, distinguishing the router and modem functions and the signal conversion at each end of the telephone link.

S2.14.A01S2.14.A02
Answer and checking points — teacher-written
  1. The laptop sends the request through its network interface and LAN equipment.
  2. The router uses the destination IP address and routing information to forward the packet toward the provider network.
  3. The local modem modulates the digital data into an analogue signal.
  4. The analogue signal travels over the telephone line and public switched telephone infrastructure.
  5. The receiving modem demodulates the analogue signal to recover digital data.
  6. The provider can then forward the packet toward the wider internet.

Common error: A router selects a path between networks; a modem converts signals, even if both functions share a case.

Question 3 · Command word: Suggest6 teacher marks

Suggest a dedicated line or cell phone network for a remote emergency unit that moves weekly but must upload records. Explain how the chosen network provides access and give a balanced comparison.

S2.14.A03S2.14.A04S2.14.A05
Answer and checking points — teacher-written
  1. A cell phone network suits the regularly moving unit, provided suitable coverage exists.
  2. The device connects by radio to a base station and then through the provider network.
  3. The radio connection supports mobility without installing a fixed line at each weekly location.
  4. Coverage gaps or shared cell capacity can interrupt or slow record uploads.
  5. A dedicated line can give a permanent connection with predictable capacity at one site.
  6. Repeated fixed-line installation and rental would conflict with the unit’s frequent relocation.

Common error: Do not claim cellular always has coverage.

Question 4 · Command word: Describe5 teacher marks

Describe a returned web response over the illustrated telephone-access arrangement: home digital system, home modem, telephone/PSTN connection, provider modem and provider network. Identify which end modulates and which demodulates, and distinguish a router’s responsibility.

S2.14.A01S2.14.A02
Answer and checking points — teacher-written
  1. Response data reaches the provider modem through the provider network.
  2. The provider modem modulates the data onto the appropriate access signal.
  3. The telephone connection carries the signal to the home modem.
  4. The home modem demodulates it and supplies digital data to the home system.
  5. A router chooses an onward network using destination information; this differs from modem signal adaptation.

Common error: Reverse the conversion roles for the return direction and do not label the entire PSTN analogue.
