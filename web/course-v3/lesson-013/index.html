01

Concept teaching

Visual overview and core explanation

01

The internet carries many services; the WWW is one

S2.13.A01S2.13.A02S2.13.A03

Visual overview

Core explanation

The internet is the global network of interconnected networks, routers and transmission links that carries data using common protocols.

The World Wide Web is one service using that infrastructure. It provides linked resources identified by URLs and normally accessed with browsers and web protocols.

Email, file transfer, online games and voice/video communication can use the internet without being WWW resources. A failed web service does not imply that every internet service has failed.

Common misconception

A browser can provide interfaces to many services, but that does not make every underlying service part of the WWW.

02

Access infrastructure connects the local router to wider networks

S2.14.A01S2.14.A02S2.14.A03S2.14.A04S2.14.A05

Visual overview

Core explanation

A modem converts or adapts signals into the form required by the access link and converts received signals back for the local digital system. A modem and router may share one physical case, but conversion and routing are distinct functions.

The PSTN is the public switched telephone network. Existing telephone infrastructure can carry access traffic, but characteristics depend on the service and shared provider network.

A dedicated line provides a permanent or reserved connection for one customer or site, offering predictable availability/capacity at higher cost. A cell phone network connects mobile devices by radio to a base station, providing mobility but depending on coverage, shared capacity and radio conditions.

From a home device to the internet

  1. DeviceCreates the application data
  2. LAN equipmentNIC/WNIC, WAP and switch carry it locally
  3. RouterSelects the route to another network
  4. Modem/access equipmentAdapts signals for the access link
  5. Provider networkCarries packets toward the wider internet
Common misconception

A modem does not choose the internet route; the router performs the routing decision.

02

Cambridge command words

Practice questions

Command word: Explain4 marks

Explain the difference between the internet and the WWW, then classify email and a web page.

S2.13.A01S2.13.A02S2.13.A03
Answer and marking points
  1. Internet is the interconnected network infrastructure.
  2. WWW is one service of linked resources.
  3. Email uses the internet but is not necessarily WWW.
  4. A web page is a WWW resource.

Common error: Do not define the internet as a collection of web pages.

Command word: Complete6 marks

A home uses a PSTN access service. Complete a trace table for a request from a laptop through the home network and PSTN to the provider, distinguishing router and modem roles.

S2.14.A01S2.14.A02
Answer and marking points
  1. Laptop connects through NIC/WNIC and LAN equipment.
  2. Router identifies an external destination.
  3. Router selects/forwards toward another network.
  4. Modem/access equipment adapts signals for the access link.
  5. The adapted signal crosses the public switched telephone infrastructure.
  6. Provider equipment carries the packet onward toward the wider internet.

Common error: A combined router-modem case still contains two functions; PSTN names the public telephone-network path, not the router.

Command word: Suggest6 marks

Suggest a dedicated line or cell phone network for a remote emergency unit that moves weekly but must upload records. Give a balanced explanation.

S2.14.A03S2.14.A04S2.14.A05
Answer and marking points
  1. Recommend cellular for mobility/rapid deployment, if coverage is adequate.
  2. Connects by radio to a base station.
  3. Coverage/shared capacity/interference risk is stated.
  4. Dedicated line can offer predictable permanent connectivity.
  5. Dedicated installation/cost conflicts with weekly movement.
  6. Conclude from mobility and availability requirement.

Common error: Do not claim cellular always has coverage.

Question 1 · Command word: Identify · 4 marks

Identify a web page, an email message, a voice-over-IP call and a file-transfer session as WWW or non-WWW internet services, explaining the basis of the classification.

Marking points

  • The internet is the underlying global network infrastructure used by all four communications.
  • A web page is a linked web resource and therefore belongs to the World Wide Web service.
  • Email is an internet service but is not itself a World Wide Web resource.
  • Voice over IP and file transfer also use internet infrastructure without becoming WWW services merely because software presents them on a screen.

Question 2 · Command word: Compare · 5 marks

Compare a PSTN access connection with a dedicated line for a permanent bank branch that requires predictable continuous connectivity, and suggest the more suitable option.

Marking points

  • A PSTN service uses public switched telephone infrastructure and suitable modem or access equipment to adapt signals for that link.
  • Its performance and availability depend on the shared access service provided over the telephone infrastructure.
  • A dedicated line provides a continuously available link reserved for the branch rather than a temporary or shared access path.
  • The dedicated line can offer more predictable capacity and availability but has greater installation and rental cost.
  • The dedicated line is more suitable when the bank values predictable continuous connectivity more than the additional cost.

Question 3 · Command word: Describe · 5 marks

Describe how a passenger's phone on a moving bus connects to an internet service through a cellular network, and explain one cause of variable performance.

Marking points

  • The phone transmits and receives radio signals through a nearby cellular base station.
  • The cellular provider carries the data from its access network toward the wider internet service.
  • As the bus moves, the connection may be transferred between cells so that a reachable base station continues to serve the phone.
  • Signal strength changes with distance, buildings, terrain or movement between coverage areas.
  • Shared radio capacity or interference can also make the available data rate vary.
