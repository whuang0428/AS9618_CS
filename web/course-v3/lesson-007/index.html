Communicate data · Concept 01

What changes when the school connects its devices?

Observe

One school, one changing timetable

  • Thirty students need the latest timetable.
  • The teacher has one printer and one updated file.
  • Students will later open a course page and watch the same lesson video.

Look, then discuss

If the teacher changes the timetable, how could everyone obtain the new version without carrying a storage device around the room?

Discuss the observation

The useful object is one current timetable. Connecting devices provides a path for requesting and receiving it. A connection alone does not decide who may change the file.

Recall

Recall data without assuming expert vocabulary

Data is represented using bits, each 0 or 1. A file is an organised collection of stored data. Sending a file means using physical signals to communicate its data so that a receiving system can interpret it.

Explain

Explanation · 1 / 4

Start with two connected devices

A network connects devices so that they can exchange data and use resources. A resource can be a file, an application, storage, a printer or a connection to another network. The devices need both a communication path and agreed rules for exchanging information.

Explanation · 2 / 4

Explain a benefit through its cause

If thirty computers can send jobs to one shared printer, the school can buy fewer printers. If authorised students request one centrally maintained timetable, the teacher can update that copy instead of manually replacing thirty separate copies. State the shared resource and the resulting benefit.

Explanation · 3 / 4

Add communication and management

Devices can exchange messages and support collaborative work. An administrator can manage user accounts, access permissions and backups centrally where the chosen system provides those services. These are configured services; merely joining cables does not automatically create a backup or protect a file.

Explanation · 4 / 4

Notice the new dependence

Sharing also introduces dependencies. If the printer is unavailable, connected devices cannot print through it. If the shared timetable service cannot be reached, the network does not magically provide a second copy. Later lessons ask which connection or device failed.

Work together

Replace thirty timetable copies with one managed copy

The teacher changes Friday’s room from 12 to 18. Every student has permission to read the central timetable, but only staff can edit it.

Work together · 1 / 3

Make one authorised change

The teacher updates the managed timetable. This removes the need to replace a separate copy on every student device.

Work together · 2 / 3

Request the current resource

A student opens the shared timetable and receives the updated version, provided the service and connection are working.

Work together · 3 / 3

State the benefit precisely

Central maintenance reduces duplicated update work and helps students access consistent information. Permissions control editing; backup still needs its own process.

A useful explanation connects a network feature to a concrete consequence.

Check

Try it yourself · Teacher-written

Explain one benefit of sharing a printer and one benefit of centrally backing up school files.

Check your reasoning

A shared printer lets several devices use one printer, reducing duplicated printer purchases. A central backup process can preserve managed copies of school files for recovery, reducing the need to organise separate backups on every device. Neither service is automatic merely because a network exists.

Keep this idea

Networks exchange data and make resources or services accessible to connected devices.

The same purpose can apply inside one school or across schools in different cities. Next, describe that change in scale.

Communicate data · Concept 02

Distinguish a local site from links between distant sites

Observe

Extend the school network

  • First connect the classroom and library on one school site.
  • Then connect partner schools in two other cities.
  • Some local devices use cables and others use wireless links.

Look, then discuss

Which change affects geographical scope: replacing a cable with WiFi, or connecting a school in another city?

Discuss the observation

WiFi changes the kind of connection. The inter-city link changes the area covered. These are independent descriptions.

Explain

Explanation · 1 / 3

Describe the LAN

A local area network, or LAN, connects devices within a limited geographical area such as a building or managed school site. It is normally owned or managed by one organisation. It may include several rooms, cables and wireless access points.

Explanation · 2 / 3

Describe the WAN

A wide area network, or WAN, covers a much larger area and can connect separate LANs. Links between cities commonly use telecommunications-provider infrastructure. Each school can retain its own LAN while participating in the wider network.

Explanation · 3 / 3

Keep scope separate from performance

LAN and WAN describe geographical and organisational scope. They do not guarantee a speed, a particular signal carrier or whether the public may use them. A carefully designed WAN link can outperform a congested local connection.

Work together

Label a three-school system

School A has a classroom and library. Schools B and C are in different cities. A provider supplies the inter-city connections.

Work together · 1 / 3

Identify the local networks

The devices managed within each school site form a LAN. The classroom and library do not become a WAN merely because they occupy different rooms.

Work together · 2 / 3

Identify the wider connection

Connecting the three school LANs across cities creates a WAN. Provider links carry communication between the sites.

Work together · 3 / 3

Change one property

Replacing classroom cables with WiFi leaves the local geographical scope unchanged: it remains a LAN.

Name the scope from the arrangement, then discuss the connection technology separately.

Check

Try it yourself · Teacher-written

A school LAN connects to another school 300 km away. Explain why the whole arrangement is a WAN without making a claim about speed.

Check your reasoning

The arrangement connects separate local networks over a large geographical area, normally using inter-site telecommunications infrastructure. That geographical scope makes it a WAN; a data rate would require additional information.

Original question · Cambridge 9618/12

1. Compare the scope and ownership of a LAN and WAN

Cambridge 9618/12 · May/June 2025 · 6(a) · 2 marks

Selected parts: 6(a) [2].

Hint — reading the question

Give two paired differences. For each, say what is typical of the WAN and what is typical of the LAN. The company scenario has sites in different cities.

Reasoning and model answer — teacher-written

The WAN links sites across a larger geographical area, while a LAN covers a smaller local area such as one site.

The WAN can use external provider transmission media between sites; the organisation normally controls the transmission media within its LAN.

Official mark scheme
Why this earns marks — teacher explanation

The scheme awards one mark for each accepted difference, up to two. The comparison concerns scope and infrastructure; neither Wi-Fi nor a guaranteed data rate defines a LAN.

Common mistakes — teacher analysis

Do not claim that every WAN is slower than every LAN, that a LAN must use cables, or that WAN access must be public.

Communicate data · Concept 03

Follow a request to the computer that supplies the service

Observe

Two ways to share a class photograph

  • The school photo service stores the file and checks school accounts.
  • Alternatively, a student shares a file directly from their own laptop.
  • In both cases, another device asks for the photograph.

Look, then discuss

What happens in each arrangement when the computer supplying the photograph is switched off?

Discuss the observation

The request needs a working provider. The distinction is how service roles and management are organised, not the shape of the cables.

Explain

Explanation · 1 / 4

Name the client and the server

A client requests a service or resource. A server receives requests and provides or manages the service. For the timetable, the student application sends a request, the server obtains the permitted file, and the client receives and displays the response. A server is a role; one computer can run several services.

Explanation · 2 / 4

Explain central management

A client-server system can centralise accounts, permissions, files and backups. Staff can apply one set of access rules and maintain a managed copy. Dedicated server resources and administration cost money, and dependent clients can lose access when the service fails.

Explanation · 3 / 4

Reverse roles between peers

In a peer-to-peer system, each participating peer can request and provide resources. A student laptop can receive a photograph from another peer and later provide a different file. A dedicated central server is not required, but sharing, accounts and backups may need separate management on individual peers.

Explanation · 4 / 4

Choose from the requirements

A small trusted group occasionally sharing non-critical files may prefer the lower initial cost of peer-to-peer. A school needing centrally controlled examination documents and consistent backups has reasons to choose client-server. Explain both the requirement and the consequence rather than claiming one model is always better.

Work together

Choose a service model for examination files

Forty school computers require individual accounts, restricted examination files and a nightly managed backup.

Work together · 1 / 3

Link the requirement to a role

Use a server to manage authentication and provide permitted files when clients request them.

Work together · 2 / 3

Explain the alternative

With independently managed peers, maintaining consistent permissions and backups across all sharing computers would be harder.

Work together · 3 / 3

State the trade-off

Client-server meets the central-management requirement, but the school must fund administration and plan for server or connection failure.

A justified choice connects roles, management and availability to the stated scenario.

Experiment

Predict whether the requested file can be returned. Follow the request and response, then make the provider unavailable and explain the missing dependency. Compare server and peer arrangements.

Request a shared worksheet

Predict which device must stay available. Follow a request to the device that holds the only shared copy.

Change conditions

Predict: Where is the file, and will Student A receive it after the chosen failure?

Only the shown file copy and local connection are available. File permissions and extra backup copies are not modelled.

Check

Try it yourself · Teacher-written

Four peers remain connected after the fifth switches off. Why might a shared file still be unavailable? Would central accounts alone justify changing the model?

Check your reasoning

If the fifth peer was the only device providing the file, the other connections do not supply it. A requirement for centrally managed accounts is a reason to consider client-server because a central service can apply consistent account rules; cost and dependence must also be considered.

Original question · Cambridge 9618/11

1. Assign client and server roles in a banking app

Cambridge 9618/11 · May/June 2024 · 5(a) · 4 marks

Selected parts: 5(a) [4].

Hint — reading the question

Identify the devices in this banking system before describing what each does. Give both ends of the request-response exchange.

Reasoning and model answer — teacher-written

The bank’s central computer is the server. It receives account requests from customers’ devices, processes them using account data, and sends a response.

The customer’s smartphone running the banking application is a client. It sends the customer’s request, waits for the server’s response and displays the returned information.

Official mark scheme
Why this earns marks — teacher explanation

The four marks distinguish identifying the server, describing its role, identifying the client and describing its role. “A server serves clients” does not supply the banking application or the work performed.

Common mistakes — teacher analysis

The phone does not become the server simply because it displays the balance. Identify where the request is processed and where the response is requested and shown.

Communicate data · Concept 04

Locate the processing, software and working data

Observe

The same document in two arrangements

ArrangementWhere the document application mainly runs
AOn a school server; the terminal sends input and displays returned output
BOn the student laptop; it can edit an available local file without the network

Look, then discuss

Which arrangement is more likely to keep editing when its network connection fails?

Discuss the observation

Arrangement B has the application and working data locally. Knowing where processing happens explains the outcome better than knowing how large the device looks.

Explain

Explanation · 1 / 4

Explain thin-client dependence

A thin client relies mainly on server resources for application processing and/or storage. It still handles input, communication and display. Central applications can be updated in one managed place, and the client may need less local processing power or storage.

Explanation · 2 / 4

Explain the cost of that dependence

The server and network must support the users who depend on them. Losing the connection can interrupt the remote application even if the terminal still has power. Central maintenance reduces repeated local work but does not remove the need for adequate server capacity.

Explanation · 3 / 4

Explain thick-client local work

A thick client performs substantial application processing locally and normally has more local software or data. It can continue suitable work offline if the required application, data and permissions are available. Maintaining installations and security across many devices creates more distributed work.

Explanation · 4 / 4

Keep the two classifications independent

A powerful laptop running a local application can still request a centrally stored file and therefore be a client in a client-server system. Thin/thick concerns the location of processing; client-server/peer-to-peer concerns who requests and provides services.

Work together

Choose clients for two school activities

An examination room needs identical centrally managed software. A fieldwork group edits recordings where connectivity is unreliable.

Work together · 1 / 3

Evaluate the examination room

Thin clients can obtain the same managed application and store work centrally. The school must provide a reliable network and server, because a failure could interrupt the examination.

Work together · 2 / 3

Evaluate fieldwork

Thick clients with the editing program and recordings stored locally can perform substantial work while disconnected. Updates and local data protection must be managed on those devices.

Work together · 3 / 3

Test the classification

Uploading the edited recording to a server later does not turn the thick client into a thin client.

Choose processing placement from the task and its dependencies.

Check

Try it yourself · Teacher-written

A small laptop runs a large local graphics application but saves completed files to a server. Explain why physical size and server storage do not make it a thin client.

Check your reasoning

The application performs substantial processing locally, which is characteristic of a thick client. A small case says nothing about processing placement. A thick client may still request server storage and use a client-server service.

Teacher-written consolidation. Explain your reasoning before opening an answer.

Question 1 · Command word: Explain6 teacher marks

A company has one LAN in each of three cities. Explain why the complete network is a WAN. Compare client-server with peer-to-peer for centrally controlled payroll files, then suggest a model and give one drawback of your choice.

S2.01.A02S2.01.A03S2.02.A01S2.02.A02S2.02.A03
Answer and checking points — teacher-written
  1. Each city LAN covers a limited managed site.
  2. The WAN joins these geographically separated LANs through inter-site provider links.
  3. Client-server uses servers to provide requested services; in peer-to-peer each computer can both request and provide files.
  4. Client-server centralises permissions and backup, whereas peers manage their own sharing and protection.
  5. Client-server suits the requirement for centrally controlled payroll files.
  6. Dedicated server hardware and administration cost more, or a server failure can make the payroll service unavailable.

Common error: Compare the models using the same factor before linking the choice to payroll control.

Question 2 · Command word: Suggest5 teacher marks

Suggest thin or thick clients for a school examination room that requires identical software and central storage. Justify the choice, compare the processing location with the alternative and give one drawback.

S2.03.A01S2.03.A02S2.03.A03
Answer and checking points — teacher-written
  1. Thin clients suit the centrally managed examination room.
  2. They rely mainly on the server for processing and storage.
  3. Thick clients carry out more processing and store more applications locally.
  4. Central software installation and updates help keep the examination environment consistent.
  5. A server or network failure can prevent the thin clients from using the required applications.

Common error: A recommendation without scenario-linked reasons is incomplete.

Question 3 · Command word: Explain4 teacher marks

Explain why a CAD workstation can be a thick client in a client-server network. Its engineers must edit while the site connection is unavailable. State two local requirements for that offline work.

S2.02.A01S2.03.A02S2.03.A03
Answer and checking points — teacher-written
  1. The workstation performs substantial CAD processing locally, so it is a thick client.
  2. It can still request centrally provided accounts or files, which is client-server use.
  3. The required CAD application must be available to run locally.
  4. The required working data and permission to use it must be available without the lost connection.

Common error: A server connection does not make all application processing remote.

Question 4 · Command word: State4 teacher marks

State two networking benefits and explain the consequence of each.

S2.01.A01
Answer and checking points — teacher-written
  1. Users can share a network printer.
  2. One shared printer reduces the need to buy a separate printer for every computer.
  3. Files can be stored and backed up centrally.
  4. A single managed backup process makes shared data easier to recover after loss.

Common error: Accept other valid feature-and-consequence pairs; give a mechanism rather than “easier” or “faster” alone.
