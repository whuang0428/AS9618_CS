Pseudocode from a flowchart or structured-English description: Translating descriptions into Cambridge pseudocode

S11.01.A01

Visual overview

Core explanation

Implementing a design means preserving its input, processing, decisions, repetition and output in complete Cambridge pseudocode. A flowchart symbol or structured-English verb must become the matching construct, not an approximate comment.

Follow every flowchart arrow from Start, translate each input/output symbol, convert decisions into IF or CASE conditions, convert repeated paths into an appropriate loop and preserve every branch reconnection. For structured English, use its controlled verbs and indentation to identify the same control structure.

After translation, trace at least one case through every branch and check that all constructs close correctly. The pseudocode is equivalent only when it produces the designed result for the same inputs.

From flowchart to pseudocode

  1. Identify input, output and control shapesMark each design element as sequence, decision or repetition before writing syntax.
  2. Write the matching complete constructPreserve each condition, branch, loop back-edge and reconnection using Cambridge keywords.
  3. Check equivalence with representative dataFollow the design and pseudocode side by side and compare their outputs.

Worked example · Translate structured English into a complete selection

  1. Design

    Input Mark. If Mark is at least 50, output 'Pass'; otherwise output 'Fail'.

  2. Pseudocode
    INPUT Mark
IF Mark >= 50 THEN
  OUTPUT 'Pass'
ELSE
  OUTPUT 'Fail'
ENDIF
  3. Trace

    Mark = 50 follows the true branch and outputs Pass; Mark = 49 follows the false branch and outputs Fail.

Common misconception

A comment that says 'repeat' is not an implemented loop, and a decision without its false path may not preserve the design.

Cambridge command words

Practice questions

Command word: Explain4 marks

Explain translate this structured-English design into Cambridge pseudocode: input five temperatures; count those below zero; output the count.

S11.01.A01
Answer and marking points
  1. initialises count to 0.
  2. uses a five-iteration count-controlled loop with INPUT.
  3. tests Temperature < 0 and increments count.
  4. outputs count after the loop with coherent Cambridge syntax.

Common error: For the command word design, perform that exact action; do not replace it with an unrelated fact.

Command word: Describe2 marks

Describe how a flowchart decision is normally translated into pseudocode.

S11.01.A01
Answer and marking points
  1. As a selection or loop condition, depending on where arrows reconnect.

Common error: Do not repeat the same point in different words; each mark needs a separate idea or method step.

Command word: State2 marks

State two precise facts about translating descriptions into cambridge pseudocode.

S11.01.A01
Answer and marking points
  1. Implement and write pseudocode from a given design presented as either a flowchart or structured English.
  2. To translate a flowchart, follow arrows from Start, convert input/output symbols directly, convert diamonds into IF/CASE or loop conditions, and preserve every branch and reconnection.
  3. To translate structured English, identify its controlled verbs and indentation before selecting Cambridge constructs.

Common error: Do not copy the worked example unchanged; transfer the method and check it against the new context.
