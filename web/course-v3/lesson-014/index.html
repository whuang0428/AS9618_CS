Concept teaching

Visual overview and core explanation

01

An IP address identifies a network interface for routing

S2.15.A01S2.15.A02S2.15.A03

Visual overview

Read version and interface separately

IPv432 bits · four decimal octets
192.0.2.37

Each octet represents 8 bits and is written from 0 to 255.

IPv6128 bits · eight hexadecimal groups
2001:0db8:0000:0000:0000:0000:0000:0042

Each full group represents 16 bits; hexadecimal digits compact the notation.

Core explanation

IPv4 addresses contain 32 bits and are normally written as four decimal octets, each from 0 to 255, such as 192.0.2.37.

IPv6 addresses contain 128 bits and are normally written as eight groups of hexadecimal digits separated by colons, such as 2001:0db8:0000:0000:0000:0000:0000:0042.

An IP address is associated with a network interface on a network. A device with wired and wireless interfaces can have different IP addresses, and a dynamically assigned address may change over time.

Common misconception

An IP address identifies an interface in a network context; it is not a permanent identity for a person or an entire machine.

02

Subnet, public/private and static/dynamic answer different questions

S2.15.A04S2.15.A05S2.15.A06

Visual overview

Core explanation

Subnetting divides an address space into smaller logical networks. A host combines the destination address with the given subnet mask or prefix: a local destination can be sent within the subnet; a destination in another subnet is sent to a router.

A public IP address is routable on the public internet. A private address is used inside a local network and normally reaches public networks through address translation. Reduced direct reachability is useful, but private addressing does not guarantee security; firewalls, authentication, updates and permissions are still required.

A static address remains assigned until deliberately changed, which suits a server or printer that clients must find predictably. A dynamic address is allocated for a lease, commonly by DHCP, and may change; it simplifies management for ordinary client devices.

Worked local-or-router decision

  1. GivenHost 192.168.10.37/24 sends to 192.168.10.80
  2. Compare subnetBoth have network prefix 192.168.10
  3. DecisionDestination is local; send within the LAN
  4. Contrast192.168.11.80 is outside that /24; send to the router
Common misconception

Static does not mean public, and dynamic does not mean private; the pairs describe different properties.

03

DNS resolves the domain; the browser requests the path

S2.16.A01S2.16.A02S2.16.A03

Visual overview

Break the URL before resolving it

Schemehttps://Domainlearn.example.orgPath/course/page.htmlQuery?unit=2Fragment#quiz

DNS reads the domain: learn.example.org. The browser, not DNS, uses the remaining URL parts.

Core explanation

A Uniform Resource Locator identifies a WWW resource. The scheme states how to access it, the domain names the host, and the path identifies the resource on that host. Optional query and fragment components have separate jobs.

DNS resolves the domain name to an IP address. DNS does not resolve the path, store the web page or return the resource.

After resolution, the browser uses the IP address to contact the web server and requests the required host/path. The server locates or generates the resource and returns it.

DNS and browser sequence

  1. Parse URLSeparate scheme, domain and path
  2. DNS queryAsk for the IP address of learn.example.org
  3. DNS responseReturn the matching IP address
  4. ConnectBrowser contacts the server using that address
  5. RequestBrowser requests /course/page.html?unit=2
  6. DisplayServer returns the resource; browser handles #quiz locally
Common misconception

DNS maps a domain name to an IP address; it does not turn the whole URL into a page.

Practice questions

Command word: State6 marks

State the length and normal notation of IPv4 and IPv6, then explain why one device can have more than one IP address.

S2.15.A01S2.15.A02S2.15.A03
Answer and marking points
  1. IPv4 is 32-bit.
  2. Four decimal octets.
  3. IPv6 is 128-bit.
  4. Hexadecimal groups separated by colons.
  5. Addresses are associated with interfaces.
  6. Wired and wireless interfaces can have different addresses.

Common error: Do not state that IPv6 is 129-bit.

Command word: Explain4 marks

A host 192.168.10.37/24 sends to 192.168.10.90 and then 192.168.11.90. Explain both forwarding decisions.

S2.15.A04
Answer and marking points
  1. 192.168.10.90 shares the /24 network prefix.
  2. It can be sent within the local subnet.
  3. 192.168.11.90 has a different /24 network prefix.
  4. It must be sent to a router for another subnet.

Common error: Compare the supplied subnet information; do not decide from physical distance.

Command word: Suggest4 marks

Suggest public/private and static/dynamic addressing properties for an internal school printer, including the security implication.

S2.15.A05S2.15.A06
Answer and marking points
  1. Private address for internal scope.
  2. Static/reserved assignment so clients find it predictably.
  3. Not directly publicly routed under normal design.
  4. Private addressing alone does not guarantee security.

Common error: Static/private are compatible; the pairs are not opposites.

Command word: Identify7 marks

For https://learn.example.org/course/page.html?unit=2#quiz, identify the scheme, domain and path, then explain how DNS and the browser retrieve the resource.

S2.16.A01S2.16.A02S2.16.A03
Answer and marking points
  1. Scheme: https.
  2. Domain: learn.example.org.
  3. Path: /course/page.html.
  4. DNS resolves domain to IP.
  5. Browser contacts the server using the IP.
  6. Browser requests path with query unit=2.
  7. Fragment #quiz is handled within the returned document, not by DNS.

Common error: DNS does not receive or resolve the path.

Question 1 · Command word: Identify · 4 marks

Identify why 192.168.4.300 is not a valid IPv4 address and why 2001:db8:0:1:0:0:0:25 cannot be written as four decimal octets.

Marking points

  • An IPv4 address contains four 8-bit octets written in decimal.
  • Each IPv4 octet must be from 0 to 255, so the value 300 is invalid.
  • The second address uses eight hexadecimal groups and is IPv6 notation.
  • IPv6 contains 128 bits, so four decimal octets would provide only the 32 bits used by IPv4.

Question 2 · Command word: Explain · 5 marks

A host at 192.168.50.70/26 sends one packet to 192.168.50.100 and another to 192.168.50.130. Explain which packet can be delivered within the local subnet and which must be sent to a router.

Marking points

  • A /26 prefix divides the final octet into ranges of 64 addresses.
  • The source 192.168.50.70 is in the subnet whose final-octet range is 64 to 127.
  • The destination ending in 100 shares that subnet prefix, so its packet can be delivered locally.
  • The destination ending in 130 lies in the next subnet range, 128 to 191.
  • The packet for 192.168.50.130 must be forwarded to a router for delivery outside the source subnet.

Question 3 · Command word: Suggest · 5 marks

Suggest suitable public or private and static or dynamic addressing for a public web server and an employee laptop used only inside the organisation.

Marking points

  • The public web server needs a publicly reachable address so internet clients can route requests to it.
  • A static or reserved assignment gives the server a predictable address for its published service and DNS record.
  • The internal laptop can use a private address because it does not need to accept direct public internet connections.
  • A dynamic assignment is suitable for the laptop because its address can be allocated automatically when it joins the internal network.
  • Firewalls, authentication and updates are still required because address type alone does not provide complete security.
