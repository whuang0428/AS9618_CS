5.1.4

Program libraries and DLL files

What is a program library?

A program library is a collection of pre-written subroutines that can be called from other programs. Examples include maths routines for square roots, image routines for resizing pictures and compression routines for producing smaller files.

Sources9618/12/M/J/23 · Q7(a)(i–ii) · Define and explain (QP p13, MS p9)

What is a Dynamic Link Library (DLL)?

A Windows DLL is a separate file containing compiled code that applications can link to when they load or while they run.

1. Match five utilities to their purposes

Cambridge 9618/12 · October/November 2022 · 1(a) · 5 marks

Selected parts: 1(a) [5].

Original question
Reading the question — teacher guidance

Draw one line from each tool on the left. One of the six purposes on the right will be left over.

Solution / model answer — teacher-written
UtilityMatching purpose
Virus checkerScans for malicious code.
Disk formatterInitialises the disk for use.
Back-upMakes copies that can be restored if the originals are lost.
Disk repairDetects and fixes inconsistencies on the disk.
DefragmentationMoves file blocks together so that each file is contiguous.
Official mark scheme
Why this earns marks — teacher explanation

Each correct connection earns one mark, up to five marks.

A file can occupy the same number of blocks before and after defragmentation. Reducing the file size would require compression, which is the unused purpose here.

Original question · Cambridge 9618/12

2. Link two OS management tasks to multitasking

Cambridge 9618/12 · May/June 2024 · 6 · 4 marks

Selected parts: 6 [4].

Original question
Reading the question — teacher guidance

Explain both memory management and process management in terms of multiple active programs. Avoid spending the whole answer on just one task.

Solution / model answer — teacher-written

Memory management keeps data for the active programs in RAM and protects their allocated areas so that one program does not overwrite another’s data.

Process management schedules which process runs next, pauses one when necessary and switches the processor to another. This lets processes share processor time and make progress.

Official mark scheme
Why this earns marks — teacher explanation

The total is four marks, with no more than three from either management task. This model supplies two memory points and two process points. The official list contains alternatives; listing every alternative still cannot exceed four.

Common mistakes — teacher analysis

Giving four memory facts cannot bypass the three-mark memory cap. Multitasking does not mean that one processor core executes every process simultaneously.

Original question · Cambridge 9618/12

3. Define a library and explain two DLL benefits

Cambridge 9618/12 · May/June 2023 · 7(a)(i), 7(a)(ii) · 6 marks

Selected parts: 7(a)(i) [2]; 7(a)(ii) [4].

Original question
Reading the question — teacher guidance

Define the reusable resource first. For each DLL benefit, explain why dynamic linking produces that benefit for the developer.

Solution / model answer — teacher-written

7(a)(i): A program library is a collection of pre-written or pre-compiled subroutines that other programs can import and call.

7(a)(ii): benefitExplanation
Smaller application executableThe application file does not contain all the library routines; the required library is separate.
No need to recompile the main program for a compatible DLL correctionThe DLL can be corrected independently while its existing interface remains usable by the application.
Official mark scheme
Why this earns marks — teacher explanation

The definition is capped at two marks. The DLL answer is marked in two pairs: one mark for each benefit and one for a corresponding expansion. Unrelated facts beside a benefit do not supply its explanation.

Common mistakes — teacher analysis

Calling a library a folder of data files misses reusable subroutines. A compatible interface is needed for safe separate replacement; a changed parameter contract can still require application changes.

Original question · Cambridge 9618/11

1. Manage a saved file and protect a recoverable copy

Cambridge 9618/11 · October/November 2024 · 4(a)(i), 4(a)(ii) · 4 marks

Selected parts: 4(a)(i) [2]; 4(a)(ii) [2].

Reading the question — teacher guidance

First describe what the OS does to organise files. Then explain why back-up software is needed. Recall file management from the previous lesson before answering the back-up part.

Solution / model answer — teacher-written

4(a)(i): The OS maintains a directory structure so files can be organised and located. It allocates secondary-storage space to individual files.

4(a)(ii): Back-up software automatically makes regular duplicate copies of data. A saved copy can be restored if the working data is lost.

Official mark scheme
Why this earns marks — teacher explanation

The two parts each have a two-mark maximum. File management earns credit for distinct tasks. The back-up explanation links making a copy to restoring lost data; automatic or regular copying is also accepted by the scheme.

Common mistakes — teacher analysis

Saving the current file is different from keeping an additional recoverable copy. A second copy on a failed physical device may be lost with the original; the original answer should still explain copying and restoration.

Original question · Cambridge 9618/13

2. Prepare program files for download and a disk for storage

Cambridge 9618/13 · October/November 2023 · 5(b)(i), 5(b)(ii) · 5 marks

Selected parts: 5(b)(i) [2]; 5(b)(ii) [3].

Reading the question — teacher guidance

Both source-code files and library files are being downloaded. Treat them as files whose contents must be preserved. Explain why compression helps the transfer, then explain how formatting prepares a new disk for use. No knowledge of the omitted IDE question is needed.

Solution / model answer — teacher-written

5(b)(i): Compressing the files reduces the amount of data transferred, so the download takes less time on the same connection. The compressed files also use less storage space on the server or the user’s device.

5(b)(ii): A formatter prepares the disk for initial use by creating a file system and setting up its allocation records, such as a file allocation table. A full format can also check the disk for errors.

Official mark scheme
Why this earns marks — teacher explanation

Compression has a two-mark maximum: reduced transfer time and reduced storage space are the two listed reasons. Formatting has a three-mark maximum; the scheme accepts preparation for initial use, checking for errors, creating the file system and setting up the file allocation table. The model includes these alternatives; it cannot earn more than three marks.

A file allocation table is one example of allocation records. Different file systems use different structures, and a quick format may omit a full surface check.

Common mistakes — teacher analysis

Defragmentation rearranges an existing file’s blocks; formatting creates the structures needed to use a disk. For program files, use lossless compression so the original code can be restored exactly.

Original question · Cambridge 9618/12

3. Choose a utility that meets an exclusion

Cambridge 9618/12 · October/November 2023 · 8(b) · 3 marks

Selected parts: 8(b) [3].

Reading the question — teacher guidance

The question excludes utilities intended to improve security. Choose a maintenance tool and explain the problem that makes it useful.

Solution / model answer — teacher-written

Defragmentation software. Saving and deleting files can leave a file split across separate parts of a magnetic disk. Defragmentation places the file’s blocks contiguously, reducing head movement and improving access time.

Official mark scheme
Why this earns marks — teacher explanation

One mark is for the utility name and two are for the explanation. The scheme also permits appropriate disk-repair, compression or formatting examples with their reasons.

Common mistakes — teacher analysis

Antivirus does not satisfy the exclusion. Do not present magnetic-disk head movement as an SSD mechanism, or guarantee that disk repair can recover every corrupted file.

Teacher-written practice
Question 1 · Command word: Explain3 teacher marks

Explain why defragmentation may speed up reading a large fragmented file from a magnetic hard disk without reducing the file's size.

S5.02.A03
Answer and checking points — teacher-written
  1. It brings separated file blocks into fewer contiguous groups.
  2. The magnetic read head can spend less time seeking between those groups.
  3. The file still contains the same data; only its placement has changed.

Common error: Do not describe the mechanism as compression or apply the moving-head explanation to an SSD.

Question 2 · Command word: Explain4 teacher marks

Report A says that a consistent 100 GB volume contains 70 GB of videos, 25 GB of other files and 5 GB free. Report B says its file-allocation records are inconsistent. Explain which utility function addresses each report and give one limit of repair when data is physically unreadable.

S5.02.A04
Answer and checking points — teacher-written
  1. Contents analysis identifies the large video files or folders responsible for the space use in A.
  2. A gives no file-system corruption to repair; the user must review storage needs and which files to retain or move.
  3. Disk checking/repair investigates the inconsistent allocation in B and attempts supported corrections.
  4. Repair cannot guarantee recovery of physically unreadable or missing data; an available backup may be needed.

Common error: Nearly full storage is not by itself evidence of corruption.

Question 3 · Command word: State3 teacher marks

A separate recovery device holds a successful 10:00 backup containing Draft A. The working file is saved as Draft B at 10:20 and the working disk fails at 10:25, before another backup. State the restored contents, explain why, and describe a useful restore check.

S5.02.A06
Answer and checking points — teacher-written
  1. Restoring the available 10:00 backup recovers Draft A.
  2. Draft B was not captured; the separate device protects the saved version against the working-disk failure, not every subsequent edit.
  3. Restore to usable storage, open the recovered file and compare its contents with the selected saved version.

Common error: A successful older backup cannot reconstruct an unbacked-up edit.

Question 4 · Command word: Explain3 teacher marks

Explain what a program library provides and how a developer can use an existing routine correctly.

S5.03.A01S5.03.A02
Answer and checking points — teacher-written
  1. It provides pre-written routines or modules for reuse.
  2. The developer calls the chosen routine according to its documented arguments and result.
  3. The calling program is tested to check that the routine has been integrated correctly.

Common error: Calling existing code does not eliminate all testing of the caller.

Question 5 · Command word: Explain3 teacher marks

Explain one storage benefit and one maintenance benefit of a DLL used by several applications. Give one compatibility risk.

S5.03.A03
Answer and checking points — teacher-written
  1. One separate DLL can avoid storing an incorporated copy of its code in every executable.
  2. A compatible library correction can serve the applications without rebuilding each calling executable.
  3. An interface change can make an existing application's calls fail.

Common error: Distinguish two benefits and one risk; do not award the same reuse benefit twice.

Question 6 · Command word: Identify5 teacher marks

Identify suitable utilities for three needs: prepare a known-empty volume with no file system; isolate a program flagged as suspicious; send source-code files using fewer bits when possible. Explain the relevant action for each, then state why a clean scan cannot prove every threat absent and why a tiny archive might be larger than its source files.

S5.02.A01S5.02.A02S5.02.A05
Answer and checking points — teacher-written
  1. A formatter creates the file-system organisation on the known-empty volume.
  2. A virus checker can quarantine the suspect program to prevent normal execution while it is handled.
  3. A lossless compression utility can create an archive whose extraction restores every original source character.
  4. The scan may fail to recognise a threat; no detection is not proof that all possible threats are absent.
  5. Archive overhead or poorly compressible data can outweigh the size reduction, especially for tiny inputs.

Common error: Do not propose formatting for recovery, or call a compressed working copy an independent backup.

Question 7 · Command word: Identify2 teacher marks

Identify the utility needed to prepare an empty storage volume for files and describe what it creates.

S5.02.A01
Answer and checking points — teacher-written
  1. Use a disk formatter.
  2. It creates the volume's file-system organisation for storing and locating files.

Common error: Do not suggest formatting as a way to recover files already on a damaged disk.

Question 8 · Command word: Explain2 teacher marks

Explain why a virus checker needs updated detection information and describe the purpose of quarantine.

S5.02.A02
Answer and checking points — teacher-written
  1. Updated information can identify threats that were not recognised by the older detection data.
  2. Quarantine isolates a suspect item to prevent normal execution while it is investigated or handled.

Common error: Quarantining an item does not restore every document it may already have damaged.

Question 9 · Command word: Explain2 teacher marks

Explain why lossless file compression is appropriate for a folder of source-code files being sent to a colleague.

S5.02.A05
Answer and checking points — teacher-written
  1. Reducing the transmitted size can shorten the transfer on the same connection.
  2. Lossless decompression restores the original source characters without changing the program.

Common error: Compression reduces representation size, not the importance of the data.
