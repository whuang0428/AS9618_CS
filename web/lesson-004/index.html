Core syllabus content

Binary addition and fixed-width overflow

Perform binary addition from the least-significant bit, carrying left when a column total is 2 or 3. Positive and negative integers must be interpreted using the stated representation and fixed bit width.

Overflow occurs when the mathematical result is outside the range representable in the available bits. For unsigned 8-bit addition, a carry beyond bit 7 shows that the true result is greater than 255. For signed arithmetic, compare the result with the signed representable range rather than treating every carry as overflow.

Binary subtraction applies to each positive or negative binary integer as well as binary addition; use the stated fixed width and signed representation when interpreting the result.

Worked example: Add two unsigned 8-bit integers

11110000 + 00110000 = 1 00100000. The true result is 288, which is outside the unsigned 8-bit range 0 to 255, so the stored eight-bit result cannot represent the mathematical answer and overflow occurs.

Unsigned 8-bit overflow

  1. Lesson fact: 00000000₂ to 11111111₂ = 0 to 255
  2. Lesson fact: An unsigned 8-bit result cannot store a value above 255.
  3. Lesson fact: Carry-out
  4. Lesson fact: 11110000₂ + 00010000₂ = 1 00000000₂
  5. Lesson fact: The ninth bit is a carry-out beyond the 8-bit storage width.
  6. Lesson fact: Boundary warning
  7. Lesson fact: 01111111₂ + 00000001₂ = 10000000₂
  8. Lesson fact: No unsigned overflow: the result is 128, which still fits in 8 bits.

8-bit addition method

  1. Lesson fact: Align the two 8-bit operands and start at the rightmost column.
  2. Lesson fact: Add both bits and any carry-in; write the result bit and carry 1 left when required.
  3. Lesson fact: For unsigned addition, a carry-out beyond bit 7 means the true sum needs more than 8 bits.
  4. Lesson fact: Without a carry-out, the stored 8-bit result remains within the unsigned range 0 to 255.
  5. Lesson fact: A leftmost result bit of 1 is not by itself evidence of unsigned overflow.

Knowledge point 1

Single-bit addition rules

0 + 0sum 0, carry 0
0 + 1sum 1, carry 0
1 + 0sum 1, carry 0
1 + 1sum 0, carry 1
1 + 1 + carry 1sum 1, carry 1
In binary, `1 + 1 = 10₂`: write 0 in the current column and carry 1 left.

Single-bit addition rules

  1. Lesson fact: A full-adder truth table has eight A, B and carry-in combinations.
  2. Lesson fact: 000 gives sum 0 carry 0; 001 and 010 give sum 1 carry 0; 011 gives sum 0 carry 1.
  3. Lesson fact: 100 gives sum 1 carry 0; 101 and 110 give sum 0 carry 1; 111 gives sum 1 carry 1.

Knowledge point 2

8-bit addition method

Column method

  1. Align the two 8-bit values.
  2. Start at the rightmost bit.
  3. Add the two bits and any carry-in.
  4. Write the result bit; carry 1 left if the column total is 2 or 3.
  5. After the leftmost bit, check whether there is a carry-out.

Exam discipline

  1. Show the carry row or annotate carried bits.
  2. Give the 8-bit result if the question asks for 8-bit addition.
  3. State whether overflow occurs.
  4. Explain overflow using range or carry-out, not vague "too big".

Knowledge point 3

Unsigned 8-bit overflow

Range

00000000₂ to 11111111₂ = 0 to 255

An unsigned 8-bit result cannot store a value above 255.

Carry-out

11110000₂ + 00010000₂ = 1 00000000₂

The ninth bit is a carry-out beyond the 8-bit storage width.

Boundary warning

01111111₂ + 00000001₂ = 10000000₂

No unsigned overflow: the result is 128, which still fits in 8 bits.

Common error

Do not say every carry means overflow. Carries inside the 8-bit result are normal.

Answers: `00101101₂ + 00011011₂ = 01001000₂`, no overflow; `11110000₂ + 00010000₂ = 00000000₂` with carry-out, overflow; `11001010₂ + 01110101₂ = 00111111₂` with carry-out, overflow.

Explanation focus: internal carries are used to calculate later columns; overflow occurs only when the true result exceeds the 8-bit unsigned range or produces a carry-out beyond the leftmost bit.
