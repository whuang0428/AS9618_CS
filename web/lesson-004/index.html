Knowledge point 1

Single-bit addition rules

0 + 0sum 0, carry 0
0 + 1sum 1, carry 0
1 + 0sum 1, carry 0
1 + 1sum 0, carry 1
1 + 1 + carry 1sum 1, carry 1
In binary, `1 + 1 = 10₂`: write 0 in the current column and carry 1 left.

Knowledge point 2

8-bit addition method

Column method

  1. Align the two 8-bit values.
  2. Start at the rightmost bit.
  3. Add the two bits and any carry-in.
  4. Write the result bit; carry 1 left if the column total is 2 or 3.
  5. After the leftmost bit, check whether there is a carry-out.

Exam discipline

  1. Show the carry row or annotate carried bits.
  2. Give the 8-bit result if the question asks for 8-bit addition.
  3. State whether overflow occurs.
  4. Explain overflow using range or carry-out, not vague "too big".

Knowledge point 3

Unsigned 8-bit overflow

Range

00000000₂ to 11111111₂ = 0 to 255

An unsigned 8-bit result cannot store a value above 255.

Carry-out

11110000₂ + 00010000₂ = 1 00000000₂

The ninth bit is a carry-out beyond the 8-bit storage width.

Boundary warning

01111111₂ + 00000001₂ = 10000000₂

No unsigned overflow: the result is 128, which still fits in 8 bits.

Teaching cue

Use denary range only as a check. The working should still show binary addition.

Common trap

Do not say every carry means overflow. Carries inside the 8-bit result are normal.

Mistake 1

00110101₂ + 00010110₂ = 01001001₂

Correct result is `01001011₂`. The student lost a carry in the low-order columns.

Mistake 2

01111111₂ + 00000001₂ overflows because the leftmost bit becomes 1

For unsigned 8-bit addition, `10000000₂ = 128`, so it still fits. No carry-out means no unsigned overflow.

Homework support

Check only after attempting

Answers: `00101101₂ + 00011011₂ = 01001000₂`, no overflow; `11110000₂ + 00010000₂ = 00000000₂` with carry-out, overflow; `11001010₂ + 01110101₂ = 00111111₂` with carry-out, overflow.

Explanation focus: internal carries are used to calculate later columns; overflow occurs only when the true result exceeds the 8-bit unsigned range or produces a carry-out beyond the leftmost bit.
