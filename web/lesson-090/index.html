Why this matters

Paper 1 rewards exact method and units. A correct idea with a missing conversion can lose the final mark.

Common trap

Bandwidth is not latency. More bandwidth moves more data per second; lower latency reduces delay.

Homework

Clear tasks for consolidation

Task 1: Calculation set Complete two image file-size calculations and two sound file-size calculations. Show bits, bytes and final unit conversion.
Task 2: Communication explanations Write 3-mark explanations for packet switching, DNS and HTTPS. Each answer must include mechanism and consequence.
Task 3: Improve weak answers Rewrite: "Bandwidth and latency are both about speed." Use precise definitions and a scenario.
