Text files let data survive after the program ends.

Variables disappear when a program stops. A text file stores characters on secondary storage, so a program can read existing lines, write a new file, or append extra lines. The exam focus is not drama; it is the exact file mode, loop condition and close-file step.

Readuse OPENFILE, EOF, READFILE and CLOSEFILE
Writecreate or replace file contents carefully
Appendadd new lines without removing existing lines
Scores.txt Ali,72 Bea,64 Chen,85
OPENFILE "Scores.txt" FOR READ

Open. Process line by line. Close. The file does not enjoy being left open.

Why this matters

Paper 2 often asks for a file algorithm: open with the correct mode, loop until EOF, process each line and close.

Common trap

WRITE can replace file contents. Use APPEND when existing lines must remain.

Read loop

Use EOF so the loop stops at the end of the file

OPENFILE "Scores.txt" FOR READ
WHILE NOT EOF("Scores.txt")
    READFILE "Scores.txt", Line
    OUTPUT Line
ENDWHILE
CLOSEFILE "Scores.txt"
The file line is read into Line. Only after that can the program output, split or validate it.

Pseudocode vs Java

Cambridge pseudocode is the exam answer format

Cambridge-style pseudocode

OPENFILE "Scores.txt" FOR READ
WHILE NOT EOF("Scores.txt")
    READFILE "Scores.txt", Line
    OUTPUT Line
ENDWHILE
CLOSEFILE "Scores.txt"

Java support only

try (Scanner file = new Scanner(new File("Scores.txt"))) {
    while (file.hasNextLine()) {
        String line = file.nextLine();
        System.out.println(line);
    }
}
