Timed method

The four-pass approach

1. Decode

Underline inputs, outputs, constraints and any required data structure or file.

2. Skeleton

Write the outer shape first: initialisation, loop, selection, output.

3. Fill

Add conditions, assignments, function calls and file statements.

4. Check

Trace one normal and one boundary case; confirm the output happens once in the right place.

Trace check

Trace a tiny case before trusting a big answer

Prompt

Write an algorithm to count values in Scores that are greater than or equal to 50.

SET Count TO 0
FOR Index TO 1 TO 4
    IF Scores[Index] >= 50 THEN
        SET Count TO Count + 1
    ENDIF
NEXT Index
OUTPUT Count

Fast check

Use Scores = [49, 50, 72, 20]. Expected Count is 2. If your trace gives 1, your condition probably excluded 50.

Checking one boundary value often catches the most expensive mistake.

Quality checklist

Before moving on, ask six questions

InputsWhere does the data come from: user, array or file?
InitialisationAre counters, totals and flags set before use?
LoopDoes the loop include the correct items and stop safely?
SelectionAre boundary conditions correct, such as greater than or equal to?
OutputIs the final result output once, after processing?
File handlingAre OPENFILE, READFILE or WRITEFILE and CLOSEFILE used correctly?

Homework

Complete two timed pseudocode responses

  1. Set a 7-minute timer and write pseudocode to count valid marks in an array.
  2. Set an 8-minute timer and write pseudocode to read records from a file and output selected records.
  3. For each answer, add a trace check using one normal and one boundary case.
  4. Mark your answer using the checklist: input, initialisation, loop, condition, output and file handling.
Marking focus: visible method, correct loop boundaries, correct file mode and final output in the right place.
