System software runs the show. Security stops the show becoming a crime scene.

This review joins two explanation-heavy areas: system software and security. You will distinguish OS roles, utility software and translators, then match security threats to controls using precise mechanism-and-consequence language.

If the answer says "protects it", the examiner asks: from what, how, and with what consequence?

Why this matters

These questions are often wordy. Marks reward precise roles and controls, not dramatic cybersecurity vocabulary.

Common trap

Encryption does not prove who a user is. Authentication checks identity; encryption protects data readability.

Which topic is being tested?

Translator review

Compiler, interpreter and assembler

CompilerTranslates whole source program into object code before execution; can report errors after compilation.
InterpreterTranslates and executes code line by line; useful for testing and debugging.
AssemblerTranslates assembly language mnemonics into machine code.

Homework

Clear tasks for consolidation

Task 1: Comparison answers Write one compiler-vs-interpreter comparison and one OS-vs-utility comparison. Use two precise differences each.
Task 2: Risk-control grid Create a table with five risks and suitable controls. Include mechanism and limitation for each control.
Task 3: Improve weak answer Rewrite: "Encryption is good because it makes data secure." Include what encryption does and what it does not do.
