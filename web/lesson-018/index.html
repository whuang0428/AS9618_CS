The internet does not send your file as one heroic lump.

Data is split into packets. Each packet carries control information and payload, may travel by different routes, and is reassembled at the destination using sequence information and error checks.

Knowledge point 1

Packet switching

Split

A message or file is divided into smaller packets before transmission.

Share

Packets from many users can share network links instead of one message reserving a whole route.

Route

Each packet can be routed independently through available paths.

Reassemble

The destination uses sequence numbers to put packets back in the correct order.

Chinese support: packet = 数据包；payload = 有效载荷/实际数据；routing = 路由；reassemble = 重新组装。

Knowledge point 2

Packet structure

Header

Source address, destination address, sequence number, protocol/control data.

Payload

The actual data being sent, such as part of a file or message.

Trailer

Error-checking information such as checksum, depending on the protocol.

Common trap

Do not describe the header as “extra information” only. Name what is inside it and what each item does.

Knowledge point 3

Routing and arrival

Router decisionRouters forward packets based on destination address and routing information.
Different pathsPackets from the same message may take different routes through the network.
Out of orderPackets may arrive in a different order because routes have different delays.
Error handlingChecksum/error checks can detect corruption; missing/corrupt packets may be requested again.

Fix the weak packet answer

“Packets arrive in order because the internet sends them one by one.”

Packets may take different routes and arrive out of order. Sequence numbers allow the destination to reassemble them correctly.

“A packet only contains data.”

A packet contains payload plus control information such as source address, destination address, sequence number and error-checking data.
