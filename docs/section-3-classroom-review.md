# Section 3 初学者课堂改版审校记录

审校日期：2026-09-29。范围：Section 3 Hardware，保留 `lesson-015` 至 `lesson-020` 的六个主题入口。

## 教学结构

- 面向已学 Section 1–2、首次学习硬件的学生。正文使用英文短句，解释设备部件、物理变化和数据流；保留必要术语。
- 24 个知识组覆盖本地 syllabus 映射的 42 个细分 objective。依据为 [Cambridge 9618 2027–2029 Version 2 syllabus](https://www.cambridgeinternational.org/Images/721397-2027-2029-syllabus.pdf) 第 17–18 页。
- 建议分为 16 次、每次 45 分钟的课堂学习；每组在课时计划中出现一次。课时安排是教学建议，可按学生理解速度调整。
- 每组提供观察材料、分步解释、理解检查和要点总结；适合的组加入互动，并在相关知识讲完后安排真题。教师按需展开提示、推理答案和官方评分标准。
- 8 类互动：磁盘定位与读写、激光打印、3D 分层打印、buffer、RAM/ROM 数据状态、控制与反馈、单个逻辑门、组合逻辑电路。互动模型用于展示指定机制，不代表设备的全部工程细节。
- 页面一次聚焦一个概念与教学阶段，支持目录跳转、前后移动和重新开始，兼顾触摸板操作、触屏和课后回看。

## 覆盖限制

**42 个 objective 的教学覆盖不等于每个 objective 都有直接原理真题。** 本次核对了本地 2023–2025 年的 18 份 Paper 1，按可验证的题目内容选题，没有把自编题标为真题。

- 九种指定硬件中，所选真题直接检查 3D 打印、HDD、光盘、触屏和 VR。激光打印、麦克风、扬声器、flash 的核心原理仍主要通过教学材料和自编理解检查巩固。
- 已找到的 flash 原题使用需要另作技术解释的历史模型，本次未选入；没有为了匹配该题而把相关措辞强加到核心教学。
- 所选真题也不能单独证明全部硬件角色、嵌入式系统的优点、RAM/ROM 的完整比较、SRAM/DRAM 的所有使用理由都已掌握。
- E025 的传感器证据涉及 infra-red 和 pressure，不能代替 temperature、sound 的完整检查。E027 不等于六种门的符号、功能及真值表全部考核；E028 也不覆盖 syllabus 要求的所有表示形式转换。
- 光盘题 MS 保留其原始简化措辞；教师解释区分压制光盘的 pits/lands 与可记录介质的记录层变化。

因此，本版本可报告“完整教学映射、12 组经过来源核对的真题”，不能报告“所有独立知识点均有直接真题覆盖”。
