## 实施约束

- 两个 encryption 实例共享模型，先概览、后完整讲解，状态彼此隔离。
- 签名和加密使用明确标注的教学模型；验证保留计算规则及原发送检查值。
- 全部 32 个目标、26 个旧知识单元入口、既有练习和题目书签保留。
- 真题只关联实际考查的目标；原题、提示、教师解释、官方 MS 分开显示，答案默认关闭。
- 所有互动可前进、后退、重置、改变条件；静态解释保留用于无 JavaScript 和打印。
- 两个分层分别固定为六组 20 分、五组 17 分，原题及分值见 source review。
- 局部构建只更新本章、必要构建入口和课程清单；不提交、推送或部署。
